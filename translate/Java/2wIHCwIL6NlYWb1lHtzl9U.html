更改

  • 幽匿方块的更改
  • 可替换方块不再阻挡附魔台与书架之间的连接
  • 在沙漠神殿中，新房间的屋顶塌陷得更多，并且顶层总是能看到一个可疑的沙子方块
  • 更新了 Minecraft: Java Edition 徽标
  • 主菜单背景现在是“足迹与故事”全景图

幽匿尖啸体

  • 现在对它们进行含水处理将使尖啸声静音
  • 已添加到创造模式菜单中的红石方块选项卡

幽匿感测体

  • 对于普通和校准过的幽匿感测体，已进行以下更改：
    • 默认红石输出已修改，以便在距离计算中更可靠
    • 现在会对放置它们的方块进行强充能

校准幽匿感测体

  • 主动冷却时间为1秒，而不是2秒
  • 可检测最远16格外的振动，而不是8格
  • 在校准输入侧接受信号的方式与其他红石组件更加一致
    • 例如，现在可以通过方块接收信号

技术性更改

  • 带有点击命令的告示牌现在即使未涂蜡也可以交互
    • 带有非text聊天组件的告示牌将无法再编辑
  • 添加了名为reference的新战利品表函数
  • 添加了对快速游戏的支持
  • 移除了server & port参数，因为其功能已被快速游戏取代
  • 标签的更改
  • 资源包版本现为14
    • 更新了minecraft.png的精灵图布局
    • 从 Programmer Art 资源包中移除了覆盖的minecraft.png
    • 更新了invite_icon.png的精灵图布局

战利品表

新函数reference允许函数调用子函数（类似于reference条件）。

字段：

  • name - 要调用的函数的位置

快速游戏

  • 添加了对四个新命令行参数的支持，允许游戏直接启动到世界中
  • quickPlayPath 接受用于记录的指定路径（相对于运行目录）
    • 如果提供了路径，加入世界时将记录以下内容：
      • type：singleplayer、multiplayer或realms之一
      • identifier：表示你想要加入的世界
        • 对于单人游戏，为世界的文件夹名称
        • 对于多人游戏，为服务器的IP地址
        • 对于Realms，为Realms ID
      • port：表示服务器端口，仅对多人游戏记录
      • name：世界的名称
      • gamemode：世界的游戏模式
      • lastPlayedTime：你加入世界的时间
    • 示例：
      • --quickPlayPath "quickPlay/log.json" 将解析为 .minecraft/quickPlay/log.json
  • quickPlaySingleplayer、quickPlayMultiplayer和quickPlayRealms都接受各自的identifier
    • 如果提供了这些参数之一，游戏将尝试直接启动到给定世界中
    • 示例：
      • --quickPlaySingleplayer "New World"
      • --quickPlayMultiplayer "localhost:25565"
      • --quickPlayRealms "1234"

标签

  • 添加了replaceable_by_trees，以更好地表示树木生长穿过时会被替换的方块
  • 移除了replaceable_plants，因为它仅用作上述标签方块的一个子集，且并非通用
  • 添加了sword_efficient，表示用剑破坏比正常略快的方块
