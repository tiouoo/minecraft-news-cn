Minecraft: Java Edition 现在提供了另一个快照。此快照带来了一些游戏玩法更改和一些技术性调整，例如 place 命令和加密签名的聊天命令。

玩得开心！

22w18a 中的更改

  • 悦灵现在即使看不见它们喜欢的玩家也会跟随
  • 悦灵只有在玩家距离超过 64 格时才会丢失目标
  • 音爆粒子的纹理已更新
  • 振动监听器（如幽匿感测体、幽匿尖啸体和循声守卫）现在会监听最近的振动，而不是同一游戏刻中的第一个振动

22w18a 中的技术更改

  • 织布机中可用的旗帜图案现在可以通过标签控制（banner_pattern/no_item_required 用于无图案物品，banner_pattern/pattern_item/* 用于特定的旗帜图案物品）
  • 服务器现在可以为客户端定义不同的聊天样式格式
  • 移除了 placefeature 命令
  • 添加了 place 命令
  • 捆绑的 Java 运行时已升级到 17.0.3
  • 移除了战利品表函数 set_goat_horn_sound
  • 添加了战利品表函数 set_instrument
  • 来自 /say、/msg、/teammsg 和 /me 命令的聊天现在也都经过加密签名

聊天类型

  • 服务器现在可以通过 chat_type 注册表控制不同的聊天样式格式
    • 这些会在客户端加入服务器时同步到客户端
    • 可以定义翻译键或翻译格式，例如 chat.type.text 或 %s says: "%s"
      • 聊天同样可以选择性地使用自定义翻译键或格式进行朗读
    • 整个消息可以应用格式，例如斜体或特定颜色（但目前不支持点击或悬停事件）

place 命令

新命令替代了 placefeature，可以在指定位置放置地物、拼图方块和结构。语法：

place feature <feature> [pos]
place jigsaw <pool> <start> <depth> [pos]
place structure <structure> [pos]

参数：

  • feature：要尝试放置的地物的命名空间 ID
  • structure：要尝试生成的结构的命名空间 ID
  • pool：开始生成的模板池的命名空间 ID
  • start：用作起始锚点的拼图方块的命名空间 ID 名称
  • depth：放置期间要遍历的拼图连接的最大数量
  • pos：用作生成原点的位置（如果省略，则使用 ~ ~ ~）

战利品表

新函数

set_instrument

将乐器物品所需的物品标签设置为从标签中随机选择的值。

参数：

  • options —— 一个标签引用，指定要随机选择的乐器选项
