幽匿尖啸体

  • 为幽匿尖啸体加入了功能：这个方块以其骨状附肢著称，会在幽匿感测体检测到振动时向远处的循声守卫发出警告信号
    • 踩到它们时要小心，因为它们也会感应到并发出信号！
  • 起初，循声守卫可能需要一段时间才会到达，但你会听到它在远处回应……
  • 一旦距离足够近，幽匿尖啸体的信号就会召唤附近的循声守卫出现——做好准备！

新增循声守卫生物

循声守卫

深暗之域的恐怖存在！循声守卫是一种没有眼睛的生物，外形大致类似于遍布深暗之域的幽匿方块，是栖息于此生物群系的不可阻挡的自然之力。

  • 与幽匿感测体一样，这些可怕的生物会借助振动来感知周围环境
  • 当振动不够时，它们还会用嗅觉追踪猎物——你可以看到它们嗅探周围环境，向毫无防备的玩家和生物靠近
  • 它们探测你的方式多种多样，所以尽量不要靠得太近！如果你撞到循声守卫，它就会发现你
  • 在深暗之域中，循声守卫无处不在——只是你看不见它们。它们沉睡在你脚下，只有在足够多的幽匿尖啸体警示它们你的存在后，它们才会钻出来
  • 注意脚下：循声守卫检测到的振动越多，就会越愤怒。你可以通过它胸膛中灵魂跳动的速度听到并看到这一点
  • 一旦某个生物突破了循声守卫的愤怒阈值，它就会面向猎物咆哮，然后发起冲锋
  • 但是，如果你让循声守卫在60秒内没有注意到你或没有生气，它就会重新钻回地下并消失
  • 它们与投掷出的投射物有特殊互动
    • 如果循声守卫在5秒内接连收到两次投射物振动，它就会对投掷者更加愤怒
    • 如果循声守卫收到投射物振动的时间距离上一次投射物超过5秒，它就不会对投掷者更加愤怒
    • 这样一来，你就能在搜刮附近箱子里的战利品时，有策略地引开循声守卫而不激怒它
  • 对所有玩家来说不幸的是，循声守卫用拳头击中目标时还会使盾牌失效
  • 它们不会掉落任何战利品
  • 循声守卫是强大的生物，面对已经钻出的循声守卫时，偷偷绕行往往比正面交锋更好——你已经被警告过了

黑暗

  • 一种新的状态效果，为循声守卫和幽匿尖啸体特有，当它们在附近时会施加给你
  • 拥有此效果时，会使伽马值降低到相当于“昏暗”的等级
  • 会以周期性脉冲降低世界的整体亮度，使黑暗逐渐蔓延到光源周围
  • 当循声守卫在附近时，火把将比以往任何时候都重要！
  • 选项菜单中新增了一个名为“黑暗脉冲”的辅助功能滑块
    • 控制循声守卫或幽匿尖啸体将黑暗效果施加给你时效果有多暗，但不会影响雾的距离

带箱子的船

  • 让你在乘船冒险时携带更多物品
  • 如果你在船上，按打开物品栏键即可访问箱子内容
  • 如果你不在船上，潜行并右键点击即可访问箱子内容
  • 如果破坏船，箱子里的物品会像其他箱子一样散落出来
  • 也可以与漏斗、投掷器以及其他与箱子互动的方块配合使用
  • 与其他箱子一样，打开船上的箱子或破坏船会激怒猪灵，因为它们认为所有箱子都是自己的

迅捷潜行

将这种闪亮的新附魔赋予你的护腿，即可在潜行时获得与正常行走一样快的移动速度！

  • 应用后，它会提高你潜行时的移动速度
  • 有3个不同等级，各等级的速度提升不同
  • 这是第一个专属于护腿装备的附魔！
