雪比以前更雪了。

对于今天的快照，我们更改了上一个快照中引入的大部分纹理。这仅仅是为了测试这些纹理是否能带来更好的探索和建造体验。我们很想听听你的看法。请记住，某些纹理将来可能会被还原或再次更改。

20w46a 的新特性

  • 加入了细雪！

细雪

更雪白的雪！

  • 细雪是一种陷阱方块，任何实体走入其中都会陷入
  • 你可以用桶采集和放置细雪
  • 穿上皮革靴子可以防止你陷入细雪方块中
  • 将炼药锅放在下雪的环境中，它会慢慢装满细雪

冰冻

  • 站在细雪中会使实体慢慢被冻伤
  • 一旦被冻住，被冰冻的实体每隔几秒就会受到一次冰冻伤害
  • 每件皮革盔甲都能减缓实体的冰冻速度
  • 穿上全套皮革盔甲可以完全免疫冰冻

20w46a 的技术更改

  • 移除了/replaceitem命令
  • 添加了/item命令
  • 添加了物品修饰器，它重用战利品表函数语法来描述/item命令中的物品修改。

物品修饰器

战利品表的函数部分现在可以定义为数据包资源中独立的 item_modifiers 目录。 此类文件可以包含单个函数（即单个 JSON 对象）或函数数组。

命令

item

修改物品或方块容器。

此命令有三种形式：

  • /item <目标> replace <物品堆叠> [<数量>] - 与旧的 replaceitem 相同
  • /item <目标> modify <修饰器> - 修改物品（不复制）。
  • /item <目标> copy <来源> [<修饰器>] - 将物品从来源复制到目标，可选择应用修饰器

可能的来源和目标：

  • entity <选择器> <槽位>
  • block <x> <y> <z> <槽位>

例如，/item block ~ ~ ~ container.0 copy entity @s enderchest.0 会将玩家末影箱中的第一个物品复制到玩家当前所站方块的第一个容器槽位中。

战利品表

新条件

value_check

检查值的范围。

参数：

  • value - 参见“新值提供器”部分（目前是随机数生成器和计分板的组合）
  • range - 最小/最大范围

更改的条件

score

entity 参数现在已被替换为 target。 它既可以包含旧 entity 字段中的值（如 this），也可以是计分板持有者名称，形式为 {"name": "..."}。

更改的函数

set_damage

此函数现在有 add 参数。如果为 true，更改将相对于当前耐久度。如果为 false，耐久度将被替换为当前值（默认行为）

set_count

此函数现在有 add 参数。如果为 true，更改将相对于当前物品数量。如果为 false，物品数量将被替换为当前值（默认行为）

copy_nbt

source 参数现在可以设置为 {"storage": <命名空间 ID>}，以访问命令存储。

新函数

set_enchantments

修改物品上的附魔

参数
  • enchantments - 附魔 ID 到等级值的映射（可以是计分板或随机数）
  • add - 如果为 true，更改将相对于当前等级。如果为 false，等级将被替换为当前值（默认行为）

新值提供器

注意：值提供器可以在与随机数生成器相同的地方使用。

score

返回缩放后的计分板数值。

参数
  • score - 计分板名称
  • target - 与 score 谓词中的 target 相同
  • scale - 缩放因子（浮点数）
