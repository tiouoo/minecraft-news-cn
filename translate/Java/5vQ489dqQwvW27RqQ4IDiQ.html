红树林沼泽

泥泞！昏暗！壮丽！欢迎来到 Minecraft 最新的生物群系——红树林沼泽

  • 生成在 Minecraft 中通常能找到沼泽生物群系的更温暖、更潮湿的地方
  • 在这里你可以找到蜜蜂和热带青蛙
  • 这个生物群系的地面覆盖着一层厚厚的泥巴
  • 在红树巨大根系的周围和下方享受愉快的船程吧
  • 泥巴从地表一直生成到石头层
  • 高红树比矮红树常见得多

红树

引入一种适应水生环境的新树木，生成时由根部支撑

  • 有概率生成蜂巢
  • 由红树胎生苗生长而成
  • 树根顶部会生成苔藓地毯

红树木材方块

新增一种木材：红树！

  • 红树原木和去皮红树原木
  • 红树木和去皮红树木
  • 红树根和沾泥红树根
  • 红树船、按钮、压力板、门、活板门、告示牌、台阶、栅栏、栅栏门和楼梯

红树树叶和胎生苗

  • 红树胎生苗是一种从红树树叶底部生长的树苗
  • 对红树树叶使用骨粉会使其下方开始生长新的胎生苗
  • 胎生苗有 4 个生长阶段，使用骨粉可加速生长
  • 你可以摘取完全长成的胎生苗，像树苗一样种植
  • 胎生苗可以放置并生长在所有普通树苗能生长的方块上，此外还有泥巴和黏土
  • 胎生苗可以在水下生长
  • 流浪商人现在有时会出售胎生苗

泥巴

  • 泥巴是一种会在红树林生物群系中生成的方块
  • 在泥巴上行走时，实体会像在灵魂沙上一样微微下沉
    • 与灵魂沙不同，泥巴不会施加减速效果
  • 手持水瓶对泥土使用，或使用发射器，可以将泥土变成泥巴
  • 泥巴可以合成泥坯

泥砖

  • 泥砖是一种可由泥坯合成的建筑方块
  • 泥砖可以使用工作台或切石机合成为泥砖楼梯、泥砖墙和泥砖台阶

黏土的可再生性

  • 将泥巴放置在下方有滴水石锥的方块上方，最终会把泥巴方块变成黏土

青蛙

  • 青蛙可以在沼泽和红树林沼泽中的草、泥巴、红树根和沾泥红树根上生成
  • 青蛙会呱呱叫
  • 青蛙可以在陆地上行走、游泳和跳跃
  • 青蛙会吃掉小型史莱姆，使其掉落黏球
  • 青蛙会吃掉小型岩浆怪，使其掉落蛙明灯方块
  • 每种青蛙变体会掉落特定的蛙明灯方块
  • 加入了三种蛙明灯方块，属于光源方块

蝌蚪

  • 蝌蚪可以在水中游泳
  • 陆地上的蝌蚪会像陆地上的鱼一样“跳来跳去”，最终会死亡
  • 蝌蚪长大后变成青蛙
  • 蝌蚪会根据其成长所在的生物群系（寒冷、温带、温暖）长成不同种类的青蛙
  • 蝌蚪可以用水桶捕获

深暗之域生物群系

深入地下深处，探索 Minecraft 中最黑暗的生物群系——深暗之域。

  • 光线昏暗、诡异可怖，深暗之域必定会让即使最勇敢的玩家也心生恐惧
  • 比周围区域更少积水
  • 深暗之域的地面覆盖着幽匿
  • 深暗之域中不会自然生成生物

远古城市

在深暗之域深处徘徊于这些废弃已久的结构大厅中，发掘一些早已被遗忘的遗物。

  • 远古城市结构生成在深暗之域生物群系中
  • 在由幽匿感测体和幽匿尖啸体守护的箱子中，你可以找到新的迅捷潜行附魔
  • 你还可以在这里找到一种神秘的新方块，名为强化深板岩，它在生存模式中无法获得
  • 远古城市中不会生成生物

黑暗

  • 由循声守卫和幽匿尖啸体对附近玩家施加的一种新状态效果
  • 拥有此效果时，会将伽马值降至与“阴暗”相当
  • 它会周期性地降低世界整体亮度，让黑暗向光源方向蔓延
  • 黑暗效果的图标只在物品栏中显示
  • 选项菜单中新增了一个辅助功能滑块，名为“黑暗效果”
    • 控制黑暗光照效果的强度
    • 不影响迷雾距离

音乐唱片 5

游戏中新增了一张音乐唱片

  • 与其他唱片不同，这张唱片只能通过找到 9 个唱片碎片并合成获得
  • 这些唱片碎片可以在远古城市的箱子中稀有地找到

追溯指针

新的追溯指针可以用回响碎片合成，回响碎片是另一种只能在远古城市箱子中找到的新物品

  • 与普通指南针不同，追溯指针会指向你最后一次死亡的位置
  • 如果你不在上次死亡的维度中，或者你在世界中还没有死亡过，它会随机旋转
  • 它可以用 1 个指南针和 8 个回响碎片合成，回响碎片可以在远古城市中找到

迅捷潜行

为你的护腿附上这个闪亮的新魔咒，让你在潜行时移动速度与正常行走一样快！

  • 附魔后，会提高你潜行时的移动速度
  • 有 3 个不同的等级，每个等级的速度提升不同
  • 这是第一个专属于护腿装备的魔咒！

幽匿

幽匿感测体那些嘎嘎作响的卷须总得来自什么地方，对吧？欢迎来到幽匿——一个栖居在深暗之域中的新方块家族。它们会找到可供其汲取养分的有效基质。

  • 加入了幽匿催发体方块，一种神秘地散发灵魂的方块，会在附近生物死亡时于其下方绽放出幽匿斑块
    • 在幽匿催发体附近死亡的生物不会掉落经验
  • 加入了幽匿块
    • 当生物在幽匿催发体附近死亡时，某种未知的过程似乎会消耗下方的方块并将其转化为幽匿块
    • 扩散的幽匿能量有一定概率消耗部分能量，长出幽匿感测体或幽匿尖啸体
    • 幽匿块的爆炸抗性非常低
  • 加入了幽匿脉络块
    • 这些脉络生成在幽匿斑块的边缘
    • 与发光地衣类似，它们可以以任意方向放置
    • 脉络的扩散会导致其他方块被幽匿占据
    • 幽匿脉络可以在水下扩散
  • 加入了幽匿尖啸体方块
    • 幽匿尖啸体可以罕见地从幽匿催发体的能量中长出
    • 幽匿尖啸体可以含水
    • 这个方块以其骨状附属物著称，会在幽匿感测体检测到振动时向远处的循声守卫发出警告呼叫
      • 踩上去时要小心，因为它们也会感觉到并发出呼叫！
    • 起初循声守卫可能需要一段时间才会到来，但你会听到它在远处回应……
    • 一旦它足够接近，幽匿尖啸体的呼叫就会召唤附近的循声守卫——做好准备！
  • 生物的灵魂会沿随机方向通过幽匿脉络和幽匿块扩散，直到
    • 幽匿块和幽匿脉络中来自灵魂的能量最终会衰减，但在幽匿催发体附近时衰减得更慢，离宿主越远衰减得越快
    • 如果能量在催发体范围外耗尽，它有机会长出幽匿感测体
  • 幽匿块、幽匿脉络和幽匿催发体需要使用精准采集才能获得
    • 如果没有精准采集，挖掘它们会掉落经验
  • 所有幽匿家族方块的高效工具是锄

循声守卫

深暗之域的恐怖存在！一种没有眼睛的生物，大致类似于遍布深暗之域的幽匿。循声守卫是栖居于此生物群系的不可阻挡的自然之力。循声守卫是强大的生物，遇到已经出现的循声守卫，最好偷偷绕过而不是正面迎击——你已经被警告了。

  • 就像幽匿感测体一样，这些可怕的生物利用振动来感知周围环境
  • 当振动不够时，它们还会用嗅觉追踪猎物——你可以观察到它们嗅探周围，靠近毫无防备的玩家和生物
  • 如果有东西靠得太近，就会被发现
  • 在深暗之域中，循声守卫可以在任何地方出现
    • 当足够多的幽匿尖啸体感应到你的存在时，循声守卫就会出现
  • 循声守卫检测到的振动越多，它就越愤怒
    • 你可以通过它胸腔中灵魂跳动的速度听到和看到这一点
  • 一旦生物超过循声守卫的愤怒阈值，它就会面对猎物咆哮，然后发起冲锋
  • 建高、躲在墙后或超出其强力近战攻击范围，会促使循声守卫切换为远程攻击
    • 它们的肋骨会张开，发出可以穿透墙壁的音波充能远程攻击
    • 这种攻击会无视护甲和盾牌的保护
  • 然而，如果你让循声守卫在 60 秒内没有注意到你或没有生气，它就会挖回地下并消失
    • 如果循声守卫被困在液体中，它会直接消失而不是挖洞
  • 它们与投掷物有特殊的互动
    • 如果循声守卫在 5 秒内接连收到两次投掷物振动，它会对投掷者变得更加愤怒
    • 如果循声守卫收到投掷物振动距离上次投掷物超过 5 秒，它就不会对投掷者更加愤怒
    • 这样你就可以策略性地分散循声守卫的注意力，而不让它生气，同时从附近的箱子中取走战利品
  • 循声守卫用拳头击中盾牌时也会使其失效
  • 它们死亡时会掉落幽匿催发体

振动的变更

  • 地毯现在与羊毛块一样，会抑制因放置、破坏或作为物品掉落而产生的振动
  • 地毯现在也会抑制在其上奔跑和跳跃所产生的振动
  • 潜行时会忽略 item_interact_start 和 item_interact_finish 振动

悦灵

  • 悦灵会收集周围所有与其手持物品相同的物品
  • 悦灵会喜欢递给它物品的玩家，并将收集到的物品带给它喜欢的玩家
  • 如果悦灵听到音符盒发声，该音符盒会成为悦灵 30 秒内最喜欢的音符盒
    • 在此期间，悦灵会待在该音符盒附近，并将收集到的物品带到音符盒而非玩家处
  • 空手与悦灵互动会移除悦灵手持的物品
  • 悦灵可以在掠夺者前哨站和林地府邸中找到
  • 悦灵免疫其喜欢的玩家造成的伤害
  • 悦灵每秒自然恢复 2 点生命值

箱子船

  • 让你在乘船冒险时携带更多物品
  • 如果你在船上，按下打开物品栏键即可访问箱子内容
  • 如果你不在船上，潜行并使用交互键访问箱子内容
  • 如果破坏箱子船，箱子里的物品会像其他箱子一样掉落出来
  • 漏斗、投掷器以及其他与箱子互动的方块也可以与之互动
  • 与其他箱子一样，打开箱子船或破坏箱子船会激怒猪灵，因为它们认为所有箱子都属于它们

山羊角

  • 山羊撞击树木或任何其他山羊生成地自然生成的硬方块（原木、石头、浮冰、铁矿石、铜矿石或绿宝石矿石）时，会掉落一个山羊角
    • 其他固体方块山羊不熟悉，所以不会去撞击
  • 使用山羊角可以吹出响亮的声音，远处也能听到
  • 每个山羊角都有其独特的声音，取决于它来自的山羊
  • 山羊角有 8 种变体，其中 4 种是尖叫山羊独有的
  • 山羊角有时可以在掠夺者前哨站中找到

进度

  • 加入了“它传播了”（It Spreads），用于在幽匿催发体附近杀死生物
  • 加入了“你是我的朋友”（You've Got a Friend in Me），用于让悦灵向你递送物品
  • 加入了“生日歌”（Birthday Song），用于让悦灵在音符盒处放下蛋糕
  • 加入了“我们联合起来”（With our Powers Combined），用于在物品栏中拥有所有蛙明灯
  • 加入了“桶桶”（Bukkit Bukkit），用于用水桶捕获蝌蚪
  • 加入了“当小队跳进小镇”（When the Squad Hops into Town），用于用拴绳牵引每种青蛙变体
  • 加入了“潜行 100”（Sneak 100），用于在幽匿感测体或循声守卫附近潜行以防止其发现你
  • 将黑暗效果加入了“我们是怎么到这里的？”（How Did We Get Here?）进度

随机事件的可预测性

某些随机事件现在更具可预测性，不再可能出现极端行为：

  • 从投掷器/发射器中掉落物品的位置和速度
  • 容器被破坏时生成的物品的位置和速度
  • 生物的随机 follow_range 组件属性
  • 骷髅陷阱生成的马的初始速度
  • 烈焰人的随机位置和烈焰人投射物的随机速度
  • 箭的随机伤害部分和速度
  • 烟花火箭的随机飞行模式
  • 钓鱼竿的浮动模式以及鱼出现的等待时间

四首新音乐曲目

  • 新音乐曲目名为 Ancestry、Aerie、Firebugs 和 Labyrinthine
  • 它们会在特定生物群系中播放

矿车变体

  • 箱子/熔炉/TNT/漏斗矿车的合成配方现在为无序合成
  • 每种矿车变体被破坏时会掉落自身作为物品，而不是拆分成两个物品（如箱子和矿车）

怪物生成

  • 末影人、骷髅、凋灵骷髅和猪灵现在可以在下界更广的光照等级范围内生成（从光照等级 0 到 11）
    • 这使得更多种类的生物可以在下界传送门内生成，导致它们在生成后立即改变维度
    • 我们未来的意图是阻止大多数生物在下界传送门中生成，即使生成了也不会立即穿过传送门——敬请期待后续版本中的这些改动

聊天预览

  • 服务器可以通过在 server.properties 中设置 previews-chat=true 来启用聊天预览
  • 自定义服务器可以通过发送新的网络数据包为某些客户端启用或禁用聊天预览
  • 启用后，聊天编辑框上方会出现一个由服务器控制的预览，显示消息发送后的样式
    • 聊天相关命令（如 /say 和 /msg）也会显示预览
  • 服务器可以利用此功能预览应用了样式（如表情符号或聊天颜色）的消息
  • 聊天预览会在输入时就将聊天消息发送到服务器，甚至在实际发送之前
    • 然后服务器会实时发回带样式的预览
    • 这使服务器可以应用动态消息样式，同时仍允许安全签名聊天
  • 当加入启用了聊天预览的服务器时，客户端会显示警告屏幕，并且可以在聊天设置中全局禁用

聊天类型

  • 不同的聊天样式格式现在可以通过 chat_type 注册表由服务器控制
    • 这些格式会在客户端加入服务器时同步到客户端
    • 可以定义翻译键或翻译格式，例如 chat.type.text 或 %s says: "%s"
      • 聊天消息同样可以选择性地使用自定义翻译键或格式进行旁白朗读
    • 整条消息可以应用格式，例如斜体或特定颜色（但目前不支持点击或悬停事件）

命令

place

新命令取代了 placefeature，可以在指定位置放置地物、拼图、结构和模板。语法：

place feature <feature> [pos]
place jigsaw <pool> <start> <depth> [pos]
place structure <structure> [pos]
place template <template> [pos] [rotation] [mirror] [integrity] [seed]

参数：

  • place feature 的行为与之前的 placefeature 相同
  • place jigsaw 的行为与使用拼图方块界面中的生成按钮相同
  • place template 的行为与使用结构方块界面中的加载按钮相同
  • place structure 会生成一个完整结构，与世界生成时的结构生成方式一致
  • feature：要尝试放置的已配置地物的命名空间 ID
  • structure：要尝试生成的结构的命名空间 ID
  • template：要加载和放置的模板（“结构方块文件”）的命名空间 ID
  • pool：开始生成的模板池的命名空间 ID
  • start：用作起始锚点的拼图的命名空间 ID 名称
  • depth：放置期间要遍历的拼图连接的最大数量
  • pos：用作生成原点的位置（如果省略，则使用 ~ ~ ~）
  • rotation：要应用的旋转（如果省略，则使用 none）
  • mirror：要应用的镜像（如果省略，则使用 none）
  • integrity：结构完整性值，介于 0 和 1 之间
  • seed：当完整性小于 1 时用于随机劣化的种子

多人游戏安全聊天签名

  • 玩家之间的聊天消息现在会进行加密签名
    • /say、/msg、/teammsg 和 /me 命令的消息参数也都会被签名
  • 玩家在启动时会获得 Mojang 提供的密钥对
  • 服务器可以通过在 server.properties 中设置 enforce-secure-profile=true 来要求玩家拥有 Mojang 签名的公钥
    • 强制执行安全配置文件会阻止没有 Mojang 签名公钥的玩家连接
    • 默认情况下此值为 false，允许没有 Mojang 签名公钥的玩家连接
  • 静态聊天样式现在可以由服务器通过 chat_type 注册表控制，或像以前一样使用服务器资源包控制
  • 动态聊天样式也可以由服务器控制，但只有在启用聊天预览时才会签名
    • 客户端可以选择在聊天设置中启用“仅显示安全聊天”，以始终显示原始的已签名消息
  • 仍使用 Mojang 账户的玩家的聊天消息不会被签名
    • 启用了“仅显示安全聊天”的玩家将看不到他们的消息
    • 他们可能无法加入启用了 enforce-secure-profile 选项的服务器

包过滤器

  • 数据包和资源包可以在 pack.mcmeta 中包含 filter 部分
  • 此部分有必填字段 block，它是针对命名空间和路径的模式（正则表达式）列表
  • 如果某个包中的任何文件添加在带有 filter 的包之前，该 filter 部分会匹配 block 中的任何模式，然后该文件会被过滤掉（即视为不存在）
  • filter 部分不适用于包含它的包——仅适用于在它之前加载的包
  • namespace 和 path 都可以省略
    • 缺失的字段会匹配所有值
  • 例如，在原版包之后添加一个在 pack.mcmeta 中包含此部分的包，将隐藏原版包定义的所有配方和进度

示例

"filter": {
    "block": [
        {
            "namespace": "minecraft",
            "path": "recipes/.*"
        },
        {
            "namespace": "minecraft",
            "path": "advancements/.*"
        }
    ]
}
