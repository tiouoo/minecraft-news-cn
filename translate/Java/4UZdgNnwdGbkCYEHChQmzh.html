中立生物的愤怒

更新了大多数中立生物（北极熊、狼、蜜蜂、末影人、猪灵、僵尸猪灵）的愤怒管理。

  • 当受到玩家伤害时，中立生物将锁定该玩家并试图杀死它
  • 该生物会一直保持愤怒，直到玩家死亡或失去视野一段时间
  • 愤怒是持久的，所以玩家不能通过暂时退出游戏或切换维度来逃脱
  • 如果被锁定的玩家在被激怒的生物附近死亡，它将会停止愤怒（除非 forgiveDeadPlayers 被禁用）
  • 中立生物也会对伤害它们的其他生物感到愤怒。但是，这种愤怒不会持久
  • 被激怒的中立生物只会攻击冒犯它们的玩家，而不会攻击无辜的旁观者
    • 值得注意的例外：如果蜂巢或蜂箱被破坏，蜜蜂会对附近所有玩家感到愤怒
  • 有些生物会传播愤怒（狼、僵尸猪灵、猪灵、蜜蜂）。如果玩家攻击了其中一只，附近所有同类型的生物都会对该玩家感到愤怒

普遍愤怒

普遍愤怒基本上是一种连带责任。被玩家攻击的中立生物会普遍地对玩家感到愤怒，无论攻击者是谁。更具体地说：

  • 被玩家攻击的中立生物将锁定最近的玩家，即使该玩家不是攻击者
  • 每次中立生物被玩家击中时，它都会将攻击目标更新为最近的玩家
  • 玩家可以利用这一点让中立生物攻击其他玩家。谁会做这么阴险的事呢？
  • 普遍愤怒不适用于中立生物被其他生物攻击的情况——只适用于被玩家攻击时
  • 普遍愤怒是持久的。被激怒的生物会保持愤怒，即使玩家退出游戏再登录，或者穿过传送门再回来
  • 传播愤怒的生物也会传播普遍愤怒。因此，如果玩家攻击了一只僵尸猪灵，视野内所有其他僵尸猪灵都会普遍愤怒，并攻击它们最近的玩家
  • 被激怒的中立生物如果在短时间内看不到任何合格的目标，将会停止愤怒

下界合金

  • 一种在下界发现的新型高级材料。用它来升级你的钻石装备！

如何制作下界合金

  1. 在下界深处挖掘远古残骸。风险自负。这可不投保
  2. 在熔炉或高炉中将其精炼为下界合金碎片
  3. 在工作台中将四个下界合金碎片与四个金锭合成，以制作一个下界合金锭
  4. 使用锻造台将下界合金锭与你的钻石武器、工具或盔甲融合

下界合金的效果

  • 下界合金物品会漂浮在熔岩中——这样你就不至于在意外洗了个熔岩澡后丢失所有装备
  • 下界合金物品的附魔值比钻石高（但没有金高）
  • 下界合金工具比钻石工具工作更快，更耐用
  • 下界合金武器比钻石武器造成更多伤害
  • 下界合金盔甲比钻石盔甲具有更高的韧性值和耐久度
  • 下界合金盔甲会给予你击退抗性，因此当你被箭矢等击中时，几乎不会被击退
  • 下界合金块可以作为信标底座，下界合金锭可以作为信标燃料。奇怪的炫耀方式，但也可以
  • ……而且它看起来酷毙了！

进度

扩展实体检查

触发器中的实体检查现在可以使用战利品表条件语法。旧写法：

{
  "trigger": "minecraft:player_killed_entity",
  "conditions": {
    "entity": {
      "type": "minecraft:blaze"
    }
  }
}

现在等价于：

{
  "trigger": "minecraft:player_killed_entity",
  "conditions": {
    "entity": [
      {
        "condition": "minecraft:entity_properties",
        "predicate": {
          "type": "minecraft:blaze"
        },
        "entity": "this"
      }
    ]
  }
}

注 1：与战利品表一样，必须满足顶层数组中的所有条件，整个条件才会触发。
注 2：要使用新功能，顶层元素必须是 JSON 数组。JSON 对象被解释为旧写法。
扩展触发器的完整列表：

  • 每个触发器中的新字段 player
  • bred_animals - parent、partner、child
  • channeled_lightning - victims
  • cured_zombie_villager - zombie、villager
  • fishing_rod_hooked - entity
  • killed_by_crossbow - victims
  • player_killed_entity - entity
  • entity_killed_player - entity
  • player_hurt_entity - entity
  • summoned_entity - entity
  • tame_animal - entity
  • target_hit - projectile
  • villager_trade - villager

其他触发器更改

  • 由于新增了 player，现有 location、slept_in_bed、hero_of_the_village、voluntary_exile 的内容现在可以放在 location 字段中，而不是顶层对象中。旧语法仍然支持，但已弃用
  • location 新增了一个属性 smokey，用于检查该位置是否紧邻营火上方
  • entity_properties 新增了属性 vehicle 和 targetedEntity，用于匹配载具或生物所锁定的实体

新触发器

  • target_hit 触发器类型
    • signal_strength 匹配方块被击中时输出的信号强度
    • projectile 匹配投射物实体
    • shooter 匹配射出或投出投射物的玩家
  • item_used_on_block 触发器类型
    • item 匹配被拾起的投掷物品
    • entity 匹配拾起物品的实体
  • player_generates_container_loot 触发器类型

方块存储

Sections 元素中的 BlockStates 不再包含跨越多个 64 位字段的值。
如果每个方块的位数不是 2 的幂（即单个 64 位值不能填满整数个方块状态），则一些位将不被使用。
例如，如果单个方块状态占用 5 位，则每个 64 位字段的最高 4 位将未被使用。
这也意味着存储大小略有增加（在 5 位的情况下，从 320 个 64 位字段增加到 342 个）。

命令

attribute

在单个实体上添加或修改属性。可能的语法：
参数：

  • attribute <target> <attribute> get [<scale>] - 获取属性的总值
  • attribute <target> <attribute> base set <value> - 设置基础值
  • attribute <target> <attribute> base get [<scale>] - 获取基础值
  • attribute <target> <attribute> modifier add <uuid> <name> <value> add|multiply|multiply_base - 添加修饰符（如果修饰符已存在则失败）
  • attribute <target> <attribute> modifier remove <uuid> - 移除修饰符
  • attribute <target> <attribute> modifier value get <uuid> [<scale>] - 获取修饰符的值
  • target - 单个实体（注意：只有玩家、盔甲架和生物拥有属性）
  • attribute - 属性的名称（如 minecraft:generic.max_health）
  • name - 描述修饰符可读名称的字符串（可选引号）
  • value - 浮点值（注意：某些属性对最终值有限制，因此你的更改可能不会生效）

此功能的状态可以通过以下选项手动控制：

  • 对于专用服务器：server.properties 中的 sync-chunk-writes
  • 对于客户端：options.txt 中的 syncChunkWrites

JMX 监控

现在可以通过 JMX 监控服务器 tick 时间。
这样做的理由是，JMX 是一种众所周知且受支持的监控技术，具有现有的集成和工具。
这使服务器管理员能够使用普通的 JMX 客户端和仪表板连接警报和绘图工具。

启用 JMX 监控

  • 在 server.properties 文件中新增了一个标志 enable-jmx-monitoring，如果设置为 true，将公开一个对象名为 net.minecraft.server:type=Server 的 MBean，以及两个属性 averageTickTime 和 tickTimes，以毫秒为单位公开 tick 时间
  • 为了在 Java 运行时启用 JMX，你还需要在启动时添加几个 JVM 标志，如此处所述

检查钓鱼钩的属性

参数
  • in_open_water - 匹配钓鱼位置是否为开阔水域。如果钓鱼钩在水中，水面上除睡莲外没有其他方块，并且所有水方块都是水源方块，且周围没有固体水下方块，则该钓鱼位置被视为开阔水域

包选择屏幕

  • 包现在可以直接拖放到数据包和资源包选择屏幕上
  • 拖放的文件和目录将被复制到适当的位置

粒子

  • 新粒子类型：ash、crimson_spore、soul_fire_flame 和 warped_spore
  • 新粒子类型：dripping_obsidian_tear、falling_obsidian_tear 和 landing_obsidian_tear
  • 新粒子类型：soul

渲染

  • 将实体阴影固定在地面上
  • 新增实体距离比例选项，范围从 50% 到 500%
  • 新增对访问深度缓冲区的着色器支持
  • 新增新的“极佳！”图形选项
    • 这会对某些透明元素使用逐像素混合层

锻造配方

现在有一个 smithing 配方类型。这种类型的配方用于锻造台，将一种物品类型升级为另一种类型，同时保留标签。

  • base - 指定要升级物品的材料
  • addition - 指定触发升级的有效物品的材料
  • result - 指定升级后物品类型的物品

文本样式

颜色

color 属性现在可以包含以 # 为前缀的 RGB 值。例如 #55ff55 将产生与 green 相同的颜色

自定义字体

聊天组件样式现在支持 font 属性，它是资源包中字体的资源位置。没有条目等同于 minecraft:default
