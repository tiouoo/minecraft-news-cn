幽匿感测体阶段

  • 幽匿感测体和校频幽匿感测体有三种阶段：未激活、激活和冷却
  • 默认阶段是未激活
    • 这一阶段会无限持续，直到方块接收到一次振动
    • 在此阶段，方块能够聆听附近的振动，直到一个振动被计划
  • 当接收到一个已计划的振动时，方块切换到激活阶段
    • 此阶段对于幽匿感测体持续30游戏刻，对于校频幽匿感测体持续10游戏刻
    • 在此阶段，方块停止聆听附近的振动，摆动其触须，并发出红石信号和光
  • 激活阶段结束后，方块切换到冷却阶段
    • 此阶段持续10游戏刻
    • 在此阶段，方块继续摆动其触须，但不再发出红石信号或光
    • 最后，此阶段结束后，方块将切换回未激活阶段
  • 此前，其中一些阶段有不同的时间值：
    • 激活：幽匿感测体40游戏刻，校频幽匿感测体20游戏刻
    • 冷却：两种幽匿感测体均为1游戏刻
  • 这些阶段时间被调整，以降低被激活的装置递归激活为其供能的幽匿感测体的可能性

字体

新的 unihex 字形提供器

  • 用于读取 Unifont HEX 文件的新字形提供器
    • HEX 格式描述了位图字体字形
      • 每个字形的高度为16像素
      • 字形宽度可以是8、16、24或32像素
    • 每一行由两个十六进制数字组成，以:分隔
    • 第一个值描述码点 - 必须有4、5或6个十六进制位
    • 第二个值以比特流的形式逐行描述字形
  • 渲染时，字形左右两侧的空列会被移除
    • 可以使用size_overrides设置自定义字形宽度
  • 提供器需要两个字段：
    • hex_file - 包含一个或多个*.hex文件的ZIP压缩包路径（包中扩展名不同的文件将被忽略）
    • size_overrides - 一个码点范围列表，这些范围的字形宽度应与自动检测到的宽度不同（根据字形中的空白确定）。字段：
      • from、to - 码点范围的起点和终点（包含）
      • left、right - 描述该范围内字形最左列和最右列位置的整数
        • 此范围之外的任何列中的位都将被丢弃

新的 reference 字形提供器

  • 新的字形提供器可用于包含来自其他字体的提供器
    • 无论被包含多少次，提供器都保证只加载一次
  • 提供器有一个字段id，用于描述要包含在当前已加载字体中的其他字体
    • 包含操作在所有字体加载完成后执行，因此它将包含所有数据包中为给定字体定义的所有提供器

已移除 legacy_unicode 字形提供器

  • legacy_unicode 字形提供器已被移除
  • 此功能已被 unihex 提供器取代
