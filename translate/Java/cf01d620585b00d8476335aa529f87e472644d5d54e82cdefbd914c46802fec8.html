本周是一个较快的快照，带来了新的主菜单全景图、服务器行为准则，以及对我们的新朋友铜傀儡的诸多调整与修复。祝挖矿愉快！

开发者说明: 25w31a 中针对实体引入的渲染更改现已扩展至影响方块实体和物品。如果这些区域遇到任何问题，请及时报告。

新特性

  • 服务器现在可以在游戏内设置行为准则

服务器行为准则

连接服务器时，现在可以显示行为准则界面。

  • 必须接受行为准则才能进入服务器游玩
  • 可以选择一个复选框，以便以后不再显示相同的行为准则
    • 如果行为准则发生更改，将再次显示

服务器设置

  • 已在 server.properties 中添加了一个新的布尔字段 enable-code-of-conduct
    • 将其设置为 true 将让服务器在存放 server.properties 的同一文件夹下的 codeofconduct 子文件夹中查找行为准则文件
    • 文件夹中的每个文件应采用 <language_code>.txt 的形式
      • 显示的语言将尝试与玩家的语言匹配
      • 如果不存在，将使用 en_us 行为准则
      • 如果那也不存在，则任意使用一个可用条目

更改

  • 主菜单现在使用更新的背景全景图，显示村庄中的铜傀儡

末地闪光

  • 闪光产生的音效现在具有更高的延迟
  • “隐藏闪电闪光”辅助功能设置已重命名为“隐藏天空闪光”，并且现在也会禁用末地闪光
    • 当通过该设置禁用闪光时，世界不会被闪光照亮，但闪光来源仍会在天空中可见，并且音效仍会播放

方块、物品和实体的微调

  • 铜傀儡被隐身药水溅射时，其眼睛现在也会隐形
  • 铜傀儡的碰撞箱已进行调整
    • 碰撞箱宽度现在为 0.6 格，以便能够寻路通过打开的门
    • 碰撞箱高度现在为 1.01 格，以避免卡在某些方块中

声音

命令

新增 fetchprofile

  • 新增的命令，用于从 Minecraft 服务器获取玩家档案的内容
  • 由于该操作可能需要一些时间，它会异步工作
    • 结果只会在操作完成时打印，但游戏会继续运行且不会暂停
  • 成功完成后，将打印一条消息，让用户可以复制完全解析后的 minecraft:profile 组件的内容，或带有该组件的 /give @s minecraft:player_head 命令
  • 由于结果在执行时未知，此命令始终返回 1

语法：

  • fetchprofile name <player name> - 按名称解析档案（不区分大小写）
  • fetchprofile id <uuid> - 按 ID 解析档案

数据组件

修改 minecraft:profile

  • 以前，当档案被解析（即从 Minecraft 服务下载）时，此组件的内容会永久改变
  • 为避免此意外更改带来的问题，已不再存储解析后的值，档案内容将始终保持不变
  • 这意味着该组件现在有两种行为：
    • 静态：当它有 properties 字段，或 name 和 id 都存在，或两者都不存在时
      • 在此状态下，档案将始终按原样显示
      • 如果缺少 properties 字段，将使用默认皮肤（根据 id 选择，与离线模式相同）
      • 这意味着皮肤将在组件创建时被固定
      • 此选项适合装饰用途
    • 动态：当它有 name 或 id（但不同时具备）时
      • 当包含此档案的物品在客户端渲染时，档案将被解析为最新值
      • 这意味着该物品将始终使用目标玩家当前的皮肤渲染
        • 注意：如果玩家在游戏运行时更改皮肤，除非客户端重启，否则该更改不会可见
      • 解析可能延迟发生，期间物品将使用默认皮肤渲染
      • 只有存在档案名称时，才会替换物品名称
        • 只有 id 的物品将显示默认名称
      • 带有动态档案的物品将在工具提示中通过标签与静态档案物品区分
  • 物品根据精确内容堆叠，因此即使动态组件最终解析为与静态组件相同的档案，它们也不会堆叠在一起
  • 旧地图中尚未在较新版本中加载过的玩家头颅，通常会被转换为动态内容
