本周我们带来一个可让您尽情沉浸其中的快照！这次我们带来了数据驱动的唱片机、一个新的游戏规则，以及一堆修复。

祝您玩得开心！

更改

  • 看来上周我们做新活塞声音时有点过头了，因此我们将再次改回旧声音
  • 降低了原始声音的音量，以回应关于活塞声音过大的初步反馈
  • 暂停菜单现在可以包含服务器提供的链接列表
  • 对断开连接界面进行了改进
  • Realms 的任何成员现在都可以升级世界
  • 在 Realms 主界面，会显示 Realm 的所有在线玩家
    • 悬停时，会显示包含每位玩家头颅和名称的提示框

宝库

  • 添加了音效，帮助玩家了解他们已经搜刮过宝库

试炼密室

  • 试炼密室现在不太可能在深暗之域中生成

动物恐慌

  • 动物现在会根据预定义的伤害来源类型所造成的伤害而恐慌
  • 恐慌在受到伤害后持续 2 秒。原版动物使用以下伤害类型标签：
    • panic_environmental_causes：狼、北极熊（成年）和熊猫使用
    • panic_causes：所有其他动物和北极熊幼崽使用

服务器链接

  • 服务器现在可以向客户端提供链接列表
  • 如果客户端收到了任何链接，暂停游戏界面中会显示一个名为“服务器链接...”的新按钮
    • 为了给该按钮腾出空间，“报告漏洞”和“提供反馈”按钮可能会在必要时移至子界面

断开连接界面改进

  • 在某些情况下，客户端现在会存储有关断开连接的详细信息（类似于崩溃报告）
  • 发生这种情况时，断开连接界面将新增“打开断开连接报告目录”按钮
  • 当服务器提供错误报告的链接时，该链接也会作为按钮添加到断开连接界面

技术性更改

  • 资源包版本现在为 34
  • 数据包版本现在为 45
  • 服务器现在可以向客户端提供链接列表
  • 服务器可以向崩溃报告和断开连接报告添加自定义详细信息

游戏规则

  • 添加了新的 entitiesWithPassengersCanUsePortals 游戏规则
    • 当设为 true 时，带有乘客的实体可以使用下界传送门、末地传送门和末地折跃门
    • 默认值为 false

服务器链接

  • 新的客户端绑定数据包 server_links 可在 configuration 和 game 协议中使用
  • 收到后，客户端将在暂停菜单中提供这些链接
  • 链接标签可以是内置的或自定义的（即任何文本）
  • 某些内置链接也具有特殊功能：
    • report_bug：
      • 如果断开连接是由数据包处理错误引起的，该链接将显示在断开连接界面上
      • 该链接将作为注释包含在断开连接报告中
  • 将 bug-report-link 添加到了 server.properties，以允许原版服务器配置 report_bug 链接
    • 如果此字段非空，服务器将向客户端发送该链接
    • 此字段应包含格式正确的 URL

自定义服务器崩溃报告详细信息

  • 新的客户端绑定数据包 custom_report_details 可在 configuration 和 game 协议中使用
  • 此数据包包含一系列键值文本条目
  • 如果收到，此数据包的内容将作为单独的部分添加到连接到此服务器期间生成的任何崩溃报告或断开连接报告中

数据包版本 45

  • 唱片机音乐现在由数据驱动
  • 添加了新命令语法

唱片机音乐

  • 添加了从数据包加载的唱片机音乐注册表
  • 唱片机音乐定义路径为 data/<namespace>/jukebox_song/<id>.json
  • 定义中的字段：
    • sound_event - 唱片机播放时流式传输的音效事件
    • description - 歌曲名称，以文本组件形式表示，会显示在悬停提示框中
    • length_in_seconds - 歌曲长度（秒），为正浮点数
    • comparator_output - 在唱片机中播放时比较器输出的红石信号，范围为 0 到 15
  • 添加了 minecraft:jukebox_playable 物品堆叠组件

jukebox_playable 物品组件

  • 如果设置了该组件，物品可以放入唱片机以播放音乐
  • 格式：包含以下字段的对象
    • song：唱片机音乐 ID
      • 将此物品堆叠放入唱片机时将要播放的音乐
    • show_in_tooltip：布尔值（默认：true）
      • 如果为 false，歌曲名称将不会显示在提示框中
      • 这以前由音乐唱片上的 hide_additional_tooltip 组件控制
    • 例如：jukebox_playable={song:'minecraft:precipice'}、jukebox_playable={song:'minecraft:precipice', show_in_tooltip:false}

属性

  • 属性修饰符不再使用 UUID 和名称的组合
  • 取而代之的是，属性修饰符现在通过与其它资源类似的命名空间 ID 来唯一标识
  • 修饰符的 ID 在单个属性的修饰符集合中唯一标识该修饰符
  • 只要修饰符用于不同属性，则允许不同的修饰符使用相同的 ID
  • 现有内置修饰符将升级为新 ID
  • 现有自定义修饰符将升级为使用 GUID 作为 minecraft 命名空间中的 ID

attribute 命令

  • uuid 和 name 参数已被单个 id 参数取代

物品堆叠属性修饰符

  • uuid 和 name 字段已被移除。
  • 属性修饰符现在拥有 id（命名空间 ID）字段
    • 这是该修饰符在每个属性上的唯一标识符

实体属性

  • 属性现在以 attributes 存储
  • 属性格式：
    • id，由 Name 重命名而来
    • base，由 Base 重命名而来
    • modifiers，由 Modifiers 重命名而来
      • 现在存储修饰符的格式与 attribute_modifiers 物品堆叠组件中的修饰符相同：
        • id，取代 UUID 和 Name
        • amount，由 Amount 重命名而来
        • operation，由 Operation 重命名而来，现在为命名常量而非整数：
          • add_value - 之前为 0
          • add_multiplied_base - 之前为 1
          • add_multiplied_total - 之前为 2

附魔

属性效果

字段：

  • name 和 uuid 已被移除，由 id 取代
  • id：要添加的属性修饰符的命名空间 ID
    • 当附魔物品装备到槽位时，此 ID 会加上槽位名称作为后缀
    • 必须是唯一的，以避免不同附魔（或其他系统）相互干扰
