金色蒲公英

  • 金色蒲公英是一种新类型的花，可用于阻止幼年生物成长
    • 手持金色蒲公英与幼年生物交互将阻止其成长
    • 手持金色蒲公英与已停止成长的幼年生物交互将使其重新开始成长
    • 金色蒲公英不能用于敌对性幼年生物和村民
  • 可以使用蒲公英和金粒合成

minecraft:crafting_transmute

  • 此类型的配方现在可以接受由 material 材料匹配的多种物品

新增字段：

  • material_count - 整数范围，描述由 material 材料匹配的物品数量
    • 必须是 [2,8] 的子范围
    • 默认值：[1,1]（即恰好一个物品）
  • add_material_count_to_result - 布尔字段（默认值：false）
    • 为 true 时，包含由 material 材料匹配的物品的槽位数量将添加到结果的最终数量中

minecraft:crafting_dye

  • 取代 minecraft:crafting_special_armordye
  • 输出：
    • 此配方将首先把 target 材料匹配的物品中的 minecraft:dyed_color 组件当前值与 dye 材料匹配的物品中的 minecraft:dye 组件值混合
    • 结果将通过将 target 材料匹配的物品转化为 result 物品堆叠，然后应用 minecraft:dyed_color 组件的新值来构建

字段：

  • category - 合成书类别，可为 building、redstone、equipment、misc, 默认值：misc
  • group - 用于在合成书中对配方进行分组的字符串值，默认值：空字符串
  • show_notification - 可选布尔值，描述此配方解锁时是否显示弹窗，默认值：true
  • target - 材料（原硬编码为 #dyeable 标签）
  • dye - 材料（原硬编码为染料物品）
    • 匹配整个配方时，匹配物品上需要 minecraft:dye 组件
  • result - 结果物品堆叠（原始终为 target 材料匹配物品的副本）

minecraft:crafting_special_bookcloning

  • 材料与输出现在可以配置
  • 移除了未使用的 category 字段
  • 新增字段：
    • source - 用作源书的材料
      • 匹配整个配方时，匹配物品上需要 minecraft:written_book_contents 组件
    • material - 用于指定待克隆物品的材料（原硬编码为 #book_cloning_target 标签
    • allowed_generations - 整数范围，描述 material 材料匹配物品上的 minecraft:written_book_contents 组件中 generation 字段的允许值
      • 必须是 [0,2] 的子范围
      • 默认值：[0,1]（即接受原版和第一份副本，但不接受副本的副本）
    • result - 结果物品堆叠（原始终为 source 材料匹配物品的副本）
  • 输出：
    • 该配方将首先获取 source 材料匹配物品中的 minecraft:written_book_contents 组件值
    • minecraft:written_book_contents 中的 generation 字段将增加一
      • 如果 generation 值为 2 或更高，该配方将不会产生结果
    • 结果将通过将 source 材料匹配的物品转化为 result 物品堆叠，然后应用 minecraft:written_book_contents 组件的新值来构建
    • 超过第一个的由 material 材料匹配的物品数量将添加到结果堆叠大小中
    • 由 source 材料匹配的原始物品将保留在合成网格中
