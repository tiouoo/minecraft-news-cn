这周我们发布了今年第二次更新的最终特性。今天的快照带来了可合成的鞍，以及一些由 Amos Roddy 创作的惊艳曲目。我们还新增了一个选项，可以在游戏内的暂停菜单中显示当前正在播放的歌曲。

新特性

  • 添加了一张新音乐唱片，收录了 Amos Roddy 的曲目“Tears”
  • 使鞍可以合成，并可用剪刀取下
  • 更新了主界面全景图

音乐

  • 在樱花树林、森林、沙漠、雪林和繁茂洞穴生物群系中添加了以下 Amos Roddy 的新音乐曲目：
    • Below and Above
    • Broken Clocks
    • Fireflies
    • Lilypad
    • O's Piano
  • 这些歌曲也加入到了菜单音乐的轮播中

鞍的更新

合成鞍

  • 鞍现在可以用 3 个皮革和 1 个铁锭合成
  • 玩家拾取第一个皮革时解锁配方

移除鞍和装备

  • 鞍、马铠、挽具和地毯现在可以使用剪刀从可装备的生物身上移除
  • 当生物有骑乘者时，无法使用剪刀移除鞍、马铠、挽具和地毯
  • 玩家潜行时，无法使用剪刀移除鞍、马铠、挽具和地毯
  • 无法使用剪刀从劫掠兽身上移除鞍
  • 装有剪刀的发射器无法移除生物身上装备的鞍、马铠、挽具或地毯

战利品表更改

某些战利品表中的鞍已被移除，并替换为 1-5 个皮革：

  • 地牢箱子
  • 远古城市箱子
  • 沙漠神殿箱子
  • 丛林神庙箱子
  • 要塞祭坛箱子

更改

  • 雾现在会应用到 3D 界面元素上，例如第一人称视角下的玩家手部和手中的物品
  • 恶魂现在被玩家弹回的火球杀死时，会掉落“Tears”音乐唱片
  • 对 MC-3697 的修复已被部分回退。装饰性悬挂实体（例如画和物品展示框）现在对水下 TNT 的爆炸免疫，而物品和盔甲架则再次会受到影响
  • 更新了音乐和音效
  • 下雨和雷暴天气的雾现在稍微减少了
  • 雨雾对室内的影响减少了
  • 鞍现在可以合成，使用 3 个皮革和 1 个铁锭即可合成
  • 鞍、马铠和地毯现在可以使用剪刀从可装备的生物身上移除
  • 某些战利品表已修改，改为掉落皮革而非鞍
  • 干恶魂块不再因水流入而碎裂

音乐与音效

数据包版本 77

  • 在 equippable 物品组件中添加了新的可选字段 can_be_sheared 和 shearing_sound
  • 添加了一种向用户显示非常简单的对话框的方法
  • 为文本组件添加了新的 click_event 操作类型：custom
  • 当书和聊天中的 run_command 点击操作所执行的命令无法解析或需要更高权限（即高于 0）时，用户现在需要先进行确认

对话框

  • 添加了一种向用户显示简单模态对话框的方法
  • 对话框存储在 minecraft:dialog 注册表中，但也可以内联定义
  • 对话框是一个实验性功能
  • 为避免用户困惑，对话框屏幕在标题旁边标有警告标志
    • 单击此警告会弹出一个对话框，向用户说明此屏幕由自定义内容提供
    • 它还会给用户一个选择，可以退出当前世界，以避免被锁定在对话框的无限循环中
  • 服务器可以在 play 和 configuration 连接阶段显示对话框
    • 但是，在 configuration 阶段只允许内联注册表，因为该阶段还未提供注册表
  • 用户选择任何操作后，对话框总会关闭
  • 默认情况下，按 Esc 键后对话框也会关闭
    • 发生这种情况时，对话框将运行下文描述为“退出操作”的特定于对话框类型的操作
    • 此行为是可配置的
  • 关闭对话框屏幕时，游戏会返回到之前显示的非对话框屏幕或返回游戏
    • 这意味着新对话框总是替换已打开的对话框（如果有）
  • 在单人游戏模式下，对话框屏幕将暂停游戏
  • 对话框可以配置为可从暂停菜单访问
    • 这取代并扩展了先前版本中添加的“服务器链接”按钮
  • 大多数对话框遵循通用布局，但具体内容取决于类型：
    • 带有标题和警告按钮的头部
    • 正文元素（标签、输入框、按钮和提交操作），可根据需要滚动
    • 可选的底部，包含主要按钮和提交操作

开发者注记：对话框并非用于完整描述任何游戏内 UI，而只是允许自定义内容显示简单消息并从用户那里获取输入。此功能特意限制以匹配此用例。

对话框描述格式

  • 对话框存储在 minecraft:dialog 注册表中，该注册表可由数据包提供

字段：

  • type - 来自 minecraft:dialog_type 注册表的对话框类型之一
  • <type-specific> - 见下文

通用对话框字段

  • 大多数对话框类型共享一些字段。为避免重复，它们在本节中列出

字段：

  • title - 屏幕标题，文本组件
    • 无论具体类型如何，都应始终在屏幕上可见
  • external_title - 用于指向此对话框的按钮的名称（例如从暂停界面），可选的文本组件
    • 如果不存在，则使用 title 代替
  • body - 可选的正文元素列表或单个元素，见下文
  • can_close_with_escape - 对话框是否可以通过 Esc 键关闭，默认为 true

通用按钮数据

  • 对话框类型中的大多数操作共享以下字段，这些字段描述了与该操作关联的按钮的外观：
  • label - 文本组件
  • tooltip - 可选文本组件，在按钮高亮或悬停时显示
  • width - 按钮宽度，正整数，默认为 150

点击操作

  • 用于表示对话框上可点击操作的通用对象
  • 字段：
    • 通用按钮数据（见上文）
    • on_click - 可选的点击事件（与文本组件上的 click_event 格式相同）
      • 如果不存在，点击按钮将只是关闭屏幕，不执行任何操作

对话框类型

minecraft:notice
  • 一个简单的屏幕，底部有一个操作
  • 退出操作：同 action

字段：

  • 通用对话框字段（见上文）
  • action - 点击操作（见上文），默认为带有 gui.ok 标签且没有操作或工具提示的按钮
minecraft:confirmation
  • 一个简单的屏幕，底部有两个操作
  • 退出操作：同 no 操作

字段：

  • 通用对话框字段（见上文）
  • yes - 用于肯定结果的点击操作（见上文）
  • no - 用于否定结果的点击操作（见上文）
minecraft:multi_action
  • 一个可滚动的操作列表，按列排列
  • 屏幕底部也有一个按钮，用于运行退出操作并关闭屏幕
    • 如果对话框定义了退出操作，标签为 gui.cancel；如果没有副作用，则为 gui.back
  • 退出操作：在 on_cancel 字段中定义

字段：

  • 通用对话框字段（见上文）
  • actions - 非空的点击操作列表（见上文）
  • on_cancel - 可选的点击事件（与文本组件上的 click_event 格式相同）
  • columns - 描述列数的正整数，默认：2
minecraft:server_links
  • 一个可滚动的链接列表，这些链接在 minecraft:server_links 数据包中从服务器接收，按列排列
  • 屏幕底部也有一个按钮，用于运行退出操作并关闭屏幕
    • 如果对话框定义了退出操作，标签为 gui.cancel；如果没有副作用，则为 gui.back
  • 注意：这是对先前“服务器链接”界面的替代，但现在带有一个附加正文
  • 退出操作：在 on_cancel 字段中定义

字段：

  • 通用对话框字段（见上文）
  • on_cancel - 可选的点击事件（与文本组件上的 click_event 格式相同）
  • columns - 描述列数的正整数，默认：2
  • button_width - 列表中按钮的宽度，正整数，默认为 150
minecraft:dialog_list
  • 一个可滚动的按钮列表，直接指向其他对话框，按列排列
    • 这些按钮的标题将取自目标对话框的 external_title 字段
  • 屏幕底部也有一个按钮，用于运行退出操作并关闭屏幕
    • 如果对话框定义了退出操作，标签为 gui.cancel；如果没有副作用，则为 gui.back
  • 退出操作：在 on_cancel 字段中定义

字段：

  • 通用对话框字段（见上文）
  • dialogs - 对话框、对话框列表或对话框标签
  • on_cancel - 可选的点击事件（与文本组件上的 click_event 格式相同）
  • columns - 描述列数的正整数，默认：2
  • button_width - 列表中按钮的宽度，正整数，默认为 150
minecraft:simple_input_form
  • 一个接受用户输入的屏幕
  • 底部有一个提交操作
  • 退出操作：无（提交数据会关闭屏幕，但除了向服务器发送数据外，不会运行任何操作）

字段：

  • 通用对话框字段（见上文）
  • inputs - 非空的输入控件列表，见下文
  • action - 提交操作，见下文
minecraft:multi_action_input_form
  • 一个接受用户输入的屏幕
  • 可以有多个提交操作
  • 没有底部，提交操作附加到正文中
  • 退出操作：无（提交数据会关闭屏幕，但除了向服务器发送数据外，不会运行任何操作）

字段：

  • 通用对话框字段（见上文）
  • inputs - 非空的输入控件列表，见下文
  • actions - 非空的提交操作列表，见下文

对话框正文类型

  • 所有对话框都有一个正文元素列表，描述标题与操作或输入之间的内容

字段：

  • type - 来自 minecraft:dialog_body_type 注册表的对话框正文类型之一
  • <type-specific> - 见下文
minecraft:plain_message
  • 一个多行标签

字段：

  • contents - 文本组件
  • width - 消息的最大宽度，正整数，默认为 200
minecraft:item
  • 带有可选描述的物品
    • 如果存在描述，则会渲染在物品右侧
  • 物品将像在物品栏槽位中一样渲染
  • 即使 width 和 height 设置为非默认值，物品也不会缩放

字段：

  • item - 带有数量的物品堆叠
  • description - 可选对象，包含字段：
    • contents - 文本组件
    • width - 内容的最大宽度，正整数，默认为 200
    • 也可以是文本组件
  • show_decorations - 如果为 true，则会在物品上渲染数量和耐久条，默认：true
  • show_tooltip - 如果为 true，当物品悬停时会出现物品工具提示，默认：true
  • width - 元素的水平尺寸，默认：16
  • height - 元素的垂直尺寸，默认：16

输入控件类型

  • 输入对话框使用一组控件来接受用户输入
  • 提交时，输入的当前值将转换为字符串，并按下文“提交操作”部分所述发送到服务器

字段：

  • type - 来自 minecraft:input_control_type 注册表的输入控件类型之一
  • key - 提交数据时所用值的字符串标识符，必须是有效的模板参数（字母、数字和 _）
  • <type-specific> - 见下文
minecraft:text
  • 简单的文本输入
  • 发送当前内容而不作修改

字段：

  • width - 输入框的宽度，正整数，默认：200
  • label - 在控件左侧显示的文本组件
  • label_visible - 控制标签可见性，默认：true
  • initial - 初始内容，默认：""（空）
minecraft:boolean
  • 一个带有标签的普通复选框

字段：

  • label - 在控件右侧显示的文本组件
  • initial - 初始值，默认：false（即未选中）
  • on_true - 控件选中时发送的字符串值，默认：'true'
  • on_false - 控件未选中时发送的字符串值，默认：'false'
minecraft:single_option
  • 一个在点击时在一组选项中循环的按钮
  • 发送与当前选中预设关联的值

字段：

  • label - 在按钮上显示的文本组件
  • label_visible - 如果为 true，标签将合并到按钮文本中，默认：true
  • width - 按钮宽度，正整数，默认：200
  • options - 一个对象列表，包含字段：
    • id - 提交时发送的字符串值
    • display - 在按钮上显示的文本组件，可选（如果不存在，则使用 id）
    • initial - 可选的布尔标志，用于选择初始选项（只能有一个选项将其设置为 true）
    • 此外，列表也可能包含纯字符串——在这种情况下，它等同于一个条目，其中字段 id 设置为该字符串，其他字段设置为默认值
minecraft:number_range
  • 一个用于在某个范围内选择数值的滑块
  • 发送当前选中的值
    • 整数将不带小数点发送

字段：

  • label - 用作滑块标签的文本组件
  • label_format - 用于构建标签的翻译键（第一个参数是 label 字段的内容，第二个参数是当前值），默认：options.generic_value
  • width - 输入框的宽度，正整数，默认：200
  • start - 起始值（滑块位于最左侧时）（包含），浮点数
  • end - 结束值（滑块位于最右侧时）（包含），浮点数
  • steps - 增量数量，正整数
    • 注意：1 表示滑块将有两个位置（起始和结束）
  • initial - 滑块的初始值，向下舍入到最近的步长值，必须在范围内，默认为 min

提交操作

  • 输入对话框上的每个提交操作都有一个关联的按钮
  • 当点击其中一个按钮时，将收集所有输入的值，并使用下文描述的方法之一发送到服务器
  • 提交操作的 id 字段将作为键为 action 的输入包含在内
  • 提交操作字段：
    • 通用按钮数据（见上文）
    • id - 操作的字符串标识符
    • on_submit - 点击按钮时运行的提交方法，包含以下字段的对象：
      • type - 来自 minecraft:submit_method_type 注册表的提交方法类型之一
      • <type-specific> - 见下文
  • 注意：服务器不会验证各个值，因为它们以填充的命令或自定义负载形式到达

提交方法类型

minecraft:command_template
  • 此方法将使用提供的宏模板构建命令，并请求服务器运行它（与 minecraft:run_command 点击事件相同）
  • 如果命令需要高于 0 的权限（即需要任何操作员权限），将显示确认对话框
  • 宏将使用输入中的值进行展开
    • 例如，如果宏是 some_command $(action)，则 action 参数将展开为提交操作的 id 字段
    • 宏中未使用的输入将被忽略，而未匹配任何输入的宏参数将替换为空字符串

字段：

  • template - 包含宏模板的字符串，将被解释为命令
minecraft:custom_template
  • 此方法将使用提供的宏模板构建自定义服务器点击操作，并将其发送到服务器（与 minecraft:custom 点击事件相同）
  • 宏将使用输入中的值进行展开
    • 宏中未使用的输入将被忽略，而未匹配任何输入的宏参数将替换为空字符串

字段：

  • template - 包含宏模板的字符串，用作负载
  • id - 命名空间 ID
minecraft:custom_form
  • 此方法将从所有值构建自定义服务器点击操作，并请求服务器运行它（与 minecraft:custom 点击事件相同）
  • 格式：
    • 键与值之间用水平制表符（U+0009）分隔
    • 键值条目之间用换行符（U+000A）分隔
    • 如果任何键或值中存在 U+0009 和 U+000A 字符，它们将被转义为 \t 和 \n

字段：

  • id - 命名空间 ID

内置对话框

内置数据包包含一些自定义对话框，用于定制客户端使用的特定界面

minecraft:server_links
  • 替代先前存在的“服务器链接”界面
  • 旨在简化先前使用此功能的服务器的迁移
minecraft:custom_options
  • 显示 minecraft:pause_screen_additions 标签的内容（见下文）
  • 如果此标签包含多个条目，则允许用户选择特定的对话框
  • 注意：由于此标签用于互操作性，任何替换此对话框的内容都应小心不要隐藏其他对话框提供者

对话框命令

  • 添加了新命令，用于向客户端显示对话框

语法：

  • dialog show <targets> <dialog> - 向玩家显示对话框
    • <targets> - 玩家名称、UUID 或玩家选择器
    • <dialog> - 来自 minecraft:dialog 注册表的命名空间 ID，或如上所述的内联对话框值
    • 返回 targets 参数中的玩家数量
  • dialog clear <targets> - 清除玩家的对话框（如果有任何可见的）
    • <targets> - 玩家名称、UUID 或玩家选择器
    • 返回 targets 参数中的玩家数量

暂停界面配置

  • 数据包可以请求从暂停界面访问某些可用的对话框
  • 此功能取代“服务器链接”按钮，并按照相同的规则放置在暂停界面上
  • 指向以此方式公开的对话框的按钮将使用 external_title 字段中描述的标签
  • 此功能由 minecraft:pause_screen_additions 对话框标签配置：
    • 如果此标签未指定或为空，但服务器已发送 server_links 数据包，则该标签将被视为包含 minecraft:server_links 对话框
      • 注意：这与先前“服务器链接”功能的行为一致
      • 如果此对话框被移除，标签将保持为空
    • 如果此标签仍然为空，则按钮不可见（改为显示“发送反馈”和“报告漏洞”按钮）
    • 如果此标签只有一个元素，暂停界面按钮将直接指向此对话框
    • 如果此标签有多个元素，暂停界面按钮将指向 minecraft:custom_options，它（默认）允许用户选择标签元素之一
      • 如果此对话框被移除，按钮不可见

文本组件

点击事件

  • 添加了新的点击操作 minecraft:custom
    • 当用户点击带有此点击操作的组件时，客户端将向服务器发送专用数据包 minecraft:custom_click_action
    • 其预期用途是作为 run_command 的替代方案，供模组服务器使用，而无需担心必须添加自定义命令
    • 此数据包在原版服务器上没有任何功能
    • 字段：
      • id - 命名空间 ID
      • payload - 可选的字符串字段

对话框点击事件

  • 添加了新的操作 show_dialog
    • 当用户点击此组件时，将为他们打开一个对话框
    • 字段：
      • dialog - 来自 minecraft:dialog 注册表的命名空间 ID，或如上所述的内联对话框值

equippable 物品组件

  • 添加了新的可选字段：can_be_sheared（布尔值）

    • 如果未指定，默认为 false
