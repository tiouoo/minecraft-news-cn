在今天的快照中，我们进行了一些必要的更改，这些更改直接与我们最近发布的公告相关。如果你还没有阅读过，我们强烈建议你去阅读。你还可以查看来自 Agnes 和 Henrik 的洞穴与山崖视频，以了解更多关于本次更新的计划。

尽管一些特性会比我们原先计划的发布时间更晚，你仍然可以通过单独的数据包来试用它们。更多信息以及我们最新的调整，请参见下文。

洞穴与山崖世界生成

  • 世界高度已改回 1.16 的水平。
  • 噪声洞穴和含水层已关闭。
  • 洞穴和峡谷雕刻器已恢复为旧设置。
  • 裂隙雕刻器已关闭。
  • 矿石分布已恢复为 1.16 的设置。
  • 铜现在会生成在世界底部至高度 192 之间，在高度 96 附近最为常见。
  • 凝灰岩现在以团块形式生成在高度 0 至 16 之间。
  • 在快照 21w05b 或任何更早版本中创建的世界现在可以再次打开。
  • 在快照 21w06a 至 21w14a 之间的任何版本中创建的世界将无法再打开。

洞穴与山崖原型数据包

你仍然可以使用数据包来试用后续更新中的世界生成，该数据包会以实验性自定义世界的形式启用这些更改：

  • 下载数据包
  • 启动游戏，进入“创建新世界”界面，然后点击“数据包”按钮。
  • 将下载的 zip 文件拖拽到 Minecraft 窗口上。
  • 游戏会询问你是否要添加该数据包——点击“是”。
  • 点击列表中刚刚出现的数据包上的播放箭头——这会将其移动到屏幕右侧的列表中。
  • 点击“完成”按钮，然后像平常一样继续创建你的世界。

请记住，使用该数据包创建的世界会被游戏标记为实验性世界，并且此类世界不保证能在未来的版本中继续使用。另外，请注意，你不能将改变世界生成的数据包添加到已有的世界中，因此你必须创建一个新世界才能体验这些实验性特性。

  • 所有矿石都已被重新排序，在创造模式物品栏中位于同一位置。

21w15a 的技术性更改

  • 添加了标记实体。
  • 添加了 /debug function。
  • selector 和 nbt 聊天组件现在可以配置元素之间的分隔符。
  • 服务器现在可以自定义一条消息，在提示玩家使用自定义资源包时显示。

标记

标记是一种新型实体，用于地图制作和数据包等自定义用例。

  • 仅存在于服务端，绝不会发送给客户端。
  • 不会自行进行任何更新。
  • 拥有一个可以包含任意数据的 data 复合字段。

/debug function

新的调试子命令会执行命令，其语法与函数相同。

  • 所有执行的命令、消息（即使是通常不可见的消息）、结果或错误都会存储到文件中。
  • 不能在函数内部运行。

聊天组件分隔符

  • 打印名称列表的组件（如 selector 或 nbt）现在可以使用 separator 元素覆盖默认分隔符（默认为 ", "）。
  • 示例：
    • {"selector": "@e[type=chicken]", "separator": "|"}
    • {"nbt": "CustomName", "entity": "@e[type=chicken]", "interpret": true, "separator": {"text": "*", "color": "red"}}

自定义服务器资源包

当在 server.properties 中使用 require-resource-pack 时，服务器现在可以选择添加自定义消息。

  • 专用服务器可以配置在资源包提示中显示额外消息（server.properties 中的 resource-pack-prompt，期望使用聊天组件语法，可以包含多行）。
