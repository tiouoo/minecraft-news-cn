鹦鹉螺

  • 鹦鹉螺是全新中立水生生物
  • 生成于所有海洋生物群系
  • 受到挑衅时会使用冲刺攻击
  • 会主动对范围内的河豚发动冲刺攻击
  • 拥有类似骆驼的冲刺技能，按下跳跃键释放
  • 在陆地上会受到窒息伤害
  • 骑乘鹦鹉螺的玩家会获得「鹦鹉螺之息」效果
  • 可以使用河豚或河豚桶驯服、繁殖鹦鹉螺
  • 驯服后的鹦鹉螺：
    • 装上鞍之后可以骑乘
    • 装备鞍：游荡范围限制16格
    • 未装备鞍：游荡范围限制32格

僵尸鹦鹉螺

  • 僵尸鹦鹉螺是全新水下生物，生成时通常搭载手持三叉戟的溺尸骑手
  • 仅当搭载敌对生物骑手时，僵尸鹦鹉螺才具备攻击性
  • 行为模式与普通鹦鹉螺相近，但无法繁殖

鹦鹉螺盔甲

  • 可穿戴在鹦鹉螺与僵尸鹦鹉螺身上
  • 共有铜制、金制、铁制、钻石制、下界合金制五种版本

长矛武器

  • 全新武器，拥有木质、石质、铜制、铁制、金制、钻石制、下界合金制版本
  • 不同材质拥有不同攻击节奏，影响使用速度
  • 存在最低攻击距离，距离目标过近无法造成伤害
  • 最大攻击距离长于其他工具与武器
  • 拥有两种攻击方式：突刺与蓄力冲锋
  • 僵尸、尸壳、僵尸猪灵、猪灵生成时有可能手持长矛

突刺攻击

  • 快速按下左键触发
  • 伤害较低，附带击退效果
  • 攻击存在冷却时间
  • 木质长矛冷却最短，下界合金长矛冷却最长
  • 可以同时击中多个目标
  • 无法破坏方块

蓄力冲锋攻击

  • 长按右键蓄力释放
  • 伤害取决于长矛材质、玩家视角角度、玩家与目标双方移动速度
  • 长按期间攻击分为三个阶段，结束后恢复待机状态：
    • 就绪阶段：满足速度阈值时，可以造成伤害、击退，并且击落目标坐骑
    • 乏力阶段：长矛竖直并抖动。满足速度阈值可造成伤害与击退，但无法击落坐骑
    • 脱力阶段：长矛向下低垂。满足速度阈值仅造成伤害，无击退、无法击落坐骑
  • 生物使用长矛时攻击距离为玩家的一半，但达成伤害、击退、击落坐骑所需的速度阈值更低
  • 僵尸、尸壳、僵尸猪灵掌握长矛蓄力冲锋的攻击方式

突进附魔

  • 长矛专属附魔
  • 仅对突刺攻击生效
  • 使用带有突进附魔的长矛突刺时，会将玩家朝视线方向水平推送
  • 视线保持完全水平时，可以达到最远突进距离
  • 该附魔会大幅消耗长矛耐久

指令

新增指令 stopwatch

  • 可创建秒表，追踪现实流逝时间
  • 秒表计时不依赖游戏刻
  • 仅在服务器/世界运行时计时（世界暂停时依旧计时）

语法：

  • stopwatch <命名空间ID> create — 创建指定ID的秒表
  • stopwatch <命名空间ID> query — 在聊天栏输出该秒表累计秒数
  • stopwatch <命名空间ID> restart — 重置秒表计时
  • stopwatch <命名空间ID> remove — 删除秒表

开发注释：新增此指令是为了替代利用世界边界计时的方案。未来快照中世界边界逻辑将改为基于游戏刻运行。如果你此前依靠世界边界测算真实时间，请迁移至本指令，遇到问题欢迎反馈。感谢大家！

execute 指令

  • 新增语法 /execute if|unless stopwatch <id> <区间>
  • 支持对比指定秒表耗时与浮点区间
    • 计时单位为秒，精度最高1毫秒
    • 示例：/execute if stopwatch foo:bar ..10 run say 秒表foo:bar尚未达到10秒

物品组件

新增 minecraft:use_effects

  • 控制玩家手持物品右键使用时的移动行为
  • 格式为对象，字段：
    • can_sprint：布尔值，使用物品时能否奔跑。默认 false
    • speed_multiplier：浮点数(0~1)，使用物品时移速倍率。默认 0.2
    • 示例：use_effects={can_sprint:true,speed_multiplier:1.0}

新增 minecraft:minimum_attack_charge

  • 设置发动攻击所需最低蓄力进度（攻击指示器）
  • 浮点 0.0~1.0
    • 0.0：无需蓄力
    • 1.0：必须蓄满

新增 minecraft:damage_type

  • 指定该物品造成伤害的类型
  • 字符串，伤害类型标识符
    • 示例：damage_type='minecraft:spear'

新增 minecraft:kinetic_weapon

  • 启用蓄力型攻击（主要供长矛使用），持续使用时每刻沿射线判定伤害，伤害基于双方相对速度
  • 对象字段：
    • min_reach：最小攻击距离（格），默认0.0
    • max_reach：最大攻击距离（格），默认3.0
    • hitbox_margin：碰撞盒判定余量，默认0.3
    • delay_ticks：生效前等待刻数，默认0
    • dismount_conditions、knockback_conditions、damage_conditions：分别控制触发击落坐骑、击退、伤害的条件，内含：
      • max_duration_ticks：延迟结束后条件持续有效最大刻数
      • min_speed：攻击者沿视线方向最低速度（格/秒），可选，默认0.0
      • min_relative_speed：攻击者与目标沿视线方向最低相对速度（格/秒），可选，默认0.0
    • forward_movement：动画中武器向前伸出距离，默认0.0
    • damage_multiplier：相对速度伤害倍率，默认1.0
    • sound：武器就绪时可选音效
    • hit_sound：命中实体可选音效
    • 示例：kinetic_weapon={max_reach:5.0,forward_movement:1.0,delay_ticks:20,damage_conditions:{max_duration:60},knockback_conditions:{max_duration:40},dismount_conditions:{max_duration:20}}
  • 伤害计算公式：floor(相对速度 × 速度倍率)，相对速度为双方速度向量在玩家视线轴上投影差值；附魔与属性加成在该计算之后叠加

新增 minecraft:piercing_weapon

  • 启用快速穿刺攻击，射线击中多个实体（长矛突刺专用）
  • 对象字段：
    • min_reach、max_reach、hitbox_margin 同 kinetic_weapon
    • deals_knockback：是否造成击退，默认true
    • dismounts：是否击落目标坐骑，默认false
    • sound：玩家攻击音效（可选）
    • hit_sound：命中实体音效（可选）
    • 示例：piercing_weapon={min_reach:0,max_reach:4,dismounts:true}

新增 minecraft:swing_animation

  • 对象字段：
    • type：动画ID，可选 none、whack、stab，默认 whack
    • duration：动画持续刻数，默认6
    • 示例：swing_animation={type:'stab',duration:20}

条件判定器

组件判定器

  • 方块、物品、实体判定器内的 predicates 支持检测任意组件是否存在
  • 格式写作 {<组件类型>: {}}，只要组件存在即判定成功，不校验内部数值
  • 原有指定组件内容匹配语法保持不变
  • 示例：
    • {predicates:{written_book_content:{author:"foo"}}} — 原有匹配成书作者写法
    • {predicates:{written_book_content:{}}} — 仅检测成书组件是否存在
    • {predicates:{instrument:{}}} — 检测乐器组件是否存在（旧版本不支持）

实体判定器

flags 判定新增选项：

  • is_in_water：实体接触水或气泡柱时成立

物品判定器

  • 指令物品筛选语法 <物品>[predicate~{...},component={...}] 扩展支持任意组件空判定

  • 原有简写语法保留：*[instrument] 等价于 *[instrument~{}]
