Minecraft 1.20 的预发布版 7 现已在 Minecraft 启动器中提供。此预发布版添加了对符号链接的验证并修复了一个错误。

更改

为了提高安全性，游戏现在会检测世界目录中使用的符号链接。有关详细说明，请查看我们的帮助文章。

  • 如果符号链接的目标不在用户配置的允许列表中，游戏将不会继续加载世界
    • 注意：世界目录本身仍然可以被链接
  • 允许的符号链接目标列表存储在客户端或服务器顶层目录的 allowed_symlinks.txt 文件中
  • 该文件包含条目（每行一个），允许使用以下格式：
    • 以 # 开头的行是注释，将被忽略
    • [type]pattern，其中 type 可以是 glob、regex 或 prefix
      • prefix 匹配路径开头与给定模式匹配（因此对于 /test，路径 /test、/test/ 和 /test/foo.txt 都会匹配）
      • regex 将正则表达式与整个路径匹配
      • glob 使用操作系统特定的路径匹配机制（例如，*.txt 通常匹配具有 txt 扩展名的文件）
      • 注意：路径将使用操作系统特定的分隔符
    • pattern，使用默认的 prefix 类型

1.20 预发布版 7 中修复的错误

  • MC-257778 竹马赛克台阶和楼梯不在 #slabs 和 #stairs 方块及物品标签中
