是时候发布 1.16.4 了！此版本新增了社交互动界面，并修复了一些崩溃问题。

如果你错过了，我们最近宣布 Mojang 账户将迁移到 Microsoft 账户。此版本为此做了准备，让游戏能够识别 Microsoft 账户的设置和屏蔽列表。你可以点击这里了解更多信息，并可在FAQ中找到你可能关心的问题，该 FAQ 将持续更新。

1.16.4 的新特性

  • 名为“社交互动界面”的新 UI
  • 辅助功能选项界面中现在可以找到一个按钮，用于打开辅助功能指南的链接

社交互动界面

多人游戏中新增了一个界面，显示服务器上所有玩家的列表，以便你可以隐藏任意玩家的聊天信息。

  • 可通过可配置的按键绑定打开，默认按键为 P
  • 当你断开服务器连接时，被隐藏的玩家列表会重置

被屏蔽的玩家

  • 使用 Microsoft 账户登录时，账户中屏蔽的玩家现在也会在游戏中被屏蔽，并且账户限制现在会被遵守
  • 被屏蔽玩家的聊天信息将始终隐藏
  • 来自被屏蔽玩家的 Realms 邀请会被隐藏

1.16.4 修复的 Bug

  • MC-192434 下界合金护腿的纹理出现异常
  • MC-199487 世界生成死锁
  • MC-201885 末影龙实体类中的除零错误可能导致服务器崩溃和无限速度
  • MC-202147 社交互动、配方书和铁砧菜单中的光标不会闪烁
