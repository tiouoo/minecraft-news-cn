我们现在发布了快照 23w51a，这是 Minecraft 1.20.5 的首个快照。这个快照为你的宠物狼带来了一份节日礼物——还有犰狳。

刷得开心！

新内容

  • 添加了犰狳、犰狳鳞甲和狼铠

犰狳

  • 犰狳是一种新的被动型生物，具有以下特性：
    • 会周期性地掉落犰狳鳞甲
    • 被刷时会掉落犰狳鳞甲
    • 生成于热带草原
    • 最喜欢的食物是蜘蛛眼

犰狳的蜷缩行为

  • 犰狳在察觉到威胁时会蜷缩起来，例如：
    • 疾跑的玩家
    • 骑乘载具或生物的玩家
    • 亡灵生物
  • 在以下情况下不会蜷缩：
    • 逃跑时
    • 在水中时
    • 在空中时
    • 被拴绳拴住时
  • 当犰狳蜷缩时，它无法行走、无法进食，也不会被食物吸引。
    • 它会继续扫描威胁：如果在 3 秒内未检测到任何威胁，就会展开身体。

犰狳鳞甲

  • 犰狳鳞甲可用于合成狼铠
  • 犰狳会掉落犰狳鳞甲
  • 可以使用发射器为犰狳刷下犰狳鳞甲

狼铠

  • 对成年且已驯服的狼使用狼铠，即可为狼装备上狼铠。
  • 只有狼的主人才能为自己的驯服狼装备狼铠；因此，发射器无法为狼装备狼铠。
  • 狼铠提供的保护效果与钻石马铠相同。
  • 对穿着狼铠的狼使用剪刀，会使其掉落狼铠。
  • 只有狼的主人才可以从狼身上剪下狼铠；因此，发射器无法移除狼身上的狼铠。
  • 如果穿着狼铠的狼死亡，狼铠会掉落。

更改

  • 将海龟身上的鳞甲更名为海龟鳞甲
  • 羊驼和潜影贝不再能摧毁盔甲架

技术性更改

  • 数据包版本现在为 27

数据包 27

  • 羊驼现在使用新的伤害类型 spit，而不是 mob_projectile
  • FactorCalculationData 已从状态效果实例标签中移除
  • 添加了 generic.scale 属性，可用于重新缩放任何生物
  • 玩家触及距离现在可通过 generic.block_interaction_range 和 generic.entity_interaction_range 属性控制
  • 实体无需跳跃即可迈上的最大方块数量现在由 generic.step_height 属性控制

实验性内容

旋风人

  • 添加了新的“旋转”空闲音效
  • 添加了“蓄力攻击”音效
  • 添加了旋风人处于空中时播放的音效
  • 添加了弹射物弹开音效
  • 微调了现有音效

试炼刷怪笼

  • 试炼刷怪笼现在拥有与试炼密室中相同的两个默认战利品表
