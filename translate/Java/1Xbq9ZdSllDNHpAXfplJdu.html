竹子

他们称之为异域风情。其实就是人们所说的“棒极了”。它确实如此，所以我们很高兴将它加入游戏。

  • 可以在丛林和两个新生物群系中找到：竹林和竹林丘陵
  • 最高可生长到 12 到 16 格
  • 撒上骨粉后，竹子会在顶部生长出一到两个竹子方块
  • 用剑击打竹子时会立即破坏
  • 两根竹子可以合成一根木棍
  • 可以作为燃料，烧炼一个物品需要四根竹子
  • 竹子可以放入花盆中
  • 竹子也可以在沉船和丛林神庙中找到

弩

这把武器太可怕，让我们颤抖！

  • 射出的箭基础威力比弓稍强，但耐久度较低
  • 三种独特附魔
  • 有趣且具有挑战性的进度
  • 新的装填机制
  • 独特的装填动画

附魔

  • 为你的弩选择以下三种附魔之一：

多重射击（I）

  • 想一次射出多支箭？不用再找了！有了多重射击，你的弩会把一支箭分成三支，一支照常向前射出，另外两支从侧面呈角度射出！
  • 不能与穿透组合

穿透（I、II、III、IV）

  • 有了这个尖尖的附魔，从弩射出的箭可以穿过生物，一次射击命中多个目标
  • 单支箭能伤害的生物数量等于此附魔的等级 + 1
  • 不能与多重射击组合

快速装填（I、II、III）

  • 快速装填的每一级都会减少弩完全装填所需时间 0.25 秒

装填机制

  • 要装填弩，按住“使用”按钮
  • 当弩弦完全拉回后，松开
  • 砰！你的弩已装填完毕，点击一次“使用”按钮即可射击

NBT 路径

  • 现在可以返回多个值。用作目标时，修改将应用于每个元素
  • 当设置位置且未找到元素时，将创建新的匹配元素：
    • 例如，写入 Items[{Slot:10b}] 要么在 Items 中找到槽位 10 的元素，要么创建新元素
  • 添加 [{k1:v1,k2:v2}] 以匹配列表中具有匹配字段的对象
  • 添加 {k1:v1,k2:v2} 以匹配对象（选择 0 或 1 个元素，主要是为了防止条目不匹配）
    • 注意：这也适用于根对象：{} 是引用根对象的有效路径

以从表中选取的概率通过，按附魔等级索引。

  • chances - 按附魔等级排列的概率列表，从 0 开始索引

这里没什么好惊讶的。

参数

  • thundering - 可选布尔值

新条目

alternatives

测试子条目的条件并执行第一个可以运行的条目。没有权重或质量，但可以有条件。

dynamic

获取特定方块的掉落。目前已实现：

  • minecraft:contents - 方块实体内容，用于潜影盒
  • minecraft:self - 用于旗帜和玩家头颅

group

当自身条件通过时执行子条目。没有权重或质量。

sequence

执行子条目，直到第一个因条件而无法运行的条目。没有权重或质量，但可以有条件。

tag

添加物品标签的内容。字段：

  • name - 标签的 ID
  • expand - 如果为 false，条目将返回标签的所有内容；否则条目将表现为多个物品条目（所有条目具有相同的权重和质量）

新函数

apply_bonus

应用一种预定义的奖励公式。

通用字段
  • enchantment - 用于计算的附魔等级 ID
  • formula - 使用的奖励公式类型
  • parameters - 公式所需的值（取决于类型）
公式（基于现有的时运加成）：
  • binomial_with_bonus_count：
    • 参数：extraRounds : int、probability : float
    • 使用二项分布添加随机值，其中 n <- level + extraRounds 和 p <- probability
  • uniform_bonus_count
    • 参数：bonusMultiplier
    • 使用从 0 到 bonusMultiplier * level 的均匀分布添加随机值
  • ore_drops
    • 无参数
    • 应用公式 count * (max(0, random(0..1) - 1) + 1)

copy_name

将显示名称从方块实体复制到物品（参见附魔台行为）

copy_nbt

将 NBT 从来源复制到物品标签。

参数
  • source - 可以是 this、killer、killer_player 或 block_entity
  • ops - 复制操作列表：
    • source - 来源路径（与 /data 命令相同）
    • target - 目标路径
    • op - replace、append（用于列表）、merge（用于复合标签）

explosion_decay

对每个要被销毁的物品施加固定概率（等于 1/爆炸半径）（堆叠中的物品单独处理）

fill_player_head

将玩家档案信息复制到玩家头颅物品。

参数
  • entity - 档案来源（关于值的说明见实体目标参数的注释，如果不是玩家则不会执行任何操作）。

limit_count

将每个物品堆叠的数量限制在范围内。

参数
  • limit：
    • min - 可选
    • max - 可选

set_contents

用条目中的物品填充 BlockEntityTag.Items（适用于潜影盒、箱子等）。

参数
  • entries - 条目列表（与池中的相同）

set_loot_table

设置 BlockEntityTag.LootTable 和 BlockEntityTag.LootPoolSeed 标签。

参数
  • name - 战利品表的 ID
  • seed - 种子（如果省略或为 0，则不会设置 LootPoolSeed）

set_lore

添加或替换 lore 行。

参数
  • lore - 要添加的行列表（聊天组件格式）
  • replace - 如果为 true，先前的 lore 将被清除
  • entity - 如果存在，将使用所选实体解析名称（关于值的说明见实体目标参数的注释）。
