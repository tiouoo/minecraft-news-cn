啊，一个新鲜出炉的快照！它闻起来无疑比我们刚刚加入的猪灵还要好……

20w07a 中的新特性

  • 末影人现在可以捡起一些新的下界方块
  • 末影人将不再捡起下界岩
  • 为疣猪兽赋予了一些实际功能
  • 添加了猪灵
  • 下界合金块可以用作信标底座，下界合金锭可以用作信标燃料。奇怪的炫耀，但没问题。

进度

  • 怪物猎人和猎取怪物现在需要猪灵和疣猪兽

疣猪兽

  • 疣猪兽是生活在下界绯红森林中的大型攻击性生物
  • 它们一看到玩家就会攻击，所以要小心，它们很容易把你撞下悬崖！
  • 疣猪兽会掉落生猪排，有时还会掉落皮革，但它们可不会心甘情愿
  • 你可以通过喂食绯红菌类来繁殖疣猪兽，但这么做后果自负
  • 疣猪兽有时会被猪灵猎杀，但它们不会轻易倒下！
  • 尽管如此，疣猪兽和猪灵并不是敌人——它们更像是一个生态系统
  • 小疣猪兽喜欢假装自己很厉害——但别担心，它们更像是没有牙齿的生气小狗
  • 想让疣猪兽离你远点？专业提示：疣猪兽讨厌诡异菌类的气味！

猪灵

  • 猪灵是生活在下界的攻击性文明
  • 它们大多待在绯红森林里，但你也有可能在下界荒地找到一些
  • 它们把玩家当作靶子练习，一看到就会攻击
  • 然而，如果你穿着得体，它们会把你视为值得尊敬的人物，至少是可容忍的
  • 猪灵对陌生人很警惕，如果它们看到你打开箱子或挖掘金块，就会认为你在偷东西，并以相应的方式对待你
  • 猪灵非常喜欢黄金，并且会被金制物品分散注意力
  • 金锭是猪灵的货币，你可以向它们扔金锭，或用金锭右键点击它们，以换取各种物品
  • 猪灵有时会饿，会猎杀疣猪兽作为食物。至少它们会尝试这样做。结果……各有不同。
  • 猪灵更喜欢成群结队地狩猎和战斗，一旦打起来，大家都想参与
  • 不知为何来到主世界的猪灵很快会僵尸化
  • 猪灵会被灵魂火和僵尸猪灵吓到，会尽可能保持距离
  • 凋灵骷髅是历史宿敌，猪灵一看到就会攻击
  • 小猪灵不那么危险，但它们很调皮，所以要当心背后
  • ……而且它们喜欢和小疣猪兽一起玩
