星期二是新的星期三，你知道吗？这里是快照 23w04a，在 Update_1_20 实验包中新增了一个实验性的盔甲纹饰锻造功能。

祝你纹饰愉快！

更改

  • 物品和盔甲上的附魔闪光现在更加柔和

实验性功能

  • 新增了盔甲纹饰系统，可让你在视觉上自定义盔甲
  • 新增了锻造模板物品
  • 重新设计了锻造台
  • 更改了下界合金装备的制作方式

锻造模板

  • 锻造台已被重新设计为一个用于装备升级和修改的工作站
  • 除了用于组合一件装备和材料的槽位外，现在还有一个必需的槽位，用于放置名为“锻造模板”的物品类型
  • 锻造模板定义了你将对装备进行何种类型的升级
    • 它既指定了你可以升级哪些类型的物品，也指定了哪些材料是有效的，用于定制升级
    • 目前有两类锻造模板：盔甲纹饰和下界合金升级
  • 锻造模板在锻造台中使用以升级物品时会被消耗
  • 你可以在工作台中使用 7 个钻石 + 1 个模板所对应的材料块 + 1 个锻造模板来合成一个锻造模板的副本，输出 2 个相同的锻造模板

下界合金装备

  • 下界合金装备的制作现在也需要下界合金升级锻造模板
  • 下界合金升级锻造模板可以在所有堡垒遗迹的箱子中随机找到，并且在每个藏宝室堡垒遗迹中保证有 2 个
  • 这一更改是出于多种原因：
    • 增加玩家在下界合金之前使用钻石装备的时间
    • 使下界合金装备成为游戏进程中更重要的成就
    • 让下界合金更自然地融入新的锻造台制作系统

盔甲纹饰

  • 你现在可以在锻造台中使用各种独特的纹饰来在视觉上自定义你的盔甲
    • 除皮革盔甲外，所有盔甲都可以应用纹饰
  • 盔甲纹饰纯粹是视觉上的，没有游戏玩法上的好处，并且只能应用于头盔、胸甲、护腿和靴子
    • 所有纹饰图案在盔甲的物品图标上看起来都是一样的，但颜色仍会根据纹饰材料而变化
    • 若要检查一件盔甲具有哪种纹饰图案，你可以在物品栏中悬停在其上
  • 盔甲纹饰锻造模板可以在世界各地找到，以下每个结构都包含其独特的锻造模板：
    • 掠夺者前哨站
      • 哨兵盔甲纹饰
    • 沙漠神殿
      • 沙丘盔甲纹饰
    • 沉船
      • 海岸盔甲纹饰
    • 丛林神庙
      • 荒野盔甲纹饰
    • 海底神殿
      • 潮汐盔甲纹饰
    • 远古城市
      • 守卫盔甲纹饰
    • 林地府邸
      • 恼鬼盔甲纹饰
    • 下界要塞
      • 肋骨盔甲纹饰
    • 堡垒遗迹
      • 猪鼻盔甲纹饰
    • 要塞
      • 眼眸盔甲纹饰
    • 末地城
      • 尖塔盔甲纹饰
  • 锻造模板可以在其各自结构的箱子中找到，但海底神殿除外。在海底神殿中，远古守卫者有时会在死亡时掉落一个锻造模板，而不是从箱子中找到它
  • 一些盔甲纹饰锻造模板比其他模板更稀有，所以要保持留意，以便用它们给你的朋友留下深刻印象！
  • 盔甲纹饰有两个属性：图案和材料
    • 图案由用于应用纹饰的锻造模板定义，并代表纹饰的视觉图案
    • 材料由你用于应用纹饰的材料定义，并代表纹饰的颜色
  • 你可以用于定义盔甲纹饰颜色的可用材料如下：
    • 铁
    • 铜
    • 金
    • 青金石
    • 绿宝石
    • 钻石
    • 下界合金
    • 红石
    • 紫水晶
    • 石英
  • 盔甲不能应用与其所制材料相同的纹饰材料
    • 例如，金色胸甲不能拥有金色盔甲纹饰

技术性更改

  • 新增了一种图集配置源类型：paletted_permutations

  • 盔甲架在放置和破坏时现在会保留自定义名称

  • 为盔甲纹饰系统新增了一个注册表 trim_pattern

  • 为更新的下界合金升级配方新增了一个配方序列化器 smithing_transform

  • 为新的盔甲纹饰配方新增了一个配方序列化器 smithing_trim

  • 锻造台暂时有两种菜单类型

    • 没有锻造模板槽位的旧菜单已重命名为 legacy_smithing
      • 当盔甲纹饰功能不再是实验性功能时将被移除
    • 新增了带有锻造模板槽位的新菜单，名为 smithing

  • 向 HideFlags NBT 字段添加了新标志（值 128），用于隐藏盔甲纹饰物品的提示文本

Paletted Permutations

  • paletted_permutations 是一种新型的图集配置源，用于根据一组调色板在内存中动态生成新的纹理
  • 调色板允许你替换纹理中的颜色，而无需在资源包中提供纹理变体的所有文件
  • 这对于像盔甲纹饰这样的情况非常有用，你希望能够改变盔甲部分的颜色，而无需为每种颜色创建新纹理
  • paletted_permutations 源具有一组必需的参数：
    • textures：基础纹理的命名空间位置列表
      • 这些纹理将用于生成经过调色板修改的变体
    • palette_key：调色板键文件的命名空间位置
      • 调色板键用于定义我们想要使用下面定义的调色板替换的一组关键像素颜色
    • permutations：从后缀到调色板文件的命名空间位置的排列映射
      • 后缀会附加到输出变体纹理的资源位置的开头，并使用 _ 字符分隔后缀和基础纹理名称
      • 调色板是一个纹理文件，其中包含一组像素，用于替换每个基础纹理中与调色板键匹配的像素
      • 每个调色板中的像素数量必须与为此源定义的 palette_key 的像素数量相同
      • 键匹配通过将 palette_key 中每个像素的 RGB 值与调色板中每个像素的 RGB 值进行比较来完成
      • 键匹配会忽略 Alpha 通道，但在生成的纹理中，Alpha 通道会与调色板的 Alpha 通道相乘
      • 与 palette_key 不匹配的像素会按原样复制到生成的纹理中
  • 在定义了一个 paletted_permutations 源之后，你可以在资源包中的其他资源中引用这些命名空间输出纹理
    • 例如，如果你有以下 paletted_permutations 源：
      {
    "type": "paletted_permutations",
    "textures": [
        "minecraft:item/leather_helmet",
        "minecraft:item/leather_chestplate",
        "minecraft:item/leather_leggings",
        "minecraft:item/leather_boots"
    ],
    "palette_key": "minecraft:colormap/color_palettes/leather_armor_color_key",
    "permutations": {
        "red": "minecraft:colormap/color_palettes/red",
        "green": "minecraft:colormap/color_palettes/green",
        "blue": "minecraft:colormap/color_palettes/blue"
    }
}
    • 然后你可以像这样在其他资源中引用生成的纹理：
      {
    "textures": {
        "layer0": "minecraft:item/leather_helmet_red",
        "layer1": "minecraft:item/leather_chestplate_green",
        "layer2": "minecraft:item/leather_boots_blue"
    }
}

纹饰图案与材料

  • 盔甲的纹饰图案和材料分别由服务器通过 trim_pattern 和 trim_material 注册表定义
    • 因此，可以通过数据包添加新的纹饰图案和材料
  • 这些会在客户端加入服务器时同步到客户端
    • 但是，客户端必须随附资源包才能看到这些注册的纹饰图案和材料
    • 这些纹理的路径是根据图案 json 的文件名推断的，并将尝试在与纹饰图案的 name 字段相同的命名空间中查找纹理
  • 纹饰图案定义以下数据：
    • asset_id：用于推断纹理位置和本地化的命名空间 id
    • template_item：用于应用纹饰图案的锻造模板物品的 id
    • description：一个文本组件，用于在悬停盔甲物品堆叠时显示盔甲纹饰的图案名称
  • 纹饰材料定义以下数据：
    • asset_name：用作盔甲纹饰纹理位置后缀的字符串
    • ingredient：用于应用纹饰材料的材料物品的 id
    • item_model_index：一个浮点数，用于定义每个盔甲物品模型为了更改此材料的视觉效果而应指向的物品模型覆盖
    • incompatible_armor_material：可选 id，指定此纹饰材料无法应用于哪种盔甲材料
    • description：一个文本组件，用于在悬停盔甲物品堆叠时显示盔甲纹饰的材料名称
      • 此描述中定义的样式也会应用于盔甲纹饰图案的 description

命令

  • execute on 新增了关系：origin：
    • 射手，如果执行实体是弹射物（如箭、火球、三叉戟、烟花、投掷药水等）
    • 投掷者，如果执行实体是物品
    • 效果来源，如果执行实体是区域效果云
    • 点燃者，如果执行实体是已点燃的 TNT
    • 召唤者，如果执行实体是唤魔者尖牙或恼鬼
