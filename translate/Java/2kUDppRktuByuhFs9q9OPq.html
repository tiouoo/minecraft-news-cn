自从下界更新以来，猪灵们一直看着玩家偷偷溜进来窥探它们的箱子——好了，再也不会有这种事发生了！在 1.16.2 中，我们引入了猪灵蛮兵——一种专注于守护堡垒遗迹箱子的猪灵，连黄金都无法分散它们的注意力。

1.16.2 中的新特性

辅助功能

新增了两个辅助功能设置，以改善视觉舒适度：

  • 反胃和下界传送门覆盖等扭曲效果现在可以减弱
  • 数值较低时，反胃效果会替换为绿色覆盖层作为替代可视化效果
  • 在应用速度修改器后显示的视野效果现在可以减弱

聊天延迟

  • 聊天设置界面中新增了聊天延迟选项
  • 按下 F3+D 现在会清除待发送的聊天消息

堡垒遗迹

  • 调整了堡垒遗迹箱子的战利品
  • 堡垒遗迹中的箱子现在更可能位于镶金黑石上方

方块

  • 酿造台现在可以用黑石合成
  • 灯笼和灵魂灯笼现在可以含水
  • 绯红菌和诡异菌现在可以放在菌丝上
  • 锁链现在可以以所有方向放置

物品

  • 创造模式物品栏中的工具现在会按材料排序
  • 不死图腾在激活时现在会给予 40 秒的抗火状态效果

生物

  • 末影人不再会将手中的方块放置在基岩上
  • 僵尸疣猪兽现在可以被拴绳拴住
  • 当僵尸猪灵骑着炽足兽生成时，现在会手持诡异菌钓竿
  • 移除了 Herobrine

猪灵

  • 加入了猪灵蛮兵！
  • 猪灵现在会对打开或破坏箱子矿车的玩家发怒
  • 调整了以物易物的战利品

猪灵蛮兵

  • 猪灵蛮兵是猪灵的更强变种，它们生活在堡垒中并守护那里的宝藏
  • 与那些胆小又贪婪的同类不同，猪灵蛮兵不会被黄金分散注意力，而且什么都不怕
  • 猪灵蛮兵一看到玩家就会攻击，无论玩家穿着什么
  • 猪灵蛮兵手持斧头，不需要任何盔甲，因为它们就是这么强悍

重生方块位置

  • 修改了床和重生锚选择重生位置的方式
  • 重生锚会优先选择轴向方向而不是角落
  • 床会优先选择玩家进入床时所在的一侧，然后依次选取围绕床尾到床头的空间
  • 重生的玩家现在会面向其重生位置所在的方块
  • 现在会尽可能避免将玩家放置在危险方块上

村民

  • 村民在加入村庄、设置床铺或获得工作站/职业时现在会发出绿色粒子
  • 村民在改变维度时现在会失去工作站

1.16.2 中的技术性更改

  • 自定义世界现在支持自定义生物群系
  • 告示牌编辑界面现在会从已有文字初始化（对原版应该没有明显影响）
  • 对数据包和资源包选择界面进行了小幅改进
  • 标签现在可以有可选条目

命令

Execute

  • execute in 现在会遵循维度缩放

spawnpoint 和 setworldspawn

添加了一个角度参数，用于设置重生玩家的默认朝向角度。
语法：spawnpoint [<targets>] [<pos>] [<angle>]
语法：setworldspawn [<pos>] [<angle>]
新参数：

  • angle - 以度为单位的浮点角度。支持相对 ~ 修饰符

自定义世界生成

  • 自定义世界生成和维度设置现在与其他资源一样，在数据包中使用相同的文件夹模式（namespace/<type>/resource.json）
  • 数据包中的 worldgen 文件夹现在提供实验性支持
  • worldgen/biome 可以包含生物群系定义
  • worldgen/configured_carver 可以包含世界雕刻器设置的定义
  • worldgen/configured_feature 可以包含地物放置的定义
  • worldgen/configured_structure_feature 可以包含结构放置的定义
  • worldgen/configured_surface_builder 可以包含表面的定义
  • worldgen/noise_settings 现在可以包含噪声配置
  • worldgen/processor_list 可以包含一组方块处理器
  • worldgen/template_pool 可以包含拼图结构的池定义
  • 自定义生物群系现在可以用于单一生物群系/洞穴/浮空岛世界类型（先添加包含该生物群系的数据包）
  • 自定义生物群系现在可以用于自定义维度生成器

专用服务器数据包限制

  • 专用服务器现在可以踢出持续在一秒内发送过多数据包的客户端
  • 通过 server.properties 中的 rate-limit 设置进行控制
  • 默认速率限制为 0 表示“无限制”

包选择界面

  • 当界面打开时，如果包目录内容发生变化，界面会自动更新
  • 两个包选择界面现在都会将 pack.png 的内容显示为包图标

包版本

  • 资源包版本提升至 6

标签

可选条目

标签中的条目现在可以标记为可选。无法解析可选条目不会阻止整个标签加载。
示例：

{
  "replace": false,
  "values": [
    "#minecraft:beds", // existing syntax
    { "id":"#missing:tag", "required": false }, // optional sub-tag entry
    "minecraft:anvil", // existing syntax
    { "id":"minecraft:stone_button", "required": true }, // new syntax for required tags
    { "id":"missing:block", "required": false } // optional single-element entry
  ]
}
