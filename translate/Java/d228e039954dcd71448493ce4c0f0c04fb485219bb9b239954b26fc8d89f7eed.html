时间线

时间线是在数据包中的 timeline 注册表下定义的一个新实验性概念（即位于 data/<namespace>/timeline/<id>.json）。

时间线基于绝对昼夜时间（即由 /time set 设定的时间）指定游戏行为。时间线可以选择指定一个重复周期。

时间线主要能够通过充当环境属性来源来应用环境属性修饰符，从而修改游戏行为或视觉效果。

格式：包含以下字段的对象

  • period_ticks：可选整数，定义时间线重复的 tick 时长
    • 如果未指定，时间线将不会重复
  • tracks：可选的映射，将环境属性 ID 与对应的环境属性轨道对象关联
    • 有关详细信息，请参阅下方的环境属性部分

默认情况下，时间线没有任何效果，除非它们被某个维度包含——请参阅下方的维度类型部分。

引入时间线后，环境属性来源按以下顺序处理（从低优先级到高优先级）：

  • 维度
  • 生物群系
  • 时间线
  • 天气（不可数据驱动）

插值

时间线可以定义属性轨道——它们通过定义关键帧来指定特定环境属性的修饰符如何随时间变化。根据属性不同，每个关键帧之间可能会使用插值。如果不使用插值，则始终选择上一个关键帧的值。

例如，一个周期为 24000 的时间线可能设置如下：

  • 在 time = 0 时，时间线提供 sky_color = #ff0000（红色）
  • 在 time = 1000 时，时间线提供 sky_color = #ff0000（红色）
  • 在 time = 6000 时，时间线提供 sky_color = #ff00ff（品红色）

在 time = 0 和 time = 1000 之间，天空颜色将为红色。在 1000 和 6000 之间，它将从红色过渡到品红色。然后，从 6000 一直到时间线重复并再次到达 time = 0，颜色将缓慢过渡回红色。

注意：与生物群系不同，如果时间线使用修饰符而不是覆盖，插值将应用于修饰符参数，而不是最终修改后的值。

属性轨道

时间线内指定的属性轨道采用具有以下字段的对象格式：

  • ease - 可选的缓动类型（见下文），用于缓和关键帧之间值的插值
    • 默认值：linear
    • 如果目标属性不支持插值，缓动模式将没有效果
  • keyframes - 关键帧对象列表，必须按 ticks 字段排序：
    • ticks - 介于 0 和 period_ticks（如果指定）之间的整数，定义该关键帧值生效的 tick（在周期内）
    • value - 修饰符参数（格式取决于所选的修饰符）
      • 如果未指定 modifier（或使用了 override），此字段的类型与环境属性本身相同
      • 此值的使用方式取决于修饰符的类型
    • 注意：同一 tick 上最多可以放置两个关键帧，以创建即时过渡
  • modifier - 可选的字符串修饰符 ID，取决于属性类型（请参阅下方的常见修饰符部分）
    • 默认值：override

例如，以下时间线的周期为 24000，并具有一个仅修改 minecraft:gameplay/cat_waking_up_gift_chance 的属性轨道。由于缓动为 constant，在 tick 362 和 23667 之间值为 0.0，而在 tick 23667 和 362 之间为 0.7。

与其他环境属性来源一样，指定的值用作指定修饰符的参数。然后将其应用于优先级较低的来源之上。在本例中，修饰符为 maximum，因此此时间线只会将 cat_waking_up_gift_chance 的值增加到轨道中指定的值。

{
    "period_ticks": 24000,
    "tracks": {
        "minecraft:gameplay/cat_waking_up_gift_chance": {
            "ease": "constant",
            "modifier": "maximum",
            "keyframes": [
                { "ticks": 362,   "value": 0.0 },
                { "ticks": 23667, "value": 0.7 }
            ]
        }
    }
}
缓动类型

缓动类型通过应用曲线来控制两个关键帧之间的插值。提供了以下内置缓动类型：

  • constant - 始终选择上一个关键帧
  • linear
  • in_back
  • in_bounce
  • in_circ
  • in_cubic
  • in_elastic
  • in_expo
  • in_quad
  • in_quart
  • in_quint
  • in_sine
  • in_out_back
  • in_out_bounce
  • in_out_circ
  • in_out_cubic
  • in_out_elastic
  • in_out_expo
  • in_out_quad
  • in_out_quart
  • in_out_quint
  • in_out_sine
  • out_back
  • out_bounce
  • out_circ
  • out_cubic
  • out_elastic
  • out_expo
  • out_quad
  • out_quart
  • out_quint
  • out_sine

缓动类型也可以使用三次贝塞尔曲线指定，格式为：{ "cubic_bezier": [ x1, y1, x2, y2 ] }

  • x1：介于 0 和 1 之间的浮点数，第一个控制点的 x 坐标
  • y1：浮点数，第一个控制点的 y 坐标
  • x2：介于 0 和 1 之间的浮点数，第二个控制点的 x 坐标
  • y2：浮点数，第二个控制点的 y 坐标

开发者注：如果想尝试和可视化缓动效果，easings.net 和 cubic-bezier.com 是很棒的参考！

修饰符

  • 添加了 blend_to_gray RGB/ARGB 修饰符——通过取其灰度形式、应用亮度修饰符，并使用某个因子与之混合来修改颜色
    • 其中 gray = brightness * (0.3 * red + 0.59 * green + 0.11 * blue)，result = lerp(factor, subject, [gray, gray, gray])
    • 参数格式：包含以下字段的对象：

      • factor：介于 0 和 1 之间的浮点数，用于混合的因子
