如果您在韩国进行游戏，我们依据游戏法律添加了游戏计时器和提示，以帮助提醒玩家适时休息。更多信息请参见常见问题解答。

22w06a 中的技术性更改

  • 注册表中存在的任何类型（方块、物品、生物群系等）现在都可以拥有标签

通用标签

  • 现在可以为任何注册表（方块、物品、生物群系等）定义标签 - 请参阅报告中的 registries.json
  • 新标签存储在数据包的 tags 目录下（与旧标签相同）
    • 新标签目录的名称与注册表名称相同（因此为 /data/[namespace]/tags/potion 和 /data/[namespace]/tags/worldgen/biome）
    • 现有标签（blocks、items、fluids、entity_types、game_events 和 functions）暂时保留其名称
  • 世界生成结构中的某些字段以前只能接受元素 ID 列表，现在可以接受标签
  • 这些条目现在接受 [id, ...]、id（[id] 的简写）和 #tag
  • 更改的字段如下：
    • feature.glow_lichen 配置：can_be_placed_on
    • feature.spring_feature 配置：valid_blocks
    • feature.simple_random_selector 配置：features
    • block_predicate_type.matching_blocks：blocks
    • block_predicate_type.matching_fluids：fluids
    • biome：features 中的内部列表，carvers 中的映射值
    • biome_source.checkerboard：biomes
  • 某些标签字段现在要求 ID 前加上 #（但它们尚不接受元素列表）
    • dimension_type：infiniburn
    • feature.geode 配置：blocks.cannot_replace、blocks.invalid_blocks
    • feature.vegetation_patch、feature.waterlogged_vegetation_patch 配置：replaceable
    • feature.root_system 配置：root_replaceable
    • structure_processor.protected_blocks：value
