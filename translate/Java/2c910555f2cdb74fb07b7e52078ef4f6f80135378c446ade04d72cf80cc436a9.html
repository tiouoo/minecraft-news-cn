连续发布！昨天发布新版本真是太有趣了，所以我们决定今天也为 Minecraft: Java Edition 1.20.5 再推出一个预发布版。本次更新带来了重要的 Bug 和崩溃修复。

祝挖矿愉快！

技术性更改

  • 数据包版本现为 41

数据包版本 41

  • 将实体类型标签 minecraft:punchable_projectiles 替换为标签 minecraft:redirectable_projectile，用于表示可被玩家攻击和弹射物偏转的弹射物

修复 1.20.5 Pre-Release 3 中的 Bug

  • MC-269384 退出世界时全景图有时会快速旋转
  • MC-270097 当 set_ominous_bottle_amplifier 物品修饰器设置 amplifier 超出范围时崩溃
  • MC-270375 更改渲染距离和生物群系过渡设置时屏幕反复闪烁
  • MC-270608 弹射物不再能够偏转恶魂火球
  • MC-270609 客户端需要在 StoreCookiePacket 和 TransferPacket 之间经过一个 tick，cookie 才能被存储
  • MC-270634 从发射器射出的烟花火箭比之前飞得高得多
  • MC-270668 物品数据序列化速度明显慢于之前
  • MC-270799 自 1.20.5 Pre-Release 2 起，玩家不再能够冲刺/走过一格宽的间隙
