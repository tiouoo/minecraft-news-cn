技术更改

展示实体插值的变化：

  • 插值始终在客户端 tick 的开头开始。
  • 字段 interpolation_start 被替换为 start_interpolation，其含义有所不同。
  • start_interpolation 描述从收到更新后的下一个客户端 tick 开始到插值开始所经过的 tick 数量。
    • 例如，值 0 表示插值将在收到更新后的下一个客户端 tick 开始时开始。
  • start_interpolation 不存储在实体数据中。
    • 当使用 data 命令时，如果插值被更新，但被修改的标签中不存在 start_interpolation，插值将从上一次更新的时间点继续，但使用新值。

修复 1.19.4-rc1 中的漏洞

  • MC-260857 使用初始变换召唤的展示实体在下一次变换期间会从默认变换错误地进行插值。
