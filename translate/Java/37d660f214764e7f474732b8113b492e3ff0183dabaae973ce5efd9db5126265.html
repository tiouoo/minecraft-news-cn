又一个星期二如期而至！我们回到发布室，带来另一个 26.1 快照。正如一位智者曾说过的，这一次是十一档。本周我们专注于打磨和收尾即将推出的游戏掉落功能、技术变更以及漏洞修复。

挖矿愉快！

已知问题

  • 修复了成年和幼年兔子的纹理，使其与其他新纹理保持一致
  • 猪的音效变体现在有了吃食物的声音
  • 幼年山羊现在在冲撞时会旋转头部
  • 幼年猪灵的鬃毛现在出现在身体纹理的两侧
  • 修复了幼年熊猫头部背面的纹理

交易

  • 大师图书管理员不再提供命名牌
  • 大师图书管理员现在会以三个绿宝石的价格提供红色蜡烛和黄色蜡烛
  • 流浪商人现在会以一个绿宝石的价格提供命名牌

声音

  • 更新了音符盒小号的声音资源

技术更改

  • 数据包版本现在为 100
  • 资源包版本现在为 83

数据包版本 100

猪音效变体

现在通过新字段 eat_sound，大型变体音效组支持了进食声音自定义

游戏测试环境

添加了 timeline_attributes 定义，用于设置任意数量的时间轴

  • timelines：要设置的时间轴列表

方块状态

  • 旗帜和告示牌的默认方块状态中的 rotation 属性已从 0 更改为 8

开发者附注：默认方块状态很少使用，最显著的是不带任何属性的 /setblock。此更改是为了使这些方块的默认朝向与其他方块（如头颅或发射器）保持一致

战利品表

  • 从远古城市和林地府邸中移除了命名牌

世界生成

  • 方块状态提供器现在有一个新类型，称为 rule_based_state_provider
    • 这以前是一个单独解析的类型，但现在变成了方块状态提供器的子类型
    • 它们现在可以作为方块状态提供器用于任何其他地物配置，而不再是 disk 地物独有
    • 格式：
      • fallback - 一个可选的方块状态提供器
      • rules - 规则列表
        • if_true - 一个方块谓词，在提供方块之前检查方块位置
        • then - 一个方块状态提供器

标签

方块标签

  • 添加了 #prevents_nearby_leaf_decay，它定义了哪些方块类型可以阻止树叶方块在曼哈顿距离 6 格内腐烂

资源包版本 83

  • 物品模型格式现在支持单个子模型的变换

声音

    • entity.baby_pig.eat
    • entity.pig_mini.eat

    • entity.pig.eat

物品模型

  • minecraft:model、minecraft:special、minecraft:range_dispatch、minecraft:composite、minecraft:select、minecraft:condition 物品模型类型现在具有 transformation 字段
    • 这些字段与 minecraft:display 实体上的 transformation 字段格式相同，即一个由 16 个数字组成的矩阵或包含分解的平移、缩放和旋转信息的结构
    • 对于有子类型的类型（minecraft:range_dispatch、minecraft:composite、minecraft:select、minecraft:condition），变换将与子类型的变换组合，除了 minecraft:bundle/selected_item
    • 模型变换将在物品显示变换之后应用（即模型文件中的 display 部分）
  • 一些特殊物品模型（由 minecraft:special 物品模型引用的类型）的变换已提取到物品模型本身
    • 受影响的特种模型类型：
      • minecraft:bed
      • minecraft:banner
      • minecraft:conduit
      • minecraft:copper_colem_statue
      • minecraft:head
      • minecraft:player_head
      • minecraft:shulker_box
      • minecraft:shield
      • minecraft:trident
      • minecraft:standing_sign
      • minecraft:hanging_sign

minecraft:bell 特殊模型类型

  • 新增特殊模型类型，用于渲染钟方块的动画部分
  • 无字段

minecraft:book 特殊模型类型

  • 新增特殊模型类型，用于渲染一本通常属于附魔台和讲台一部分的书
  • 字段：
    • open_angle - 书封面与书中心线之间的角度（以度为单位）（0 表示合起，90 表示平展打开）
    • page1、page2 - 书内两页的位置
      • 0.0 表示页面在最左侧位置，1.0 表示页面在最右侧位置

minecraft:bed 特殊模型类型

  • 该模型现在只渲染床的一半
  • 要渲染两半，请使用 minecraft:composite 模型
  • 新字段：
    • part - 下列之一：head、foot

minecraft:banner 特殊模型类型

  • 新字段：
    • attachment - 选择要使用的模型，为 wall、ground 之一，默认：ground

minecraft:chest 特殊模型类型

  • 新字段：
    • chest_type - 选择要使用的模型，为 single、left、right 之一，默认：single

minecraft:hanging_sign 特殊模型类型

  • 新字段：
    • attachment - 选择要使用的模型，为 wall、ceiling、ceiling_middle 之一，默认：ceiling_middle

minecraft:standing_sign 特殊模型类型

  • 新字段：
    • attachment - 选择要使用的模型，为 wall、ground 之一，默认：ground

minecraft:shulker_box 特殊模型类型

= 移除了 orientation 字段

方块状态渲染

  • 在末影人手持方块、方块显示实体等地方（但不包括下落方块或活塞），方块状态的渲染方式发生了一些变化
    • 附魔台现在会在方块顶部显示一本合上的书
    • 使用特殊渲染器的方块（如箱子、旗帜、头颅）现在应遵循方块状态属性：
      • 渲染现在遵循 rotation 和 facing 属性（如适用）
      • 床现在根据 part 属性只渲染模型的一半
      • 铜傀儡雕像现在遵循 copper_golem_pose 属性
      • 墙壁和独立式告示牌、悬挂式告示牌、旗帜和头颅/玩家头颅现在将有单独的模型
      • 箱子现在遵循 part 属性（如适用）
    • 注意：一般来说，所有方块状态在方块显示中渲染时，应与在世界中放置时看起来相同，除了：
      • 流体
      • 末地折跃门
      • 末地传送门
