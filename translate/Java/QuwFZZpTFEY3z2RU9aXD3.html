新年新快照 - 我们现已发布 Minecraft 1.20.5 的第三个快照。本次更新带来了犰狳、旋风人的一些改动，以及无障碍功能改进。

除了大量漏洞修复外，我们还对出生点区块的处理方式进行了更改。

出生点区块是主世界中位于世界出生点的一片区域，始终加载在内存中。这对部分玩家很有用，但会占用更多计算机资源，并使游戏加载和运行变慢。（你可以在社区 wiki上了解更多关于出生点区块的信息！）

在本快照中，我们通过添加新的游戏规则 spawnChunkRadius 使出生点区块的大小可配置。新的默认值为 2（即 48x48 方块区域）。这比之前的区域小 98%，将为大多数玩家带来显著的性能提升。

如果你希望出生点区块像以前一样工作，可以使用游戏规则将出生点区块半径值改为 10。这将使你的出生点区块与之前相同，但你会错失性能提升。

我们很乐意听取你对此更改以及新默认设置对你有何影响的反馈。

聊聊出生点区块吧！

新特性

犰狳

犰狳视觉更新！我们收集了第一个犰狳快照的反馈，犰狳、犰狳鳞甲和狼铠的外观下一步调整现已到来。

  • 犰狳现在也会在恶地生成

犰狳蜷缩行为

  • 蜘蛛和洞穴蜘蛛现在会逃离未处于蜷缩状态的犰狳

更改

  • 调整了狼项圈层的纹理，使其与新的狼铠更加一致

无障碍功能

  • 使用 Tab 或方向键导航时，进入或退出任何菜单现在始终会设置默认焦点

技术性更改

  • 数据包版本更新至 28
  • 资源包版本更新至 24
  • 自定义村民交易现在可配置为接受与预期物品标签不同的物品，方法是在交易的 NBT 中添加 ignoreTags: true
  • 当实体离开或进入末地时，到达区域现在会保持加载 15 秒，与下界传送门的行为一致
  • 添加了传送数据包
  • 添加了 Cookie 数据包
  • 减小了出生点区块的默认大小，并使该值可配置

传送数据包

  • 自定义服务器现在可以通过新数据包请求客户端连接到另一台服务器
  • 客户端被传送时，会以新的传送意图（ID 3）连接到目标服务器
  • 默认情况下，服务器不会接受传入的传送请求，并将断开客户端连接
  • 可以通过在 server.properties 文件中将 accepts-transfers 属性设置为 true 来更改此行为
  • 资源包会跨传送保留
  • 在传送的情况下，自定义服务器可以使用新标志跳过身份验证

Cookie 数据包

  • Cookie 数据包允许自定义服务器在客户端上请求和存储数据
    • 每个 Cookie 最大为 5 KiB
    • 可以在登录、配置和游戏阶段请求 Cookie，但仅在配置和游戏阶段存储
  • Cookie 会在服务器传送期间保留，但不会在玩家断开连接时保留
    • 这使得服务器可以将身份验证或自定义游戏数据等信息传递给新服务器

出生点区块更改

  • 出生点区块的大小从半径 10（19x19 实体滴答区块）更改为半径 2（3x3 实体滴答区块）
    • 这样做是为了减少内存使用、加载时间和 CPU 占用
    • 我们选择不完全移除出生点区块，以便目前使用此功能的玩家可以继续使用
  • 添加了新的游戏规则 spawnChunkRadius 来设置出生点区块的大小
    • 可能的值为 0 到 32，其中 0 完全禁用出生点区块，10 等同于此更改前的功能
    • 默认值为 2，等同于 3x3 实体滴答区块

数据包版本 28

  • minecraft:sweeping 附魔已重命名为 minecraft:sweeping_edge
  • 添加了进度触发器 default_block_use，当玩家与方块进行默认交互时触发，例如开门
  • 添加了进度触发器 any_block_use，当玩家与方块进行任何类型的交互时触发，例如在方块上使用物品或默认使用方块

实体类型标签：

  • 添加了 minecraft:ignores_poison_and_regen，用于不受中毒和再生效果影响的实体
  • 添加了 minecraft:illager_friends，用于被灾厄村民视为盟友的实体（除非处于不同队伍）
  • 添加了 minecraft:inverted_healing_and_harm，用于治疗和伤害效果含义相反的实体
  • 添加了 minecraft:not_scary_for_pufferfish，用于不会导致河豚膨胀的实体
  • 添加了 minecraft:sensitive_to_bane_of_arthropods，用于对节肢杀手敏感的实体
  • 添加了 minecraft:sensitive_to_impaling，用于对穿刺敏感的实体
  • 添加了 minecraft:wither_friends，用于凋灵不会攻击且无法伤害凋灵的实体

资源包版本 24

  • ttf 字体提供程序变换已调整，以具有更合理的默认值
    • shift 不再双重应用，现在直接表示游戏 UI 中的像素数
    • 字体 EM 方形现在适配到游戏 UI 中的 size 像素，而不是字体上升部和字体下降部之间
    • 字体基线位置与默认字体一致（行顶下方 7 像素）
    • 这意味着通常，任何具有 size 为 9 且没有 shift 的字体在默认情况下应该看起来正确

实验性特性

旋风人

  • 旋风人现在会偏转所有弹射物
  • 偏转的弹射物现在会朝射击者的方向偏转

交易再平衡

  • 在交易再平衡实验中，购买盔甲的村民现在会忽略耐久度，并且可以购买损坏的盔甲
