在今日激动人心的新快照中，我们带来了更多坐骑——以及更多混乱！认识一下骆驼尸壳，一种在沙漠中繁衍生息的不死被动生物，并直面其敌意骑士！被尸壳骑乘时，骆驼尸壳还会搭载第二个挑战者：一种栖息于沙漠的骷髅，名为“焦渴者”！

伴随这些新威胁的还有对长矛“猛冲”附魔的进一步调整（现在它不那么“饥饿”了！），并且我们赋予马、骡、驴和骆驼在被骑乘时能漂浮在水面上的能力，而此前它们会下沉。

与往常一样，本次更新还带来大量错误修复和技术更新，包括重命名游戏规则使其更具描述性。

祝挖矿愉快！

新特性

  • 更新了进度，纳入骆驼尸壳和焦渴者
  • 添加了新的图形选项“各向异性过滤”

焦渴者

  • 新的骷髅变种
  • 在沙漠中光照等级为 0 的地方生成，取代部分普通骷髅
  • 不会在阳光下自燃
  • 射出虚弱之箭
  • 射速比普通骷髅更慢，类似于沼骸
  • 不会在洞穴中生成，遵循尸壳的生成规则

骆驼尸壳

  • 新的不死骆驼变种
  • 在沙漠中光照等级为 0 的地方生成
  • 不会在阳光下自燃
  • 生成时带有两名骑手：一名手持长矛的尸壳和一名焦渴者
  • 不会在洞穴中生成，遵循尸壳的生成规则
  • 如果骑手是敌对生物，则具有敌对性
  • 没有骑手时被动
  • 像其他敌对生物一样消失，但被玩家骑乘后会变为持久存在
  • 最喜欢的食物是兔子脚
  • 不能被繁殖
  • 作为坐骑，它们的工作方式与普通骆驼相似

长矛武器

猛冲附魔

  • 所有附魔等级下使用猛冲消耗的饥饿点数减少
    • 一级猛冲现在消耗 1 点饥饿值，二级消耗 2 点，三级消耗 3 点（原为 4、5、6 点）
  • 所有附魔等级下使用猛冲现在消耗 1 点耐久度

各向异性过滤

  • 这一新选项可改善方块在远距离或以一定角度观看时的视觉质量
  • 默认值取决于你的图形预设，可选值为“关”、“2 倍”、“4 倍”和“8 倍”
  • 如果你的硬件不支持，则不会使用该选项
  • 这会显著影响显存占用（尤其是在配合较高的 mipmap 级别时）

更改

  • 鹦鹉现在可以模仿僵尸鹦鹉螺、僵尸马、骆驼尸壳和焦渴者的声音
  • 鹦鹉螺和僵尸鹦鹉螺现在如果被某个生物激怒，可以攻击该生物，而不仅仅是玩家
  • 下界的环境雾不再依赖渲染距离设置，将持续应用于 10 到 96 格范围内
  • 马、骡、驴和骆驼在被玩家骑乘时不再沉入水中
  • 区块现在会淡入而不是突然出现，淡入时间可通过视频设置调整
  • 蝙蝠在 10 月 20 日至 11 月 3 日期间不再以更高频率和更高光照等级生成

用户界面

  • 视频设置屏幕中的“界面”已重命名为“偏好设置”
  • 单一生物群系自定义屏幕现在有搜索框
  • 语言选择屏幕现在有搜索框以筛选语言

新增 minecraft:fire_spread_radius_around_player

  • 控制火焰可以在玩家周围蔓延的最大距离（以格为单位）
    • 这取代了之前的 doFireTick 和 allowFireTicksAwayFromPlayer 游戏规则，这些规则现已移除
    • 将其设为 0 将禁用火焰蔓延
    • 将其设为 -1 将允许在周围没有玩家时火焰蔓延
    • 限制：最小值 -1

新增 minecraft:visual/cloud_color

云的颜色。如果完全透明，云将完全禁用，并且快乐恶魂在云层高度时将不会更快地恢复生命值。

  • 值类型：ARGB 颜色

  • 可插值：是

槽位来源

  • 新增了槽位来源，允许在数据包中指定任何物品栏槽位的位置
  • 格式：包含字段的对象
    • type：槽位来源类型
    • <type-specific>：取决于类型的附加字段

minecraft:empty 类型

  • 不包含任何槽位的空选择

minecraft:group 类型

  • 将多个槽位来源合并为一个，结果选择包含所提供每个槽位来源的所有槽位
    • 如果一个槽位包含在多个槽位来源中，它将在结果槽位来源中重复
    • 例如 [a, b] + [c, a] -> [a, b, c, a]
  • 格式：
    • terms：要连接的槽位来源列表
  • 也可以内联写为槽位来源列表

minecraft:slot_range 类型

  • 从实体或方块实体的物品栏中选择一个槽位范围内的槽位
  • 镜像了 /item 命令的 from 参数的行为
  • 格式：
    • source：槽位来源，来自战利品上下文的实体或方块实体
      • 可以是 block_entity、this、attacking_entity、last_damage_player、direct_attacker、target_entity 或 interacting_entity
    • slots：一个槽位范围，格式为 <slot_type> 或 <slot_type>.<slot_number>（例如 armor.chest 或 container.*）

minecraft:contents 类型

  • 从一个或多个物品的物品栏组件中选择所有非空槽位
    • 如果该组件中没有存储任何物品，则结果选择将为空
    • 其物品栏组件要使用的物品位置由另一个槽位来源指定
    • 如果槽位来源包含多个具有该组件的物品，结果选择将像 minecraft:group 类型一样合并
    • 例如 Bundle [a, b] + Shulker Box [c, d] -> [a, b, c, d]
  • 格式：
    • component：要定位的物品栏组件
      • 允许的值为 minecraft:bundle_contents、minecraft:charged_projectiles 和 minecraft:container
    • slot_source：包含带有要定位物品槽位的槽位来源

minecraft:filtered 类型

  • 对所选槽位应用过滤器，从结果选择中排除任何不匹配的槽位
  • 格式：
    • item_filter：用于匹配每个槽位中物品的物品谓词
    • slot_source：要过滤的槽位来源

minecraft:limit_slots 类型

  • 限制提供的槽位数量，结果选择最多包含该数量的槽位
    • 任何使槽位数量超过该限制的槽位将按包含顺序被排除
    • 例如，如果限制设为 3，则 [a, b, c, d] -> [a, b, c]
  • 格式：
    • limit：整数，结果选择中要包含的最大槽位数
    • slot_source：要限制的槽位来源

示例槽位来源，从实体的快捷栏和盔甲槽位中选择所有物品数量超过 16 的槽位：

{
    "type": "minecraft:filtered",
    "item_filter": {
        "count": {
            "min": 16
        }
    },
    "slot_source": [
        {
            "type": "minecraft:slot_range",
            "source": "this",
            "slots": "hotbar.*"
        },
        {
            "type": "minecraft:slot_range",
            "source": "this",
            "slots": "armor.*"
        }
    ]
}
