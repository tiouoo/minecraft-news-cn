我们现在发布了 Minecraft 1.19.4 的第一个预发布版。此预发布版包含一个新的高对比度辅助功能设置、对创建世界选项卡界面的一些更新、一个新的 execute 子命令、对启动性能的改进，以及大量漏洞修复！

在 1.19.4 的剩余开发周期中，你应该会看到大部分是漏洞修复。此外，预发布版不会遵循常规的每周三发布快照的节奏，所以请留意下一个预发布版。

挖矿愉快！

重要提示

  • 在之前的快照（23w07a）中创建的实验性 1.20 世界无法再在此版本中打开

更改

  • 物品栏中物品的附魔闪光现在更加明显
  • “闪光强度”设置的默认值已降低至 75%
  • 药水不再有附魔闪光，因为它会掩盖药水内容的颜色
  • 为 Realms 添加了一个通知系统，用于告知你关于你的 Realm 的重要信息

辅助功能

  • 添加了一个内置资源包，可增强 UI 元素的对比度
    • 该资源包可以在辅助功能选项界面中启用，也可以手动在资源包界面中启用
    • 目前这仅在菜单中可用，但我们未来也会考虑将其带到游戏内界面中

更新后的创建新世界界面

  • 创建新世界界面中的选项卡栏外观已更新
    • 选项卡现在拥有独特的视觉效果，而不是传统的按钮
    • 选项卡现在对齐到屏幕中央
    • 内容已对齐到屏幕顶部

技术性更改

  • 资源包版本现在是 13
  • 更改了以下游戏事件：
    • item_interact_finish 现在的振动频率为 2，而不是 14
  • 新伤害类型标签：bypasses_cooldown - 具有此标签的伤害类型将绕过受到伤害后的常规无敌时间
  • 新实体类型标签：fall_damage_immune - 具有此标签的实体类型不会受到坠落伤害

资源包格式

  • 附魔闪光现在有两个独立的纹理文件：enchanted_glint_entity.png 和 enchanted_glint_item.png

命令

execute positioned over

新的 execute 子命令，用于查找高度图顶部的位置。将执行位置的高度更改为指定高度图顶部。语法：

  • execute positioned over <heightmap>
高度图

高度图根据某些标准记录一列方块中的最高位置。可用选项：

  • world_surface：任何非空气方块
  • motion_blocking：任何阻挡运动的材料（例如忽略花和草）
  • motion_blocking_no_leaves：任何非树叶的阻挡运动材料
  • ocean_floor：任何非流体的阻挡运动材料

实验性功能的更改

  • 刷子的合成配方现在使用羽毛、铜锭和木棍垂直排列
  • 嗅探兽刷怪蛋的颜色已更新
  • 由全部砖块制成的饰纹陶罐的配方现在可以在配方书中找到
