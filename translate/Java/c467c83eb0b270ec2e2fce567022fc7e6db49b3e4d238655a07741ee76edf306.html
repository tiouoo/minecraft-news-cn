看起来这个快照已经到了不能等到星期二的程度！它提前一天到来，为领域带来了新的自定义选项。所有者现在可以将渲染距离提高到最多 25 个区块，并分别配置渲染距离和模拟距离，以找到最适合其世界的平衡点。

除了这些变化，我们还加入了不少技术性改进和错误修复。

挖矿愉快！

新特性

领域

  • 在领域配置设置中添加了渲染距离和模拟距离滑块

方块、物品与实体的调整

  • 末影人若骑乘在物体上，现在会受到弹射物伤害
  • 末影人和潜影贝不再传送到基岩上

UI

  • 在 macOS 上，在“控制”设置中增加了“模拟右键点击”选项，该选项将 Ctrl + 左键视为右键点击
    • 默认为关闭

技术更改

  • 数据包版本目前为 117.0

数据包版本 117.0

进度

验证

  • 可见的根进度（即具有 display 字段但没有 parent 字段的进度）必须始终在 display 结构中声明 background 字段
  • 只有根进度可以在 display 结构中具有 background 字段

插槽来源

更改：minecraft:group

  • 只能在顶层文件中使用内联定义

战利品函数

更改：minecraft:sequence

  • 只能在顶层文件中使用内联定义

数字提供器

更改：minecraft:sum

  • 将 summands 字段重命名为 operands，现在它可以接受内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或一个带哈希前缀的 minecraft:number_provider 类型的标签 ID
  • 现在至少需要一个操作数
  • 在整数模式下使用时，中间步骤也使用整数模式

添加：minecraft:product

  • 字段：
    • operands - 以数字列表为内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或一个带哈希前缀的 minecraft:number_provider 类型的标签ID
  • 返回操作数的乘积，即将它们全部相乘
  • 至少需要一个操作数

添加：minecraft:minimum

  • 字段：
    • operands - 以一个内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表或一个带哈希前缀的 minecraft:number_provider 类型的标签 ID
  • 返回操作数中的最小值
  • 需要至少一个操作数

添加：minecraft:maximum

  • 字段：
    • operands - 以一个内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表或一个带哈希前缀的 minecraft:number_provider 类型的标签 ID
  • 返回操作数中的最大值
  • 需要至少一个操作数

添加：minecraft:average

  • 字段：
    • operands - 以一个内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表或一个带哈希前缀的 minecraft:number_provider 类型的标签 ID
  • 返回操作数的平均值
  • 需要至少一个操作数

标签

方块标签

  • 添加了 #uncarvable - 雕刻器无法雕刻的方块
  • 添加了 #dangerous_for_teleportation - 定义传送到其上危险的方块的集合标签
  • 添加了 #cat_does_not_teleport_to - 猫不会传送到这些方块
  • 添加了 #enderman_does_not_teleport_to - 末影人不会传送到这些方块
  • 添加了 #shulker_does_not_teleport_to - 用于末影贝不会传送到的方块
  • 添加了 #consumable_does_not_teleport_to - 生物在食用随机传送食物时不会传送到的方块
    • 默认为空

物品标签

  • 添加了 #brewing_potion_inputs - 可以放置在酿造台药水槽中的物品，无论它们是否是酿造配方的输入

药水标签

  • 添加了 #douses_fire - 碰撞到物体时能扑灭火焰的方块药水
  • 添加了 #hurts_water_sensitive_entities - 对水敏感实体（如末影人）造成伤害的药水
  • 添加了 #extinguishes_entities - 可以灭火的实体药水
  • 添加了 #rehydrates_axolotls - 会使美西螈补充水分的药水
