绵羊在温暖和寒冷生物群系中的毛色

  • 绵羊现在根据其生成的生物群系，拥有更新后的毛色规则：
    • 温带生物群系：（这些颜色与当前行为一致，没有变化）
      • 常见绵羊毛色为白色
      • 不常见绵羊毛色为黑色、灰色、淡灰色和棕色
      • 有极小概率生成粉色绵羊
    • 寒冷生物群系：
      • 常见绵羊毛色为黑色
      • 不常见绵羊毛色为淡灰色、淡蓝色、蓝色和青色
      • 有极小概率生成粉色绵羊
    • 温暖生物群系：
      • 常见绵羊毛色为棕色
      • 不常见绵羊毛色为灰色、黄色、橙色和红色
      • 有极小概率生成粉色绵羊

着色器与后期处理效果

开发者注释：虽然在资源包中可以覆盖核心着色器，但这被视为不受支持的功能，并非资源包的预期用途。这些着色器作为游戏内部实现的一部分存在，因此随着游戏内部的演变，它们可能随时发生变化。我们理解覆盖核心着色器被用于实现非常酷炫的资源包功能，其中许多功能缺乏受支持的替代方案。我们希望在将来提供更好、受支持的替代方案。

  • 核心着色器和后期处理效果的着色器程序定义（JSON 文件）已被移除
  • 着色器程序本身仍然可用，并且可以被覆盖
  • 后期处理效果仍然可以作为 JSON 进行配置

后期处理效果定义

  • program 字段已被 vertex_shader 和 fragment_shader 取代
    • <namespace>:<path> 将解析为 assets/<namespace>/shaders/<path>.<vsh|fsh>
  • type 现在是每个 uniform 的必填字段
    • 目前可能的值有 int、ivec3、float、vec2、vec3、vec4、matrix4
  • 每个 uniform 中的 values 现在为可选
    • 不建议将其留空，它用于模糊效果的运行时配置
  • 未指定 uniform 会导致未定义行为，你必须指定着色器将使用的每一个 uniform

物品渲染

物品展示实体

  • firstperson_lefthand 和 thirdperson_lefthand 变换现在与手持时的渲染效果相同

物品实体

  • 在地面上时，确定悬浮运动现在会考虑模型大小
    • 这意味着无论模型大小如何，模型都不应再穿入下方的方块
  • 地面上物品堆叠中物品的位置现在取决于模型大小和模型类型
    • 如果模型深度（Z坐标）小于方块的1/16，物品将渲染为扁平的物品堆叠
    • 否则，模型将渲染为围绕中心向各个方向偏移的物品簇
    • 之前，扁平堆叠渲染仅适用于具有 builtin/generated 父级的模型
