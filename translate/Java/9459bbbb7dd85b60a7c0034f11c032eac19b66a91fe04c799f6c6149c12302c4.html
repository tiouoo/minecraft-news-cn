26.3 的第一个预发布版来了！这里有技术性更改，但我们现在主要是在修复漏洞、进行改进，并在发布前完成最后的润色。

祝挖矿愉快！

更改

界面

  • 在 macOS 上，独占全屏模式现已重新可用
  • 在 macOS 上，视频设置中新增了“菜单栏/Dock 可见性”选项，用于控制在全屏模式下将鼠标移动到屏幕边缘时是否显示 macOS 菜单栏和 Dock
  • 光标现已被限制在独占全屏模式下的窗口内

技术性更改

  • 数据包版本现为 119.0
  • 资源包版本现为 97.1

数据包版本 119.0

  • minecraft:number_provider 和 minecraft:number_provider_type 注册表已拆分为独立的整数计算（minecraft:context_int_provider、minecraft:context_int_provider_type）和浮点数计算（minecraft:context_float_provider、minecraft:context_float_provider_type）注册表

数字提供器

数字提供器的类型和值已被拆分为两个独立的注册表：minecraft:context_int_provider 和 minecraft:context_float_provider，以避免因混用浮点数和整数运算而导致精度和范围意外丢失

注意：这些新类型不应与已有的 minecraft:int_provider_type 和 minecraft:float_provider_type 混淆，后者是无上下文的提供器，主要用于世界生成

以下数字提供器类型已被拆分为整数和浮点数变体：

  • minecraft:constant
  • minecraft:uniform
  • minecraft:storage
  • minecraft:sum（已重命名为 minecraft:add）
  • minecraft:product（已重命名为 minecraft:mul）
  • minecraft:minimum（已重命名为 minecraft:min）
  • minecraft:maximum（已重命名为 minecraft:max）
  • minecraft:average（已重命名为 minecraft:avg）
