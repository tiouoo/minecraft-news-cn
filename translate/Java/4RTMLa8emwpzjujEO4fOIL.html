创造模式物品栏更改

为回应反馈，我们对创造标签页的排序进行了（希望是）最后一轮更改：

  • 如果拥有所需权限，现在可以在红石方块标签页中找到仅限操作员的方块和物品
  • 功能方块
    • 新增：
      • 遮光玻璃
      • 蜂巢
    • 将重生锚移至床之前
    • 按功能重新排序压力板
    • 将末地传送门框架和虫蚀方块从自然方块标签页移至本标签页
  • 红石方块
    • 新增：
      • 箱子
      • 木桶
      • 炼药锅
      • 熔炉
      • 堆肥桶
  • 建筑方块
    • 新增：
      • 锁链
      • 紫水晶块
    • 将红石块和煤炭块从自然方块标签页移至本标签页
  • 合成
    • 新增：
      • 远古残骸
  • 为保持一致性，重新排序了以下标签页
    • 建筑方块
    • 自然方块
    • 消耗品
  • 重新排序了矿物材料与方块，使其在各标签页间更一致

刷怪笼

  • 玩家放置刷怪笼时，不再有默认的生物生成类型（此前为猪）
  • 未定义生物生成类型时不再发出火焰粒子
  • 更名为“刷怪笼”以匹配基岩版，并移除了紫色文字颜色
  • 现在可对刷怪笼使用选取方块功能
  • 现在刷怪笼物品堆的悬停描述中会显示生物类型
    • 如果尚未定义生物类型，悬停描述将说明如何设置它

刷怪蛋

  • 在创造模式中新增了末影龙、铁傀儡、雪傀儡和凋灵的刷怪蛋物品
    • 末影龙和凋灵刷怪蛋只能通过命令获得，以防止意外破坏玩家的建筑
  • 北极熊刷怪蛋的颜色已更改，以与恶魂刷怪蛋区分

游戏规则

  • 新增了 blockExplosionDropDecay、mobExplosionDropDecay 和 tntExplosionDropDecay 游戏规则
    • 设为 false 时，所有方块都会掉落战利品
    • 设为 true 时，方块会根据与爆炸中心的距离随机掉落战利品
    • TNT 默认为 false，方块和生物默认为 true
  • 新增了 snowAccumulationHeight 游戏规则
    • 下雪时，该游戏规则决定每个方块中可累积的雪层的最大数量
    • 默认为 1
    • 设为 0 将完全不会形成雪
    • 设为 8 或以上可让雪累积到完整方块的高度
  • 新增了 waterSourceConversion 和 lavaSourceConversion 游戏规则
    • 设为 true 时，允许形成该流体的新源方块
    • 水默认为 true，熔岩默认为 false
  • 新增了 globalSoundEvents 游戏规则，用于控制某些游戏事件是否会被所有玩家听到，无论其位置如何
    • 默认为 true
