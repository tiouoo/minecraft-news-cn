世界时钟

世界时钟包含一个每刻增加的内部时间。它们可以在数据包中的 world_clock 注册表下定义（位于 data/<namespace>/world_clock/<id>.json）

  • 世界时钟可以暂停或恢复，时钟的时间可以通过 time 命令更改或查询
  • 格式：无字段对象

时间线

  • 添加了 clock 字段：世界时钟 ID，指定时间线所绑定的世界时钟
    • 此字段为必填项，但为了匹配之前的行为，可以使用 minecraft:overworld 时钟
  • 添加了可选的 time_markers 字段，一个介于带命名空间的时刻标记 ID 与整数或时刻标记对象之间的可选映射，
    • 格式：
      • 非负整数，即时刻标记所标记的刻
      • 或包含字段的对象：
        • ticks - 0 到 period_ticks 之间的整数，即时刻标记所标记的刻
        • show_in_commands - 可选布尔值，指定时刻标记是否显示在命令建议中
          • 默认值：false

时刻标记

时刻标记为特定世界时钟的特定（可选循环）时间点指定一个名称。时刻标记取代了之前 /time set 可使用的预定名称，例如 day 或 night。

时刻标记将存在于特定世界时钟的上下文中。这意味着即使不同的时刻标记由不同的时间线定义，对于特定世界时钟，也只能存在一个具有特定 ID 的时刻标记。这也意味着两个世界时钟可以具有同名的时刻标记。

时刻标记的内置用途

一些时刻标记用于驱动原版游戏行为。通常，它们被配置为不显示在 /time 命令中。

  • minecraft:wake_up_from_sleep - 将维度默认时钟推进到该维度玩家睡醒后的时间
  • minecraft:roll_village_siege - 维度默认时钟的时间，在该时间点应评估僵尸村庄围攻发生的随机概率

环境属性

新增 minecraft:visual/block_light_tint

方块光的色调。方块光颜色在低亮度时从深灰色开始，在中亮度时被此属性着色，在高亮度时变为白色。默认情况下，它提供火把的黄色调。亮色最适合此属性，至少需要一种颜色分量完全明亮。该色调全局应用于屏幕上所有可见光源。单个光源不能有不同色调。

  • 值类型：RGB 颜色
  • 默认值：#FFD88C
  • 修饰器：RGB 颜色修饰器
  • 插值：是
  • 在相机位置解析

新增 minecraft:visual/ambient_light_color

定义环境光的色调和亮度。此光以 0 亮度应用于世界。方块光和天空光在其之上添加。

  • 值类型：RGB 颜色
  • 默认值：主世界为 #0A0A0A，下界为 #302821，末地为 #3f473f
  • 修饰器：RGB 颜色修饰器
  • 插值：是

数据驱动的村民交易

村民和流浪商人提供的交易现在由数据驱动，数据包开发者可以自定义

村民交易

  • 位于 villager_trade 文件夹中，代表交易蓝图，村民和流浪商人使用它生成实际交易
  • 条目格式：
    • wants - 对象，表示交易所需的物品类型和数量
      • id - 字符串，物品的 ID
      • count - 可选数字提供器，交易所需的物品数量
        • 默认为常量 1
      • components - 可选组件映射，物品上预期的数据组件
        • 默认为空映射
    • additional_wants - 可选对象，商人所需的额外物品，格式与 wants 相同
    • gives - 物品堆叠，交易时商人给予的最终物品
      • 使用现有的物品堆叠格式
    • given_item_modifiers - 可选物品修饰器列表，应用于 gives 中物品的修饰器，如附魔或药水，用于为交易增加动态性，而非硬编码特定值
      • 使用现有的物品修饰器格式（也称为战利品修饰器、物品函数、战利品函数等）
      • 如果其中任何一个返回空物品，整个交易将被丢弃
      • 尚不支持物品修饰器引用
      • 如果最终物品的 stored_enchantment 组件包含 #double_trade_price 标签中的附魔，则 wants 的数量将加倍
    • max_uses - 可选数字提供器，交易最大可使用次数
      • 如果数字提供器返回较低值，则设置为 1
      • 默认为常量 4
    • reputation_discount - 数字提供器，需求、折扣或惩罚等因素影响 wants 所代表成本的程度
      • 如果数字提供器返回较低值，则设置为 0.0
      • 默认为常量 0.0
    • xp - 可选数字提供器，交易完成时商人获得的经验值数量
      • 如果数字提供器返回较低值，则设置为 0
      • 默认为常量 1
    • merchant_predicate - 谓词，提供交易前商人需要满足的条件
      • 使用现有的谓词格式（也称为战利品条件）
      • 尚不支持谓词引用
    • double_trade_price_enchantments - 可选附魔 ID、带命名空间的附魔 ID 列表或带哈希前缀的附魔标签，表示当 minecraft:enchant_randomly 和 minecraft:enchant_with_levels 将 include_additional_cost_component 设为 true，且物品的 minecraft:stored_enchantments 组件中包含提供的值之一时，将使额外成本加倍的附魔

`time` 的更改

  • time 命令现在基于世界时钟
    • 可以可选地使用 time of <clock> ... 为 time 命令指定时钟作为输入
    • 如果未指定时钟（如之前的 /time ...），则使用维度的默认时钟
  • set 和 add 子命令的返回值（例如来自 /execute store）现在是时钟的总经过刻数，而不是当前时间
  • 此外还新增了 rate 子命令，可以修改世界时钟前进的速度

语法：

  • time [of <clock>] set <time> - 设置时钟的总经过刻数
  • time [of <clock>] set <timemarker> - 将时钟向前推进到时刻标记的下一次出现
    • 对于 minecraft:overworld 时钟，可用的时刻标记为：day、noon、night 和 midnight
  • time [of <clock>] add <time> - 向时钟添加刻数，可以是负数或正数
  • time [of <clock>] pause - 暂停时钟
  • time [of <clock>] resume - 恢复时钟
  • time [of <clock>] rate <rate> - 设置时钟前进的速率倍率
    • 注意：这只会改变世界时钟及其依赖的任何时间线推进内部计时器的速率
      • 例如，对于 minecraft:overworld 时钟，较大的值会使昼夜循环更快，但实际游戏模拟不会加速（如同 /tick rate 那样）
    • rate 为 1 对应正常速度
    • rate 是 0（不含）到 1000（含）之间的浮点数
  • time [of <clock>] query <timeline> - 显示并返回时间线周期内的当前刻数
  • time [of <clock>] query <timeline> repetitions - 显示并返回时间线周期已重复的次数
  • time [of <clock>] query time - 显示并返回时钟的总经过刻数
  • time query gametime - 与之前一样，世界内总经过刻数（不受使用 /time 对时钟所做更改的影响）

  • selector 字段不再接受选择器后的尾随数据

minecraft:nbt

  • 当 interpret 字段设为 false 时，使用 minecraft:nbt 文本组件解析的标签现在会美观打印，而不是被展平为单个 text 组件
  • nbt 和 block 字段的内容在解析失败时不再被静默拒绝
  • entity 字段不再接受选择器后的尾随数据
  • 新增了一个名为 plain 的选项，用于移除美观打印文本的样式
    • plain 和 interpret 选项不能同时启用

minecraft:object

  • 新增了一个名为 fallback 的可选字段，包含在对象组件本身无法显示时使用的文本组件（例如在服务器日志中打印消息或进行叙述时）
  • player 类型的对象（玩家头颅）不能再用于服务器状态消息 (MotD) 中
    • 该类型的所有组件都将被回退文本替换
    • 嵌套超过 16 次的组件将被丢弃并替换为省略号

资源包版本 75 到 84

  • 绊线纹理现在以 alpha 裁剪方式渲染，而不是透明
  • 发光鱿鱼、避雷针以及上蜡、脱蜡和刮蜡的方块发出的发光粒子现在以不透明方式渲染，因为它们实际上从未使用过半透明
  • 移除了 demo_background.png，改用 popup/background.png 精灵图
  • 物品模型格式现在支持单个子模型的变换

方块状态渲染

  • 对方块状态在某些地方的渲染方式做了一些更改，例如末影人手持的方块、展示方块实体等（但不包括下落的方块或活塞）
    • 附魔台现在会在方块顶部显示一本合上的书
    • 使用特殊渲染器的方块（如箱子、横幅、头颅）现在应遵循方块状态属性：
      • 渲染现在遵循 rotation 和 facing 属性（如适用）
      • 床现在仅根据 part 属性渲染模型的一半
      • 铜傀儡雕像现在会遵循 copper_golem_pose 属性
      • 墙壁和独立的告示牌、悬挂式告示牌、横幅以及头颅/头现在具有单独的模型
      • 箱子现在遵循 part 属性（如适用）
    • 注意：通常，所有方块状态在展示方块实体上渲染时与在世界中放置时看起来应该相同，流体除外

方块模型格式

  • 任何方块模型现在都可以支持裁剪或半透明（部分透明像素）纹理
    • 四边形是在裁剪还是半透明渲染通道中渲染，取决于其分配精灵图的内容
      • 任何具有半透明（部分透明）像素的精灵图将被分配至“半透明”通道
      • 任何具有完全透明像素的精灵图将被分配至“裁剪”通道
      • 所有其他精灵图被分配至“不透明”通道
    • 注意：分配的渲染通道也意味着渲染顺序：所有不透明几何体先于所有裁剪几何体渲染，而裁剪几何体先于所有半透明几何体渲染
  • textures 映射的格式已更新：
    • 非字符串条目现在将被拒绝，而不是解释为字符串
    • 除了之前的内联精灵图 ID 形式外，条目现在可以定义为包含字段的对象：
      • sprite - 精灵图 ID
      • force_translucent - 可选布尔值，如果具有此纹理的任何几何体应强制进入“半透明”通道，则为 true
        • 例如，这对于没有任何半透明像素但使用 mean mipmap 策略的方块很有用
        • 默认：false

物品模型

  • minecraft:model、minecraft:special、minecraft:range_dispatch、minecraft:composite、minecraft:select、minecraft:condition 物品模型类型现在具有 transformation 字段
    • 该字段与 minecraft:display 实体上的 transformation 字段格式相同，即可以是表示矩阵的 16 个数字数组，也可以是包含分解位移、缩放和旋转信息的结构
    • 对于具有子模型的类型（minecraft:range_dispatch、minecraft:composite、minecraft:select、minecraft:condition），变换将与子模型的变换组合，minecraft:bundle/selected_item 除外
    • 模型变换将在物品展示变换（即模型文件中的 display 部分）之后应用
  • 一些特殊物品模型（由 minecraft:special 物品模型引用的类型）的变换已提取到物品模型本身
    • 受影响的特殊模型类型：
      • minecraft:bed
      • minecraft:banner
      • minecraft:conduit
      • minecraft:copper_golem_statue
      • minecraft:head
      • minecraft:player_head
      • minecraft:shulker_box
      • minecraft:shield
      • minecraft:trident
      • minecraft:standing_sign
      • minecraft:hanging_sign

minecraft:bell 特殊模型类型

  • 新的特殊模型类型，渲染钟方块的动画部分
  • 无字段

minecraft:book 特殊模型类型

  • 新的特殊模型类型，渲染通常属于附魔台和讲台的书
  • 字段：
    • open_angle - 浮点数，书封面与书中心线之间的角度（度）（0 表示合上，90 表示完全打开）
    • page1、page2 - 0.0 到 1.0 之间的浮点数，书内两页的位置
      • 0.0 表示页面在最左侧位置，1.0 表示页面在最右侧位置

minecraft:bed 特殊模型类型

  • 模型现在仅渲染床的一半
  • 要渲染两半，请使用 minecraft:composite 模型
  • 新字段：
    • part - 字符串，head 或 foot 之一

minecraft:banner 特殊模型类型

  • 新字段：
    • attachment - 可选字符串，选择要使用的模型，wall 或 ground 之一
      • 如果未提供，默认为 ground

minecraft:chest 特殊模型类型

  • 新字段：
    • chest_type - 可选字符串，选择要使用的模型，single、left 或 right 之一
      • 如果未提供，默认为 single

minecraft:hanging_sign 特殊模型类型

  • 新字段：
    • attachment - 可选字符串，选择要使用的模型，wall、ceiling 或 ceiling_middle 之一
      • 如果未提供，默认为 ceiling_middle

minecraft:standing_sign 特殊模型类型

  • 新字段：
    • attachment - 可选字符串，选择要使用的模型，wall 或 ground 之一
      • 如果未提供，默认为 ground

minecraft:shulker_box 特殊模型类型

  • 移除了 orientation 字段

minecraft:end_cube 特殊模型类型

  • 新的特殊模型类型，渲染具有与末地传送门和末地折跃门方块相同纹理效果的立方体
  • 格式：
    • effect - 字符串，要应用的纹理效果，portal 或 gateway 之一
