今天我们为 Minecraft Java 版发布了 20w30a 快照，其中我们调整了堡垒遗迹，并允许你将灯笼放置在水下。

20w30a 中的更改

  • 修改了床和重生锚的重生位置选择方式
  • 灯笼现在可以含水
  • 灵魂灯笼现在可以含水
  • 调整了堡垒遗迹的箱子战利品
  • 堡垒遗迹中的箱子现在更有可能位于镶金黑石上方

重生方块位置

  • 重生锚会优先选择基本方向而非角落
  • 床会优先选择玩家上床时所在的一侧，然后选择围绕床尾至床头的空间
  • 重生的玩家现在会面向他们重生的那个方块
  • 现在会尽可能避免将玩家放置在危险方块上

20w30a 中的技术性更改

  • 告示牌编辑界面现在会从已有的告示牌文本进行初始化（对原版应该没有明显影响）
  • 标签现在可以包含可选条目

可选标签条目

标签中的条目现在可以标记为可选。解析可选条目失败不会阻止整个标签加载。

示例：

{
  "replace": false,
  "values": [
    "#minecraft:beds", // existing syntax
    { "id":"#missing:tag", "required": false }, // optional sub-tag entry

"minecraft:anvil", // existing syntax
{ "id":"minecraft:stone_button", "required": true }, // new syntax for required tags
{ "id":"missing:block", "required": false } // optional single-element entry



]
}
