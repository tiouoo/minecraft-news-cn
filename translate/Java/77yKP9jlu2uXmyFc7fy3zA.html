我们现在已经发布了 Minecraft 1.16 预发布版 4，调整了生成速率，并修复了另一批漏洞。

1.16 预发布版 4 的更改

  • 调整了诡异森林和灵魂沙峡谷中敌对生物的生成速率

1.16 预发布版 4 修复的漏洞

  • MC-136085 破坏多方块结构的一半时，附着在其上的方块会被删除
  • MC-177463 崩溃报告中的“Connection:”字段包含无用的值（Object.toString()）
  • MC-179851 属性 generic.movement_speed 在 /attribute 命令中不起作用
  • MC-180967 进度描述的 JSON 可能会忽略第一个指定的颜色
  • MC-181498 在火焰上方使用火焰弹会短暂地在火焰上方再生成一个火焰
  • MC-181556 幼年僵尸猪灵骑乘炽足兽时会浮空
  • MC-181576 已在另一个 Minecraft 实例中打开的世界仍可通过方向键和 Tab 键选中
  • MC-184613 浮岛世界中会生成末地石
  • MC-184644 洞穴自助式世界生成器即使使用非下界生物群系也会生成下界岩
  • MC-186468 即使重载失败，游戏也会提示“已禁用数据包 [XXX]”
  • MC-187419 用金胡萝卜喂养马或驴时不会播放手臂动画
  • MC-188352 创造模式下挤奶/盛蘑菇煲与拾取放置的流体不一致
  • MC-188451 使用发射器发射潜影盒时游戏崩溃“java.lang.NullPointerException: Exception while ticking”
  • MC-188463 当图形设置为“极佳！”时，透明的掉落物在实体后方会以错误的顺序渲染
  • MC-188467 制作人员名单中的“Sound Director”相比其余文字颜色过浅，并且缺少字母“S”
  • MC-188517 无法在数据包中创建多个空标签
  • MC-188519 云会渲染在方块的上方
  • MC-188528 粒子会渲染在染色玻璃的上方
