Minecraft: Java Edition 现已推出又一个预发布版！此预发布版修复了大量漏洞，同时也进行了一些小幅调整。下界更新临近，我们计划在几周内发布该更新。

1.16 预发布版 3 中的更改

​

  • 食物现在可以放置在未点燃的营火上
  • 下界要塞现在略微更常见
  • 在抗火效果下，熔岩中的能见度现在略微提升
  • 猪灵现在即使看不到你，也能听到你破坏箱子、金块（或类似物品）的声音，并会认为你在偷窃
  • 游戏规则界面中的规则描述现在可以根据需要换行显示
  • 游戏在读取世界数据以加载、创建或重新创建世界时，现在会显示加载界面
  • 游戏现在将尝试恢复在 1.16 预发布版 1 中损坏的世界

​

1.16 预发布版 3 中的技术性更改

​ 区域文件现在仅在 Windows 上以同步模式打开，其他操作系统上则不会。此功能的状态可通过以下选项手动控制：

  • 对于专用服务器：server.properties 中的 sync-chunk-writes
  • 对于客户端：options.txt 中的 syncChunkWrites
