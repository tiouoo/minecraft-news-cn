磨利你的镐子，又一个快照来了！在今天的快照中，我们带来了一系列组件改进，树脂团现在可以含水，兔子也终于可以再次自由漫步了。此外，还有一大群其他漏洞修复。

更改

  • 凋灵骷髅不再将弓作为首选武器
  • 嘎枝现在会在世界重新加载后继续存在
  • 嘎枝之心的挖掘速度和爆炸抗性翻倍
  • 树脂的声音已调整得更柔和
  • 树脂团方块现在可以放置在相邻方块的任何完整面上
  • 树脂团方块现在可以含水，因此可以放置在水下

技术更改

  • 数据包版本现在是 60
  • 资源包版本现在是 45

数据包版本 60

  • 移除了 creaking_transient 实体类型

物品标签

  • 移除了 trim_templates
  • 为凋灵骷髅不想捡起的武器添加了 #wither_skeleton_disliked_weapons

资源包版本 45

  • 之前仅渲染方块实体（旗帜、头颅、床、箱子、潮涌核心、饰纹陶罐、潜影盒和告示牌）的所有方块，现在也会在其上方渲染普通方块模型（与钟、附魔台等现有行为相同）
    • 注意：渲染的方块实体仍然无法移除或由数据驱动，此更改仅影响以前被忽略的方块模型

物品模型

minecraft:special 物品模型类型

更改了 minecraft:head 特殊模型类型

  • 添加了字段 texture - 可选的纹理命名空间 ID，不需要 textures/entity/ 前缀和 .png 后缀
    • 如果不存在，将根据 kind 字段使用默认纹理
    • 此外，如果存在，将忽略 minecraft:profile 组件

添加了 minecraft:standing_sign 特殊模型类型

  • 渲染一个立式告示牌
  • 字段：
    • wood_type - 以下之一：oak, spruce, birch, acacia, cherry, jungle, dark_oak, pale_oak, mangrove, bamboo, crimson, warped
    • texture - 可选的纹理命名空间 ID，不需要 textures/entity/signs/ 前缀和 .png 后缀
      • 如果不存在，将从 wood_type 派生

添加了 minecraft:hanging_sign 特殊模型类型

  • 渲染一个悬挂告示牌
  • 字段：
    • wood_type - 以下之一：oak, spruce, birch, acacia, cherry, jungle, dark_oak, pale_oak, mangrove, bamboo, crimson, warped
    • texture - 可选的纹理命名空间 ID，不需要 textures/entity/signs/hanging/ 前缀和 .png 后缀
      • 如果不存在，将从 wood_type 派生

minecraft:condition 物品模型类型

  • 移除了 minecraft:xmas 布尔属性，由 minecraft:local_time 替代
  • 移除了 minecraft:shift_down 布尔属性，由 minecraft:extended_view 替代

更改了 minecraft:has_component 布尔属性

  • 添加了字段：ignore_default - 是否应将默认组件值视为“无组件”，默认值：false

添加了 minecraft:extended_view 布尔属性

  • 如果玩家按住 Shift 键请求扩展详细信息，则返回 true
    • 注意：这不是按键绑定，无法重新绑定
  • 仅在物品显示在 UI 中时有效
  • 无字段

添加了 minecraft:keybind_down 布尔属性

  • 如果按键绑定当前处于活动状态，则返回 true
  • 字段：
    • keybind - 按键绑定 ID，与 keybind 文本组件中的值相同
      • 示例：key.use、key.left

添加了 minecraft:local_time 属性

  • 返回根据给定模式格式化后的当前时间
  • 该值每秒更新一次
  • 有关区域设置、时区和模式的完整格式文档，请参阅 ICU（International Components for Unicode）文档
  • 字段：
    • locale - 描述区域设置的可选值
      • 示例：
        • en_US：英语（用于星期名称等），格式与美国相同
        • cs_AU@numbers=thai;calendar=japanese：捷克语、澳大利亚格式、泰语数字和日本日历
      • 默认值为 ""，表示“根”区域设置（一组默认值，包括英文名称）
    • time_zone - 描述时区的可选值
      • 如果不存在，则默认为客户端上设置的时区
      • 示例：
        • Europe/Stockholm
        • GMT+0:45
    • pattern - 描述用于时间格式化的格式
      • 示例：
        • yyyy-MM-dd - 4位年份数字，接着是2位月份数字，然后是2位日期数字，必要时以零填充，并用 - 分隔
        • HH:mm:ss - 当前时间（小时、分钟、秒），24小时制，必要时以零填充到2位，并用 : 分隔
  • 值：任意字符串

开发者注：没有“使用客户端设置的区域设置”选项，以避免当用户区域设置与包开发者的不同时出现意外问题。此外，时间很复杂，请小心。

添加了 minecraft:holder_type 属性

  • 如果存在，返回持有实体类型
  • 无字段
  • 值：命名空间实体类型 ID
