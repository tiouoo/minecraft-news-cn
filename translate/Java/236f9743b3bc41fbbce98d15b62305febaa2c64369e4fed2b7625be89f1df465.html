是时候推出一个新的 Minecraft 快照了！我们带来了一些底层更新，包括一个此前在基岩版中出现的 tntExplodes 游戏规则、SNBT 语法中的新特性，以及允许所有实体存储自定义数据。此外，我们还为你准备了一些漏洞修复。

你现在还可以享受新的主菜单背景，挖矿愉快！

更改

  • 绵羊羊毛纹理已调整，移除了背部的明显线条
  • 被活塞破坏的方块现在会播放其破坏音效
  • 更新了今年首个游戏更新的菜单全景图
  • 测试方块和测试实例方块的纹理已更新
  • 仙人掌花现在可以放置在耕地上

技术性更改

  • 数据包版本现在为 70
  • 资源包版本现在为 54

数据包版本 70

  • 所有实体现在都可以存储自定义数据
  • 统一了实体和方块实体上组件谓词的格式与功能
  • SNBT 新增操作
  • 新增 tntExplodes 游戏规则
  • 新增 #flowers 物品标签 - 与已有的 #flowers 方块标签相对应的物品标签

实体数据

  • 自定义数据（此前仅存在于标记实体上）现在可用于所有实体
    • 它以 minecraft:custom_data 组件的形式公开，因此可以通过生成物品进行设置，并可通过谓词进行匹配
    • 该组件目前存储在一个名为 data 的字段中，未来引入更合适的实体组件存储方式时，该字段将会更改
    • 仅当非空时才会存储

实体谓词

  • 实体谓词新增了一个可选字段：predicates
    • 其功能与格式与物品谓词上的 predicates 字段相同，但它们作用于实体组件
      • 当存在时，predicates 将匹配实体组件的部分内容

方块谓词

  • 方块谓词新增了可选字段：components 和 predicates
  • 其功能与格式与物品谓词上的 components 和 predicates 字段相同，但它们作用于方块实体组件（当存在时）
    • 当存在时，components 将匹配方块实体组件的精确内容
    • 当存在时，predicates 将匹配方块实体组件的部分内容

SNBT 格式

  • 为简化数据输入和宏使用，SNBT 现在也支持以下操作：
    • bool(arg) - 将参数转换为布尔值
      • 如果参数是布尔值，则直接返回该值
      • 如果参数是数值，则在该值非零时返回 true
    • uuid(str) - 将 UUID 的字符串表示转换为整数数组
  • 隐式无限浮点数值（如 1e1000）现在会被拒绝

tntExplodes 游戏规则

  • 当设为 false 时，TNT 不会爆炸，也无法被点燃
  • 默认值：true

资源包版本 54

  • 现在可以在任何着色器中定义“全局”uniform 变量，游戏将尝试填充它
    • 目前，这些变量包括：ModelViewMat, ProjMat, TextureMat, ScreenSize, ColorModulator, Light0_Direction, Light1_Direction, GlintAlpha, FogStart, FogEnd, FogColor, FogShape, LineWidth, GameTime, ModelOffset
    • uniform 的类型必须与其通常情况下的类型一致，否则将产生未定义行为
