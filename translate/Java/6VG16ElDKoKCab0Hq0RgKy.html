今天的快照可真是响亮！它带来了一批新的环境音效，为下界的生物群系增添了非常棒的氛围。除此之外，你现在需要使用锻造台来合成下界合金。挖矿愉快！

20w10a的新内容

  • 添加了绯红菌索和诡异菌索——六面全纹理的“菌柄”类方块，包括去皮变种
  • 使用锻造台将下界合金锭与你的钻石武器/工具/盔甲融合
  • 下界生物群系的新环境音效

​

20w10a的更改

​

  • 锄现在更像其他用于破坏方块的工具了
  • 鱼现在与最近的玩家距离超过64格时会消失
  • 更新了下界合金物品的纹理

​

锄的更改

​ 我们对锄进行了一些更改，使它们在下界中更有用。 ​

  • 不同等级的锄在挖掘它们对其有效的方块时，速度各不相同
  • 锄现在可以附魔以下附魔：效率、时运、精准采集
  • 这些附魔现在可以通过附魔台获得了

​

20w10a的技术性更改

​

实体UUID

​

  • 弹射物（如箭或雪球）所有者的UUID现在以四个整数组成的数组形式存储。将来所有UUID都会以这种格式存储

​

物品展示框的新标签

​

  • Invisible - 使物品展示框隐形（展示框内的物品保持可见）
  • Fixed - 防止物品展示框被破坏以及其中的物品被移除

​

target_hit 进度触发器类型

​ 条件：

  • signal_strength匹配击中时方块输出的信号强度
  • projectile匹配弹射物实体
  • shooter匹配射出或投掷该弹射物的玩家
