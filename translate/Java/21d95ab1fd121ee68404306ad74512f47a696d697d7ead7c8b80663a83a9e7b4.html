环境属性

环境属性提供了一种数据驱动的方式，用于控制各种视觉和游戏系统。

每个环境属性控制一个特定的视觉或游戏效果：例如，minecraft:visual/sky_color 控制天空的颜色，minecraft:gameplay/water_evaporates 控制是否可以在给定位置放置水。

开发者注： 此系统以及许多引入的属性都应视为非常实验性的，在接下来的快照和正式版中可能仍会发生重大变化。与此同时，我们一如既往地欢迎您提供任何反馈或建议！

来源

环境属性值可以由以下环境属性来源提供（按从低到高的优先级顺序）：

  • 维度
  • 生物群系

环境属性的“有效”值（即最终在游戏中显示的值）将根据优先级，由每个来源提供的值组合而成。

例如，在以下场景中：

  • overworld 维度提供 sky_color = #00ff00（绿色）
  • plains 生物群系提供 sky_color = #ff0000（红色）

当玩家处于 plains 生物群系时，他们会看到红色的 sky_color，而在 overworld 的其他任何地方则会看到绿色。

当环境属性来源提供环境属性时，它可以：

  • 覆盖该值，例如上述场景中 plains 生物群系覆盖 overworld 的 sky_color
  • 对先前的值应用修饰器（请参阅下文关于修饰器的章节）

修饰器

如上述示例所述，环境属性来源可以简单地覆盖特定属性的值。然而，有时也希望对较低优先级来源提供的值应用修饰器。

例如，在以下场景中：

  • overworld 维度提供 water_fog_radius = 96.0
  • plains 生物群系使用 multiply 修饰器（0.85）修改 water_fog_radius

在 plains 生物群系中，water_fog_radius 将解析为 96.0*0.85 = 81.6，而在主世界的其他任何生物群系中，它将解析为 96.0。

可用的修饰器种类取决于环境属性的类型。每个环境属性都支持的最基础修饰器是 override 修饰器。它的行为纯粹是对先前值的覆盖。如果环境属性来源未指定修饰器，则默认始终为 override。

有关可用修饰器及其行为的完整描述，请参阅下文“常用修饰器”部分。

插值

修饰器描述了一个来源提供的值如何应用于先前来源的值，而插值则描述了同一来源内值的组合。插值会在修饰器应用之后，对来自某个来源的值执行。

只有部分环境属性支持插值。这允许在两个或多个值之间平滑过渡，例如在两个生物群系之间移动时。

生物群系

例如，在以下场景中：

  • plains 生物群系提供 sky_color = #ff0000（红色）
  • desert 生物群系提供 sky_color = #ffff00（黄色）

sky_color 就是这样一种会基于位置平滑过渡的属性：例如，在上述场景中，当玩家从 plains 生物群系移动到 desert 生物群系时，天空颜色会逐渐从红色变为黄色。其他属性（如 water_evaporates）表示离散值，不会进行平滑过渡——只会考虑主体位置正上方的那个生物群系。

生物群系之间的平滑过渡基于相机 8 格半径内的生物群系。在该半径中占据较大部分且距离相机较近的生物群系，会对最终插值结果产生更强的影响。

环境属性映射

维度类型和生物群系定义现在包含一个新的 attributes 字段，使它们能够定义环境属性。

此映射通常采用环境属性 ID 与其对应值之间的对象映射形式，例如：

"attributes": {
    "minecraft:visual/fog_color": "#ffaa00",
    "minecraft:gameplay/water_evaporates": true
}

上述定义的值将始终假定使用 override 修饰器。

但是，值对象可以扩展以表达不同的修饰器，格式为包含以下字段的对象：

  • modifier：可选的字符串修饰器 ID，取决于属性类型（请参阅下文“常用修饰器”部分）
    • 默认值：override
  • argument：修饰器参数（格式取决于所选的修饰器）
    • 参数的使用方式也取决于修饰器的类型

例如，以下定义描述了将 water_fog_radius 乘以 85%：

"attributes": {
    "minecraft:visual/water_fog_radius": {
        "modifier": "multiply",
        "argument": 0.85
    }
}

常用数据类型

以下数据类型在环境属性系统的各个部分中被复用，并将在后续章节中引用。

RGB 颜色

格式可以是以下之一：

  • 十六进制颜色 RGB 字符串，格式为 #rrggbb
  • 包含 3 个分量的浮点数组，范围在 0 和 1 之间，格式为 [r, g, b]
  • 打包为 RGB 形式的整数

ARGB 颜色

格式可以是以下之一：

  • 十六进制颜色 ARGB 字符串，格式为 #aarrggbb
  • 包含 4 个分量的浮点数组，范围在 0 和 1 之间，格式为 [a, r, g, b]
  • 打包为 ARGB 形式的整数

粒子选项

粒子的完整定义，包括任何类型特定的属性（如 /particle 命令中所示）。

例如：

{
  "type": "minecraft:block_crumble",
  "block_state": {
    "Name": "minecraft:dirt"
  }
}

常用修饰器

每个环境属性都有一个特定的值类型，该类型描述了值必须如何定义、哪些修饰器可用以及它们如何插值。有些类型非常特定，而其他类型则被许多属性复用。

虽然这不是一个详尽的列表，但以下属性类型在许多环境属性中被普遍使用：

布尔值修饰器

参数格式：布尔值

  • override
  • and
  • nand
  • or
  • nor
  • xor
  • xnor

浮点值修饰器

参数格式：浮点数

  • override
  • add
  • subtract
  • multiply
  • minimum
  • maximum

颜色值修饰器

参数格式：RGB 颜色（alpha_blend 除外）

  • override
  • add - 逐分量加色混合
  • subtract - 逐分量减色混合
  • multiply - 逐分量乘色混合
  • alpha_blend - 图像编辑软件中常见的传统 Alpha 混合
    • 参数格式：ARGB 颜色
    • 当参数 Alpha 为 1 时，它的行为将等同于覆盖，不进行混合

新增环境属性

minecraft:visual/fog_color

雾的颜色（当相机未浸没在其他物质中时）。注意：最终值还会受到时间、天气和药水效果的影响。

  • 值类型：RGB 颜色
  • 默认值：#000000
  • 修饰器：颜色修饰器
  • 插值：是
  • 在相机位置解析
  • 取代生物群系的 effects.fog_color 字段

minecraft:visual/extra_fog

控制是否应使用浓雾（如下界中的雾）（当相机未浸没在其他物质中时）。

  • 值类型：布尔值
  • 默认值：false
  • 修饰器：布尔修饰器
  • 插值：否
  • 在相机位置解析

minecraft:visual/water_fog_color

浸没在水中时雾的颜色。注意：最终值还会受到时间、天气和药水效果的影响。

  • 值类型：RGB 颜色
  • 默认值：#050533
  • 修饰器：颜色修饰器
  • 插值：是
  • 在相机位置解析
  • 取代生物群系的 effects.water_fog_color 字段

minecraft:visual/water_fog_radius

相机到水下雾达到最大密度时的距离（以格为单位）。
注意：最终值还会根据玩家在水下的时间进行修改。

  • 值类型：非负浮点数
  • 默认值：96.0
  • 修饰器：浮点修饰器
  • 插值：是
  • 在相机位置解析
  • 取代 #has_closer_water_fog 生物群系标签

minecraft:visual/sky_color

天空的颜色。此颜色仅在主世界的天空可见。注意：最终值还会受到时间和天气的影响。

  • 值类型：RGB 颜色
  • 默认值：#000000
  • 修饰器：颜色修饰器
  • 插值：是
  • 在相机位置解析
  • 取代生物群系的 effects.sky_color 字段

minecraft:visual/cloud_opacity

云的透明度。如果为 0，云将完全禁用，且快乐恶魂在云层高度时不会更快地恢复生命值。

  • 值类型：介于 0 和 1 之间的浮点数
  • 默认值：0.0
  • 修饰器：浮点修饰器
  • 插值：是
  • 在相机位置解析以进行渲染，或在快乐恶魂的位置解析以进行回复

minecraft:visual/cloud_height

所有云出现的高度。

  • 值类型：浮点数
  • 默认值：192.33
  • 修饰器：浮点修饰器
  • 插值：是
  • 在相机位置解析以进行渲染，或在快乐恶魂的位置解析以进行回复
  • 取代维度类型的 cloud_height 字段

minecraft:visual/default_dripstone_particle

当上方没有放置流体时，从滴水石方块滴落的默认粒子。

  • 值类型：粒子选项
  • 默认值：{type:"minecraft:dripping_dripstone_water"}
  • 修饰器：override
  • 插值：否
  • 在滴水石方块的位置解析
  • 取代维度类型的 ultrawarm 字段

minecraft:visual/ambient_particles

控制相机周围随机生成的环境粒子。

  • 值类型：对象列表，字段如下
    • particle：要生成的粒子选项
    • probability：介于 0 和 1 之间的浮点数，表示在随机刻中于空位生成该粒子的概率
  • 默认值：[]
  • 修饰器：override
  • 插值：否
  • 在相机位置解析
  • 取代生物群系的 effects.particle 字段

minecraft:audio/background_music

控制播放背景音乐的方式和内容。

  • 值类型：对象，字段如下
    • default：可选对象，字段如下：
      • sound：要播放的声音事件
      • min_delay：整数，曲目之间的最小延迟（以刻为单位）
      • max_delay：整数，曲目之间的最大延迟（以刻为单位）
      • replace_current_music：可选布尔值，此曲目是否可以替换当前正在播放的内容
        • 默认值：false
      • 如果未定义且未被覆盖，则在此属性生效期间不会开始播放任何音乐
    • underwater：可选对象，字段格式与 default 相同——如果存在且玩家处于水下，将覆盖 default
    • creative：可选对象，字段格式与 default 相同——如果存在且玩家处于创造模式，将覆盖 default
  • 默认值：{}
  • 修饰器：override
  • 插值：否
  • 在相机位置解析
  • 取代生物群系的 effects.music 字段

minecraft:audio/music_volume

音乐播放的音量。正在播放的任何音乐都会随时间淡入淡出到此值。

  • 值类型：介于 0 和 1 之间的浮点数
  • 默认值：1.0
  • 修饰器：浮点修饰器
  • 插值：否
  • 在相机位置解析
  • 取代生物群系的 effects.music_volume 字段

minecraft:audio/ambient_sounds

控制相机周围播放的环境声音以及播放时机。

  • 值类型：对象，字段如下
    • loop：可选声音事件，要持续循环播放的声音
    • mood：对象，字段为根据周围亮度随机播放的声音
      • sound：要播放的声音事件
      • tick_delay：整数，假设光照等级为 0 时，情绪声音之间的刻数
      • block_search_extent：整数，采样光照等级的范围半径
      • offset：双精度浮点数，应用于生成的声音的额外距离偏移
    • additions：对象列表，字段为随机播放的声音
      • sound：要播放的声音事件
      • tick_chance：介于 0 和 1 之间的浮点数，在一个刻内播放给定声音的概率
  • 默认值：{}
  • 修饰器：override
  • 插值：否
  • 在相机位置解析
  • 取代生物群系的 effects.ambient_sound、effects.mood_sound 和 effects.additions_sound 字段

minecraft:gameplay/can_start_raid

如果为 false，带有袭击之兆的玩家无法开始袭击。

  • 值类型：布尔值
  • 默认值：true
  • 修饰器：布尔修饰器
  • 插值：否
  • 在袭击将要开始的位置解析
  • 取代维度类型的 has_raids 字段

如果为 true，则无法使用水桶放置水，熔化的冰不会产生水，湿海绵放置后会变干，滴水石不会从泥方块产生水。

  • 值类型：布尔值
  • 默认值：false
  • 修饰器：布尔修饰器
  • 插值：否
  • 在交互位置解析
  • 取代维度类型的 ultrawarm 字段

minecraft:gameplay/bed_rule

控制床是否可以用于睡觉，以及是否可以用于设置重生点。

  • 值类型：对象，字段如下
    • can_sleep：以下之一：
      • always - 床始终可以用于睡觉（假设床未被阻挡且附近没有怪物）
      • when_dark - 仅当全局天空光照等级小于 4 时，床才能用于睡觉
      • never - 床永远不能用于睡觉
    • can_set_spawn - 与 can_sleep 相同
    • explodes - 可选布尔值，如果为 true，床在交互时会爆炸
      • 默认值：false
    • error_message：可选文本组件，当玩家无法睡觉或设置重生点时显示的消息
  • 默认值：{type:"can_sleep_when_dark",error_message:{translate:"block.minecraft.bed.no_sleep"}}
  • 修饰器：override
  • 插值：否
  • 在床方块的头部位置解析
  • 取代维度类型的 bed_works 字段

minecraft:gameplay/respawn_anchor_works
