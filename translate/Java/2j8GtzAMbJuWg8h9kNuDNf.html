1.19.1 预发布版 2 中的更改

我们增加了查看聊天消息签名状态的功能——这样你就可以轻松判断服务器是否在篡改或移除其玩家消息的签名安全性。

聊天信任状态

  • 未使用安全聊天系统签名、或已被服务器篡改的消息现在将被标记
    • 缺少签名或签名无效的消息会被标记为“不安全”
    • 检测到被修改的消息会被标记为“已修改”
  • 消息的信任状态同时以彩色指示器和图标显示
    • 彩色指示器始终可见
    • 图标仅在聊天界面打开时可见
  • 将鼠标悬停在图标上会提供更多关于信任状态的信息
    • 对于已修改的消息，原始安全文本也会显示在工具提示中

1.19.1 预发布版 2 中的技术更改

聊天类型

  • 添加到 chat_types 注册表中的聊天类型现在仅用于玩家聊天，不用于系统消息
    • system 和 game_info 聊天类型已被移除
  • 聊天类型已简化，现在只需定义 chat 和 narration 装饰
    • 聊天类型不再支持叠加层
    • 应改用系统消息来显示叠加层

server.properties

  • 对于专用服务器，enforce-secure-profile 现在默认为 true
