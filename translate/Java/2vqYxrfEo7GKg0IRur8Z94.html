繁茂洞穴生物群系

草甸生物群系

  • 会生成驴、兔子和绵羊。

  • 改变了矿石生成以匹配新的世界高度，并为挖矿增添更多策略。

  • 金矿石在 y 32 以下生成，强烈偏向 y -16。

噪声洞穴和含水层

  • 噪声洞穴是一种新的洞穴生成方式，提供更多自然变化。它们有时会变得非常巨大！
  • 噪声洞穴有三种类型：
    • 奶酪洞穴。如同瑞士奶酪中的孔洞。这些通常会形成大小不一的洞穴大厅
    • 意大利面洞穴。长长的弯曲隧道，有时宽阔如意大利宽面
    • 面条洞穴。比意大利面洞穴更细、更弯曲、更令人感到幽闭
  • 不，它们并不吵闹。“噪声”中的“noise”是一个技术术语，与声音无关。
  • 旧的洞穴雕刻器和峡谷仍然会生成，与噪声洞穴结合形成有趣的洞穴系统。
  • 与雕刻器一样，当噪声洞穴与地表相交时，会形成洞穴入口。
  • 含水层是一个具有局部水位的区域，独立于海平面。在世界生成过程中，含水层用于在噪声洞穴内生成水体。这有时会形成大型地下湖泊！它们也可能在山体内部和地表形成。
  • y0 以下的含水层有时会是熔岩含水层，而不是水含水层
  • 岩浆块有时会生成在地下水体底部
  • 水下洞穴雕刻器和水下峡谷已被移除，因为现在使用含水层在洞穴中生成水

概述

Java Flight Recorder（https://openjdk.java.net/jeps/328）是 Java 运行时自带的内部 JVM 性能分析工具，用于分析性能和运行时特征。它是一个有用的工具，可以暴露内部 JVM 性能指标以及自定义指标，可使用任何标准的 Java 分析器或监控代理进行监控或分析。

报告

摘要 JSON 报告会写入日志文件和调试文件夹，并附带一个 .jfr 记录，可在 JMC https://github.com/openjdk/jmc 或任何其他支持该格式的分析器工具中进行分析。

开始性能分析运行

可以通过以下任一方式开始性能分析运行：

  • 启动 Minecraft 服务器或客户端时的 --jfrProfile 启动标记
  • 游戏内命令 jfr start
  • 常规 Java 命令行工具，例如 jcmd

  • 新选项“按玩家”和“无”可显著减少放置或移除方块（尤其是光源）时的卡顿，但可能会导致罕见的世界更新视觉可察觉延迟。

刷怪笼数据更改

  • 刷怪笼现在支持 SpawnData 字段和 SpawnPotentials 列表中的 custom_spawn_rules NBT
  • custom_spawn_rules 当前可能包含字段 block_light_limit 和 sky_light_limit —— 两者都是带有 min_inclusive 和 max_inclusive 字段的整数范围
  • 为使 SpawnPotentials 格式与其他加权列表类似，结构已改为 {weight: <int>, data: <先前内容去掉 'Weight'，'Entity' 重命名为 'entity'>}
  • 为适应此更改，SpawnData 的先前内容已移至 SpawnData.entity（使该字段的格式与 SpawnPotentials.data 元素相同）

示例：

SpawnData: {
    entity: {
        id: "minecraft:cow"
    },
    custom_spawn_rules: {
          sky_light_limit: {min_inclusive: 10, max_inclusive: 15}
    },
}
SpawnPotentials: [
  {
    data: {
      custom_spawn_rules: {
          block_light_limit: {min_inclusive: 0, max_inclusive: 15}
      },
      entity: {id: "minecraft:pig"},
    },
    weight: 2
  },
  {
    data: {
      custom_spawn_rules: {
          block_light_limit: {min_inclusive: 5, max_inclusive: 10},
          sky_light_limit: {min_inclusive: 10, max_inclusive: 15}
      },
      entity: {id: "minecraft:panda"}
    },
    weight: 1
  }
]
