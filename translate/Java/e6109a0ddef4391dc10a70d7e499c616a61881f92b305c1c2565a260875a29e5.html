我们正在本周的快照中添加一些新的、有趣又可爱的特性。刷怪蛋刚刚变得更可爱了，新纹理让它们看起来更像它们所生成的生物。狼将凭借各自独特的声音变得更加与众不同。当狼生成时，它会获得七种性格之一，与它们的变种或生物群系无关。从可爱到暴躁，每只狼都会以自己独特的方式吠叫、咆哮、喘气、哀鸣和表达自己。最棒的是，落叶现在会以新颜色呈现得更好看，而且我们还对绵羊在不同生物群系中生成的颜色进行了一些调整。

玩得开心！

新特性

  • 为狼添加了新的声音变种
  • 全面改进了每个刷怪蛋的视觉效果，以提高可读性和可访问性

家畜变种

温暖和寒冷生物群系中绵羊毛的颜色

  • 撤销了上周允许蓝色、浅蓝色、青色、黄色、橙色和红色绵羊在不同生物群系中自然生成的更改
  • 黑色绵羊仍将是寒冷生物群系中最常见的类型，而棕色绵羊将是温暖生物群系中最常见的类型
  • 粉色绵羊仍将非常稀有，并且能够在任何绵羊可以生成的地方生成
  • 寒冷生物群系中不常见的绵羊颜色有灰色、浅灰色、白色和棕色
  • 温暖生物群系中不常见的绵羊颜色有灰色、浅灰色、白色和黑色

落叶

  • 落叶会根据其所处的生物群系进行着色

刷怪蛋视觉全面翻新

  • 每个刷怪蛋现在都有其独特的视觉外观，体现出它所生成的生物的个性与特征
  • 每个刷怪蛋的视觉形状各不相同，以反映它所生成的生物在游戏世界中的大小
    • 例如，较小的生物往往拥有较小的刷怪蛋

狼的声音变种

  • 添加了6个新的狼声音变种，具有独特的环境音、受伤、死亡、咆哮、哀鸣和喘气声音
    • 新声音属于名为 big、cute、puglin、angry、grumpy 和 sad 的变种的一部分
    • 原始的狼声音现在用于称为 classic 的变种
    • 每只狼都会从6个新变种和原始变种中随机分配一个声音变种
    • 声音变种与纹理变种无关

更改

  • 绵羊的羊毛底毛现在在染色时也会着色，与基岩版现有行为一致
  • 绵羊现在可以吃蕨类植物方块，以与基岩版一致

技术性更改

  • 数据包版本现在为68
  • 资源包版本现在为53

数据包版本68

  • 为狼添加了数据驱动的声音变种
  • 生物群系效果新增了一个字段 dry_foliage_color，用于定义使用干枯植物着色对方块进行着色所用的颜色

狼的声音变种

  • 狼的声音变种可以通过向 data/<namespace>/wolf_sound_variant/<id>.json 添加条目来实现数据驱动
  • 该文件包含以下字段，这些字段对应于用于特定行为的声音事件：
    • ambient_sound
    • death_sound
    • growl_sound
    • hurt_sound
    • pant_sound
    • whine_sound

物品组件

blocks_attacks 组件

  • 如果被阻挡的伤害没有位置，则对于 damage_reductions 的 horizontal_blocking_angle 字段，比较角度将假定为最大值 180

实体组件

  • 新组件
    • wolf/sound_variant - 来自 wolf_sound_variant 注册表的命名空间 ID

资源包版本53

  • 添加了根据干枯植物颜色图来着色方块的功能
  • 更新了刷怪蛋的纹理
  • 为狼声音变种添加了新声音并更新了现有声音
  • 添加了用于着色干枯植物着色方块的颜色图纹理
  • 纹理 sheep_fur 的名称已重命名为 sheep_wool
  • 绵羊现在有一个单独的羊毛底毛纹理，该纹理会在游戏内动态重新着色
    • 这个底毛纹理的名称是 sheep_wool_undercoat

更新了刷怪蛋的纹理

  • 为所有刷怪蛋添加了新纹理
  • 移除了 spawn_egg.png 和 spawn_egg_overlay.png

装备资源

  • 配置为可染色的装备层，如果物品上存在 dyed_color 组件，即使该物品不在 #dyeable 标签中，现在也会显示

新增和更新的狼声音变种

  • 经典狼声音的声音文件已移入狼声音文件的 classic 文件夹
  • 移除了未使用的 howl 声音
  • 为新的狼声音变种添加了声音：big、cute、puglin、angry、grumpy 和 sad

修复25w08a中的漏洞

  • MC-177522 狼的吠叫和哀鸣声音被字幕显示为“狼的喘气”
  • MC-280182 盾牌可以阻挡某些环境伤害来源
  • MC-280230 DeathLootTable 字段被错误地命名为 DeathLoothTable
