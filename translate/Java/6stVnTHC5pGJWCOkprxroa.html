20w20a 的新特性

  • 添加了新的游戏模式切换器调试菜单
  • 添加了新的下界进度

​

游戏模式切换器

新的 F3 调试功能，允许你使用传统的“Tab”循环方式来切换游戏模式。 ​

  • 按住 F3 并轻点 F4 打开菜单
  • 轻点 F4 将循环切换游戏模式，或使用鼠标
  • 松开 F3 以应用
  • 你的上一个游戏模式会被记住，并作为第一个选中的选项，这样你就可以通过单次按下 F3 + F4 在两个游戏模式之间快速切换！

​

F3 + N（切换旁观模式）

对这个调试组合键做了一个小改动。 ​

  • 默认情况下，使用此键会从旁观模式切换回创造模式。现在它会切换回你之前所处的游戏模式。
  • 例如，如果你处于生存模式，然后切换到旁观模式再切换回来，你将被设置回生存模式。

20w20a 中的技术更改

  • 带有 “NoAI” 的潜影贝现在可以带着旋转角度召唤。
  • 添加了 thrown_item_picked_up_by_entity 进度触发器
  • 添加了 player_generates_container_loot 进度触发器
  • 添加了 item_used_on_block 进度触发器
  • 移除了 safely_harvest_honey 进度触发器

​

进度

item_used_on_block 触发器类型

属性：

  • item 匹配被拾起的投掷物品
  • entity 匹配拾取物品的实体

​

player_generates_container_loot 触发器类型

属性：

  • loot_table 匹配所生成战利品表的资源路径

​

item_used_on_block 触发器类型

属性：

  • location 匹配使用物品时该方块中心的位置
  • item 匹配使用在该方块上的物品

​

其他触发器更改

  • location 新增了一个属性 smokey，用于检查该位置是否紧邻营火上方
  • entity_properties 新增了属性 vehicle 和 targetedEntity，分别匹配生物乘坐的载具或生物瞄准的实体
