数据包版本 25

  • 为记分板条目添加了个性化显示名称

命令

scoreboard

显示名称

  • 每个记分板条目现在都可以有一个自定义显示名称
  • 这些值按目标和得分持有者分别保存
  • 如果名称不存在，则使用得分持有者的名称（即旧行为）
  • 如果分数被重置或整个目标被移除，则名称不会被保留
  • 队伍装饰仍将正常应用于名称
  • 管理名称的子命令：
    • scoreboard players display name <targets> <objective> <text component> - 设置显示名称
    • scoreboard players display name <targets> <objective> - 清除显示名称

显示名称自动更新

  • 为了使显示名称管理更简单，目标还可以配置为在每次分数更新时自动更新显示名称
  • 此选项默认禁用
  • 如果得分持有者没有显示名称（因为它无法归属于任何当前加载的实体），则保留当前名称
  • 控制目标自动更新的命令：
    • scoreboard objectives modify <scoreboard> displayautoupdate [true|false]

数字格式化

  • 数字形式的分数现在可以格式化
  • 格式可以同时为目标和单个分数设置
  • 设置了格式的分数将在所有上下文中以相同方式显示（侧边栏、玩家名称下方等）
  • 管理格式的子命令：
    • scoreboard objectives modify <objective> numberformat <format> - 用于设置目标的默认格式
    • scoreboard objectives modify <objective> numberformat - 用于清除目标的默认格式
    • scoreboard players display numberformat <targets> <score> <format> - 用于为特定得分持有者设置格式
    • scoreboard players display numberformat <targets> <score> - 用于清除特定得分持有者的格式

格式：

  • styled <style> - 分数将以所选样式显示（例如 {"bold":true}）
  • fixed <text component> - 分数将被文本替换
  • blank - 分数将不会显示
