硫磺立方怪

  • 添加了硫磺立方怪生物
  • 生成于新的硫磺洞穴生物群系中
  • 当玩家手持方块与它互动时：
    • 硫磺立方怪会吸收该方块
    • 其 AI 会被禁用
    • 在吸收了方块期间：
      • 硫磺立方怪会变成一个物理对象：
        • 不会受到摔落或玩家伤害
        • 玩家可以击打和推动它
      • 它会呈现为下列原型之一，其物理属性会随吸收的方块而改变
      • 玩家可以用剪刀与它互动：
        • 这会移除所吸收的方块
        • 硫磺立方怪的 AI 会重新启用
  • 硫磺立方怪会跟随手持其可吸收方块的玩家
  • 硫磺立方怪会寻找附近的方块物品，并朝它们移动以将其吸收
  • 被杀死时，硫磺立方怪会分裂成两个较小的硫磺立方怪
  • 可以喂给小型硫磺立方怪黏液球，使其成长为大型硫磺立方怪
  • 大型硫磺立方怪可以用空桶装起
  • 硫磺立方怪不能进入船，但可以乘坐矿车
  • 发射器可以：
    • 向硫磺立方怪内部放入或替换方块
    • 使用剪刀移除其持有的方块
    • 从硫磺立方怪桶中生成硫磺立方怪
  • 河豚不会被硫磺立方怪吓到

硫磺立方怪原型

  • 每种原型都通过以下特征区分：硫磺立方怪被击中时的速度、与方块和可碰撞实体碰撞时的弹性，以及它的地面摩擦力、空气阻力和是否能在液体中漂浮
  • 有以下几种原型：
    • 普通：速度中等、弹性中等、地面摩擦力中等、空气阻力低
      • 具有浮力
      • 用于吸收松散矿物和泥土类方块时
    • 弹跳：速度快、弹性高、地面摩擦力中等、空气阻力低
      • 具有浮力
      • 用于吸收木质方块时
    • 慢速弹跳：速度慢、弹性高、摩擦力中等、空气阻力中等
      • 用于吸收类石头方块时
    • 慢速平坦：速度慢、弹性低、地面摩擦力中等、空气阻力中等
      • 用于吸收金属方块时
    • 快速平坦：速度快、弹性低、地面摩擦力中等、空气阻力低
      • 用于吸收有机方块时
    • 轻盈：速度慢、弹性高、地面摩擦力中等、空气阻力高
      • 具有浮力
      • 用于吸收羊毛方块时
    • 快速滑行：速度快、无弹性、地面摩擦力低、空气阻力低
      • 用于吸收冰类方块时
    • 慢速滑行：速度慢、无弹性、地面摩擦力低、空气阻力低
      • 用于吸收蘑菇方块时
  • 还有以下特殊原型：
    • 高抗性：速度极慢、低阻力、低弹性、高摩擦力
      • 用于吸收灵魂沙和灵魂土时
    • 黏着：与快速平坦原型属性相同，但具有极高的地面摩擦力且不弹跳，以模拟黏性
      • 用于吸收蜜脾块时
    • 爆炸：与普通原型属性相似，但空气阻力略高
      • 用于吸收 TNT 方块时
      • 被吸收的 TNT 可被红石、火源（包括装有打火石的发射器）或附近的爆炸点燃
      • 被火或红石点燃时，被吸收的 TNT 的引信时间为 6 秒
      • 被爆炸点燃时，被吸收的 TNT 的引信时间会在 0.75 到 3 秒之间随机
      • 吸收了已点燃 TNT 方块的硫磺立方怪无法用桶装起
      • 已吸收的点燃 TNT 方块无法用剪刀取出
      • 爆炸时不会生成小型硫磺立方怪
    • 灼热：与普通原型属性相同，但接触时会对实体造成伤害
      • 用于吸收岩浆块时

强效硫磺

  • 是一种新方块，会自然生成在硫磺洞穴生物群系内的水池中
  • 会产生气泡，最多升至其上 4 格水源方块处
  • 当放置在最上方不超过 4 格水源方块下方时，会在水面上生成一团引发反胃的气体
    • 这团气体会扩散至相邻水域，最大半径为 3 格
  • 可由 9 个硫磺方块合成
  • 当放置在岩浆块或熔岩方块上方，且下方? 且上方有 1-4 格水源方块时，会产生间歇泉
  • 下方为岩浆块时，间歇泉会随机间隔喷发，向上喷出一股水粒子羽流，并对上方的实体施加向上的冲量
  • 下方为熔岩方块时，间歇泉会持续喷发，但声音比岩浆块引发的喷发略低沉
  • 间歇泉喷发在开始和结束时都会发出游戏事件，可被幽匿感测体检测到

硫磺尖刺

  • 是一种新方块，会自然生成在硫磺洞穴生物群系内的硫磺方块上
  • 放置在天花板上会形成钟乳石，放置在地板上会形成石笋
  • 可以组合形成更长的钟乳石和石笋
  • 如果尖端相邻，钟乳石和石笋会合并，除非你在放置时潜行
  • 硫磺尖刺钟乳石放置在硫磺方块下方时能够生长
  • 石笋如果下方没有连接物就会破坏
  • 钟乳石如果上方没有连接物就会掉落
  • 被下落的钟乳石击中会受伤，因为它们很锋利！
  • 石笋并不锋利，落在上面也不会造成更多伤害
  • 投掷的三叉戟会破坏硫磺尖刺
  • 四个硫磺尖刺可以合成一个硫磺方块

Vulkan 支持

  • 正如此前公布的那样，我们计划将游戏从 OpenGL 迁移到 Vulkan
  • 旧硬件或驱动程序不支持 Vulkan - 在这些情况下将使用 OpenGL 作为后备方案
    • 当前要求为支持动态渲染和推送描述符的 Vulkan 1.2，但这一要求日后可能会提高或降低
  • 这目前是一个实验性渲染后端，可能不如预期的性能或稳定
    • 如果你在使用时发现任何漏洞，请报告到我们的漏洞追踪器
  • 在 Vulkan 下，我们会优先使用你的独立显卡而非任何集成显卡，这与 OpenGL 不同
  • 你可以在 F3 调试覆盖层中（system_specs 部分）查看当前正在使用哪个后端
  • 在 macOS 上，我们使用 MoltenVK 将 Vulkan 转换为 Metal

“图形 API”视频设置

  • 这是“视频设置”中新增的一个选项
  • 有三个值：“默认”、“优先使用 Vulkan（实验性）”和“优先使用 OpenGL”
  • “默认”可能会由我们酌情更改，我们建议所有用户使用此选项，除非你遇到问题并需要更改
    • 目前，它与“优先使用 OpenGL”相同
  • “优先使用 Vulkan（实验性）”将尝试使用 Vulkan 渲染，但如果无法工作则回退到 OpenGL
    • Vulkan 支持目前是实验性的，在某些系统上使用它可能会降低性能或导致不稳定
  • “优先使用 OpenGL”将尝试使用 OpenGL 渲染，但如果无法工作则回退到 Vulkan

启动与回退行为

  • 如果在设置为“优先使用 Vulkan（实验性）”时游戏在启动时崩溃，该设置将自动更改为“默认”
  • 设置为“默认”时，游戏仍会在启动时尝试收集有关 Vulkan 的系统信息
  • 如果在设置为“默认”时游戏在启动时崩溃，该设置将自动更改为“优先使用 OpenGL”
    • 设置为“优先使用 OpenGL”后，将不会与 Vulkan 进行任何交互，以防导致崩溃

服务器属性

  • 添加了 chat-spam-threshold-seconds 和 command-spam-threshold-seconds 属性，将聊天与命令的刷屏阈值分开
    • 两个阈值默认均设为 10，这是原有的命令+聊天合并刷屏阈值
    • 这些阈值用于配置自动踢出发送过多聊天消息或命令的玩家的机制
    • 该值描述玩家需要刷屏多少秒才会被踢出，其中玩家每发送一条消息，计数器就增加 1 秒
    • 计数器每游戏刻（相当于 1/20 秒）递减一次，如果玩家的计数器达到配置的阈值，该玩家将被踢出
    • 任一阈值均可设为 0，以禁用对相应刷屏类型的踢出
    • 在默认阈值为 10 的情况下，会导致踢出的消息速率示例：
      • 在 1 秒内发送 11 条消息
      • 在 2 秒内发送 14 条消息
      • 在 10 秒内发送 21 条消息

遥测

世界事件中的新属性

  • server_session_id：多人游戏会话的唯一标识符，该会话中的所有玩家共享
    • “会话”定义为至少有一名玩家在服务器中的连续时间段
    • 此属性为必填项，不受选择启用设置的影响

新增必需事件

  • graphics_capabilities
    • 这是一个在启动时上报的新事件，用于告知我们用于运行游戏的图形设备的能力
    • 添加了新属性：backend_name
      • 该值将为 Vulkan 或 OpenGL，有助于我们了解玩家使用的是哪个图形 API
    • 添加了新属性：backend_failure_reason
      • 该值将是一串简短的错误代码，例如 vulkan_device_version_too_low，有助于我们识别目标 Vulkan 要求可能存在的问题
    • 添加了新属性：backend_failure_message

实体谓词

实体谓词格式已从具有多个可选字段的结构改为类似于数据组件映射的结构。

例如：此前，effects 是可选字段： 

{
    "effects": {...}
}

在此版本中，它变成了一个类似组件的子谓词条目： 

{
    "minecraft:effects": {...}
}

主要功能变化如下：

  • 实体谓词中的所有键现在都是命名空间 ID
    • 由于命名空间 ID 可以省略命名空间（默认为 minecraft 命名空间），因此现有字段名仍然有效
    • 例外：字段 type 已重命名为 minecraft:entity_type
  • 无法识别的子谓词组件现在会被拒绝（此前，未知字段会被忽略）

现有的类型特定子谓词已重命名并移至顶层。

  • minecraft:lightning 改为 minecraft:type_specific/lightning
  • minecraft:fishing_hook 改为 minecraft:type_specific/fishing_hook
  • minecraft:player 改为 minecraft:type_specific/player
  • minecraft:raider 改为 minecraft:type_specific/raider
  • minecraft:sheep 改为 minecraft:type_specific/sheep
  • minecraft:slime 改为 minecraft:type_specific/cube_mob，因为它现在除史莱姆和岩浆怪之外还包含硫磺立方怪

例如： 

{
  "type_specific": {
    "type": "minecraft:player",
    "looking_at": {
      "type": "minecraft:ender_dragon"
    }
  }
}

变为 

{
  "minecraft:type_specific/player": {
    "looking_at": {
      "minecraft:type": "minecraft:ender_dragon"
    }
  }
}

添加了 minecraft:interval_select

根据输入密度函数和一组阈值，在多个密度函数之间进行选择。

格式：包含以下字段的对象：

  • input - 密度函数，将与任何给定 thresholds 比较的值
  • thresholds - 非空浮点数列表，用于与 input 进行比较的阈值
    • 如果 input < thresholds[i]，则选择 functions[i] 的结果
    • 如果输入大于最后一个阈值，则选择最后一个函数
    • thresholds 中的元素数必须比 functions 少一个
  • functions - 至少包含 2 个密度函数的列表，用于从中选择结果函数
    • functions 中的元素数必须比 thresholds 多一个
