1.19.1 预发布版 3 的更改

  • 将聊天滚动条移到聊天窗口的右侧
  • 系统消息（非玩家聊天，例如由命令输出的消息）会以灰色标记显示

1.19.1 预发布版 3 的技术性更改

  • 自定义服务器现在可以通过一个新的网络数据包为常规聊天设置自己的自动补全选项
  • 社交互动界面中的玩家列表现在会将最近看到其消息的玩家条目置于列表顶部
  • msg_command 聊天类型已被拆分为 msg_command_incoming 和 msg_command_outgoing
  • 聊天类型参数 team_name 已被重命名为 target
    • 此聊天类型参数现在用于 msg_command_outgoing

1.19.1 预发布版 3 修复的漏洞

  • MC-253182 字符串 "gui.abuseReport.reason.self_harm_or_suicide.description" 中第二个反身代词使用有误
  • MC-253214 工具提示在某些情况下会出现偏移
  • MC-253223 字符串 "gui.abuseReport.reason.terrorism_or_violent_extremism.description" 中有一个介词使用不当
  • MC-253496 /execute as {player} run say 也会被计入举报系统
  • MC-253742 聊天滚动条会与用于显示消息信任状态的彩色标记重叠
  • MC-253773 私聊消息会显示为已被服务器修改
