定位条

定位条是一个新的默认 UI 元素，用于显示世界中其他玩家的方向。

如果世界中没有其他玩家，经验条将正常显示；否则，如果世界中有其他玩家（且该玩家没有隐藏），则当获得经验时会显示经验条；否则，定位条将显示在同一区域。

  • 多人游戏服务器可以使用 locatorBar 游戏规则切换定位条
  • 玩家可以通过潜行、戴上生物头颅或雕刻南瓜，或使用隐身药水来隐藏
  • 旁观模式下的玩家不会显示在定位条上
    • 但是，旁观玩家之间互相可见
  • 面对 120 度范围内的其他玩家时，这些玩家会以彩色指示器显示在定位条上
    • 屏幕上方/下方的其他玩家还会在其指示器上显示上/下箭头
    • 指示器会根据其他玩家的距离变化为不同大小的图标
    • 每个玩家的彩色指示器颜色都是随机的
      • 服务器可以使用 /waypoint 命令修改指示器的颜色
        • 例如：使用 /waypoint modify @s color red 将指示器设置为红色
      • 队伍中的玩家将使用其队伍颜色覆盖默认指示器颜色

命令

添加了 waypoint

这是一个用于查询和修改路标的新命令。

waypoint list

waypoint modify <entity-selector> color <color>
waypoint modify <entity-selector> color hex <hex-color>
waypoint modify <entity-selector> color reset
waypoint modify <entity-selector> style <waypoint_style/resource>
waypoint modify <entity-selector> style reset

参数：

  • entity-selector：用于选择作为路标传输的实体（参见 waypoint_transmit_range 属性）
  • color：覆盖此路标的定位条图标颜色
  • hex <hex-color> 参数采用 web 格式（RRGGBB）
    • 红色可以是 hex F00 或 hex FF0000
    • 矢车菊蓝是 hex 6495ED
  • style：用于更改图标精灵图集和选择距离
    • set <waypoint_style/resource> 将样式更改为 waypoint_style/ 下的特定资源
    • reset 将恢复定位条的默认图标行为

路标样式

这些样式定义了在定位条上显示的自定义图标，位于 waypoint_style/ 资源目录中。

默认实现如下：

{
  "near_distance": 128,
  "far_distance": 332,
  "sprites": [
    "minecraft:default_0",
    "minecraft:default_1",
    "minecraft:default_2",
    "minecraft:default_3"
  ]
}
  • near_distance 和 far_distance 是可选的，默认值分别为 128 和 332。
    • far_distance 距离必须大于 near_distance
  • 每个精灵图都在前缀 hud/locator_bar_dot/（即 textures/gui/sprites/hud/locator_bar_dot 目录）下进行搜索。

游戏规则

添加了 locatorBar

  • 默认值为 true：启用定位条
  • 更改为 false 将移除所有玩家现有的所有路标
  • 游戏规则在实验期间已从 useLocatorBar 重命名。这可能会破坏在先前快照中创建的世界的次要命令相关功能。

添加了 waypoint_transmit_range 和 waypoint_receive_range

  • 默认值：0.0，最小值：0.0，最大值：60000000.0
  • 玩家的默认传输和接收范围为 60,000,000
  • 传输范围大于零的生物会向该范围内的附近接收者发送路标数据包
  • 类似地，接收者只会接收其接收范围内的路标（如果该范围为零，则不会接收任何内容）

示例：

  • /attribute @s minecraft:waypoint_transmit_range base set 0 将阻止玩家传输（将其隐藏）
  • /attribute @s minecraft:waypoint_transmit_range base set 80 将只允许玩家在 80 格范围内传输（在更远的玩家面前隐藏他们）
  • /attribute @s minecraft:waypoint_receive_range base set 0 将阻止玩家接收（关闭其定位条）
  • /attribute @s minecraft:waypoint_receive_range base set 120 将只允许玩家看到 120 格范围内的定位条圆点（隐藏所有更远的玩家）

路标广播

定位条通过服务器控制的路标系统工作。路标由玩家接收，路标与玩家之间的连接由多人游戏服务器管理。

  • 默认情况下，所有玩家都会从自身传输一个路标，并且所有玩家都会接收所有路标
  • 个别玩家的传输和接收范围可以通过 waypoint_transmit_range 和 waypoint_receive_range 属性进行控制
