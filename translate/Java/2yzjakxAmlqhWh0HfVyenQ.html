我们现在发布了 Minecraft 1.19.4 的第一个快照。此版本包含了新的无障碍功能、新命令以及大量错误修复！

祝您挖矿愉快！

更改

  • 恼鬼在空手时现在会使用单独的冲锋动画
  • 盔甲架在放置和破坏时现在会保留自定义名称

无障碍

  • 为首次启动游戏的玩家新增了无障碍引导界面
  • 新增了方向键导航
  • 资源包界面现在可以使用键盘导航
  • 自动跳跃现在默认关闭
  • 新增了一个“通知显示时间”无障碍选项
    • 更改解锁配方、进度、字幕以及选中物品名称等通知的可见时间

方向键导航

  • 现在可以使用方向键浏览菜单界面
  • 使用方向键导航时，需要按 Enter 或 Space 来激活滑块以开始更改数值

技术性更改

  • 数据包版本现在为 11
  • 新增了一个网络协议特性，用于强制在同一客户端刻内处理数据包组
  • 为 translate 聊天组件新增了 fallback 字段
  • translate 格式中超出范围的参数不再被静默忽略
  • clone 命令现在支持在不同维度之间克隆
  • data modify 命令现在可用的新的 string 来源
  • 新的 execute 子命令

网络协议

  • 客户端在收到登录数据包时现在会重置其安全聊天会话状态

数据包组

  • 在客户端绑定游戏协议中新增了分隔数据包
  • 两个分隔符之间的所有数据包保证在同一刻内处理
  • 出于安全原因，此特性在服务器绑定方向不支持

方块行为

  • 火焰在某些生物群系中烧得更快，这现在由 increased_fire_burnout 生物群系标签控制

生物生成

  • only_allows_snow_and_gold_rabbits 生物群系标签已重命名为 spawns_gold_rabbits 以匹配其行为
  • 白色兔子变体现在由 spawns_white_rabbits 生物群系标签控制
  • 狐狸变体现在由 spawns_snow_foxes 生物群系标签控制

生物行为

  • 雪傀儡在温暖生物群系中融化现在由 snow_golem_melts 生物群系标签控制

命令

clone

克隆命令现在支持指定源维度和目标维度。新语法：

clone [from <sourceDimension>] <begin> <end> [to <targetDimension>] <destination> ...

参数：

  • sourceDimension：要从中克隆的维度 ID
  • targetDimension：要克隆到的维度 ID

data

可用的新来源：

  • string <entity|block|storage> [path] [start] [end] - 将值作为文本读取，生成字符串值

新参数：

  • start：字符串开头要包含的第一个字符的索引
  • end：字符串结尾要排除的第一个字符的索引

execute

execute if|unless

execute if|unless 子命令可用的新条件：

  • execute if|unless loaded <pos> - 检查给定位置是否完全加载（同时考虑方块和实体）
  • execute if|unless dimension <dimension> - 检查执行是否在匹配的维度中

参数：

  • pos：要检查的方块位置
  • dimension：维度 ID

execute on

新的 execute 子命令，用于根据与当前执行实体的关系选择实体：

  • execute on <relation>

关系：

  • vehicle - 执行实体正在骑乘的实体
  • passengers - 直接骑乘执行实体的所有实体（不包括间接乘客）
  • controller - 控制执行实体的实体（例如：船上的第一个乘客）
  • owner - 执行实体的主人，如果它是可驯服动物（如猫、狼或鹦鹉）
  • leasher - 用拴绳牵引执行实体的实体（如果拴在栅栏上，则可能是拴绳结）
  • target - 执行实体的攻击目标
  • attacker - 在之前 5 秒内最后伤害执行实体的实体

如果该关系不适用于执行实体，或者没有匹配的实体，选择器将返回零个元素。

title

  • title times 的所有时间参数现在都是持续时间，并支持 t、s 和 d 后缀

weather

  • 如果未指定，天气变化的持续时间现在与游戏常规天气循环匹配
  • duration 参数现在是持续的刻数，并支持 t、s 和 d 后缀
    • 要保留现有功能，您需要为已有的命令添加 s 后缀

ride

新命令，允许实体开始或停止骑乘其他实体

语法：

  • ride <target> mount <vehicle>
    • 使单个目标骑乘单个载具
    • 如果出现以下情况，命令将失败：
      • vehicle 是玩家
      • target 已经在骑乘载具
      • target 和 vehicle 是同一个实体
      • vehicle 已经是 target 的乘客（直接或间接）
  • ride <target> dismount
    • 让 target 从它骑乘的任何载具上下来
    • 如果 target 没有骑乘任何东西则失败

游戏规则

  • 新增了 commandModificationBlockLimit，控制 clone、fill 和 fillbiome 一次执行中改变的方块最大数量

聊天组件

翻译回退

为 translate 文本组件新增了可选的 fallback 字段。

  • 新字段是一个字符串，如果缺少翻译，将使用该字符串代替
  • 如果缺少 fallback，则保留旧行为（即使用键本身作为翻译）

实验性特性

音符盒交互

  • 生物头颅现在可以不用潜行直接放在音符盒顶部
