命令

函数

  • function 命令已更改，以更好地适应新的 return 命令
  • 函数不再有任何结果，除非它们使用 return，或者在查找或实例化过程中出现错误
    • 这意味着 function 命令将不再返回（甚至显示）执行期间运行的命令数量
    • 错误条件：
      • 调用不存在的函数
      • 调用空的函数标签
      • 宏实例化失败
  • 此处的“结果”指会通过 execute store 存储的值
  • 之前，如果函数是通过 execute store ... run function 调用的，那么函数中的每条命令都会执行存储；这一行为已被移除
    • 这意味着单次调用 function 最多存储一次（如果未调用 return 则为零次）
    • 对于包含多个条目的函数标签，函数结果将累积，但部分结果会在每个函数末尾存储

限制

现有的函数限制已经过调整，以适应新的执行规则并防止更大范围的利用：

  • 即使从命令行运行，限制也适用（因此现在其行为总是会像被放在函数中一样）
    • 例如，由 execute as @e run function 调用的所有函数都将计入同一限制
    • 来自命令方块的执行仍计为单独的执行
  • 函数的 maxCommandChainLength 限制现在将计算“操作”，例如：
    • 为单个上下文执行命令
    • 在 execute 中执行一个阶段（无论修改了多少个上下文）
    • 调用函数
  • 新的游戏规则 maxCommandForkCount 限制了像 execute 这样的函数单次执行状态可以创建的上下文总量
    • 示例：如果世界中有 5 个实体，execute as @e 会创建 5 个上下文，而 execute as @e at @e 会创建 5*5 = 25 个上下文

execute if function

一个 execute 子命令，用于运行函数或函数标签并匹配返回值。这是对先前版本中移除功能的重新引入。如果给定的是标签，则无论先前函数的结果如何，所有函数都会运行。

语法： execute if|unless function <function> <continuation>

参数：

  • function：要运行的函数或标签

匹配

对运行的函数的返回值进行匹配：

  • 至少有一个函数必须成功，匹配才能成功
  • 成功的调用定义为满足以下条件的函数：
    • 使用 return 命令返回值
    • 返回值不为 0
  • 如果没有函数通过 return 退出，则 if 和 unless 都不会运行

return run

现在可以使用 return 命令的一种形式：return run。这是对先前版本中移除功能的重新引入。

语法： return run <command>

这会从运行指定 command 中获取 result 值，并将其作为函数的返回值返回。

  • 如果命令未返回任何值（例如，调用 function 时没有 return），则 return 不会执行，函数将继续执行
  • 如果给定命令失败，则返回值为 0
  • 在其他所有方面，它的工作方式与带指定返回值的 return 相同
  • 在发生分支时（例如 return run execute as @e run some_command），命令的第一次执行将触发 return
    • 如果没有执行（例如在 return run execute if @e[something_impossible] run some_command 中），函数将不会返回，并将继续执行
