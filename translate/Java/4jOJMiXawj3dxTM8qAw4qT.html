蜜蜂

我们兴奋得嗡嗡叫！现在谁能告诉 Cory 别再讲蜜蜂双关语了？

  • 蜜蜂是可爱、毛茸茸的中立生物
  • 不要伤害它们，它们也不想伤害你
  • 如果蜜蜂真的蜇了你，它会将螫针留在你体内并最终死亡，什么也不会掉落 :(
  • 蜜蜂喜欢美丽的花朵，并一生都在采集花粉
  • 采集花粉后，蜜蜂会飞回它们的家巢
  • 蜜蜂在携带花粉回巢的途中会帮助作物生长
  • 蜜蜂喜欢与其他蜜蜂分享它们最喜欢的花朵的位置
  • 如果蜜蜂没有家巢，它会四处游荡，直到找到可以使用的巢
  • 蜜蜂不喜欢下雨，而且它们在夜间睡觉。在这种情况下它们会回到巢中
  • 蜜蜂可以用花朵繁殖
  • 如果蜜蜂找不到花蜜，过一会儿它会回家待一阵子
  • 蜜蜂会尽量避开水面
  • 只要世界中任何地方在下雨，蜜蜂就会回巢，而不仅仅限于蜜蜂所在的位置
  • 蜜蜂会在自身周围 10 格范围内向所有方向寻找一个巢穴/蜂箱作为家园

蜂巢 / 蜂箱

在现实生活中，蜜蜂会在巢中跳舞，向其他蜜蜂展示花朵的位置！

  • 蜂巢会自然生成在繁花森林、平原和向日葵平原生物群系中
  • 当蜜蜂访问这个方块并顺利完成旅程且不受干扰时，蜂蜜等级会提高
  • 蜂蜜最多 5 级
  • 5 级时……相当粘
  • 蜜蜂利用蜂巢和蜂箱与其他蜜蜂分享花朵位置
  • 有时，已经知道花朵位置的蜜蜂会选择不使用这些信息
  • 蜂箱由玩家使用蜜脾和木板合成
  • 使用精准采集工具可以获得内部储存着蜜蜂的方块
  • 除非使用精准采集，否则蜂巢会被破坏
  • 蜂蜜满时使用剪刀可以获得蜜脾
  • 蜂蜜满时使用玻璃瓶可以获得蜂蜜瓶
  • 营火的烟雾能让蜜蜂平静下来——在巢/蜂箱下方放置一个营火可以让它们保持冷静模式
  • 支持红石！
  • 蜜蜂对蜂巢和蜂箱的喜爱程度相同！它们不偏心 :)
  • 蜜蜂只会从巢/蜂箱的正面出去

蜂蜜块

粘。非常粘！

  • 行走和跳跃会受到限制
  • 如果你站在被活塞推动的蜂蜜块上，你会跟着一起移动
  • 跳向蜂蜜块墙壁会滑落并减缓你的下落速度
  • 落在蜂蜜块上会稍微缓冲你的坠落
  • 当蜂蜜块被活塞推动或拉动时，它会粘住相邻方块并尝试将它们朝同一方向移动（就像粘液块那样）
  • 蜂蜜块和粘液块不会互相粘住，因为……嗯……因为 Minecraft 的特殊化学性质
  • 生物和动物不喜欢在蜂蜜块上行走，除非它们真的需要，因为太粘了，让它们不舒服
  • 蜂蜜块由四个蜂蜜瓶合成

实体谓词

player

实体谓词现在接受 player 字段，用于检查玩家属性。当实体不是玩家时失败。

字段：
  • level - 允许的玩家等级范围
  • gamemode - 与 /gamemode 命令相同的值
  • stats - 要匹配的统计信息列表。条目字段：type（如 minecraft:custom）、stat（如 minecraft:sneak_time）和 value（整数范围）
  • recipes - 配方 ID 的映射。布尔值表示该配方是否应被玩家知晓
  • advancements - 进度 ID 的映射。如果值为布尔值，则检查进度是否完成。如果值为对象，则检查条件完成情况

team

实体谓词现在接受 team 字段，用于匹配队伍名称。

位置谓词

block 和 fluid

谓词还接受 block 和 fluid 子谓词。可用字段：

  • block/fluid - 要匹配的确切方块/流体 ID
  • tag - 要匹配的方块/流体标签
  • nbt - 方块实体 NBT 的匹配器（仅适用于方块）
  • state - 名称-值属性的映射。值可以是整数、布尔值或字符串，也可以是带有可选 min 和 max 属性的对象

light

谓词现在接受 light 子谓词。该对象具有一个整数范围——light，用于匹配可见光（max(天空变暗, 方块光照)）。

Spectate
