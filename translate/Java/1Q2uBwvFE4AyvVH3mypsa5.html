21w43a 的新特性

  • 升级世界时，旧世界与新世界生成的边缘现在会被调整

旧世界的升级

  • 在靠近旧区块生成新地形时，会对地形进行调节，以更好地匹配边界处的现有地形
  • 在旧区块中，如果 y=0 处有基岩，其下方的柱状区域将被深板岩填充
    • 在此快照中升级的世界将永久保留这些深板岩，因此如果你之后希望在高度 0 以下生成新洞穴，请确保在升级前保留备份
  • 旧区块中 y=0 到 y=4 之间的旧基岩将被深板岩替换
  • 新的基岩层将放置在 y=-64 处

21w43a 中的更改

  • 视频设置中的“优先级更新”已更名为“区块构建器”
  • 减少了河流和海洋海岸线附近被水淹没的洞穴数量
  • 含水层的水位变化频率降低，因此你更常看到更大范围的一致水位。这意味着地下瀑布稍少一些，地下乘船旅行也稍微容易一些
  • 岩浆含水层稍微少见一些
  • 将大型垂滴叶的放置限制在黏土、草方块、泥土、耕地、苔藓块、缠根泥土、灰化土和菌丝上

21w43a 中的技术更改

  • 方块和流体刻的一些内部细节已被更改，以改善保存时间。虽然其行为应与之前完全一致，但这或许是测试你的红石装置的好时机（当然，是在世界副本或备份上进行）
  • 区块格式已更新

世界数据：区块格式

  • 移除了区块的 Level，并将其包含的所有内容上移
  • 区块的 Level.Entities 已移至 entities
  • 区块的 Level.TileEntities 已移至 block_entities
  • 区块的 Level.TileTicks 和 Level.ToBeTicked 已移至 block_ticks
  • 区块的 Level.LiquidTicks 和 Level.LiquidsToBeTicked 已移至 fluid_ticks
  • 区块的 Level.Sections 已移至 sections
  • 区块的 Level.Structures 已移至 structures
  • 区块的 Level.Structures.Starts 已移至 structures.starts
  • 区块的 Level.Sections[].BlockStates 和 Level.Sections[].Palette 已移至 sections[].block_states 中的容器结构
  • 区块的 Level.Biomes 现在使用调色板，并位于 sections[].biomes 中的类似容器结构内
  • 新增 yPos，表示区块中最小区块节的 y 坐标
  • 新增 below_zero_retrogen，包含用于支持零层以下生成的数据
  • 新增 blending_data，包含用于支持将新世界生成与现有区块混合的数据
