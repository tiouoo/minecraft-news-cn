快照 25w36a 已发布，其中包含模特——一种可通过命令生成的新技术实体，可用作 NPC。冲突的按键绑定现在可以协同运作，允许您将一个键绑定到多个操作。一如既往，此快照还包含技术调整和错误修复。

开发者说明：此快照为我们收集和绘制方块实体与粒子的方式带来了巨大变化。我们预计行为不会有任何改变，因此请多加留意，并将任何可疑情况作为 bug 报告，谢谢！

新特性

  • 世界边界现在可以按维度单独设置。

末地闪光

  • 当末影龙迷雾效果激活时，天空中的闪光来源不可见，并且影响世界的光线亮度会降低。

辅助功能

  • 多个具有相同按键分配的按键绑定现在可以协同工作，而之前只有一个会生效
    • 例如，您现在可以将 D 绑定为 跳跃 和 向左平移，同时进行跳跃和向左平移
    • 将同一个键分配给多个按键绑定的红色警告已改为黄色
  • 旁观者快捷栏菜单键现在可以重新绑定
    • 它是按键绑定屏幕中新的 旁观者 类别的一部分，与原有的 高亮玩家 按键绑定并列

更改

  • 格式代码现在会从行为准则文件中移除。

世界边界

  • 世界边界现在与维度绑定。
    • 这意味着每个维度都可以拥有自己的世界边界大小、位置等。

方块、物品和实体的小调整

  • 调整了铜火把和铜灯笼的颜色，使其对色盲玩家更易辨认。

界面

  • 现在在编辑框中双击单词会选中该单词。

方块状态

  • 充能置物架现在只能连接到朝向完全相同的其他充能置物架。

性能改进

模特

添加了一种名为 minecraft:mannequin 的新型技术实体，只能通过召唤命令生成。

  • 模特是没有连接玩家的玩家形象。
  • 模特始终在玩家显示 below_score 分数的地方显示 “NPC” 文本。
  • 模特的功能与生物实体相同——它们可以持有和穿戴装备、具有属性 & 效果、受到伤害等。

数据字段：

  • profile - 要在实体上显示的档案。这可以是玩家档案（与 minecraft:profile 组件格式相同）或具有以下字段的模特档案：
    • texture - 要使用的皮肤纹理的命名空间 ID
      • 皮肤相对于 textures 文件夹指定，并带有 .png 后缀
      • 例如，entity/player/wide/steve 将使用默认的宽版 Steve 皮肤
    • cape - 可选的披风纹理命名空间 ID
      • 指定时，使用与 texture 字段相同的格式
      • 省略此字段意味着模特没有披风
    • elytra - 可选的鞘翅纹理命名空间 ID
      • 指定时，使用与 texture 字段相同的格式
      • 省略此字段意味着模特使用披风纹理；如果披风纹理也被省略，则在穿着鞘翅时使用默认鞘翅纹理
    • model - 可选的模型类型，为 wide 和 slim 之一
      • 如果省略，则使用 wide
  • hidden_layers - 要隐藏的外层皮肤图层列表
    • 有效条目：cape、jacket、left_sleeve、right_sleeve、left_pants_leg、right_pants_leg、hat
  • main_hand - 模特的惯用手是左手还是右手——为 left 和 right 之一。

粒子

  • dragon_breath 现在可选择性地接受 power 参数（浮点数，默认 1.0），该参数会在所有随机数之后乘以其初始速度。
  • instant_effect 和 effect 现在可选择性地接受 power（浮点数，默认 1.0）和 color（RGB，默认 0xFFFFFF）参数。
  • flash 现在需要 color 参数（ARGB）。
