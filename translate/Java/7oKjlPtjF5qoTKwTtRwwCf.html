是时候发布一个高级快照了！在这个快照中，你也可以再次打开以前版本的世界——但有一个重要警告！我们计划为洞穴与山崖：第二部分引入的衔接技术尚未可用。如果你在这个快照中打开一个旧世界，它将在当前世界底部下方用空气填充，并在可见的区块边界处显示新区域。

我们强烈建议在加载此快照中的世界之前备份你的世界。

21w39a 的新特性

  • 添加了洞穴与山崖：第二部分的进度

进度

  • 添加“洞穴与山崖”进度：从主世界顶部坠落到底部
  • 添加“宾至如归”进度：在主世界乘坐炽足兽在熔岩上移动 50 格
  • 添加“星际商人”进度：在建筑高度限制处与村民交易
  • 添加“音乐之声”进度：在草甸生物群系中使用唱片机播放音乐

21w39a 的更改

  • 调整了山峰，使小山看起来更像真正的崎岖山峰，而不是平坦的丘陵土丘
  • 草甸中的孤树现在总是会包含一个蜂巢
  • 溺尸现在可以在溶洞中的含水层生成
  • 僵尸不再在溶洞中生成
  • buried treasure chests 现在可以包含水肺药水
  • 默认亮度更改为 50
  • 重新设计了效果在物品栏界面中的显示方式，使其在配方书打开时也能显示

效果

  • 你的效果列表现在显示在物品栏的右侧，而不是左侧
  • 当物品栏效果列表可见时，它会从游戏视图中隐藏，以减少屏幕杂乱
  • 现在有两种查看效果列表的模式：紧凑型和经典型
    • 经典模式是预先存在的效果列表，一个接一个显示
    • 紧凑模式是每个效果只显示一个图标，适合小屏幕空间
  • 游戏会自动在两种外观之间切换，以适应可用的屏幕空间（包括配方书打开时）

21w39a 的技术更改

  • 添加了 fall_from_height 和 ride_entity_distance 进度触发器
  • 将 nether_travel 更改为与其他类似触发器匹配
  • 添加了新的战利品表函数 set_potion
  • 更改了磁盘上的区块格式
  • 资源包格式已提升到 8
  • 独立的 server.jar 现在捆绑了各个库，而不是作为扁平存档

进度

新触发器

fall_from_height

  • 在玩家坠落落地后触发
  • 条件：
    • player - 触发此进度的玩家
    • start_position - 坠落开始前最后位置的位置谓词
    • distance - start_position 与玩家之间距离的谓词

ride_entity_in_lava

  • 当玩家在熔岩中骑乘时，每个游戏刻都会触发
  • 条件
    • player - 触发此进度的玩家
    • start_position - 骑乘开始时的位置（在熔岩上的第一个刻）
    • distance - start_position 与玩家之间距离的谓词

更改的触发器

nether_travel

  • entered 条件重命名为 start_position
  • exited 已移除，因为它与 player.location 相同

战利品表

新函数

set_potion

在任何物品上设置 Potion 标签

参数：
  • id - 药水 ID

世界数据：区块格式

  • 区块的 Level.Sections[].BlockStates 和 Level.Sections[].Palette 已移动到 Level.Sections[].block_states 中的容器结构中
  • 区块的 Level.Biomes 现在使用调色板，并位于 Level.Sections[].biomes 中类似的容器结构中
  • 区块的 Level.CarvingMasks[] 现在是 long[]，而不是 byte[]

资源包格式

  • minecraft/textures/gui/container/inventory.png 现在包含一个额外的精灵图，用于物品栏中效果列表的细长布局版本

服务端捆绑

  • server.jar 现在捆绑各个库，而不是将所有文件合并到单个存档中
  • 此更改旨在解决与 Java 模块相关的某些问题
  • 启动时，server.jar 会将库解压到由 bundlerRepoDir 配置的目录（默认：工作目录）
  • 要运行不同于服务端的主类，请使用 bundlerMainClass 属性（例如 java -DbundlerMainClass=net.minecraft.data.Main -jar server.jar --reports），或手动解压 jar 并使用 META-INF/classpath-joined 的内容用于命令行
