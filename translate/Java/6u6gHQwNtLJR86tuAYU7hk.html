进度

更改的触发器

  • placed_block、item_used_on_block 和 allay_drop_item_on_block 中的所有字段都已合并为单个 location 字段
  • 新的 location 类似于 player 字段——它是一个战利品条件/谓词的列表
  • 此列表中的所有条件都必须满足，触发器才会运行
  • 条件在一个名为 advancement_location 的新战利品上下文中进行评估。它可以访问：
    • 玩家作为 this 实体
    • 放置方块的位置
    • 放置/交互方块的状态
    • 手持/使用的物品作为“工具”
  • 迁移指南：
    • 旧 location 字段的内容应迁移到 location_check 条件
    • item 字段的内容应迁移到 match_tool 条件
    • block + state 字段的内容应迁移到 block_state_property 条件

示例（来自 make_a_sign_glow 进度）：

之前：

{
    "conditions": {
        "item": {
            "items": [
                "minecraft:glow_ink_sac"
            ]
        },
        "location": {
            "block": {
                "tag": "minecraft:all_signs"
            }
        }
    },
    "trigger": "minecraft:item_used_on_block"
}

之后：

{
    "conditions": {
        "location": [
            {
                "condition": "minecraft:match_tool",
                "predicate": {
                    "items": [
                        "minecraft:glow_ink_sac"
                    ]
                }
            },
            {
                "condition": "minecraft:location_check",
                "predicate": {
                    "block": {
                        "tag": "minecraft:all_signs"
                    }
                }
            }
        ]
    },
    "trigger": "minecraft:item_used_on_block"
}

遥测

此版本包含一个新的全局属性，随每个事件发送；必需的 WorldLoaded 事件中的一个新属性，以及两个新的可选择加入的事件。更新的必需事件将帮助我们更有效地排查启动器错误，并了解 Java Realms 内容的互动方式。更新的可选事件将有助于为游戏设计决策提供信息，并使我们能够跟踪和改进游戏加载速度。

所有事件

  • 新增属性：launcher_name
    • 此属性基于 minecraft.launcher.brand 系统属性设置。这将帮助我们更有效地排查与游戏启动相关的错误，因为我们将能够看到问题源自 Minecraft 启动器还是第三方程序。

更新的必需事件

  • world_loaded
    • 新增属性：realms_map_content
      • 当加载到 Realms Map Content 世界（小游戏）时，world_loaded 事件将收到该地图的名称。这是为了帮助我们了解 Java Realms 用户如何与 Java Realms 冒险或小地图内容互动。

新的可选事件

  • advancement_made
    • 当玩家完成一个进度时触发此事件，使我们能够看到进度 ID 和完成进度的时间。这帮助我们工作室了解玩家的进度和极限，从而为游戏设计提供信息。
  • game_load_times
    • 在游戏客户端加载时触发的事件，包含客户端加载所花费的时间。这样我们就可以致力于改进和减少加载游戏客户端所需的时间。
