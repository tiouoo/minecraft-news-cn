又一个快照发布了。这次我们修复了不少漏洞，同时也对部分洞穴与山崖特性做了一些更改，此外还为旁白添加了一些额外上下文。

21w20a 中的更改

  • 这次真的让紫晶洞变得更稀有了
  • GUI 旁白现在会包含悬停或聚焦元素的位置和用途
  • 用锄头锄缠根泥土现在会将其转变为泥土，并弹出悬挂根物品
  • 美西螈现在只会在水中装死
  • 羊驼不再在和平模式下向玩家吐口水

洞穴与山崖预览版的更改

下载更新后的数据包。

21w20a 中的技术更改

  • 为实体添加了一个新的 NBT 标签——“HasVisualFire”——带有此标签的实体即使在实际上并未着火时，也会在视觉上表现为着火
