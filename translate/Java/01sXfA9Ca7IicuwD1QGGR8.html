  • 新增泥巴与泥砖方块

深暗之域

向地底深处挖掘，就能发现《我的世界》中最为阴森的生物群系——深暗之域。

  • 光线昏暗、氛围诡异，即便是最勇敢的玩家也会心生畏惧
  • 深暗之域的地表遍布幽匿物质
  • 深暗之域不会自然生成任何生物

青蛙

  • 青蛙可以跳跃
  • 青蛙可以游泳
  • 青蛙可以在陆地行走
  • 青蛙会发出呱呱鸣叫声
  • 青蛙吞食小型史莱姆后会掉落黏液球
  • 青蛙吞食小型岩浆怪后会掉落蛙明灯方块
  • 不同变种的青蛙会产出对应种类的蛙明灯
  • 新增三种蛙明灯方块，属于光源方块

蝌蚪

  • 蝌蚪能够在水中游动
  • 蝌蚪上岸后会像鱼一样不断扑腾，最终死亡
  • 蝌蚪成熟后会变成青蛙
  • 蝌蚪成长为何种青蛙，由其孵化所在生物群系决定（寒冷、温带、温暖）
  • 蝌蚪可以用水桶捕捉

红树木材方块

新增木材种类：红树！红树生物群系与红树树木将在后续快照加入。

  • 红树原木、去皮红树原木
  • 红树木、去皮红树木
  • 红树根、沾泥红树根
  • 红树船、红树按钮、红树压力板、红树门、红树活板门、红树告示牌、红树台阶、红树栅栏、红树栅栏门、红树楼梯

红树树叶与红树繁殖体

  • 红树繁殖体是幼苗，会从红树树叶下方生长出来
  • 对红树树叶使用骨粉，树叶下方会长出新的繁殖体
  • 繁殖体共有4个生长阶段，使用骨粉可以加速生长
  • 成熟的繁殖体可以被采集，像树苗一样种植。目前种植后会长出橡树，但后续更新完善后将会生长为红树。

泥巴

  • 泥巴方块将会在即将上线的红树生物群系中自然生成。
  • 实体行走在泥巴上会轻微下陷，效果类似灵魂沙，但不会造成减速。
  • 手持水瓶对着泥土使用可以生成泥巴，发射器也能实现该效果。
  • 泥巴可以合成获得压实泥巴

泥砖

  • 泥砖是建筑方块，可以使用压实泥巴合成
  • 泥砖可以在工作台或切石机中制作成泥砖楼梯、泥砖墙与泥砖台阶。

幽匿系列方块

幽匿感测体沙沙作响的卷须总得有源头吧？幽匿系列方块登场，它们栖息于深暗之域。

  • 新增幽匿催发体：一种散发神秘灵魂能量的方块，附近生物死亡时，下方会蔓延生成幽匿斑块
    • 在幽匿催发体范围内死亡的生物不会掉落经验
  • 新增幽匿块
    • 生物在幽匿催发体附近死亡时，某种未知作用会消耗下方方块并将其转化为幽匿块
    • 幽匿能量扩散时有概率生成其他方块，例如在顶部生成幽匿感测体，并消耗能量
  • 新增幽匿脉络
    • 生成于幽匿斑块边缘
    • 与发光地衣类似，可以放置在任意朝向
    • 脉络蔓延时会将其他方块转化为幽匿物质
    • 幽匿脉络可以在水下蔓延
  • 新增幽匿尖啸体
    • 幽匿尖啸体较为罕见，由幽匿催发体产生的能量催生
    • 幽匿尖啸体可以充水
    • 采集幽匿尖啸体需要精准采集附魔，否则挖掘只会掉落经验

生物释放的灵魂能量会沿着幽匿脉络、幽匿块向随机方向传播，直到找到可供依附的基底方块。

  • 存储在幽匿块与幽匿脉络中的能量最终会消散；在幽匿催发体附近消散速度极慢，远离催发体后消散速度大幅加快。
  • 如果能量脱离催发体作用范围消散，有概率生成幽匿感测体。
  • 幽匿块、幽匿脉络、幽匿催发体必须使用精准采集附魔才能完整获取，直接挖掘只会掉落经验。
  • 所有幽匿系列方块适用的高效工具为锄

3D定向音频

  • 新增3D定向音频模拟音效选项
  • 佩戴耳机可以获得最佳体验

22w11a 技术性改动

  • 数据包格式版本升级至 10
  • 资源包格式版本升级至 9
  • 新增3D混合功能
  • 新增用于空格的字体字形提供器
  • 性能分析面板与F3调试界面新增GPU预估占用百分比
    • 仅支持GPU计时器查询的显卡能够显示该数据
  • 数据包与资源包现在可以选择性屏蔽前置加载资源包内的文件
  • 创建世界界面中的世界预设、世界类型以及超平坦预设现在可由数据包控制
  • 新增服务器配置项 max-chained-neighbor-updates，限制连续相邻方块更新的最大次数；负值代表不设上限

混合渲染

  • 混合渲染现已支持3D生物群系混合，地下生物群系也能够平滑过渡。
  • 移除 blending_data.old_noise，现在区块数据中是否存在 blending_data 决定区块是否判定为旧区块
  • 新增 blending_data.min_section 与 blending_data.max_section，用于指定参与混合计算的区块区域

空格字形提供器

  • 新增 space 类型字形提供器，支持自定义空格类字形
  • 该提供器仅有一个参数 advances，为码点与字形宽度的映射表
  • 空格字形渲染不再硬编码，需要在字体配置中手动声明

资源包过滤器

  • 数据包与资源包可在 pack.mcmeta 中添加 filter 配置段
  • 该配置段必填 block 字段，内容为命名空间与路径的正则匹配列表
  • 若当前资源包之前加载的资源包里存在匹配规则的文件，则该文件会被过滤（视作不存在）
  • filter 规则仅作用于当前包加载之前的资源包，不会影响自身文件
  • namespace 和 path 均可省略，省略后匹配全部内容
  • 示例：在原版资源包之后加载带有下方配置的资源包，即可隐藏原版全部配方与成就
"filter": {
    "block": [
        {
            "namespace": "minecraft",
            "path": "recipes/.*"
        },
        {
            "namespace": "minecraft",
            "path": "advancements/.*"
        }
    ]
}

世界预设

  • 新增注册表类型 worldgen/world_preset、worldgen/flat_level_generator_preset，实现世界预设（如放大化、单一生物群系）的数据驱动
  • 为世界预设新增两个标签（normal、alternative），控制创建世界界面“世界类型”按钮显示的选项
  • 为超平坦预设新增标签 visible，控制“配置超平坦世界”界面内选项的显示顺序
  • 世界预设名称可直接填入 server.properties 的 level-type 参数

条件判定器

  • 位置判定器中的 feature 字段重命名为 structure
