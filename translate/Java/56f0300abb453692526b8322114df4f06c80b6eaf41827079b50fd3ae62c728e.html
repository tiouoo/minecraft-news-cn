更改

  • 现在需要 OpenGL 3.3 才能游玩游戏，较之前的最低要求 3.2 有所提升。这并不会改变我们发布的最低系统要求。

开发者注： 我们认为 OpenGL 版本更新不会影响到多少人，甚至可能没有人受影响。自 2017 年以来，我们发布的最低要求一直是 OpenGL 4.0，而 OpenGL 3.3 最近也已有 15 年历史了。

游戏模式切换

  • 从旁观模式切换到创造模式时，玩家将不再停止飞行。
    • 取而代之，现在只有当玩家靠近地面时，切换游戏模式才会禁用飞行。
      • 如果玩家下方 1 格内有可碰撞表面（例如方块、快乐恶魂、船等），则视为靠近地面。
    • 如果玩家位于方块或可碰撞实体内，飞行将不会被禁用。
      • 这是为了防止玩家突然从地面掉落下去。

开发者注：此更改是对之前快照中一个错误修复的部分还原。尽管修复前的旧行为并非有意为之，但我们修复飞行问题所采用的方式并未完全按我们想要的方式落地。根据社区反馈，我们正在尝试这种新方法，作为影响较小的替代方案。

Minecraft 服务器管理协议

  • 客户端必须进行身份验证才能访问 API。
    • 客户端应提供一个带有服务器特定密钥的 Authorization 持有者令牌标头。
    • 该密钥在服务器属性文件中配置。
      • management-server-secret=
      • 密钥应为恰好 40 个字母数字字符（A-Z、a-z、0-9）。
      • 如果服务器属性为空，则将自动生成密钥。
      • 未授权的请求将被拒绝，并返回 401 Unauthorized。
  • 默认启用 TLS。
    • 可以在服务器属性文件中禁用。
      • management-server-tls-enabled=false
    • 需要在服务器属性文件中设置密钥库文件。
      • management-server-tls-keystore=path/to/keystore.p12
    • 密钥库文件必须是 PKCS12 格式。
    • 密钥库密码可以通过以下方式设置，按优先级排列：
      • 环境变量：MINECRAFT_MANAGEMENT_TLS_KEYSTORE_PASSWORD
      • JVM 参数：-Dmanagement.tls.keystore.password=
      • 服务器属性：management-server-tls-keystore-password=

服务器属性

  • management-server-port 的默认值已由 25585 改为 0，即每次启动管理服务器时分配一个可用端口。
  • 新增服务器属性 management-server-tls-enabled，用于控制 Minecraft 服务器管理协议是否使用 TLS。
    • 默认为 true。
  • 新增服务器属性 management-server-tls-keystore，用于控制 TLS 所使用的密钥库文件路径。
    • 默认为空字符串。
    • 当启用 TLS 且未提供密钥库时，专用服务器将无法启动。
  • 新增服务器属性 management-server-tls-keystore-password，用于控制 TLS 所使用的密钥库文件密码。
    • 默认为空字符串。

调试功能

  • 一些之前在编译时被移除的调试功能现在得以保留，玩家可以使用。
  • 可以通过 JVM 属性启用各个值：
    • 首先，必须使用 -DMC_DEBUG_ENABLED 或 -DMC_DEBUG_ENABLED=true 启用全局调试标志。
    • 然后，可以启用特定功能，例如 -DMC_DEBUG_BRAIN 或 -DMC_DEBUG_BRAIN=true。
    • 要获取所有可用调试属性的列表，请添加 -DMC_DEBUG_PRINT_PROPERTIES。
  • 警告：这是调试代码。请极其小心地处理！
    • 这是一项高级功能，旨在帮助模组开发者——不应在正常游戏中使用。
    • 不保证这些功能能按预期运作。
    • 它可能导致游戏崩溃或损坏你的世界。
    • 个别选项可能会在未通知的情况下添加、更改或移除。
