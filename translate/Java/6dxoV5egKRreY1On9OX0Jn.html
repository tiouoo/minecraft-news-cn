我们发布了一个全新的快照，其中包含对支持库的更新，以及大量漏洞修复！

技术性更改

  • LWJGL 库已升级至 3.3.2 版本
  • 游戏自带的默认 Java 版本已升级至 Microsoft OpenJDK 17.0.8

  • MC-229121 jdk.internal.loader.NativeLibraries.load 中的 JVM 崩溃

  • MC-259475 骑乘在坐下骆驼上的乘客在缓慢调整视角时，其转向有时会受到限制
  • MC-259860 载有乘客的坐下骆驼会持续上下张望其他玩家
  • MC-261951 放置在正在播放唱片的唱片机上的龙头/猪灵头颅不会摆动
  • MC-264092 当函数包含 /say 命令时，命令执行顺序会错乱
  • MC-264558 在 "connect.reconfiging" 翻译键中，"reconfiguring" 被拼写成了 "reconfiging"
  • MC-264559 "Added pack(s) contain symbolic links" 中存在语法错误
