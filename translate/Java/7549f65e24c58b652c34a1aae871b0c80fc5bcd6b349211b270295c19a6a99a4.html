今天，我们发布了 1.21.10 的 Release Candidate 1，这是一个热修复版本，修复了《铜器时代》更新发布后浮现的若干问题。

祝挖矿愉快！

1.21.10 Release Candidate 1 中修复的漏洞

  • MC-211096 蜘蛛网中的实体会穿透活塞
  • MC-278182 物品被推过细雪或蜘蛛网时，会卡进活塞头内部
  • MC-301916 风弹与某些方块碰撞时的行为不同
  • MC-302321 玩家被传送时区块不会加载
  • MC-302383 地板铺有地毯的房间中，无法将地图放在接触地面的墙壁上的物品展示框中
  • MC-302405 使用任何形式的 /tp [player] 命令的循环（或链式）命令方块，无法持续将玩家传送到同一位置
  • 修复了导致气泡柱上的实体飞入高空的问题
