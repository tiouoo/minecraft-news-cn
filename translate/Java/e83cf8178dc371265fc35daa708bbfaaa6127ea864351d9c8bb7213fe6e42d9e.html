实验性特性

冬季更新

嘎枝怪

  • 嘎枝不会在创造模式中的玩家周围激活或冻结
  • 由嘎枝之心召唤的嘎枝无法用命名牌命名

嘎枝之心

  • 连接到嘎枝之心方块的比较器将根据与连接的嘎枝的距离输出信号强度

更改

  • 调整了气泡 UI
    • 为气泡添加了空状态，并在玩家溺水时添加了晃动效果
    • 添加了 UI 中气泡破裂时的噗噗声

技术性更改

  • 数据包版本现在为 57
  • 资源包版本现在为 41

数据包版本 57

  • 添加了 disablePlayerMovementCheck 游戏规则（默认：false），用于禁用玩家移动速度限制
    • 该规则与 disableElytraMovementCheck 规则行为相同，但对是否使用鞘翅飞行均生效

物品组件

minecraft:equippable

  • 添加了字段 camera_overlay（可选）：装备时使用的叠加纹理的命名空间 ID
    • 如果未指定，则不使用叠加
    • 该 ID 将指向 textures/ 文件夹下的纹理，并自动假定为 .png
      • 例如，misc/pumpkinblur 指向 textures/misc/pumpkinblur.png

粒子

  • 粒子选项中颜色字段的格式现在更加标准化：
    • RGB 字段始终可以编码为浮点数向量（顺序：[R,G,B]）或作为单个打包整数（顺序：RGB）
    • ARGB 字段始终可以编码为浮点数向量（顺序：[R,G,B,A]）或作为单个打包整数（顺序：ARGB）
    • 更改的字段：
      • minecraft:trail.color（之前仅接受整数）
      • minecraft:dust.color（之前仅接受浮点数向量）
      • minecraft:dust_color_transition.from_color（之前仅接受浮点数向量）
      • minecraft:dust_color_transition.to_color（之前仅接受浮点数向量）

资源包版本 41

  • 为调整后的气泡 UI 添加了纹理和声音
    • 为空的空气泡添加了新纹理
    • 为空气泡破裂时添加了声音
