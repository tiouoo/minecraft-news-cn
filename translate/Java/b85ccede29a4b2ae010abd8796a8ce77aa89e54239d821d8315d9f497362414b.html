在本周的快照中，我们为所有聊天玩家带来了一项不错的便利性改进。现在，你未发送的消息将保存为草稿，详情请见下文。物品现在默认会放置在展示架中间。在我们把重点转向本次更新的技术调整和错误修复之前，我们还要宣布最后一个功能——它涉及铜傀儡和铁傀儡之间一个非常可爱的互动！至此，我们 2025 年第三次游戏更新的所有功能都已进入测试阶段，接下来我们将开始开发下一次游戏更新，敬请期待！

新功能

  • 作为持续进行的 Vibrant Visuals 工作的一部分，末地维度新增了光线闪烁
  • 铁傀儡有时会在附近的铜傀儡身上种一朵装饰花
  • 未发送的聊天消息现在会保存为聊天草稿

末地闪光

  • 末地维度现在拥有天空光照
  • 通常情况下，天空光照不会影响该维度的外观
  • 天空中会不时出现闪光
  • 当闪光发生时，天空光照强度会增加，使整个维度充满紫色光线

铜傀儡

  • 铁傀儡有时会在附近的铜傀儡身上种一朵装饰花
    • 这朵花可以用剪刀移除
    • 当铜傀儡变成铜傀儡雕像方块时，这朵花会掉落

聊天草稿

  • 如果聊天被强制关闭，未发送的聊天消息现在会保存为聊天草稿
    • 这包括因死亡或对话框打开等外部原因而关闭的情况，但不包括玩家主动关闭聊天的情况
  • 下次打开聊天时，已存在的任何聊天草稿都会自动填入消息框
  • 草稿文本在完全恢复前会显示为灰色
  • 通过以下交互操作，草稿文本可以恢复为普通文本：
    • 输入额外文本
    • 使用方向键移动文本光标
    • 点击它
    • 高亮选中它
  • 在草稿恢复之前按回车键，会像发送普通聊天消息一样发送该草稿
  • 在草稿恢复之前按退格键，会删除该草稿
  • 在聊天设置菜单中新增了一个选项，可默认保存未发送的聊天消息
  • 启用此选项后，未发送的消息将始终保存为聊天草稿，即使玩家主动关闭了聊天窗口

更改

  • 在当前服务器的游戏世界中见过的玩家现在始终会显示在社交互动界面中，即使他们处于离线状态

方块

展示架

  • 展示架中的物品将渲染在展示架中间
  • 更新了展示架中许多物品的大小，使其更适合展示架

开发者附注： 感谢你们对展示架的所有宝贵反馈！看到你们以各种富有创意的方式使用这个新方块，我们决定撤销上周将物品放置在展示架底部的更改，因为我们也认为物品居中放置能在建造时提供更多创意空间。

用户界面

聊天

  • 现在站在下界传送门内也可以开始聊天
  • 如果玩家在传送到另一个维度之前正在聊天，聊天窗口现在会保持打开且内容不变

技术性更改

  • 数据包版本现在为 83.1
  • 资源包版本现在为 65.2
  • 新增显示变换“on_shelf”
    • 用于在展示架上显示物品

数据包版本 83.1

方块状态

  • 为展示架方块新增了 align_items_to_bottom 方块状态属性
  • 如果为 false，展示架上的物品将忽略 on_shelf 物品显示变换的垂直位移，并垂直对齐渲染到展示架中间
  • 如果为 true，展示架上的物品将从展示架底部向上渲染，并遵循 on_shelf 物品显示变换的垂直位移
  • 默认为 false（物品对齐到展示架中间）

属性

run_command 点击事件

  • 以前，如果 command 字段包含需要签名消息的命令（/say、/me、/msg、/tell、/w、/teammsg、/tm），该命令会被静默丢弃
  • 现在则会显示一个界面，让用户可以将命令插入聊天窗口；如果聊天窗口无法打开，则可以复制命令到剪贴板

魔咒

explode 效果

新字段：block_effects - 指定逐方块粒子。每个方块粒子根据权重随机选择。每 tick 会从所有刻中爆炸中生成设定数量的方块粒子。

格式：条目列表：

  • weight：非负整数，表示选择此条目的随机权重
  • particle：要生成的粒子
  • scaling：可选，应用于爆炸中心与方块位置之间的缩放，未指定时为 1.0
  • speed：可选，应用于粒子速度的缩放，未指定时为 1.0

物品标签

  • 新增 #shearable_from_copper_golem - 所有可以通过剪刀从铜傀儡头部槽位移除的物品
