20w19a 的新特性

  • 添加了“炽足兽距离”统计
  • 现在所有下界生物群系都会生成黑石和砾石斑块，灵魂沙峡谷会生成灵魂沙斑块

20w19a 的更改

  • 村民现在无论职业状态或最近工作时间如何，都可以生成铁傀儡
  • 堡垒遗迹现在稍微少见一些
  • 降低了哭泣藤和缠怨藤被使用骨粉时的生长量
  • 现在破坏下界苗时需要使用剪刀才能获得物品
  • 调整了生物的生成以更贴近生物数量上限
  • 调整了下界的生物群系分布

20w19a 的技术性更改

  • 鱼现在拥有自己的生物类别和数量上限
