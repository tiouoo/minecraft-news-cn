嘿！今天我们为你带来上周 Minecraft Live 中展示的首个特性：合成器！

实验性特性

合成器

  • 合成器是一种可通过红石合成物品和方块的新方块
  • 合成器在接收到新的红石信号/脉冲（而非持续信号）时，每次会弹出一个已合成的物品
  • 接收到新信号后，合成器会从正面弹出合成结果
  • 如果输出结果包含多种物品，所有结果物品将一起弹出
  • 放置时，合成器可以朝向任意方向

合成器界面

  • 合成器拥有一个 3x3 的可交互合成网格
  • 合成器的合成网格槽位可切换，意味着玩家可以通过空手点击或按压某个槽位来改变其行为
  • 被“切换”的槽位无法容纳任何物品，也因此不能由其他方块（如漏斗和投掷器）放入物品
  • 与工作台不同，合成器会显示将要合成的物品预览，该物品将在下一次红石脉冲时被合成并弹出，但玩家无法手动取出
  • 合成器的界面在所有与其交互的玩家之间共享，这意味着多个玩家可以同时与合成器交互，类似于箱子和漏斗

合成器与其他方块的交互

  • 比较器的信号强度为 0-9，每个非空或已切换的槽位增加 1 点强度
  • 漏斗可用于向合成器放入物品或从中取出物品
  • 投掷器可用于向合成器放入物品
  • 从其他方块（例如漏斗、投掷器）移入物品时，会按照以下规则优先将物品填充到槽位中：
    • 优先选择第一个空槽位（从左到右，从上到下）
    • 如果没有空槽位，则优先选择同种物品的最小堆叠（若有多个则选择第一个）
    • 如果遇到已切换的槽位则会跳过。然后物品会被移入容器
    • 如果物品无法被移动，它将被弹出到世界中

更改

  • 新增了一个辅助功能选项，允许隐藏主菜单中的黄色闪烁文本
  • 为数据缺失的世界新增了恢复界面（例如，由于意外关机导致保存失败时）

技术性更改

  • 数据包版本现在为 21
  • 资源包版本现在为 19
  • 对聊天组件序列化进行了小幅更改

聊天组件

序列化

  • 可选的 type 字段新增了一个允许值：selector
  • 类型为 nbt 的组件现在拥有 source 字段，允许值为 entity、block、storage

数据包版本 21

  • 引入了 Jigsaw 结构池别名，可用于重新连接池的选择
  • 为 tnt 实体添加了 block_state 字段，以允许替换渲染的方块模型
  • 将 tnt 实体上的 Fuse 字段重命名为 fuse
  • 新增了 playersNetherPortalDefaultDelay 和 playersNetherPortalCreativeDelay 游戏规则，用于控制玩家在切换维度前需要站在下界传送门中的时间（以刻为单位）
  • 新增了游戏规则 projectilesCanBreakBlocks，用于控制弹射物在撞击时是否会破坏可被其破坏的方块，例如紫颂花、滴水石锥和饰纹陶罐
  • 添加了 white_smoke 粒子类型

Jigsaw 池别名

  • 为 Jigsaw 结构添加了可选的 pool_aliases 列表
  • 别名表示通过重定向单个结构实例上的池引用来重新连接 Jigsaw 池连接的可能性
  • 别名变体在 type 中表示，可以是以下之一：
    • direct 从别名到新池的 1:1 映射
      • alias 要替换的池
      • target 用于替换的池
    • random 1:n 映射，其中从 n 个池中随机选择一个用于结构实例
      • alias 要替换的池
      • targets 用于替换 alias 的候选池随机列表
    • random_group
      • groups 每个组都是上述别名类型的随机列表
      • 每个结构实例只选择一个组
      • 这样可以模拟诸如“如果池 X 被替换为 X1，同时将池 Y 替换为 Y1”的选择

资源包版本 19

  • 为 crafter 添加了方块模型、物品模型和方块状态定义
  • 为 crafter 添加了 GUI 容器纹理和精灵图
  • 添加了 white_smoke 粒子定义
