我们正在对本快照中的玩家举报工具进行一些重要更新，以更好地保护我们玩家的在线安全。

玩 Minecraft 应该为每个人带来包容且安全的体验，因此，除了游戏内聊天消息之外，你现在还可以在 Java 版中举报违反我们社区标准的玩家皮肤和用户名。

与聊天举报一样，没有任何自动化流程。任何被举报的皮肤或用户名都将由一组训练有素的 Minecraft 审核员手动审查，他们会根据提交的证据来判断该皮肤和/或用户名是否违反了我们的社区标准。违反这些标准的皮肤将从 Minecraft 中移除，并且任何玩家都无法再使用。违反这些标准的用户名，玩家必须更改后才能在共享服务器或 Realm 上在线游玩；但单人游戏模式仍然可以访问。要了解更多相关信息和其他安全政策，包括有关封禁程序、申诉流程以及我们如何处理恶意或重复举报的更多细节，请访问我们的专属 FAQ 页面。

新特性

玩家皮肤与名称举报

  • 现在可以在社交互动界面中举报玩家皮肤和名称
  • 如果某个皮肤或名称被举报，并被发现违反社区标准，我们的人工审核团队可以采取以下几种方式：
    • 禁止任何玩家使用该皮肤
    • 禁止任何玩家使用该名称
    • 对于屡次违规的玩家，暂停其在线游玩资格
  • 当皮肤被禁用时，拥有该皮肤的玩家：
    • 其皮肤将被移除
    • 在启动游戏时会收到通知
    • 将自动分配一个默认皮肤
    • 仍然可以玩多人游戏和单人游戏
    • 可以随时选择新的自定义皮肤
  • 当玩家的名称被禁用时，该玩家：
    • 需要选择一个新名称
    • 在启动游戏时会收到通知
    • 在更改名称之前无法在线游玩
    • 仍然可以玩单人游戏
  • 被禁用的皮肤或名称将来不能被任何玩家使用

更改

  • 海绵和湿海绵现在拥有自己专属的自定义声音
  • 用于判断生物能否攻击玩家或其他生物的计算方式已更改
  • 新增了“讲述人快捷键”辅助功能选项
    • 允许通过Ctrl+B切换讲述人的开启和关闭
  • 新增了“我要举报他们”玩家举报类别
  • 已撤销一项更改，该更改曾使盔甲纹饰图案会被底层盔甲纹理覆盖

生物攻击范围更改

用于判断生物能否攻击玩家或其他生物的计算方式已更改。以前，生物的水平宽度用于确定其攻击范围，而高度不产生任何影响。现在，生物可以攻击的区域是其碰撞箱在水平方向上的延伸。

以下是一些新规则会影响生物攻击范围的情况：

  • 如果生物完全位于你下方或完全位于你上方，它将无法攻击到你
  • 当你骑乘中等体型的生物（如马）时，你将受到保护，免受小型生物（如幼年僵尸）的攻击
  • 当你骑乘高大体型的生物（如骆驼）时，你将受到保护，免受标准体型生物（如僵尸）的攻击
  • 此外，劫掠兽将不再能隔着几个方块厚的墙壁攻击你
  • 然而，要逃离末影人，你需要至少站在离地面 3 格高的位置，而不是以前的 1.5 格
  • 生物将能够用其碰撞箱底部攻击你，前提是你的头部在范围内
  • 用于困住敌对生物的建筑可能需要调整才能确保安全

此更改不影响玩家的攻击范围，生物仍然需要看到其目标才能发动攻击。我们相信这个新系统将更加直观，并带来更一致的行为，我们欢迎对这一更改的所有反馈。

技术性更改

  • 调试屏幕上的图表现在可以通过 F3+1（饼图）、F3+2（FPS 和 TPS）和 F3+3（带宽和 ping）切换，而无需在打开屏幕时按住 Shift、Alt 或 Ctrl

数据包更改

  • 为盔甲纹饰图案添加了decal字段（默认值：false）
    • 如果为true，图案纹理将根据底层盔甲进行遮罩
