是时候发布另一个快照了！首先，我们将还原对 MC-271065 和 MC-152728 的修复。

本周的快照还带来了一大堆数据包更新，包括新的组件和物品模型功能。如果你喜欢摆弄数据包，你一定会在这个更新中找到有趣的东西！

一如既往，我们期待你在 feedback.minecraft.net 上提供关于这些新功能的反馈，并且你可以在 bugs.mojang.com 上报告任何错误！以下是本周的新内容：

新特性

  • 新增了吉尔吉斯语的语言支持

更改

  • 还原了以下修复：
    • MC-271065 - 潜行或使用某些物品时，斜向移动未被归一化
    • MC-152728 - 玩家执行会使其减速的动作时仍会继续疾跑

    开发者的说明：经过考虑，我们决定还原这两个已修复的漏洞。虽然我们确实想在将来重新审视这些机制，但很明显，仅凭这些近期的修复并不完全符合预期，并给跑酷、速搭桥以及整体移动带来了太多负面副作用。

  • 弩现在会在提示框中显示所有已装填的投射物，而不仅仅是第一个
    • 所有已装填的投射物也会将其完整的提示框作为子部分添加，而不只是烟花
  • 所有含有存储内容的容器物品（例如通过 Ctrl+选取方块 获取的箱子）现在会在提示框中列出前 4 个物品，就像潜影盒一样

技术性更改

  • 数据包版本现在为 64
  • 资源包版本现在为 49

数据包版本 64

  • potion 实体类型已被拆分为 splash_potion 和 lingering_potion
  • 没有 map_id 组件的已填充地图不再显示“未知地图”提示框（无效 ID 仍会生成此提示框）
  • 纹饰模板和纹饰材料物品不再在纹饰注册表中指定，而是分别在配方和物品中指定
  • 进度定义中的 background 字段不再包含 textures/ 前缀和 .png 后缀
  • 实体变体定义的更改
    • 猫和青蛙的变体现在由数据驱动
    • 添加了统一的变体选择规则定义方式

命令

  • SNBT 字面量现在接受异构列表

SNBT 更改

  • SNBT（NBT 类数据的文本表示）已被扩展以接受异构列表，即元素类型不相同的列表
  • NBT 格式未更改
    • 如果 SNBT 命令参数将值转换为 NBT（例如 /data 或 /summon 的参数），列表可能被转换以绕过 NBT 的限制
    • 转换示例：['a', {'b':3}] 存储为 [{'':'a'},{'b':3}]
    • 此转换不会被 /data 逆转

开发者的说明：在内部，我们在新代码中使用 JSON 和 NBT 两种格式读写数据。此更改确保我们不必担心列表方面的 NBT 限制。我们选择不扩展 NBT 本身，以避免破坏现有的外部工具。

统一变体选择

  • 具有生成规则的变体现在使用统一的方法进行选择
  • 选择过程：
    • 每个变体的 spawn_conditions 字段包含一个条目列表
    • 每个条目都有一个条件和整数优先级
    • 对于给定实体类型的所有变体的条件，会在实体生成的位置进行评估
    • 优先级低于剩余条目中最大优先级的条目会被移除
    • 游戏会随机从剩余条目中选择一个
    • 如果没有剩余条件，变体将保持默认不变
  • 条目的格式：
    • priority - 整数
    • condition - 可选结构
      • 字段：
        • type - 取值见下文
        • 依赖于 type 的附加字段
      • 如果此字段不存在，则条件始终为真

minecraft:structures

  • 字段：
    • structures - 单个条目、列表或描述结构的标签

    • spawn_conditions - 上面“统一变体选择”中描述的字段

猫变体

青蛙变体

    • spawn_conditions - 上面“统一变体选择”中描述的字段

物品组件

新的 weapon 组件

  • can_disable_blocking 字段被 disable_blocking_for_seconds 取代
    • disable_blocking_for_seconds - 非负浮点数（默认值：0）
      • 如果非零，在成功攻击后将在指定秒数内禁用正在格挡的盾牌

新的 blocks_attacks 组件

  • 存在时，此物品可以像盾牌一样用来格挡攻击，以保护持有者
  • 格式：包含以下字段的对象：
    • block_delay_seconds - 非负浮点数（默认值：0）
      • 成功格挡攻击前需要按住右键的秒数
    • disable_cooldown_scale - 非负浮点数（默认值：1）
      • 当受到禁用攻击（weapon 组件上的 disable_blocking_for_seconds）时，作用于该物品冷却时间的倍率
      • 如果为 0，此物品永远不会被攻击禁用
    • damage_reductions - 包含字段的对象列表（可选）
      • 控制一次攻击中应该格挡多少伤害
      • 如果未指定，则格挡所有伤害
      • 列表中的每个条目贡献一定量的格挡伤害，可选地按伤害类型过滤
      • 每个条目累加到格挡伤害中，由 clamp(base + factor * dealt_damage, 0, dealt_damage) 决定
      • 攻击最终对实体造成的伤害由 dealt_damage - clamp(blocked_damage, 0, dealt_damage) 决定
      • 条目格式：
        • type - 伤害类型 ID、伤害类型 ID 列表或带哈希前缀的伤害类型标签（可选）
          • 仅当造成的伤害类型与此字段匹配时，此条目才会贡献格挡伤害
          • 如果未指定，则接受任何伤害类型
        • base - 浮点数
          • 要格挡的恒定伤害量
        • factor - 浮点数
          • 应被格挡的造成伤害的比例
    • item_damage - 包含字段的对象（可选）
      • 控制一次攻击对物品造成的伤害量
      • 如果未指定，则每造成一点伤害就减少一点耐久度
      • 对物品造成的最终伤害由以下公式决定：floor(base + factor * dealt_damage)
      • 最终值可能为负，导致物品被修复
      • 格式：
        • threshold - 非负浮点数
          • 攻击对物品造成伤害之前所需的最低造成伤害量
        • base - 浮点数
          • 如果达到 threshold，对物品造成的恒定伤害量
        • factor - 浮点数
          • 如果达到 threshold，应作用于物品的造成伤害的比例
    • block_sound - 声音事件（可选）
      • 如果指定，当攻击被成功格挡时会播放此声音
    • disable_sound - 声音事件（可选）
      • 如果指定，当物品因攻击进入禁用冷却时会播放此声音

新的 break_sound 组件

  • 存在时，当物品耐久耗尽并损坏时会播放此声音
  • 如果不存在，物品损坏时不会播放声音
  • 此组件默认存在于每种物品类型上
  • 格式：声音事件
    • 例如：break_sound='item.wolf_armor.break'

新的 provides_banner_patterns 组件

  • 存在时，此物品可以放入织布机的图案槽位中
  • 格式：带哈希前缀的旗帜图案标签
    • 例如：provides_banner_patterns='#minecraft:pattern_item/globe'

新的 provides_trim_material 组件

  • 存在时，此物品在用于纹饰配方时将提供指定的纹饰材料
  • 注意，要用于内置锻造配方，该物品还必须在 #trim_material 标签中
  • 因此，纹饰材料注册表定义不再指定物品
  • 格式：纹饰材料 ID
    • 例如：provides_trim_material='minecraft:iron'

实体组件

  • 一些现有组件现在也会从生成物品转移到生成的实体：
    • minecraft:custom_name - 任何实体
    • minecraft:potion_contents - 滞留药水到区域效果云
    • minecraft:potion_duration_scale - 滞留药水到区域效果云

新的 tooltip_display 组件

  • 此组件允许隐藏由任何给定物品组件专门提供的提示框
  • 这取代了之前的 show_in_tooltip 字段，以及 hide_additional_tooltip 和 hide_tooltip 组件
  • 格式：包含字段的对象：
    • hide_tooltip - 布尔值（默认值：false）
      • 如果为 true，悬停时物品将没有提示框
    • hidden_components - 物品组件 ID 列表（默认值：[]）
      • 此列表中任何组件提供的提示框都将被隐藏
      • 如果该组件不提供提示框，则不会产生任何效果

移除 hide_additional_tooltip 组件

  • 被 tooltip_display 组件和 hidden_components 字段的使用所取代
  • 以下组件先前由 hide_additional_tooltip 组件覆盖，可能需要隐藏：
    • minecraft:banner_patterns
    • minecraft:bees
    • minecraft:block_entity_data
      • 具体来说，刷怪笼和试炼刷怪笼的方块实体数据将显示所配置的生物
    • minecraft:block_state
      • 具体来说，对于任何指定了 honey_level 属性的物品，该属性都会显示在提示框中
    • minecraft:bundle_contents
    • minecraft:charged_projectiles
    • minecraft:container
    • minecraft:container_loot
    • minecraft:firework_explosion
    • minecraft:fireworks
    • minecraft:instrument
    • minecraft:map_id
    • minecraft:painting/variant
    • minecraft:pot_decorations
    • minecraft:potion_contents
    • minecraft:tropical_fish/pattern
    • minecraft:written_book_content
  • 这还意味着上述列出的组件所带的提示框不再局限于特定物品类型
  • 注意：对于世界中带有 hide_additional_tooltip 组件的现有物品，同一物品上也存在的上述任何列出组件都将添加到 tooltip_display 中要隐藏的列表中

移除 hide_tooltip 组件

  • 被 tooltip_display 组件和 hide_tooltip 字段的使用所取代

attribute_modifiers 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代
  • 此组件现在始终使用其简化形式，将 modifiers 字段内联到顶层
    • 例如：attribute_modifiers={modifiers:[...]} -> attributes_modifiers=[...]

dyed_color 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代
  • 此组件现在始终使用其简化形式，将 rgb 字段内联到顶层
    • 例如：dyed_color={rgb:12345} -> dyed_color=12345
  • 指定的颜色现在支持 RGB 数组格式
    • 例如：dyed_color=[0.5, 1.0, 0.2]

can_place_on 和 can_break 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代
  • predicates 字段已被内联到顶层，并支持单个元素或列表
    • 例如：can_place_on={predicates:[{blocks:'stone'},{blocks:'dirt'}]} -> can_place_on=[{blocks:'stone'},{blocks:'dirt'}]
    • 或：can_place_on={predicates:[{blocks:'stone'}]} -> can_place_on={blocks:'stone'}

enchantments 和 stored_enchantments 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代
  • 这些组件现在始终使用其简化形式，将 levels 字段内联到顶层
    • 例如：enchantments={levels:{sharpness:2}} -> enchantments={sharpness:2}

jukebox_playable 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代

trim 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代

unbreakable 组件

  • 移除了 show_in_tooltip 字段，由 tooltip_display 组件取代

粒子

  • 粒子类型 tinted_leaves 现在有一个参数：
    • color：色调颜色，指定为打包整数或 4 个浮点数的列表

配方

smithing_transform 配方类型

  • base 材料字段不再是可选的
    • 之前，如果未提供基础材料，配方会被解析但永远无法使用

smihing_trim 配方类型

  • base、template 和 addition 材料字段不再是可选的
    • 之前，如果未提供这些材料，配方会被解析但永远无法使用
  • 新增了 pattern 字段，控制配方中将应用哪个纹饰模板
    • 因此，纹饰模板注册表定义不再指定物品
    • 格式：纹饰模板 ID
    • 例如："pattern": "minecraft:bolt"

纹饰模板和纹饰材料

  • 纹饰模板和纹饰材料的注册表定义不再包含 item 字段
  • 相反，图案和材料中的这种映射分别由配方和物品组件定义

战利品函数

toggle_tooltips

  • 现在 toggles 映射中支持任何组件 ID
  • 指定的任何组件都将在 tooltip_display 组件中被切换

资源包版本 49

物品模型

minecraft:component 选择属性

  • 如果所选值来自注册表，而当前数据包未提供它，该条目将被静默忽略
  • 在之前的快照中，无法识别的元素会导致整个物品模型被忽略

minecraft:component 布尔属性

  • 一个新的条件模型属性已添加到 condition 物品模型中：component
  • 使用组件谓词（类似于物品谓词中使用的）来匹配物品组件
    • 然而，不是将它们编码为 <predicate type>:<predicate value> 的映射，而是将单个谓词编码在两个字段中
  • 字段：
    • predicate - 组件谓词的类型（minecraft:data_component_predicate_type 注册表的成员）
    • value - 谓词特定的值

图集

minecraft:paletted_permutations 精灵图源

  • 新字段：
    • separator - 可选字符串（默认值：_）- 用于在连接纹理和排列名称以生成精灵图名称时使用的值
