一个真正非凡的快照登场了！本快照为我们的渲染管线带来了根本性的变化，引入了全新的 OpenGL Core 3.2 技术。此外，我们终于加入了繁茂洞穴生物群系。不过，与溶洞一样，目前只能通过创建自定义世界来体验。

对于使用较旧电脑的玩家，关于本快照有一个重要提示：随着 OpenGL Core 3.2 的引入，Minecraft Java 版有可能无法在不满足最低系统要求的电脑上运行。满足最低系统要求的电脑不会受到影响。

21w10a 的新特性

  • 加入了繁茂洞穴地下生物群系！
  • 加入了裂纹深板岩砖和裂纹深板岩瓦
  • 地下现在会出现深板岩的虫蚀变种
  • 虽然默认不会在世界中生成，但深板岩版本的铜矿石、绿宝石矿石和煤矿石已加入，供地图与数据包创作者使用

繁茂洞穴生物群系

繁茂洞穴地下生物群系现在可用于单一生物群系世界。它尚未在其他世界类型中生成。

  • 苔藓覆盖地面和天花板
  • 孢子花从天花板长出并滴落粒子
  • 包含黏土池，垂滴叶植物从中生长出来
  • 包含杜鹃花丛和盛开的杜鹃花丛
  • 杜鹃花树喜欢将根扎在繁茂洞穴中，所以如果你找到一棵杜鹃花树（无论在地表还是洞穴中），就会知道脚下有一个繁茂洞穴
  • 带有发光浆果的洞穴藤蔓从天花板垂下，照亮洞穴

21w10a 的更改

  • 现在可以将深板岩圆石烧炼为深板岩。
  • 深板岩现在可以沿任意轴放置
  • 避雷针现在可以含水
  • 地下最深处的化石会生成深板岩钻石矿石，而非煤矿石
  • 部分矿石纹理已更新

矿石分布

主世界的矿石生成已经过调整。

  • 在山地生成更多绿宝石
  • 更多青金石
  • 更少的铜、金和红石
  • 钻石矿团更小，但出现频率略高。不过钻石矿石总量更少
  • 铁更少，且生成在更低处
  • 煤炭暴露在空气中的概率降低

21w10a 的技术性更改

  • 游戏现在使用 OpenGL 3.2 核心配置文件运行
  • 史莱姆可召唤的最大尺寸现在为 128
  • give 命令一次最多只能给予 100 组物品（例如 6400 个石头或 100 把铁剑）

OpenGL

渲染现在使用 OpenGL 3.2 核心配置文件。所有固定功能渲染都已被基于着色器的渲染所取代。

着色器

现在所有受支持的渲染状态都包含了着色器。除 blit 着色器外，任何着色器也可以在资源包中被替换。目前，替换这些着色器不受官方支持，其工作方式将来可能会改变。

当前的渲染引擎使用一个与后期处理着色器管线类似的系统。两个系统之间存在一些差异，以适应略有不同的需求。
