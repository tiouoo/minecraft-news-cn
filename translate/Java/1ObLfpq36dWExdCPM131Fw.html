20w17a 中的新特性

  • 添加了实体距离缩放选项，范围从50%到500%
  • 现在可以在“创建世界”界面中更改难度和游戏规则

20w17a 中的更改

  • 改进了锻造台界面
  • 废弃传送门现在生成频率降低
  • 将“灵魂火焰火把”和“灵魂火焰灯笼”更名为“灵魂火把”和“灵魂灯笼”
  • 调整了堡垒遗迹的战利品
  • 墙现在会在更多方块（如压力板和旗帜）下方生成立柱
  • 如果没有可选世界，“单人游戏”按钮将直接跳转到“创建世界”界面

20w17a 中的技术性更改

  • 区块中的方块存储格式略有更改，以加快各种任务（渲染、寻路、世界生成等）的速度
  • 聊天组件样式现在可以选择字体
  • 支持完整的 Unicode 字符范围（有些人可能知道这意味着什么 😉）
  • 添加了 attribute 命令

世界保存格式

  • 保存 level.dat 现在使用随机命名的临时文件（而不是每次都使用 level.dat_new）
  • player/*.dat 现在以类似于 level.dat 的方式保存（包括保留 .dat_old 文件）

方块存储

Sections 元素中的 BlockStates 不再包含跨越多个64位字段的值。如果每个方块的位数不是二的幂（即单个64位值不能填满整数个方块状态），则部分位将不会被使用。 例如，如果单个方块状态占用5位，则每个64位字段的最高4位将未被使用。这也意味着存储大小略有增加（在5位情况下，从320个64位字段增加到342个）。

命令

attribute

对单个实体添加或修改属性。可能的语法： 参数：

  • attribute <target> <attribute> get [<scale>] - 获取属性的总值
  • attribute <target> <attribute> base set <value> - 设置基础值
  • attribute <target> <attribute> base get [<scale>] - 获取基础值
  • attribute <target> <attribute> modifier add <uuid> <name> <value> add|multiply|multiply_base - 添加修饰符（如果修饰符已存在则失败）
  • attribute <target> <attribute> modifier remove <uuid> - 移除修饰符
  • attribute <target> <attribute> modifier value get <uuid> [<scale>] - 获取修饰符的值
  • target - 单个实体（注意：只有玩家、盔甲架和生物拥有属性）
  • attribute - 属性的名称（如 minecraft:generic.max_health）
  • name - 描述修饰符可读名称的字符串（可带引号）
  • value - 浮点数值（注意：某些属性对最终值有限制，因此您的更改可能不明显）

聊天组件

悬停事件参数

  • style.hoverEvent 参数现在有一个参数 contents，其内容取决于类型：
    • 对于 show_text - 聊天组件
    • 对于 show_item - 要么是物品 ID，要么是包含字段 id、count 和 tag 的对象（最后一个为序列化 NBT）
    • 对于 show_entity - 包含字段 id（UUID）、name（聊天组件）和 type（实体类型资源位置）的对象
  • 旧的 value 参数现已弃用（但仍受支持）

颜色

color 属性现在可以包含以 # 为前缀的 RGB 值。例如，#55ff55 将产生与 green 相同的颜色。

自定义字体

聊天组件样式现在支持 font 属性，该属性是资源包中字体的资源位置。未设置该属性等同于 minecraft:default。

字体

  • Force Unicode 选项现在在普通字体和替代字体（称为 uniform.json）之间切换——无需重新加载
