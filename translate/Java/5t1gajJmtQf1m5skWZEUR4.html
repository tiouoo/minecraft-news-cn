我们现在发布 Minecraft: Java Edition 1.17.1。此版本更改了洞穴与山崖：第一部分的某些行为，并修复了一些漏洞和关键问题。

1.17.1 中的更改

  • 蓝色美西螈现在只能通过繁殖获得
  • 非尖叫山羊在繁殖时现在有极小的概率生出尖叫山羊
  • 山羊跳跃或冲撞时，其身上的状态效果现在也会生效
  • 将溺尸掉落铜锭的概率提高到 11%，每级抢夺额外增加 2%
  • 细雪现在填充炼药锅的速度是原来的 2 倍（不过仍然很慢！）
  • 僵尸、僵尸村民、尸壳和溺尸不再会捡起荧光墨囊

1.17.1 中的技术更改

  • 现在会记录已命名生物的死亡
  • 在基于 DNS 的重定向情况下，客户端将发送实际用于连接的主机名（这恢复了 1.17 之前的行为）
