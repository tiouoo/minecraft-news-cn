更改

  • 配方书搜索已更新，更改如下：
    • 搜索将仅匹配物品名称中任意单词的开头
    • 例如，搜索“tor”仍会显示火把和红石火把，但不再显示日光传感器
  • 所有配方，包括尚未解锁的配方，现在都会出现在搜索结果中
  • 这将使经验丰富的玩家能够找到他们想要的配方（即使尚未解锁），而不会让新玩家不堪重负

技术性更改

  • 数据包版本现在为 18
  • 加入服务器时，客户端选项现在在配置网络阶段发送

数据包版本 18

此数据包版本移除了最近引入的 execute if function 和 return run 功能。这些命令的缺陷（参见错误 MC-264595、MC-264699 和 MC-264710）需要一些重大更改来修复，我们不希望在临近发布时做出这些更改。

这些命令将在下一个快照系列中尽早重新引入，届时我们可以花时间与数据包制作者一起迭代和测试。

  • 移除了 execute if|unless function 命令形式
  • 移除了 return run 命令形式
  • 用作宏参数的数值现在总是无后缀插入，无论数值类型如何
  • 添加了游戏规则 enderPearlsVanishOnDeath，控制投出的末影珍珠在投掷者死亡时是否消失（默认值 true）

实验性功能

村民交易再平衡 第二部分

此预发布版更新了村民交易再平衡实验。此实验对普通世界没有影响。如果你想尝试这些更改，你必须在创建新世界时在实验菜单中打开功能开关。你可以在此处找到关于功能开关的更多信息。

感谢所有就实验性交易更改发送建议和反馈的人！我们正在尝试这些更改，以重新平衡村民交易系统，使其对每个人都更加公平和有趣。然而，这些更改尚未最终确定，在我们继续完善它们时，它们将保持为实验性功能。我们感谢您对此更改的反馈。访问此链接分享您的想法！我们一直在关注之前关于图书管理员和流浪商人更新的讨论，并期待看到对话继续。

制图师

在此之前，制图师只出售通往海底神殿和林地府邸的地图。在此实验中，制图师还可以出售七张新地图。这些新地图每张都指向不同的村庄或结构，可用于找到七种不同的生物群系。这将帮助那些想快速找到特定位置而不必等待偶然遇到的玩家。

来自不同生物群系的制图师将出售不同的地图选择。从一个村庄开始，通过沿着地图从一个村庄到另一个村庄，可以找到所有其他类型的村庄。

制图师现在出售 7 张新地图：沙漠村庄地图、丛林探险者地图、平原村庄地图、热带草原村庄地图、雪原村庄地图、沼泽探险者地图和针叶林村庄地图。

盔甲匠

盔甲匠的交易已更新，包含许多更改。

最大的更改是，购买钻石盔甲现在需要支付少量钻石以及绿宝石。这是为了使盔甲匠的钻石盔甲交易在游戏开始时玩家没有钻石时不太有用，同时仍然为花时间收集钻石的高级玩家提供强大的优势。

早期游戏玩家会发现盔甲匠作为铁盔甲、盾牌和绿宝石的重要来源非常有用。

其他更改包括：

  • 大多数大师级盔甲匠购买铁块（并且为此付钱很高）
  • 锁链盔甲仅由秘密的丛林和沼泽盔甲匠出售
  • 热带草原盔甲匠以折扣价出售受诅咒的钻石盔甲
  • 针叶林盔甲匠可以用一件钻石盔甲交换另一件

结构战利品

某些附魔书现在在部分结构中生成几率较高：

  • 远古城市：经验修补
  • 矿井：效率（I 至 V）
  • 掠夺者前哨站：快速装填（I 至 III）
  • 沙漠神殿：耐久（I 至 III）
  • 丛林神庙：耐久（I 至 III）
