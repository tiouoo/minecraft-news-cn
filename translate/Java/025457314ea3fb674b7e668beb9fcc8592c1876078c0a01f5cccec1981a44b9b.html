技术性更改

  • 数据包版本现在为 30
  • 资源包版本现在为 25
  • 为第三方服务器添加了保留的区域文件压缩 ID，用于自定义压缩实现
  • 添加了不压缩区域文件的选项
  • 允许服务器管理员查看专用服务器 TPS 调试图表

区域文件压缩算法

  • 为专用服务器配置属性 region-file-compression 添加了第三个值：
    • none 不压缩数据。虽然 CPU 使用较少，但会占用显著更多的空间，并且读写时间较长。可能适合与文件系统级压缩配合使用

为第三方服务器保留的压缩 ID

  • 压缩 ID 127 现在可用于区域文件压缩的自定义实现
  • 使用时，版本 ID 后必须跟一个表示所用自定义算法的命名空间字符串

数据包版本 30

  • 存储在物品或实体中的药水效果将不再编码其默认值
    • amplifier：0
    • duration：0
    • ambient：false
    • show_particles：true
  • 为所有当前拥有 HandItems 和 ArmorItems 的实体添加了 body_armor_item 和 body_armor_drop_chance，处理方式与 HandItems 和 ArmorItems 相同
  • 马匹的 ArmorItem、羊驼的 DecorItem 和狼的 armor 的处理方式已改为使用 body_armod_item 和 body_armor_drop_chance
  • 在命令中，移除了 horse.armor 槽位参数，改为添加 armor.body 槽位参数，现在适用于所有生物
  • 添加了 vault_connection 粒子
  • 添加了宝库方块，带有多种 NBT 元素，可用于自定义内容
    • config
      • loot_table 解锁时弹出的战利品表
        • 默认值："minecraft:chests/trial_chambers/reward"
      • activation_range 任何未解锁宝库的玩家必须处于此范围内，宝库才会打开其钥匙孔
        • 默认值：4
      • deactivation_range 所有符合条件的玩家必须离开此范围，宝库才会关闭其钥匙孔
        • 默认值：4.5
      • key_item 解锁宝库所需的物品堆栈
        • NBT 和堆栈数量用于比较
        • 默认值："minecraft:trial_key"
      • override_loot_table_to_display 可选的战利品表，用于显示笼子内的物品，而不是使用配置中 loot_table 的结果
        • 默认值：无值
    • shared_data
      • connected_particles_range 未解锁宝库的玩家必须处于此范围内，粒子才会从他们身上流向宝库
        • 默认值：4.5

资源包版本 25

  • 核心着色器定义中未使用的属性数组已被移除
  • 未使用的 position_color_normal 和 position_tex_lightmap_color 着色器已被移除
  • position_tex_color_normal 着色器（仅用于云）已被 rendertype_clouds 取代
  • IViewRotMat 统一变量已被移除，实体的 Position 属性现在位于（相机相对的）世界空间中
  • 光照方向统一变量不再与视图矩阵预乘
  • 添加了宝库方块的纹理和模型文件
  • 更改了试炼钥匙物品的纹理
  • 添加了 vault_connection 粒子的纹理和粒子文件

实验性功能

  • 添加了宝库方块

宝库

  • 一种存放着锁定的宝藏和战利品的方块——找到正确的钥匙来弹出其奖励
    • 遍布试炼密室，包含结构中价值最高的战利品
    • 试炼密室中的宝库需要试炼钥匙才能解锁
  • 可由无限数量的玩家解锁
    • 玩家解锁宝库后，无法再次解锁该宝库
    • 如果玩家之前未解锁过该宝库，当靠近时，会有一道橙色的粒子流从玩家流向宝库
  • 有一个钥匙孔，会根据附近的玩家而打开或关闭
    • 如果附近有任何玩家未解锁该宝库，钥匙孔将打开
    • 如果附近所有玩家都已解锁该宝库，钥匙孔将关闭
  • 在其笼子内，会循环展示可能从其战利品表中弹出的物品
  • 每次解锁时，弹出的奖励都会从其战利品表中随机选择
  • 无法在生存模式中合成或获得，挖掘时也不会掉落任何物品
  • 具有抗爆性，且无法被移动
  • 宝库目前复用奖励箱之前在试炼密室中使用的战利品表
    • 此战利品表是临时的，随着开发的继续将完全修订

试炼钥匙
