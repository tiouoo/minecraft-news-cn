今天我们发布了 Minecraft 1.21.5 的首个预发布版。从现在开始，直到下一个快照周期开始，我们主要将专注于修复漏洞和进行技术性调整。随着我们进入预发布阶段，我们将比常规的周三发布节奏更频繁地发布版本，敬请关注下一个预发布版！

更改

  • 为程序员美术纹理包添加了刷怪蛋纹理

技术性更改

  • 命令中接受内联值（例如战利品表、谓词、修饰器、数据组件、格式化文本（/loot、/give、/tellraw、/execute if predicate、/execute if items 中的数据组件等））的参数已恢复为接受数字来代替布尔值

开发者说明: 此前的更改是因为我们不再使用 NBT 作为解析这些值的中间格式，这意味着布尔值与数字被分离开来（类似于 JSON 中的处理方式）。我们决定暂时撤销该更改，因为目前如果不使用存储和宏函数，某些功能还无法实现。然而，一旦这些缺失的功能被添加（并且数据无需在文本之间来回转换即可传输），旧版布尔值处理方式将再次被移除。

网络协议

  • 客户端绑定的 player_chat 数据包现在包含一个索引，该索引随发送给客户端的每条消息递增
    • 该索引在登录时从 0 开始（或由配置阶段和 login 数据包重置）
    • 对于每条消息，服务器应将此值加 1
    • 如果此值以意外方式更新，客户端将断开连接
    • 由于协议要求每个聊天数据包按生成顺序到达客户端，其目的是使自定义服务器开发者能够更快地检测到丢失或乱序的聊天消息
  • 服务器绑定的 chat 和 chat_command_signed 数据包现在包含一个校验和字节，以及“最近看到”更新
    • 这是“最近看到”签名的简单哈希，服务器应能重新构建该哈希，从而更快地检测到状态不同步
    • 为了与协议转换兼容，可以将此值设为 0 来禁用检查

资源包版本 55

  • 调整了落叶方块模型
