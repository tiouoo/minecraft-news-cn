谓词

物品子谓词

  • 物品谓词中的一些字段已移至可选字段predicates中的映射
  • 新字段类似于物品堆叠上的components字段
  • 这样做是为了简化未来谓词的添加，并使子谓词更接近它们所匹配的组件名称
  • 以下字段已被移动：
    • enchantments - 字段已移至子谓词minecraft:enchantments
    • stored_enchantments - 字段已移至子谓词minecraft:stored_enchantments
    • potions - 字段已移至子谓词minecraft:potion_contents
    • custom_data - 字段已移至子谓词minecraft:custom_data
  • durability字段已扩展为minecraft:damage谓词：
    • 此检查现在适用于任何具有minecraft:damage组件的物品
    • 没有minecraft:damage组件的物品永远不会匹配
    • 要检查不可破坏的物品，请查询minecraft:unbreakable组件的值
    • 字段：
      • damage - minecraft:damage组件值的可选范围
      • durability - 耐用度的可选范围（最大伤害减去minecraft:damage的值）
  • 谓词minecraft:enchantments、minecraft:stored_enchantments、minecraft:potion_contents和minecraft:damage要求匹配的组件存在于物品上
    • 这意味着，例如，匹配空附魔列表将不会通过没有minecraft:damage组件的物品
    • 注意：某些组件（如minecraft:enchantments）具有默认值，因此它们始终会匹配

示例：

之前：

"item": {
  "enchantments": [
    {
      "enchantment": "minecraft:silk_touch",
      "levels": {
        "min": 1
      }
    }
  ]
}

之后：

"item": {
  "predicates": {
    "minecraft:enchantments": [
        {
          "enchantment": "minecraft:silk_touch",
          "levels": {
            "min": 1
          }
        }
      ]
  }
}

战利品函数

set_fireworks

用于设置minecraft:fireworks组件详细信息的新函数。

字段：

  • conditions：条件列表（默认：[]）：
    • 应用函数前要检查的条件
  • flight_duration：可选整数，0-255：
    • 以火药数量衡量的飞行持续时间
    • 如果省略，物品的飞行持续时间将保持不变；如果之前不存在该组件，则设置为0
  • explosions：firework_explosion数据列表 - 格式与minecraft:fireworks组件中的explosion字段相同：
    • 要设置的爆炸数据
  • mode：决定爆炸处理方式的枚举值：
    • replace_all：完全替换爆炸列表
    • replace_section：替换爆炸的一部分。参数：
      • offset：可选的非负整数：
        • 替换范围的起始位置
        • 如果省略，则使用0
      • size：可选的非负整数：
        • 爆炸中要替换的范围大小
        • 如果省略，则使用explosions字段的大小
    • insert：插入爆炸，将已有爆炸移到插入部分之后。参数：
      • offset：可选的非负整数：
        • 将在其之前插入爆炸的索引
        • 如果省略，则使用0（第一个爆炸之前）
    • append：在列表末尾添加爆炸

set_firework_explosion

用于设置minecraft:firework_explosion组件详细信息的新函数。

字段：

  • conditions：条件列表（默认：[]）：
    • 应用函数前要检查的条件
  • shape：可选爆炸形状：
    • 要设置的爆炸形状
    • 如果省略，则保留原始形状（如果之前没有组件，则使用small_ball）
  • colors：可选整数数组，RGB值：
    • 用于替换现有爆炸上初始粒子颜色的颜色列表
    • 如果省略，则保留原始颜色（如果之前没有组件，则使用[]）
  • fade_colors：可选整数数组，RGB值：
    • 用于替换现有爆炸上淡出粒子颜色的颜色列表
    • 如果省略，则保留原始颜色（如果之前没有组件，则使用[]）
  • trail：可选布尔值：
    • 设置爆炸是否应有拖尾
    • 如果省略，则保留原始has_trail值（如果之前没有组件，则使用false）
  • twinkle：可选布尔值：
    • 设置爆炸是否应有闪烁
    • 如果省略，则保留原始has_twinkle值（如果之前没有组件，则使用false）

set_book_cover

用于设置minecraft:written_book_content组件封面详细信息的新函数。如果存在，书中的任何页面都将保持不变。

字段：

  • conditions：条件列表（默认：[]）：
    • 应用函数前要检查的条件
  • title：可选的可过滤文本（格式与minecraft:written_book_content组件上的title相同）：
    • 要设置的标题
    • 如果省略，则保留原始标题（如果之前没有组件，则使用空字符串）
  • author：可选字符串：
    • 要设置的作者
    • 如果省略，则保留原始作者（如果之前没有组件，则使用空字符串）
  • generation：可选整数[0; 3]：
    • 要设置的代数值
    • 如果省略，则保留原始代数值（如果之前没有组件，则使用0）

set_writable_book_pages

用于操作minecraft:writable_book_content组件页面的新函数。

字段：

  • conditions：条件列表（默认：[]）：
    • 应用函数前要检查的条件
  • pages：可过滤字符串列表（格式与minecraft:writable_book_content组件上的pages相同）：
    • 要应用的页面
  • mode：决定处理方式的枚举值：
    • replace_all：完全替换书籍内容
    • replace_section：替换书籍的一部分。参数：
      • offset：可选的非负整数：
        • 替换范围的起始位置
        • 如果省略，则使用0
      • size：可选的非负整数：
        • 书籍中要替换的范围大小
        • 如果省略，则使用pages字段的大小
    • insert：插入页面，将已有页面移到插入部分之后。参数：
      • offset：可选的非负整数：
        • 将在其之前插入页面的索引
        • 如果省略，则使用0（第一页之前）
    • append：在书籍末尾添加页面

set_written_book_pages

用于操作minecraft:written_book_content组件页面的新函数。格式与set_writable_book_content相同，但pages字段包含可过滤组件而不是字符串（格式与minecraft:writable_book_content组件上的pages相同）。

任何封面数据都将保持不变，页面内容组件会设置为在玩家下次打开书籍时解析。
