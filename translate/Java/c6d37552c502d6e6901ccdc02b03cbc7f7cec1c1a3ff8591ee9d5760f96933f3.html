在今天的快照中，我们推出了 Java 版的全新好友列表，让您比以往任何时候都更容易保持联系并一起开始游戏。想知道它是如何运作的吗？您可以在此处了解更多关于好友列表的信息。

但这还不是全部！我们可能已经功能齐全了——但还有一个最后的惊喜等着您！今天就来聆听 fingerspit（Paula Ruiz）为 Chaos Cubed 创作的官方原声带——包括音乐唱片“Bounce”！

新特性

好友列表

  • 添加了好友列表，可通过标题屏幕和暂停菜单上的新“好友”按钮访问
  • 好友列表可以通过新的按键绑定打开（默认：“O”）
  • 好友按钮会显示一个通知徽章，上面显示收到的好友请求数量，最多显示 5 个（超过后会显示“更多”指示符）
  • 好友列表以叠加层形式呈现，包含两个标签页：
    • 好友：显示您当前的好友，允许您移除他们，并允许您通过档案名称发送新的好友请求
    • 待处理：显示收到的好友请求（可以接受或拒绝）和已发送的好友请求（可以取消）
  • 好友的在线状态会显示在好友列表中其名称下方，为以下之一：
    • “离线”
    • “在线”
    • “在世界中”
    • “在可加入的世界中”
  • 发送、接受、拒绝、取消和移除操作会在界面中确认，并在服务不可用、请求频率受限或所请求的档案名称不存在时显示明确的错误信息
  • 游戏运行期间发生的好友变动会通过 toast 通知显示：
    • 当好友请求被发送时
    • 当收到好友请求时
    • 当其他玩家接受您发出的好友请求时
  • 当皮肤可用时，toast 通知会显示其他玩家的头像
  • 好友列表在打开时会每分钟检查一次更新，否则每 5 分钟检查一次
  • 首次在标题屏幕上显示好友按钮时，会弹出确认对话框，询问是否启用好友列表
  • 好友列表、好友请求隐私以及 Microsoft 帐户安全设置链接均可在在线选项的新“好友列表”部分中管理
  • 在 Xbox 档案中将聊天设置设为“仅限好友”的玩家，只能看到来自好友的聊天消息

已知问题

开发者注：这是该系统的首个版本，发布时带有一些已知问题。在接下来的快照中会对其进行改进。

  • 在接收者接受好友请求之前取消请求，可能导致接收者的待处理列表进入不同步状态
    • 接收者仍会将其视为收到的请求，但接受后，该请求会变成他们发出的好友请求
  • 拒绝好友请求可能导致发送者的已发送列表进入不同步状态
    • 发送者也需要取消他们的好友请求才能恢复到正确的同步状态
  • 如果玩家启用了好友列表，但关闭了“允许请求”设置，其他玩家将无法接受来自他们的好友请求
  • 如果您的 Xbox 档案聊天设置为“仅限好友”，您将无法看到自己的聊天消息

点对点

  • 添加了从新的多人游戏选项界面将单人世界开放为在线多人游戏的功能
  • 有两种与好友一起游玩的途径
    • 邀请加入世界：房主可以邀请好友加入他们的世界，被邀请的玩家可以接受或拒绝邀请
    • 请求加入世界：玩家可以请求加入好友的世界（如果该世界已开放为在线多人游戏），好友可以接受或拒绝请求

强效硫磺

  • 间歇泉的喷发和冷却时间现在基于方块位置随机化，并且替换方块后不会改变
  • 当下方放置熔岩方块时，强效硫磺现在可以喷发
  • 下方有熔岩时，间歇泉会持续喷发，但与岩浆块引起的喷发相比，声音会稍微低沉
  • 来自强效硫磺的有毒气体现在可以穿过不可碰撞的含水方块上升，并通过其他不可碰撞方块扩散
  • 喷发中的强效硫磺现在可以通过不可碰撞方块释放其喷流并对实体产生助推
    • 这包括脚手架，它可以作为铜格栅的替代品，让您站在喷发的强效硫磺上方而不受有毒气体的影响

多人游戏选项

  • 此界面允许您配置当前所在世界的多人游戏设置
  • 多人游戏范围可以设置为以下之一：
    • 关：（默认）没有人可以加入您的世界
    • 局域网：只有您本地网络中的玩家可以加入您的世界，就像原来的“对局域网开放”界面一样
    • 在线：您可以邀请您的好友从任何地方加入您的世界
  • 游戏模式和允许作弊选项也在此界面中可用

设置

  • 在在线选项中添加了一项设置，用于控制好友列表及其功能的可用性
  • 在在线选项中添加了“游戏内通知”开关，用于控制好友列表 toast 通知是否在世界中显示
  • 在在线选项中添加了“允许请求”开关，用于控制其他玩家是否可以给您发送好友请求
  • 在在线选项中添加了“Xbox 设置...”按钮，可打开 Microsoft 帐户隐私和在线安全设置
  • 在在线选项界面中添加了在线状态选项，用于控制与好友共享多少活动信息（默认：“全部”）
    • “全部”：共享活动信息，并在世界开放为在线多人游戏时允许好友请求加入
    • “受限”：活动共享限制为“在线”&“离线”
    • “无”：不共享任何活动信息，对好友显示为“离线”

遥测

新的自愿加入事件

  • p2p_connection
    • 该事件在尝试点对点连接后发送
    • 添加了新属性：p2p_connection_successful
      • 点对点连接是否成功建立
    • 添加了新属性：p2p_connection_failure_stage
      • 连接尝试失败时所处的阶段，例如SIGNALING、ICE_CONNECT或TIMEOUT
    • 添加了新属性：p2p_connection_ice_path
      • 连接所使用的网络路径类型，例如LOCAL、DIRECT、RELAY或UNKNOWN
    • 添加了新属性：p2p_connection_local_candidate_type和p2p_connection_remote_candidate_type
      • 连接双方各自使用的 ICE 候选类型，例如HOST、SRFLX、PRFLX或RELAY
    • 添加了新属性：p2p_connection_total_time_ms、p2p_connection_signaling_time_ms和p2p_connection_ice_connect_time_ms
      • 点对点连接流程每个阶段的计时信息
