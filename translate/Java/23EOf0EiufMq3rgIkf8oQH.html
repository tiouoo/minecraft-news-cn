我们现在为 Minecraft: Java Edition 发布 1.19.1。此版本新增了悦灵复制和新的玩家安全功能。

功能

  • 新增悦灵复制
  • 调整了幽匿催化体
  • 新增聊天信任状态
  • 新增聊天预览选项
  • 新增玩家举报

悦灵

  • 悦灵会随着唱片机中播放的唱片起舞
  • 如果悦灵在跳舞时被给予紫水晶碎片，它会进行复制
    • 复制有 5 分钟的冷却时间

幽匿催化体

  • 幽匿催化体现在会掉落 5 点经验值而非 20 点

聊天

  • 将聊天滚动条移至右侧
  • 输入消息时，所显示聊天消息的签名状态会以彩色指示器显示
    • 指示器会出现在聊天输入框左侧，或在使用聊天预览时出现在聊天预览左侧
    • 当显示的消息已签名时，指示器为蓝色
    • 当聊天预览已启用且预览等待签名时，指示器为橙色
  • 当预览等待签名时，聊天预览的背景也会略微变淡
  • 当连接到未强制安全聊天的服务器时，新增警告弹窗
  • 社交互动屏幕上的玩家列表现在会将最近有消息的玩家条目置于列表顶部

聊天信任状态

  • 未使用安全聊天系统签名或被服务器篡改的消息现在会被标记
    • 缺少签名或签名无效的消息标记为“不安全”
    • 检测到被修改的消息标记为“已修改”
  • 消息的信任状态通过彩色指示器和图标显示
    • 彩色指示器始终可见
    • 图标仅在聊天屏幕打开时可见
  • 悬停在图标上会提供有关信任状态的更多信息
    • 对于被修改的消息，工具提示中还会显示原始安全文本
  • 系统消息（非玩家聊天，例如命令输出）会以灰色指示器显示

聊天预览

  • 新增“发送时”聊天预览选项，仅在尝试发送消息时更新聊天预览
    • 要确认发送消息，需要再次按回车键
    • 之前的“开”设置已重命名为“输入时”
  • 在“输入时”模式下，如果消息未被服务器修改，聊天预览将不再显示预览
  • 聊天预览现在在单人游戏中启用，并且会在使用具有选择器替换的命令（例如 /say）时显示
  • 预览的悬停事件和点击事件会以实心背景突出显示

玩家举报

现在可以举报在游戏聊天中发送辱骂性消息的玩家。举报人需要选择包含不当内容的具体聊天消息以及举报类别，以便我们的审核团队能够根据最佳上下文采取行动。这可以通过社交互动屏幕访问。

  • 可以选择多条聊天消息进行举报
    • 所选消息附近的额外聊天消息也会被用于为我们的审核团队提供更多上下文
  • 可以从举报类别列表中选择举报类别
    • 举报类别屏幕有一个“了解举报”按钮，链接到帮助文章
  • 可以输入额外评论，以提供有关举报的更多细节和信息

有关更多信息，请参阅这篇关于玩家举报的文章和我们的举报常见问题解答。

停权与封禁

  • 如果你被暂停在线游戏，游戏现在会在启动时显示通知屏幕
    • 会显示停权原因以及生效时长

Realms

  • 被 Java Realms 不当内容过滤器过滤的消息现在会以黄色标记显示
  • 如果玩家发送的聊天消息被 Realm 上一个或多个接收玩家完全过滤，玩家将收到通知

技术性

  • 聊天输入框不再适用于具有负前进量的自定义字体字形，或前进量大于 32 的字形

聊天类型

  • 添加到 chat_types 注册表中的聊天类型现在仅用于玩家聊天，而不用于系统消息
    • system 和 game_info 聊天类型已被移除
  • 聊天类型已简化，现在仅需定义 chat 和 narration 装饰
    • 聊天类型不再支持叠加层
    • 应改用系统消息来显示叠加层
  • msg_command 聊天类型已拆分为 msg_command_incoming 和 msg_command_outgoing
  • team_msg_command 聊天类型已拆分为 team_msg_command_incoming 和 team_msg_command_outgoing
  • team_name 聊天类型参数已重命名为 target
    • 此聊天类型参数现在由 msg_command_outgoing 使用

组件

  • 文本组件的 run_command 点击事件不再支持直接发送聊天消息
    • 仅支持命令
    • 这意味着值现在总是需要以 / 为前缀
    • 不允许使用会生成已签名玩家聊天消息的命令（例如 /say）
      • 应改用 /tellraw

游戏事件

新增游戏事件

  • jukebox_play
  • jukebox_stop_play

多人游戏安全聊天签名

  • 聊天消息的顺序现在会经过加密验证
    • 这用于验证玩家举报的聊天消息上下文

服务器

  • 专用服务器的 enforce-secure-profile 现在默认为 true
  • 服务器日志中的不安全聊天消息现在带有 [Not Secure] 标签前缀
  • 自定义服务器可以通过新的网络数据包设置常规聊天的自动补全选项
  • 自定义服务器可以通过新的网络数据包隐藏玩家聊天消息的显示
    • 这不会从聊天日志中删除玩家聊天消息

1.19.1 中修复的漏洞

  • 此版本修复了 50 多个漏洞。请查看问题跟踪器上的列表。
