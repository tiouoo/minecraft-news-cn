我们现在发布了 Minecraft 1.20 的第二个预发布版。此预发布版包含错误修复。

挖矿愉快！

技术更改

  • 如果用户启用了文本转语音功能但该功能不可用，游戏现在会在启动时显示消息框。
  • "item": "minecraft:air" 现在可以在数据包配方中使用，表示匹配空槽位的原料。
    • 但以下配方类型不允许使用空原料：
      • minecraft:crafting_shaped
      • minecraft:crafting_shapeless
      • minecraft:smelting
      • minecraft:blasting
      • minecraft:smoking
      • minecraft:campfire_cooking
      • minecraft:stonecutting
