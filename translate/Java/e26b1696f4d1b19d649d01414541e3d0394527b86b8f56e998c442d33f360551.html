服务器属性

若干服务器属性已被移除，改为游戏规则，从而允许在服务器运行时更改这些设置。

  • 移除了服务器属性 allow-nether，改用新游戏规则
  • 移除了服务器属性 spawn-monsters，改用新游戏规则
  • 移除了服务器属性 enable-command-block，改用新游戏规则
  • 移除了服务器属性 pvp，改用新游戏规则
  • 添加了服务器属性 management-server-enabled，用于控制是否启用新的 Minecraft 服务器管理协议
    • 默认为 false
  • 添加了服务器属性 management-server-port，用于控制 Minecraft 服务器管理协议在哪个端口启动
    • 默认为 25585
  • 添加了服务器属性 management-server-host，用于控制 Minecraft 服务器管理协议使用哪个主机启动
    • 默认为 localhost
  • 添加了服务器属性 status-heartbeat-interval，用于控制管理服务器向已连接客户端发送心跳通知的间隔
    • 默认为 0，即表示禁用

Minecraft 服务器管理协议

为专用服务器添加了服务器管理 API（基于 WebSocket 的 JSON-RPC）

  • 该 API 默认禁用，可在服务器属性文件中启用
    • management-server-enabled=true
    • management-server-host=localhost
    • management-server-port=25585
  • 启用后，可通过 ws://<management-server-host>:<management-server-port> 访问该 API
  • 支持查询和更新服务器状态（玩家、白名单、管理员、设置、游戏规则）
  • 在状态更改时发送通知（例如玩家加入、游戏规则更新）
  • 调用 {"id":1,"method":"rpc.discover"} 会返回一个 API 架构，其中包含当前运行服务器支持的方法和通知
  • 数据生成器会在报告输出文件夹中生成 API 架构（json-rpc-api-schema.json），与 rpc.discover 方法返回的内容保持一致
  • 该 API 遵循 JSON-RPC 2.0 规范
  • 使用带命名空间的方法，保留命名空间为 minecraft（例如 minecraft:players、minecraft:allowlist/add）和 notification（例如 notification:players/joined）
    • 可通过自定义命名空间扩展更多方法和事件
  • 核心方法分组：players（玩家）、allowlist（白名单）、operators（管理员）、server（保存、停止）、server settings（服务器设置）、game rules（游戏规则）
  • 示例方法调用：
    • 请求：{"method":"minecraft:allowlist/add","id":1,"params":[[{"name":"jeb_"}]]}
    • 响应：{"jsonrpc":"2.0","id":1,"result":[{"id":"853c80ef-3c37-49fd-aa49-938b674adae6","name":"jeb_"}]}
  • 示例通知：
    • {"jsonrpc":"2.0","method":"notification:players/joined","params":[{"id":"853c80ef-3c37-49fd-aa49-938b674adae6","name":"jeb_"}]}
  • 示例错误：
    • 请求：{"method": "minecraft:foo/bar","id": 1}
    • 响应：{"jsonrpc":"2.0","id":1,"result":{"jsonrpc":"2.0","id":1,"error":{"code":-32601,"message":"Method not found","data":"Method not found: minecraft:foo/bar"}}}
    • 错误和错误代码遵循 JSON-RPC 2.0 错误对象格式

游戏规则

  • 添加了 pvp 游戏规则，用于控制玩家能否对其他玩家造成伤害
    • 默认为 true
  • 添加了 allowEnteringNetherUsingPortals 游戏规则，用于控制能否通过传送门进入下界
    • 默认为 true
  • 添加了 spawnMonsters 游戏规则，用于控制怪物是否自然生成
    • 默认为 true
  • 添加了 enableCommandBlocks 游戏规则，用于控制命令方块是否启用
    • 默认为 true

文本渲染

object 文本组件

  • 此组件已更新，支持将其他非字符对象作为文本的一部分显示
  • 新格式：
    • object：对象类型，字符串，取值见下文
    • <type-specific>：取决于对象类型的附加字段
  • 与 nbt 文本组件类似，object 字段可省略
    • 但建议提供该字段以便进行错误检查

atlas 对象类型

  • 行为与之前的 object 组件相同，但现在是一个独立的对象类型
  • 使用与之前相同的格式

player 对象类型

  • 渲染玩家头颅
  • 若提供了部分配置文件，将以与玩家头颅上的 minecraft:profile 组件相同的方式解析皮肤
  • 格式：
    • player：玩家配置文件
      • name：玩家名称，可选字符串
      • id：玩家 UUID，可选 UUID
      • properties：配置文件属性，可选映射
    • hat：控制帽子层的渲染，布尔值，默认为 false
