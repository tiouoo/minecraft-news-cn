聊天预览

  • 服务器可以通过在 server.properties 中设置 previews-chat=true 来启用聊天预览
  • 启用后，聊天输入框上方会出现一个服务器控制的预览，显示消息发送后的效果
  • 服务器可以用它来预览应用了样式（如表情或聊天变色）的消息
  • 聊天预览会在消息输入时（甚至发送前）将聊天消息发送到服务器
    • 服务器随后实时返回带样式的预览
    • 这样服务器就可以应用动态消息样式，同时仍允许聊天被安全签名
  • 当加入启用了聊天预览的服务器时，客户端会显示警告界面，并且可以在聊天设置中全局禁用
  • 动态聊天样式也可以由服务器控制，但只有在启用聊天预览时才会被签名
    • 客户端可以选择在聊天设置中启用“仅显示已签名聊天”，以始终显示原始的已签名消息

命令

  • 为 place 命令添加了 template 子命令
  • locate 命令移至 locate structure，locatebiome 移至 locate biome
  • 添加了 locate poi <type: point_of_interest_type>
  • 服务器现在还会在玩家连接后发送额外的图标和 MOTD 数据包
    • 这允许设置了 enable-status=false 的服务器为成功连接的玩家设置图标和 MOTD

Place template

place 命令现在还可以在指定位置放置模板。语法：place template <template> [pos] [rotation] [mirror] [integrity] [seed]

  • place template 的作用类似于在结构方块 UI 中使用加载按钮

参数：

  • template：要加载并放置的模板（“结构方块文件”）的命名空间 ID
  • rotation：要应用的旋转（如果省略，则使用 none）
  • mirror：要应用的镜像（如果省略，则使用 none）
  • integrity：结构完整性，范围为 0 到 1 之间的值
  • seed：当完整性小于 1 时，用于随机化损坏的种子

兴趣点类型
