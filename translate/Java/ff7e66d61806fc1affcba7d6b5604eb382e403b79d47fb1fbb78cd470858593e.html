嘿！这个快照在 Bundle 实验中为你带来了可染色的收纳袋，以及 Realms 的完整功能世界创建，包括极限模式。

祝你染色愉快！

实验性特性

收纳袋

  • 收纳袋可以使用染料染成 16 种不同的颜色

更改

  • 潜影盒染色配方现在会显示在配方书中
  • 更新了 Realms 的世界创建界面
  • 为 Realms 启用了极限模式
  • 在创造模式中非常快速地丢弃物品现在会被限制

Realms

  • 现在使用正常、功能完整的世界创建界面
    • 启用游戏规则自定义
    • 启用数据包自定义

极限模式

现在 Realms 中可以使用极限模式，可通过创建新世界或重新创建现有世界来进入

技术性更改

  • 数据包版本现在为 54
  • 资源包版本现在为 39
  • 已移除客户端忽略连接错误的临时选项（strictErrorHandling）

数据包版本 54

  • 引入了新的物品标签 bundles，包含所有收纳袋物品

新配方类型

crafting_transmute 配方类型

  • 已引入新的合成配方类型：crafting_transmute
  • 匹配时，输出将复制输入物品堆叠，改变物品类型但保留所有堆叠组件
  • 这完全取代了 crafting_special_shulkerboxcoloring
  • 字段：
    • category - 配方书类别，为 building、redstone、equipment、misc 之一
    • group - 可选字符串
    • input - 要复制的物品的原料
    • material - 要使用的附加材料
    • result - 用于输出的物品类型

资源包版本 39

  • 收纳袋的模型和纹理现在有 16 种颜色变体
  • 与火把和包含红石火把的方块相关的模型和 UV 映射已更新
    • “inverted”模型现在使用 6 个独立的面，达到与负尺寸模型相同的效果
    • 更新了 inverted 模型的 UV 布局
