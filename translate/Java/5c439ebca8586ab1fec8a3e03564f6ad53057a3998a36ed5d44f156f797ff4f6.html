今天，我们发布了 1.21.11 的首个预发布版，即“混乱坐骑”（Mounts of Mayhem）更新。从现在开始，你主要会看到漏洞修复。此外，预发布版不遵循常规快照在周二发布的节奏，所以请留意下一个预发布版。

更改

  • 添加了新的图形选项“纹理过滤”
    • 此选项现在控制是否使用各向异性过滤
  • 鹦鹉螺和僵尸鹦鹉螺的头部现在更少地穿出它们的壳

纹理过滤

  • 视频设置中的新选项
  • 控制从斜角或远处观察纹理时用于采样纹理的方法
  • 可用值为“无”、“RGSS”和“各向异性”
  • 默认值取决于你的图形预设和硬件
  • “RGSS”（旋转网格超级采样）是一种基于着色器的过滤方法，能以适度的性能开销提高纹理清晰度
    • 在所有硬件上都可用
  • “各向异性”是一种基于硬件的过滤方法，可提供最佳纹理清晰度
    • 最大各向异性可选“2倍”、“4倍”和“8倍”，可通过单独的滑块控制
    • 如果你的硬件不支持，各向异性过滤将不会生效
    • 这会显著影响显存使用量（尤其与较高的 mipmap 级别数结合时）

长矛武器

  • 猪灵会将黄金长矛视为首选武器
  • 现在，如果在初次命中后继续向目标冲锋，你可以持续对目标造成伤害，生物也可以这样做
  • 骷髅变种和溺尸不再能捡起长矛
  • 僵尸猪灵现在也懂得用长矛冲锋
  • 长矛现在在创造模式物品栏中位于剑之后

新增 minecraft:attack_range

  • 使用该物品时启用自定义攻击距离。
  • 对于玩家，覆盖正常的实体交互距离。
  • 对于生物，常规近战攻击距离根据目标的碰撞箱到其自身碰撞箱的距离计算。此组件通过调整攻击碰撞箱的最小和最大边距来修改该距离检查。
  • 使用 minecraft:kinetic_weapon 的生物，其攻击距离将按与玩家相同的方式应用
  • 格式：包含以下字段的对象
    • min_range：浮点数，攻击者到目标的有效最小距离（以方块计）
      • 默认值：0.0，有效范围 0.0 至 64.0
    • max_range：浮点数，攻击者到目标的有效最大距离（以方块计）
      • 默认值：3.0，有效范围 0.0 至 64.0
    • hitbox_margin：浮点数，检查有效碰撞箱碰撞时应用于目标包围盒的边距
      • 默认值：0.3，有效范围 0.0 至 1.0
    • mob_factor：浮点数，当物品由生物使用时，在检查有效距离时应用于 min_range 和 max_range 的倍率
      • 默认值：1.0，有效范围 0.0 至 2.0

纹理

  • *.mcmeta 文件的 texture 部分新增了 alpha_cutoff_bias 字段，用于控制镂空纹理的 Alpha 偏移
    • 从技术上讲，此值没有限制，也可以是负数，但将其设置为高于 1.0 或低于 -1.0 没有意义，因为纹理将变得完全不透明或完全透明
    • 此字段的默认值为 0.0。对于在远处可能变得过于透明/单薄的纹理，可以增大该值；如果纹理过于“不透明”，则可以减小该值
    • 建议以细粒度递增或递减此值，以找到最佳平衡点。例如，kelp 纹理使用 0.1，以防止它们在远处完全透明
    • 仅用于镂空纹理的较低 mip 级别，不会改变首个 mip 级别的 Alpha，也不会影响其他纹理
