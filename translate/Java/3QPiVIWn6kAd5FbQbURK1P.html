我们再次带来 Minecraft 1.19.4 的第三个预发布版。此预发布版包含更多漏洞修复，以及药水颜色调整。弓箭手陶片的纹理也已更新。 ​ 祝你挖矿愉快！ ​

更改

  • 药水颜色已调整，以便彼此更容易区分

​

技术性更改

  • 现在按下 F3+S 会将动态纹理（如图集、地图等）的内容导出到 screenshots/debug/ 目录

​

实验性功能更改

陶片

  • 根据社区反馈，更新了弓箭手陶片的纹理

​

修复 1.19.4-pre3 中的漏洞

  • MC-148458 可骑乘的生物在死亡时不会被击退
  • MC-250486 在更改全屏分辨率时切换全屏，保存 GUI 缩放选项出错
  • MC-258561 末影人在受到末地水晶、TNT 和凋灵骷髅头爆炸伤害时会瞬移走而不是受伤
  • MC-259666 第二次重新加载具有自定义纹理图集的资源包会导致客户端帧率严重下降
  • MC-260277 potted_cherry_sapling 和 potted_torchflower 不属于 #flower_pots 方块标签
  • MC-260451 当向右看时，具有半透明外层皮肤的物品栏角色无法正确渲染
  • MC-260456 某些药水仍然无法通过颜色区分
  • MC-260470 末影人无法躲避发射器射出的箭
  • MC-260474 玩家和生物在死亡时不再受到击退影响
  • MC-260501 无法在启动器中删除之前的快照世界
  • MC-260579 从 avoids_guardian_thorns 中移除荆棘后，守卫者对自己造成伤害时崩溃
  • MC-260605 循环命令方块生成猪灵/村民导致内存占用持续增加
  • MC-260627 带有乘客的海豚要么加速到离谱的速度，要么完全无法移动
