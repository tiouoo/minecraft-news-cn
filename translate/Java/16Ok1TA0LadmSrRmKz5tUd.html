1.20 更新的第六个预发布版已发布，依然包含更多漏洞修复。

挖矿愉快！

技术更改

  • "item": "minecraft:air" 不能再用于数据包配方中
  • 数组形式的材料现在也允许用于 smithing_trim 和 smithing_transform 配方的 template、base 和 addition 字段中
    • 这些字段也允许空数组，表示该槽位需要留空

战利品表

随机序列

随机序列的 ID 现在是一个可选字段。如果未给出序列名称，则使用非确定性随机源抽取战利品。

修复 1.20 预发布版 6 中的漏洞

  • MC-237042 击杀那些处于潜行状态且在其辅助功能设置中将潜行选项设置为“切换”的玩家，会导致其他玩家在该玩家重生后无法看到其处于潜行状态
  • MC-241326 Thomas Guimbretière 的名字在制作人员名单中被列出两次，并且拼写错误
  • MC-260411 在杀死末影龙之前退出世界，重新召唤的末影龙不会生成末地折跃门
  • MC-262340 铁傀儡可以在透明方块上生成
  • MC-262575 制作人员名单中的公司名称仍然不一致
