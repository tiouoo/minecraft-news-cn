本周我们一直在思考一些终极问题，比如“先有冷鸡，还是先有蓝蛋？”。冷鸡与暖鸡现已加入快照 25w06a，同时带来各自色彩独特的鸡蛋。除此之外，粉色仙人掌花与干草将为沙漠与恶地增添景致。

新特性

  • 新增暖鸡与冷鸡变种
  • 新增矮干草与高干草
  • 新增仙人掌花方块，可生成在仙人掌上

农场动物变种

  • 鸡新增暖变种与冷变种
  • 原有鸡变种重命名为温带鸡
  • 变种由其生成所在生物群系决定
  • 所有拥有变种的动物（鸡、猪、牛）所对应的温暖、寒冷生物群系划分标准一致
  • 为暖鸡与冷鸡新增两种鸡蛋物品
    • 蓝蛋 — 冷鸡产下，可孵化出冷鸡变种
    • 棕蛋 — 暖鸡产下，可孵化出暖鸡变种
  • 原本的鸡蛋由温带鸡产下，可孵化温带鸡变种

矮干草与高干草

  • 新增两种草方块：矮干草与高干草
  • 二者均为1格高度，因此高干草与2格高的高草有所区分
  • 在沙漠与恶地生物群系自然生成
  • 和枯萎灌木一样，可以放置在各类沙子、陶瓦与泥土方块上
  • 均可使用骨粉催生
    • 对矮干草使用骨粉，会使其生长为高干草
    • 对高干草使用骨粉，会尽可能在相邻位置生成矮干草
  • 均可放入堆肥桶
  • 绵羊食用后能够重新长出羊毛
  • 均可作为燃料用于熔炼

仙人掌花

  • 仙人掌花是全新花卉方块，有概率自然生成在沙漠、恶地的仙人掌上
  • 仙人掌花可以放置在仙人掌方块，或是顶部中心具备支撑的任意方块上方
  • 仙人掌有概率长出仙人掌花
    • 若仙人掌高度为1格或2格，有10%概率长出仙人掌花，而非向上生长
    • 若仙人掌高度达到3格及以上，有25%概率长出仙人掌花
    • 只有四周全部留有空位时，仙人掌才会长出仙人掌花
  • 仙人掌花可放入堆肥桶
  • 1朵仙人掌花可合成1个粉色染料

改动内容

  • 玩家模拟距离内的方块、或是通过其他区块加载方式（如末影珍珠）加载的方块，现在都能够接收随机刻，不再局限于玩家周围8个区块范围
    • 举例：如果区块被末影珍珠加载，或是属于出生区块，作物可以生长、冰能够融化、降雪正常发生、炼药锅可以被雨水灌满
    • 生物生成、火焰蔓延、闪电生成仍维持原有范围：玩家周边8区块以内
  • 若8区块范围内没有玩家，火焰将不再燃烧与蔓延
  • 烟花与弩的物品提示框现在会以精简形式展示多个完全相同的重复烟火之星或投射物

萤火虫灌木

萤火虫灌木播放环境音效的触发条件已调整，需要同时满足以下两点：

  • 当前处于夜晚
  • 萤火虫灌木上方没有可碰撞方块遮挡（树叶除外）

技术性改动

  • 数据包版本更新至 66
  • 资源包版本更新至 51

数据包版本 66

  • 新增游戏规则 allowFireTicksAwayFromPlayer

游戏规则

allowFireTicksAwayFromPlayer

  • 设为 true 时，火焰与岩浆刻可以在玩家8区块范围外正常触发
  • 默认值：false

方块标签

  • #dead_bush_may_place_on 重命名为 #dry_vegetation_may_place_on
  • 新增 #edible_for_sheep — 绵羊可以食用、用以恢复羊毛的方块

物品标签

  • 新增 #eggs — 全部种类的鸡蛋物品

实体数据

  • 玩家的盔甲与副手装备现在同样存储在 equipment 字段中（通过盔甲、副手槽位编号写入物品到物品栏的旧写法依旧兼容）

鸡变种

  • 鸡变种支持数据驱动，在 data/命名空间/chicken_variant/标识.json 添加配置文件即可自定义
  • 该功能属于实验性功能
  • 配置文件字段：
    • model — 可选值：normal、cold
    • asset_id — 变种资源带命名空间ID，对应路径 assets/命名空间/textures/路径.png
    • spawn_conditions — 上述统一变种选择机制对应的生成条件

  • 新增蓝蛋、棕蛋物品纹理
