本周的发布热潮仍在继续，我们带来了 1.20.5 的第一个发布候选版本！除非在其中发现重大或关键问题，否则这将是下周我们计划作为 Minecraft: Java Edition 1.20.5 发布的版本。

技术更改

  • 更改了游戏客户端在收到来自服务器的数据包中无效数据时断开连接的处理方式
    • 为缓解过渡期，模组服务器可以通过在 handshake/game_profile 数据包中设置相应字段来选择退出此行为
    • 此选项将在下一个版本中移除

1.20.5 发布候选版本 1 中修复的漏洞

  • MC-270867 升级 1.20.4 世界时出现严重卡顿
  • MC-270871 升级带有穿着皮革马铠的马的世界会使该马永久免疫冰冻
