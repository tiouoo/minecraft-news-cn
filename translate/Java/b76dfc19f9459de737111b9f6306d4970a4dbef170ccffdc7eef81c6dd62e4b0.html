苍白花园

苍白花园是黑暗森林的一个生物群系变种。

  • 苍白橡树在此生成

  • 眼眸花在地面生成
  • 苍白苔藓块/地毯在此生成于地面
  • 苍白垂挂苔藓生成于苍白橡树的树叶下方
  • 被动生物不会在苍白花园中自然生成
  • 新增生物群系特有环境音效
  • 苍白花园没有配套音乐

  • 使用种子 3515201313347228787 创建新世界时，玩家将出生在苍白花园旁边

苍白橡树

苍白橡树是一种与深色橡树类似的新树木变种。

  • 自然生成的苍白橡树带有从树叶下垂的苍白垂挂苔藓、地面上的苍白苔藓斑块，吱吱之心方块也可以在其中生成
  • 苍白橡树树叶如果底面暴露，有机会生成树叶粒子
  • 流浪商人可以出售苍白橡树树苗

苍白苔藓

苍白苔藓块是与现有苔藓块功能类似的新方块，也有地毯变种。

  • 苍白苔藓块会在苍白花园生物群系中自然生成
  • 流浪商人可以出售苍白苔藓块
  • 苍白苔藓地毯可以用两个苍白苔藓块合成
  • 苍白苔藓地毯会在苍白花园生物群系中自然生成
    • 放置后，苍白苔藓地毯会在与其相邻的任何方块的完整表面上生长最多两个方块
    • 苍白苔藓地毯可以使用骨粉促使其在与它相邻的所有方块的完整表面上完全生长

苍白垂挂苔藓

苍白垂挂苔藓是一种向下生长的藤蔓状方块。

  • 苍白垂挂苔藓在苍白花园生物群系中自然生成于苍白橡树的树叶下
  • 苍白垂挂苔藓不会随机生长，但可以使用骨粉促使其生长
  • 苍白垂挂苔藓被挖掘时会立即破坏
  • 苍白垂挂苔藓需要剪刀或精准采集工具才能获得
  • 流浪商人可以出售苍白垂挂苔藓

眼眸花

眼眸花是在苍白花园生物群系中生成的新花朵。

  • 它们有两种变种：闭合眼眸花和开放眼眸花
  • 眼眸花会根据一天中的时间在两种变种之间转换
    • 在夜间，眼眸花将变为开放状态
    • 在白天，它们将变为闭合状态
    • 在没有昼夜循环的维度中，它们将保持原状
    • 转换时，花朵会发出粒子效果和声音
  • 种植在地面上的眼眸花会相互交流，帮助附近的花朵开放或闭合
  • 开放眼眸花在夜间会发出发光的眼睛
  • 在苍白花园生物群系中对草方块使用骨粉可以获得眼眸花
  • 蜜蜂接触开放眼眸花时会中毒
  • 蜜蜂可以被开放眼眸花吸引，但玩家与其互动时蜜蜂会中毒，而不是典型的繁殖/生长行为
  • 蜜蜂完全不会与闭合眼眸花互动
  • 用开放眼眸花制作的迷之炖菜会给予失明效果
  • 用闭合眼眸花制作的迷之炖菜会给予恶心效果
  • 灰色和橙色染料可以分别用闭合和开放眼眸花合成
  • 流浪商人可以出售开放眼眸花

吱吱怪生物

如果在两根苍白橡木原木之间有一个吱吱之心方块，吱吱怪生物会在夜晚生成。这在苍白花园生物群系中会自然发生，因为吱吱之心会生成在苍白橡树内部。

  • 如果生存或冒险模式的玩家在 12 格范围内注视吱吱怪，吱吱怪就会激活
  • 当有生存或冒险模式的玩家在 32 格范围内时，吱吱怪会保持激活
  • 如果生存或冒险模式玩家正在注视激活的吱吱怪，它就不会移动
    • 在这种状态下，它还会拥有完全击退抗性
  • 吱吱怪的近战攻击造成 3 点伤害（1.5 颗心）
  • 吱吱怪对生物和弹射物造成的伤害只会原地摆动
  • 吱吱怪对火焰有抗性
  • 吱吱怪会无视仙人掌、甜浆果丛和细雪，可以穿过/走过它们
  • 当被玩家或其宠物攻击时，吱吱怪与其连接的吱吱之心方块之间会显示粒子轨迹
  • 当与吱吱怪连接的吱吱之心方块被破坏时，吱吱怪会以自定义抽搐动画被移除
  • 吱吱怪的生成基于昼夜循环，不受光照等级影响
  • 吱吱怪不能进入船
  • 吱吱怪刷怪蛋会生成一只不与吱吱之心连接的吱吱怪，这种吱吱怪：
    • 昼夜都会存在
    • 会从攻击和其他伤害来源受到伤害
    • 只有 1 点生命值（半颗心）
  • 从吱吱之心生成的吱吱怪不能穿过传送门
  • 从吱吱之心生成的吱吱怪不能用命名牌命名
  • 玩家头上戴着雕刻南瓜时可以注视吱吱怪，而不会让它定住
  • 灾厄村民害怕吱吱怪，会逃离它们

吱吱之心

吱吱之心是一种生成在苍白橡树中的“活”方块，四面被苍白橡木原木覆盖。当它放置在两根苍白橡木原木之间且都沿同一轴对齐时，可以在夜间生成吱吱怪生物。

  • 在夜间活跃，白天休眠
  • 当吱吱怪被玩家或其宠物击中时，会向连接的吱吱怪发送粒子轨迹
  • 当吱吱之心方块被破坏时，连接的吱吱怪会被移除
  • 吱吱之心会在以下情况下决定移除或替换连接的吱吱怪：
    • 到白天时
    • 吱吱怪离吱吱之心太远
    • 玩家与吱吱怪重叠了几秒
  • 连接到吱吱之心方块的比较器会输出取决于与连接吱吱怪距离的信号强度
  • 吱吱之心可以用一个树脂块和苍白橡木原木合成
  • 使用精准采集附魔工具可以获得吱吱之心方块
  • 没有精准采集时破坏吱吱之心方块会掉落 1-3 个树脂团，使用时运附魔工具时会掉落更多
  • 自然放置的吱吱之心被玩家破坏时会掉落 20-24 点经验，无论是否使用精准采集

树脂

新增树脂团、树脂块、树脂砖和树脂砖块方块家族。

  • 攻击吱吱怪会导致其吱吱之心渗出 2-3 个树脂团
    • 树脂团会出现在靠近并连接到吱吱之心的苍白橡木原木侧面
    • 吱吱之心在攻击后有 5 秒冷却时间，期间不能产生更多树脂团
  • 树脂团方块可以放置在相邻方块的任何完整面上
  • 树脂团方块可以含水
  • 树脂块是用于存储树脂团的方块
  • 树脂团可以烧炼成树脂砖物品
  • 树脂砖物品可以用作盔甲纹饰的材料
  • 树脂砖物品可以合成为树脂砖块
  • 树脂砖块可以合成为树脂砖台阶、树脂砖楼梯、树脂砖墙，以及雕纹树脂砖块
    • 切石机也可以用来制作这些物品
  • 树脂团和树脂块不需要工具即可挖掘，并且会立即被破坏
  • 树脂砖块方块家族的正确工具是镐
  • 树脂团可以在一些林地府邸的战利品箱子中找到

生物拾取物品

物品修饰器

minecraft:set_custom_model_data

现在有更多字段以适应更复杂的组件结构。

  • 新字段：
    • floats - 可选数字提供器列表操作
    • flags - 可选布尔值列表操作
    • strings - 可选字符串值列表操作
    • colors - 可选 RGB 值或数字提供器列表操作
  • 列表操作使用与 set_fireworks 修饰器中 explosions 字段相同的格式：
    • value - 要插入的值列表
    • mode：决定所应用功能的枚举值：
      • replace_all：完全替换列表
      • replace_section：替换列表的一部分。参数：
        • offset：可选的非负整数：
          • 替换范围的起始位置
          • 如果省略，则使用 0
        • size：可选的非负整数：
          • 列表中要替换的范围大小
          • 如果省略，则使用 values 字段的大小
      • insert：插入到列表中，将现有条目移到插入部分之后。参数：
        • offset：可选的非负整数：
          • 新条目将插入到该索引之前
          • 如果省略，则使用 0（第一个值之前）
      • append：在列表末尾追加值
  • 例如，{function:"set_custom_model_data",floats:{values:[2],mode:replace_all}} 将 floats 替换为单个值 2

      • daytime - 一天中的时间
      • moon_phase - 月相
      • random - 随机值

  • 返回剩余使用游戏刻，对 period 取模
  • 字段：
    • period - 正浮点数，默认值 1.0

minecraft:use_duration 数值属性

  • 返回物品使用游戏刻
  • 字段：
    • remaining - 决定是否返回已使用或剩余游戏刻的布尔值，默认值：false
      • 如果为 true，返回值为剩余使用游戏刻
      • 如果为 false，返回值为迄今已使用的游戏刻

minecraft:empty 物品模型类型

  • 不渲染任何内容
  • 无字段

minecraft:bundle/selected_item 物品模型类型

  • 如果存在，则渲染 minecraft:bundle_contents 组件中选中的物品堆叠
  • 如果组件缺失则什么都不渲染
  • 无字段
