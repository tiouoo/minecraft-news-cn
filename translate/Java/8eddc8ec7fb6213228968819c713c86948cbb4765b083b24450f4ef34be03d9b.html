今天，我们以 1.21.11 的第二个预发布版来庆祝周五！这个版本在关闭“透视树叶”时带来了一些改进，同时也修复了一些漏洞。

挖矿愉快！

更改

  • 当“透视树叶”视频设置关闭时，树叶之间的空隙现在变为深绿色，而不是黑色。
  • 关闭“透视树叶”视频设置现在能带来比之前更大的性能提升。

1.21.11 预发布版 2 修复的漏洞

  • MC-238715 当尝试打开上锁的方块时，其他玩家无法听到“minecraft:block.chest.locked”音效
  • MC-302660 “options.cutoutLeaves.tooltip”字符串缺少单词“you”，导致语法不正确
  • MC-303061 “minecraft:block.chest.locked”音效在玩家位置播放，而不是在箱子的位置播放
  • MC-304023 冗余的世界数据修复器文件被保存在世界的“data”文件夹中
  • MC-304369 在没有现有 options.txt 文件的情况下加载游戏时崩溃
  • MC-304401 与之前的快照相比，非透视树叶看起来有所不同
  • MC-304421 “attack_range”组件破坏了命中结果
