有人在要求一个充满美味洞穴与山崖特性的快照吗？那么你来对地方了！这个特殊的快照添加了滴水石相关的方块——钟乳石和石笋。还是石笋和钟乳石？管他呢，你还不能在世界中找到它们……但试试新方块的功能吧！

20w48a 的新特性

  • 添加了滴水石块和滴水石锥

滴水石锥

  • 放置在天花板上会形成钟乳石，放置在地板上会形成石笋
  • 可以组合形成更长的钟乳石和石笋
  • 石笋在下方没有支撑物时会碎裂
  • 落在或跳到石笋上会受伤！它们很锋利
  • 钟乳石如果未附着在上方物体会掉落
  • 被下落的钟乳石击中会受伤！它们很锋利
  • 钟乳石会滴水（如果天花板上有岩浆则会滴岩浆）
  • 上方天花板有水源的钟乳石会逐渐将下方炼药锅注满水
  • 上方天花板有岩浆源的钟乳石会在一段时间后将下方炼药锅注满岩浆
  • 投掷的三叉戟会击碎滴水石锥

20w48a 的更改

  • 现在在物品栏中右键点击收纳袋会从袋中倒出一个物品
  • 现在使用收纳袋会将其中全部物品丢到世界中
  • 高级提示框现在会显示收纳袋的已满程度
  • 现在蜡烛只能放置在下方有完整固体表面的位置
  • 现在穿戴任意一件皮革盔甲即可完全防止冰冻
  • 更改了紫水晶、蜡烛、时钟和指南针的纹理

20w48a 的技术性更改

  • 添加了 freezeDamage 游戏规则，允许玩家切换细雪是否会造成冰冻伤害
