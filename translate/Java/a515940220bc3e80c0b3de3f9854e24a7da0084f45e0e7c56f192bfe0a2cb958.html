今天我们为 1.21.2 发布了第二个预发布版，其中包含更多错误修复和苍白垂挂苔藓的改动。在 Minecraft Java 版 1.21.2 正式发布前的稳定阶段，我们专注于修复错误，并且不遵循每周三发布快照的常规节奏，因此请留意下一个预发布版。

实验性功能

冬季更新

苍白苔藓

  • 苍白垂挂苔藓现在只会被剪刀剪下或使用带有精准采集附魔的工具破坏时掉落
  • 苍白苔藓地毯现在用剑破坏更高效
  • 苍白苔藓地毯现在在行走其上时会播放正确的脚步声
