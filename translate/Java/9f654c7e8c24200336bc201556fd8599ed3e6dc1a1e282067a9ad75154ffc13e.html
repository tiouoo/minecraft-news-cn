我们听说周五是发布 Minecraft: Java Edition 1.21.9 第二个预发布版的绝佳日子，所以我们来了！此预发布版包含对先前快照中引入的多个问题的修复，以及一次被遗漏的数据包主版本号提升。

祝游戏愉快！

更改

  • 铜傀儡现在即使游戏规则 doDaylightCycle 被禁用时也会氧化
  • 铜傀儡变成雕像的行为已调整为与基岩版一致
    • 铜傀儡不再需要靠近空方块位置的中心即可变成雕像
    • 铜傀儡现在一旦完全氧化，就有可能变成雕像

技术性更改

  • 数据包版本现为 88.0，以匹配 1.21.9-pre1 中 /setworldspawn 和 /spawnpoint 的破坏性更改

修复 1.21.9 预发布版 2 中的错误

  • MC-300362 铜傀儡在 doDaylightCycle 被禁用时不会氧化
  • MC-301566 资源包重新加载时偶尔发生声音崩溃
  • MC-301706 服务器管理协议不支持将参数作为对象（按名称）传递
  • MC-301770 对于名为“deadmau5”的玩家和人偶，below_name 标签不会显示得更高
  • MC-301963 铜傀儡在检查箱子时会导致严重的卡顿尖峰
  • MC-302088 已氧化的铜傀儡需要极长时间才能变成雕像
  • MC-302112 摆出姿势的人偶未使用正确的碰撞箱
  • MC-302117 文本显示实体的广告牌效果损坏
  • MC-302120 特定维度的世界出生点导致其他维度中的生物生成失败
  • MC-302148 铜傀儡无法足够靠近箱子来搜寻，导致永久卡住
  • MC-302164 数据包次要版本中 /setworldspawn 和 /spawnpoint 的破坏性更改
