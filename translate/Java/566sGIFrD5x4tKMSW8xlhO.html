今天瑞典这里天气真好！阳光明媚，春意盎然，而我说“春”指的是花粉。让我们来解决这个问题：1) 待在室内，2) 引入一个全新的生物群系，其中包含玄武岩、黑石和岩浆怪！为了增添趣味，我们还为你准备了一些新曲目，供你在穿越下界时聆听。尽情享受这个快照吧！

20w15a 的新特性

  • 辅助功能改进
  • 添加了猪灵旗帜图案
  • 在下界添加了玄武岩三角洲生物群系
  • 添加了灵魂营火。用一千个灵魂的热量温暖你的小屁股！
  • 添加了三首新的下界音乐
  • 添加了錾制下界砖、裂纹下界砖和石英砖！
  • 添加了一组名为黑石的新石头方块，包含普通、磨制和磨制砖变种！
  • 添加了镶金黑石——注入黄金的黑石，被破坏时有几率掉落金粒
  • 黑石可用于合成熔炉和石制工具

辅助功能

  • 在聊天和辅助功能选项中添加了“行距”
  • 添加了“聊天延迟”辅助功能选项

玄武岩三角洲

现在可以在下界找到玄武岩三角洲了！

  • 作为火山喷发的遗迹，这个生物群系拥有高浓度的玄武岩柱和熔岩三角洲
  • 穿行其中，你会被飘落的白色灰烬包围
  • 岩浆怪终于有了栖息之地，会非常频繁地生成
  • 在这里可以找到大片的新方块——黑石

下界音乐

我们很高兴地宣布，我们为即将到来的下界更新添加了三首新曲目，全部由才华横溢的 Lena Raine 作曲。

  • Rubedo 将在下界荒地播放
  • So Below 将在灵魂沙谷和玄武岩三角洲播放
  • Chrysopoeia 将在绯红森林播放

Lena 的一些话：

  • “Minecraft 中的主要乐器之一是钢琴，所以我给自己的挑战之一就是看看我能把钢琴的声音推向多远，直到它完全像其他东西——再次，那个炼金术般的过程。”
  • “我希望每首曲子都能让人感受到情感的递进，或者是在这个异世界中从一个地方到另一个地方的旅程。下界有某种程度的美，但无论细节还是规模都令人恐惧。”
