物品谓词参数

物品谓词语法（用于 execute if|unless items 和 clear 命令）已大幅扩展。

  • 一般语法为：<type> [comma-separated list of <test>]
  • <type> 可以是以下之一：
    • 物品 ID
    • 以 # 为前缀的物品标签 ID
    • * 匹配任意物品
  • <test> 可以有 3 种形式之一：
    • <component_id>=<value> - 匹配组件的精确值（与之前格式相同）
      • <value> 是组件值的 SNBT 格式表示（与 item give 参数相同）
    • <component_id> - 检查组件是否存在
    • <predicate_id>~<value> - 检查物品子谓词
      • <value> 是物品子谓词的 SNBT 格式表示（但除此之外与用于进度和战利品表 JSON 文件的相同）
      • 示例：*[damage~{durability:{min:3}}] 将匹配任何剩余至少 3 次使用次数的堆叠
  • 特殊名称 minecraft:count 可用于匹配堆叠大小
    • count=<positive int> 仅当堆叠大小等于给定值时通过
    • count~<int range> 当堆叠大小在指定范围内时通过
      • 示例：*[count~{max:2}] 将匹配任何 count <= 2 的堆叠
    • count 始终通过
  • 任何 <test> 条目都可以通过添加 ! 前缀来取反
    • 示例：*[!count=1] 将匹配任何 count 不是 1 的堆叠
  • <test> 元素也可以使用 | 连接，以检查多种备选方案
    • 示例：*[!damage|damage=0] 将寻找没有 damage 组件或 damage 为 0 的物品
  • 用于自定义数据部分匹配（{}）的语法已被移除，转而使用 custom_data 谓词
    • 因此 stick{a:2} 变为 stick[custom_data~{a:2}]

新物品堆叠组件

minecraft:food

  • 存在时，此物品将表现得如同食物（可以被食用）
  • 格式：包含字段的对象
    • nutrition：非负整数，食用后恢复的饥饿值点数
    • saturation_modifier：浮点数，食用后恢复的饱和度
    • is_meat：布尔值（默认：false）
      • 如果为 true，可以喂给狼
    • can_always_eat：布尔值（默认：false）
      • 如果为 true，即使不饿也可以食用此食物
    • eat_seconds：浮点数（默认：1.6）
      • 食用此食物所需的秒数
    • effects：食用时施加的效果列表（默认：[]）
      • effect：效果实例（与 minecraft:potion_contents 组件中的 custom_effects 格式相同）
      • probability：介于 0 和 1 之间的浮点数，效果被施加的几率（默认：1）
  • 例如：food={nutrition:4,saturation_modifier:0.1}
  • 对于食物物品，具有该食物类型的隐式默认值

minecraft:max_stack_size

  • 控制此物品的最大堆叠数量
  • 格式：介于 1 和 99 之间的整数
    • 例如：max_stack_size=4
  • 根据物品类型具有隐式默认值（通常为 64）

minecraft:max_damage

  • 控制物品能承受的最大伤害值
  • 如果不存在，物品无法被损坏
  • 格式：正整数
    • 例如：max_damage=123
  • 对于可损坏物品具有隐式默认值

minecraft:fire_resistant

  • 如果存在，此物品不会在火中燃烧
  • 格式：空对象
    • 例如：fire_resistant={}
  • 对于下界合金等防火物品具有隐式默认值

minecraft:rarity

  • 控制物品名称的颜色
  • 格式：枚举值，以下之一：
    • common（默认）：白色名称，附魔时为青色
    • uncommon：黄色名称，附魔时为青色
    • rare：青色名称，附魔时为淡紫色
    • epic：淡紫色名称
    • 例如：rarity=rare
  • 金苹果等特殊物品具有隐式默认值

minecraft:tool

  • 控制物品作为工具的行为
  • 格式：包含字段的对象
    • rules：规则条目列表
      • blocks：要匹配的单个方块、方块列表或以 # 为前缀的方块标签
      • speed（可选）：浮点数，如果存在且匹配，则覆盖挖掘速度
      • correct_for_drops（可选）：布尔值，如果存在且匹配，则覆盖此工具是否被视为“正确”
        • true 将使方块以最有效的速度挖掘，并在目标方块需要时掉落物品
    • default_mining_speed：浮点数，当没有规则匹配且覆盖挖掘速度时使用的挖掘速度（默认：1.0）
    • damage_per_block：非负整数，使用此工具每挖掘一个方块移除的耐久度
    • 例如：tool={rules:[{blocks:"#mineable/pickaxe",speed:4.0,correct_for_drops:true}]}
  • 原版工具物品将根据其等级和工具类型具有隐式默认值

hide_tooltip

  • 如果存在，将完全隐藏整个物品提示文本（包括物品名称）
  • 在创造模式中提示文本仍然可见且可搜索
  • 格式：空对象
