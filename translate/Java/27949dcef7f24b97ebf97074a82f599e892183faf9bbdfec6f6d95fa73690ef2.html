这是新一周的开始，我们开门见山地为大家带来 Minecraft: Java Edition 1.20.5 的又一个预发布版！除了在进度方面提升我们的双关语水平外，这个预发布版还修复了大量错误和崩溃。

祝采矿愉快！

新特性

进度

  • Snip it! 进度已更名为 Shear Brilliance

更改

  • 使用 Ctrl+选取方块不再在物品提示中显示“(+NBT)”

界面

  • 当维度切换至或离开下界时，会显示下界传送门动画纹理
  • 当维度切换至或离开末地时，会显示末地传送门动画效果

技术性更改

  • 数据包版本现已更新至 40
  • 从服务器发送的数据包中的无效数据现在将导致游戏客户端断开连接

数据包版本 40

修改的战利品函数

set_fireworks

字段 explosions 和 mode 已组合为一个子对象。

  • { "explosions": <list>, "mode": <mode>, <mode-dependent fields>} 变为 {"explosions": {"values": <list>, "mode": <mode>, <mode-dependent fields>}}
  • 新的 explosions 字段现在为可选，其中的 values 字段现在为必填
