我们现在发布快照 23w40a，这是 1.20.3 的第一个快照！此快照包含盾牌的改进、聊天组件序列化的更改和 Bug 修复。

更改

  • 当玩家用盾牌格挡时，从第三人称视角观看，持有盾牌的手臂现在会跟随玩家注视的方向

技术性更改

  • 数据包版本现在为 19
  • 对聊天组件序列化进行了一些小改动

聊天组件

序列化

  • 纯文本聊天组件（文本、无兄弟组件、无样式）现在始终序列化为字符串，而不是 {"text': "blah"}
  • 聊天组件现在通过网络发送时会序列化为 NBT
  • 聊天组件现在有一个可选的 type 值（允许的值：text、translatable、score、nbt、keybind），以加快解析速度并改进错误检查
  • show_entity hoverEvent 样式中的 id 字段现在也接受 UUID 作为 4 个整数的数组
  • translate 组件的数字和布尔参数不再转换为字符串
  • 不再接受以下 JSON 组件表示形式：
    • null
    • []
  • 以下样式字段中的错误不再被静默忽略：
    • color
    • clickEvent
    • hoverEvent
    • hoverEvent[action=show_entity].contents.name
    • hoverEvent[action=show_item].contents.tag

数据包版本 19

标签

  • 添加了 can_breathe_under_water 实体类型标签，该标签会禁用溺水
  • 添加了 can_break_armor_stands 伤害类型标签，用于可以逐渐击倒盔甲架的伤害类型
