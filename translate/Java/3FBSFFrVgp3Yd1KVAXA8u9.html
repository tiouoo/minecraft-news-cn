展示实体

新增了三种实体，用于灵活展示物品、方块和文本

  • 这些实体与 marker 类似，不会接收游戏刻（tick），也没有碰撞或物理效果
  • 模型在实体位置渲染，可围绕 X 轴和 Y 轴正常旋转（因此可以通过传送命令控制），同时还支持额外的任意模型变换

通用数据类型

这些实体的标签内容包含一些结构复杂的新数据类型。可以使用任何形式来修改数据，但保存时只会使用一种形式。

rotation

  • 四元数形式（用于保存）：包含 4 个数字的数组，描述分量 (x, y, z, w)
  • 轴角形式：包含以下字段的对象：
    • axis - 三维向量
    • angle - 角度（弧度）

transformation

任意仿射变换

  • 矩阵形式：包含 16 个数字的数组，描述行主序矩阵
  • 分解形式（用于保存）：包含以下字段的对象：
    • translation - 三维向量
    • left_rotation、right_rotation - rotation
    • scale - 三维向量
    • 变换按以下顺序组合：translation、left_rotation、scale、right_rotation

插值

展示实体的某些属性可以进行插值。这意味着客户端会看到随时间逐渐变化，而不是瞬间跳变。

展示实体会跟踪插值属性的当前值和先前值：

  • 所有标记为“可插值”的属性都属于同一个插值集合
  • 对任一可插值属性的任何更新都会导致插值集合中的所有值被保存为“当前”值
    • 如果 data 命令的执行没有更改属性值（即使该值存在于 NBT 中），则不视为更新
    • 更新最多每游戏刻同步到客户端一次，因此命令中的多次更新仍会被视为一次更新
  • 先前的当前值会被保存为“先前”值
  • 如果启用了插值，实体将随时间在“先前”值和“当前”值之间过渡
  • 插值的起始点（实体完全处于“先前”状态）由字段 interpolation_start（游戏时间，以游戏刻为单位）定义
    • 设置为 -1 将改为加载当前游戏时间）
  • 插值的结束点（实体完全处于“当前”状态）定义为 interpolation_start + interpolation_duration（以游戏刻为单位）

通用属性

该家族中的每个实体都有以下字段：

  • transformation - 应用于模型的 transformation（在正常实体朝向后）。默认为单位变换。可插值
  • billboard - 控制实体在渲染时是否应旋转面向玩家的选项：
    • fixed - 不旋转（默认）
    • vertical - 实体可围绕垂直轴旋转
    • horizontal - 实体可围绕水平轴旋转
    • center - 实体可围绕中心点旋转
  • brightness - 如果存在，将覆盖用于渲染的光照值。默认省略（这意味着渲染使用实体位置的光照值）。对象包含两个字段：
    • sky - 天空光照值，0..15
    • block - 方块光照值，0..15
  • view_range - 此实体的最大可视范围。实际距离取决于客户端的渲染距离和实体距离缩放。默认值为 1.0（与火球大致相同）
  • shadow_radius - 阴影的大小。默认为 0（无阴影）。可插值
  • shadow_strength - 阴影的强度。根据与下方方块的距离控制阴影的不透明度。默认为 1。可插值
  • width、height - 描述剔除包围盒的大小。包围盒在垂直方向上从 y 延伸到 y+height，在水平方向上从实体位置向各个方向延伸 width/2。如果任一字段设置为 0，则禁用剔除。两者默认均为 0
  • glow_color_override - 覆盖发光边框颜色。默认为 0（使用队伍颜色）

item_display

展示单个物品堆叠。

  • 可以使用命令通过设置物品栏槽位 inventory.0 来更改堆叠

字段：

  • item - 要展示的物品堆叠。格式与物品栏中的相同（例如：{id: "minecraft:dirt", Count: 1}）
  • item_display - 描述应用于物品的物品模型变换（如模型 JSON 中的 display 部分所定义）
    • 值：none（默认）、thirdperson_lefthand、thirdperson_righthand、firstperson_lefthand、firstperson_righthand、head、gui、ground、fixed

block_display

展示一个方块状态。

  • 不展示方块实体，即使它们通常会在方块放置时生成（如箱子）

字段：

  • block_state - 要展示的方块状态。格式与末影人手持的物品相同（例如 {Name:"minecraft:dirt"}）

text_display

展示一个文本组件。

字段：

  • text - 要展示的文本。组件将使用展示实体的上下文进行解析
  • line_width - 用于换行的行宽（注意：也可以使用 \n 字符添加换行）。默认为 200
  • text_opacity - 渲染文本的不透明度（Alpha 分量）。默认为 255。可插值
  • background - 背景颜色。包含 Alpha 通道。默认为 0x40000000。可插值
  • default_background - 若为 true，渲染时使用默认的文本背景颜色（与聊天中相同）。默认为 false
  • shadow - 文本是否应显示阴影。默认为 false
  • see_through - 文本是否应透过方块可见。默认为 false
  • alignment - 文本应如何对齐
    • 值：center（默认）、left、right

注意：文本展示背景使用新的着色器类型 rendertype_text_background 和 rendertype_text_background_see_through

伤害类型

伤害类型是一个新的注册表，可以通过数据包进行扩展。伤害类型决定了游戏如何处理伤害。这包括伤害具有哪些属性，以及实体因该类型伤害死亡时使用哪条死亡消息。

示例：

{
  "exhaustion": 0.1,
  "message_id": "arrow",
  "scaling": "when_caused_by_living_non_player"
}

字段：

  • message_id：用于此伤害类型造成的死亡的消息 ID
    • 将与其他字符串片段组合以形成翻译键
  • exhaustion：此伤害类型造成的饥饿值消耗量
  • scaling：此伤害类型是否随难度等级变化。可能的值：
    • never：伤害始终相同
    • always：伤害始终随难度变化
    • when_caused_by_living_non_player：如果伤害由非玩家的生物实体造成，则伤害随难度变化
  • effects：可选字段，控制对玩家造成伤害时的表现形式。可能的值：
    • hurt（默认）：默认的受伤声音
    • thorns：荆棘受伤声音
    • drowning：溺水声音
    • burning：一次燃烧音效（单游戏刻）
    • poking：浆果丛刺伤声音
    • freezing：冰冻刻声音
  • death_message_type：可选字段，控制是否使用特殊死亡消息变体。可能的值：
    • default（默认）：不应用特殊死亡消息逻辑
    • fall_variants：显示摔落伤害死亡的变体消息，而不是常规死亡消息，例如 death.fell.assist.item
    • intentional_game_design：显示“故意的游戏设计”消息，而不是常规死亡消息

伤害类型标签控制着来自不同来源的伤害被解释的许多方面。

命令

damage

用于对实体造成伤害的新命令。

语法：

  • damage <target> <amount> [<damageType>] [at <location>]
  • damage <target> <amount> [<damageType>] [by <entity>] [from <cause>]

参数：

  • target：要伤害的实体
  • amount：造成的伤害量
  • damageType：造成的伤害类型
    • 这决定了伤害如何影响实体，以及显示哪条死亡消息
  • entity：造成伤害的实体
  • cause：间接伤害情况下的伤害来源
    • 示例：当被箭射中时，entity 是箭矢投射物，而 cause 可能是骷髅
  • location：伤害起始的位置（当没有实体造成伤害时）
    • 例如，location 可能表示床在下界爆炸时的位置

execute summon

新的 execute 子命令，用于生成新实体并将上下文（@s）绑定到该实体。旨在简化实体设置并减少对原始 NBT 编辑的需求。

  • execute summon <entity id>
