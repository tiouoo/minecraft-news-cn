资源包版本 81

  • 更新了 mule_baby.png 和 donkey_baby.png 以正确适配模型

方块模型格式

  • 任何方块模型现在都可以支持 cutout 或 translucent（部分透明像素）纹理
    • 四边形是使用 cutout 还是 translucent 渲染通道进行渲染，取决于其指定 sprite 的内容
      • 任何包含半透明（部分透明）像素的 sprite 都会分配到“translucent”通道
      • 任何包含完全透明像素的 sprite 都会分配到“cutout”通道
      • 所有其他 sprite 都会分配到“solid”通道
    • 注意：分配的渲染通道也意味着渲染顺序：所有 solid 几何体在所有 cutout 几何体之前渲染，而 cutout 几何体在所有 translucent 几何体之前渲染
  • textures 映射的格式已更新：
    • 非字符串条目现在将被拒绝，而不再被解释为字符串
    • 除了之前的直接 sprite ID 形式外，条目现在可以定义为包含以下字段的对象：
      • sprite - sprite ID
      • force_translucent - 可选布尔值，如果任何使用此纹理的几何体应强制进入“translucent”通道，则为 true
        • 例如，这对于没有任何半透明像素、但使用 mean mipmap 策略的方块很有用
        • 默认值：false
