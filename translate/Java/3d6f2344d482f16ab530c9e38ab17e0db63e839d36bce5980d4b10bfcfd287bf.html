铜器时代即将到来，是时候迎来本次更新的第一个预发布版了。本次发布包含更多铜傀儡的改进、对展示假人的一些更改以及多项漏洞修复。预发布版不遵循常规的周二发布安排，请留意下一个版本。

更改

方块、物品和实体的小调整

  • 铜傀儡现在作为乘客时，只会尝试打开相邻方块的箱子

Minecraft 服务器管理协议

  • 通知现在使用 minecraft:notification/ 前缀，而不是 notification:

技术性更改

  • 数据包版本现在为 87.1

数据包版本 87.1

展示假人

  • 展示假人的描述文本现在可以配置
  • 展示假人现在接受来自生成物品的 minecraft:profile 组件

修改后的数据字段

  • profile - 现在与 minecraft:profile 组件具有相同格式（该组件已扩展以允许覆盖），默认为 {}（即 id 和 name 均缺失的静态档案）

新增数据字段

  • pose - 展示假人的姿势
    • 有效值：standing、crouching、swimming、fall_flying、sleeping
  • immovable - 可选布尔值，指定展示假人无法被移动（默认为 false）
  • description - 可选文本组件，显示在玩家 below_score 分数会显示的位置
    • 如果省略，则显示默认的“NPC”（entity.minecraft.mannequin.label）文本
  • hide_description - 可选布尔值，指定完全不显示任何描述
    • 隐藏描述的展示假人会显示为玩家没有 below_score 显示的状态

命令

  • spawnpoint 命令现在可选地接受 pitch 参数
  • setworldspawn 命令不再局限于主世界
    • 这意味着玩家在没有床或重生锚时，可以在例如下界重生
    • 它现在也接受可选的 pitch 参数
  • 服务器命令现在默认从重生维度运行，而不是始终在主世界
  • fetchprofile 命令现在还会打印可点击文本，以召唤具有已解析档案的展示假人

数据组件

修改的 minecraft:profile

  • 档案现在还可以包含额外字段，用于替换各种渲染所使用的值
  • 如果省略任何字段，则使用已解析档案中的值，即使该档案解析为默认皮肤
  • 新字段
    • texture - 可选命名空间 ID，用于渲染的皮肤纹理
      • 皮肤相对于 textures 文件夹指定，并带有 .png 后缀
      • 例如 entity/player/wide/steve 将使用默认的宽版 Steve 皮肤
    • cape - 可选命名空间 ID，用于渲染的披风纹理
      • 指定时，使用与 texture 字段相同的格式
    • elytra - 可选命名空间 ID，用于渲染的鞘翅纹理
      • 指定时，使用与 texture 字段相同的格式
      • 如果此值既未作为覆盖提供，也不在玩家档案中，使用此档案的展示假人将会使用披风纹理；如果披风纹理也不存在，则穿戴鞘翅时使用默认鞘翅纹理
    • model - 可选模型类型，wide 或 slim 之一

实体数据

修改的 minecraft:player

  • 对 respawn 对象的更改
    • angle 已重命名为 yaw，现在是必填字段
    • 新增 pitch 作为必填字段
    • dimension 现在是必填字段

战利品函数

minecraft:copy_name

  • source 字段现在接受新的上下文值：
    • direct_attacker
    • target_entity
    • interacting_entity

minecraft:copy_components

  • source 字段现在接受新的上下文值：
    • this
    • attacker
    • direct_attacker
    • attacking_player
    • target_entity
    • interacting_entity
    • tool
