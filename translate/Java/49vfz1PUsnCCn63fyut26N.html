21w40a 中的更改

  • 世界生成调整
  • 生物生成的更改
  • 铜矿石现在会掉落 2-5 个（原先为 2-3 个）粗铜
  • 在切石机中，一个铜块可以转化为四个切制铜块
  • 许多具有相似特征但形状不同的生物群系变体已合并为一个，因为现在形状可以独立控制
  • 重命名了一些生物群系

世界生成

  • 更新了矿石分布，使深层分支采矿更具回报。更新后的矿石分布图
    • 例如，增加了更多未暴露的钻石
    • 铁矿石现在生成在 80 层以上，且越往高处铁矿石越多
    • 额外的金生成在 -48 层以下
  • 非洞穴生物群系不再随高度变化——所以不再有天空中的热带草原之类的情况
  • 调整了一些生物群系的相对大小，使其更接近 1.17
  • 增大了大多数生物群系的平均尺寸（这也意味着生物群系的位置与之前不同）
  • 修复了一些含水层问题（副作用是含水层现在的位置与上个快照不同）
  • 略微增加了水下岩浆的生成频率
  • 增加了地牢的数量，尤其是在 0 层以下
  • 沙砾现在生成在 0 层以下
  • 村庄的分布更加分散
  • 移除了湖泊水特征，含水层提供局部水位

生物生成

  • 美西螈现在只会在繁茂洞穴中，黏土块上方的水中生成
  • 发光鱿鱼现在只会在 30 层以下的水方块中生成
  • 鳕鱼、鲑鱼、河豚、热带鱼、鱿鱼和海豚现在只会在高度 50 到 64 的水中生成
  • 热带鱼现在也会在任何高度的繁茂洞穴中生成
  • 僵尸再次在滴水石洞穴中生成——溺尸也会在那里生成
  • 山羊不再生成在石质山峰

21w40a 中的技术更改

  • 优化了美西螈、山羊、疣猪兽、僵尸疣猪兽、猪灵、猪灵蛮兵和村民的 AI
  • 基岩层现在根据世界种子生成
