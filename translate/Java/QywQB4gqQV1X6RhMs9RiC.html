创造模式物品栏的更多更改

由于创造模式物品栏排序的更改，大量反馈纷至沓来。

更改

  • 更改了创造模式标签页的图标，以更好地进行颜色编码，并展示最具标志性的视觉效果
  • “自然方块（Nature Blocks）”标签页已更名为“自然方块（Natural Blocks）”
  • 将泥土和石头移至自然方块标签页顶部，这是许多人的强烈要求（他们表示这些方块的使用频率远高于花朵等）
  • 修复了水瓶未显示在消耗品标签页中的问题
  • 重新排序了石英，使平滑石英成为独立的分区
  • 可攀爬的植物方块现在在自然方块标签页中放在一起
  • 修复了涂蜡铜方块的排序
  • 修复了珊瑚方块的排序，使其保持一致
  • 确保自然方块标签页中下界岩与菌岩相邻
  • 重新排序了装备，使金制工具和武器处于合理的顺序
  • 将普通铁轨移动到特殊铁轨之前
  • 按颜色渐变对彩色方块排序（羊毛、陶瓦、蜡烛、旗帜、染色玻璃等）
  • 将告示牌在功能方块标签页中上移，因为玩家经常使用
  • 建筑方块标签页中，玄武岩方块现在位于下界砖块之后，紧邻黑石
  • 大致重新排序了自然方块标签页中的植物

新增玩家举报草稿

现在，玩家举报可以在连接到服务器时临时保存为草稿。

  • 退出玩家举报界面时，举报可被丢弃或保留为草稿
    • 如果界面被强制关闭（例如玩家死亡），草稿将始终保留
  • 草稿举报会一直保留到玩家离开当前服务器或世界为止
    • 离开时，玩家将收到提示，可以选择丢弃或完成并发送举报

22w43a 的技术性更改

  • 将线性代数类型迁移至 Java OpenGL 数学库（JOML）

网络协议

  • 服务器现在可以随玩家的首个聊天数据包一并惰性分发其个人资料公钥
  • 个人资料公钥现在无需重新连接即可刷新
  • 客户端现在在收到登录数据包时会重置其聊天会话
