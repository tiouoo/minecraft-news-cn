辞旧迎新！今天，我们为 Minecraft Java Edition 引入了一种新的命名惯例（好吧，其实已经有一段时间了）。以前，最后一个预发布版本实际上就是发布候选，但现在我们通过将其名称改为“发布候选”来让这一点更加明确。这意味着如果在本次发布后没有出现重大问题，那么在正式版发布之前将不再进行任何更改。
