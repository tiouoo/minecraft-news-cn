瞄准这个快照！本周内容稍少一些，你可能需要多加练习来掌握新的弹射物机制！趁此机会，何不远远地欣赏一下雾气缭绕的山峰呢？

更改

  • 弹射物的目标容错范围现在会随时间变化
  • 雾效果经过调整，以改善大气透视
  • 现在下雨时雾会更浓
  • 测试框架在服务器重启后不再尝试重启正在运行的测试

弹射物瞄准

  • 弹射物现在拥有随时间变化的目标容错范围
    • 此前，所有弹射物都有固定的 0.3 格目标容错范围
    • 现在，所有弹射物在飞行前两刻内没有容错范围
    • 之后，目标容错范围每刻扩大 0.05 格，直到达到之前的 0.3 格容错范围
    • 这样在靠近射击玩家或生物时能更精确，同时当弹射物飞得较远时仍保留一定的碰撞余地

技术性更改

  • 数据包版本现在为 76
  • --quickPlaySingleplayer 命令行参数现在可以在不带标识符的情况下使用，以启动进入最后游玩的世界

数据包版本 76

  • 快乐恶魂的 scale 属性现在有 1.0 的上限

实体数据

tnt

  • 点燃 TNT 的实体现在存储在一个可选的 owner 字段中（活体实体的 UUID）

vex

  • 恼鬼的所有者现在存储在一个可选的 owner 字段中（生物的 UUID）

资源包版本 60

  • 全景图纹理现在必须全部为相同尺寸的正方形
  • 干燥恶魂块的声音已更改

UI 精灵图

  • 状态效果图集已被移除，textures/mob_effect/ 文件夹中的精灵图现在包含在 GUI 图集中
    • 这意味着状态效果精灵图现在支持 GUI 精灵图缩放属性

着色器与后期处理效果

着色器雾效果更改

  • 雾现在分为环境雾和基于渲染距离的雾
  • 此前这两个概念混合在同一个 uniform 变量中
  • 环境雾用于表示玩家所处环境的“雾气浓度”：熔岩、水，以及现在的大气
  • 渲染距离雾用于遮住可见地形的边界
  • 环境雾使用球面距离确定其浓度，渲染距离雾使用柱面距离
  • 任意顶点的最终雾值为两者中的最大值

Fog Uniform 数据块

  • FogStart 已重命名为 FogRenderDistanceStart，现在表示渲染距离雾的起点
  • FogEnd 已重命名为 FogRenderDistanceEnd，现在表示渲染距离雾的终点
  • FogEnvironmentalStart 是新增项，表示环境雾的起点
  • FogEnvironmentalEnd 是新增项，表示环境雾的终点
  • FogShape 已被移除。渲染距离雾现在为柱面形，环境雾则为球面形

声音事件

  • block.dried_ghast.hit 已被移除
