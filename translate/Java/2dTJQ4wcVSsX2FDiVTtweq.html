1.16.4 的第一个预发布版正式发布！ ​ 如果你已经上线一段时间，你可能会注意到偶尔会遇到一些与你相处不来的玩家。为了减轻这种沮丧感，我们引入了一个名为“社交互动界面”的 UI 元素，它将允许你禁用与特定玩家的聊天，从而隐藏你从他们那里收到的任何消息。此外，1.16.4 更新将包含一些关键漏洞的修复，但除此之外，这就是这个点版本的全部内容。 ​ 请帮助我们测试新界面，并在 Minecraft 问题追踪器 上报告你发现的任何漏洞。 ​

1.16.4 预发布版 1 的新特性

​

  • 名为“社交互动界面”的新 UI

​

社交互动界面

一个在多人游戏中可用的新界面，显示服务器上所有玩家的列表，以便你可以隐藏来自任何玩家的聊天。 ​

  • 通过可配置的按键打开，默认键为 P
  • 玩家是否被隐藏会在重新加入服务器时重置

​

1.16.4 预发布版 1 的技术性更改

​

  • 新的网络协议方案，为快照设置了一个高位（位 30）。每个快照的协议版本将增加 1，但在网络协议兼容的情况下，完整版可能会保持与上一个完整版相同的协议版本。
  • 现在，在性能不佳导致服务器崩溃的情况下，崩溃日志中会添加更多信息。

​

1.16.4 预发布版 1 中修复的漏洞

​

  • MC-192434 下界合金护腿的纹理显示异常
  • MC-199487 世界生成死锁
