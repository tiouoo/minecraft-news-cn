在这个快照中，我们调整了盔甲纹饰功能，并重新定义了“创建新世界”的用户体验流程。

祝您创造世界愉快！

更改

  • 更新了“创建新世界”界面
  • 现在，手持盔甲或鞘翅物品时与之互动，会将其与已装备的装备进行交换
  • 附魔闪光效果进一步调整，现在更慢、更不明显，但在某些间隔内对比度更高

辅助功能

  • 更改了菜单界面中提示框的位置，以便按钮仍然可读
  • 在辅助功能菜单中新增了两个选项，用于调整附魔闪光的速度和透明度

更新后的“创建新世界”界面

  • 该界面现在分为三个标签页
    • “游戏”标签页允许设置世界名称、游戏模式、难度以及是否允许作弊
    • “世界”标签页允许设置世界类型和种子，并切换结构生成和奖励箱
    • “更多”标签页提供对游戏规则和数据包选择界面的访问
  • 移除了“编辑世界”界面中的“导入设置”按钮和相应的“导出设置”按钮

技术更改

纹饰图案与材料

  • 以下数据现在也由纹饰材料定义：
    • override_armor_materials，这是一个可选的映射，将盔甲材料映射到覆盖的颜色调色板
      • 映射键是该纹饰材料想要用不同颜色调色板覆盖的盔甲材料。
      • 映射值是将此纹饰材料应用于具有相应盔甲材料的盔甲件时使用的颜色调色板的名称。
  • 以下数据不再由纹饰材料定义：
    • incompatible_armor_material

命令

effect

  • infinite 现在可作为效果持续时间的有效选项
    • 无限效果持续时间在玩家物品栏视图中显示为“∞”。

实验性功能

  • 盔甲纹饰现在可以应用于皮革盔甲。
  • 盔甲现在可以使用与其制作材料相同的材料进行纹饰。
    • 例如，现在可以用金色盔甲纹饰装饰金色胸甲。
  • 沙丘盔甲纹饰的纹理已调整，使胸甲上的符号上移了几个像素。
  • 锻造模板的战利品表已调整。

锻造模板的战利品表

  • 以下常见盔甲纹饰在被发现时，现在总是在箱子中生成2个模板：
    • 沙丘
    • 海岸
    • 荒野
    • 哨兵
  • 这是为了给新玩家一个机会，让他们理解锻造模板在使用时会被消耗。
  • 下界合金升级锻造模板的生成率提高了一倍。
    • 虽然我们确实希望下界合金升级更具挑战性，但我们认为此前的生成率在玩家找到第一个下界合金升级模板后，无法鼓励他们进一步探索。
  • 现在每个要塞图书馆的箱子中必定会生成1个“眼眸”盔甲纹饰。
    • 这样即使在最不走运的世界中，这种盔甲纹饰仍然可以被找到。
  • 林地府邸现在生成“恼鬼”盔甲纹饰锻造模板的几率大大增加。
    • 林地府邸本来就很少有使用战利品表的箱子——在运气不好的生成中，甚至一个都没有。找到这些纹饰的几率过于稀有，而我们希望获得“恼鬼”盔甲纹饰的挑战更侧重于首先找到林地府邸。
  • 总的来说，锻造模板的生成现在略微更常见。
    • 由于制作模板副本的方法，我们希望玩家在某个遗迹中发现另一个模板时，会感觉自己刚刚节省了7个钻石。如果模板过于稀有，这种情况就不太会发生，这意味着玩家不会受到鼓励去探索更多遗迹。
