我们回到发布室，为你奉上 Minecraft: Java Edition 1.21.4 的首个快照版本！这次更新带来了新的苍白系好物——眼斑花和树脂，二者都是苍白花园生物群系的新增内容。你还会发现，苍白橡树现在会飘落树叶，我们希望这能进一步渲染阴森的氛围。此外，本版本还带来了一系列技术性更新和 Bug 修复。

挖矿愉快！

新特性

winter_drop 不再是实验性内容。

新增眼斑花

眼斑花是在苍白花园生物群系中生成的新花朵。特性如下：

  • 它们有两种变体：闭合眼斑花和开放眼斑花
  • 眼斑花会根据一天中的时间在两种变体间转换
    • 在夜晚，眼斑花会变成开放状态
    • 在白天，它们会变成闭合状态
    • 在没有昼夜循环的维度中，它们保持原样
    • 转换时，花朵会发出粒子效果
  • 种在地面上的眼斑花会相互沟通，帮助彼此开放或闭合
  • 开放眼斑花在夜晚会发出发光的眼睛
  • 在苍白花园生物群系中对着草使用骨粉可以获得眼斑花
  • 蜜蜂接触眼斑花时会中毒
  • 眼斑花可以吸引蜜蜂，但在玩家互动时蜜蜂会中毒，而不是产生通常的繁殖/生长行为
  • 由眼斑花制成的迷之炖菜会根据变体产生失明或反胃效果
  • 灰色染料和橙色染料可分别由闭合眼斑花和开放眼斑花合成
  • 流浪商人会出售开放眼斑花

新增树脂团、树脂块、树脂砖以及一系列树脂砖块

  • 攻击吱吱怪会导致其吱吱之心渗出 2 到 3 个树脂团
  • 树脂团会生成在附近的苍白橡木原木侧面，并与吱吱之心相连
  • 吱吱之心会进入冷却，攻击后 5 秒内无法产生更多树脂团
  • 树脂团可用作盔甲纹饰的材料
  • 树脂块是树脂团的存储方块
  • 树脂团可以烧炼成树脂砖物品
  • 树脂砖物品可以合成树脂砖块、树脂砖台阶、树脂砖楼梯、树脂砖墙，以及錾制树脂砖块
  • 树脂团和树脂块不需要工具即可瞬间挖掘
  • 树脂砖方块系列的合适工具是镐
  • 树脂团可以在林地府邸的箱子战利品中找到

掉落所需的工具

开发者说明：我们做了一项改动：任何在支撑被破坏时会掉落的方块，现在使用任何工具挖掘也会掉落。之前如果只需用任意工具破坏下方方块就能获得某个方块，而直接破坏该方块却会将其摧毁，这似乎太不公平了！

  • 以下需要支撑的方块现在使用任何工具破坏时都会掉落：钟、灯笼、灵魂灯笼、所有铜门、铁门、重型测重压力板、轻型测重压力板、磨制黑石压力板以及石头压力板
  • 酿造台现在使用任何工具破坏时都会掉落
  • 末影箱在使用不正确的工具破坏时会掉落黑曜石，而不再是什么都不掉

  • 吱吱怪无视仙人掌、甜浆果丛和细雪的伤害，并且现在可以穿过/走过它们
  • 吱吱怪有抽动的动画
  • 防火

    • 玩家与吱吱怪重叠了几秒钟

    • 以刻为单位，表示粒子从起点飞到目标点所需的时间
  • simple_block 特性类型有一个新的可选字段：schedule_tick

  • 在 attribute 命令中，现在会为存在于目标上的属性修饰符 ID 显示建议

attribute 命令

新增子命令，用于将目标实体的属性基础值重置为其默认值。如果实体上不存在该属性，命令将失败。

语法：

attribute <target> <attribute> base reset

参数：

  • target：要更新属性的实体
  • attribute：要更新的属性 ID

TNT 矿车数据

  • TNT 矿车的 TNTFuse 字段已重命名为 fuse
  • 新增可选字段 explosion_speed_factor，用于根据矿车的速度控制额外伤害量
    • 默认值：1.0

文本组件

为文本组件添加了可选的 shadow_color 样式字段，用于覆盖文本的阴影属性。

  • 格式：
    • 一个打包的整数 ARGB 值（例如 -1）
    • 一个 RGBA 值数组（例如 [1, 1, 1, 1]）
  • 如果指定为 0，则该文本永远不会显示阴影
  • 如果指定为非零值，则阴影将始终以该颜色显示
