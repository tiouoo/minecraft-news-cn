现在有了两倍的 Java 版本。

从这个快照开始，蜡烛、收纳袋和幽匿传感器只能通过命令获取。我们认为它们尚未达到我们想要的洞穴与山崖第一部分发布品质。要在生存模式中继续尝试这些特性，请使用预览数据包！

21w19a 中的更改

  • 铁砧界面中的物品名称最大长度已从 35 增至 50。
  • 紫晶洞的生成频率显著降低。
  • 未完成的物品（幽匿传感器、收纳袋和蜡烛）已从创造模式物品栏中移除。
  • 未完成物品（收纳袋、蜡烛）的配方已移除。

洞穴与山崖预览的更改

下载更新后的数据包。

  • 该数据包现在包含与收纳袋和蜡烛相关的配方。

21w19a 中的技术性更改

  • 升级至 Java 16。
  • 添加了 mineable/axe、mineable/hoe、mineable/pickaxe 和 mineable/shovel 方块标签。带有这些标签的方块可以被相应的工具更快地破坏。
  • 添加了 needs_stone_tool、needs_iron_tool 和 needs_diamond_tool 方块标签。如果方块需要正确的工具才会掉落，这些标签将决定需要该工具的哪个等级。
  • 更改了 /item 命令的语法。

Java 16

Minecraft 现在使用更新版本的 Java。如果你使用默认设置，启动器将下载并安装正确的版本。如果你使用自定义 Java 设置或第三方启动器，则需要确保你的 Java 安装版本为 16 或更高。

Item 命令

新语法：

  • /item replace <target> with <item stack> [<count>] - 与旧的 replaceitem 相同
  • /item replace <target> from <source> [<modifier>] - 将物品从来源复制到目标（们），可选应用修饰器
  • /item modify <target> <modifier> - 修改物品（不复制）

例如，/item replace block ~ ~ ~ container.0 from entity @s enderchest.0 会将玩家末影箱中的第一个物品复制到玩家当前所站容器的第一个槽位。
