22w14a 中的新特性

  • 添加了黏土的可再生获取
  • 添加了红树
  • 添加了红树林沼泽生物群系
  • 添加了回响碎片和追溯指南针

黏土的可再生获取

  • 将泥巴放置在下方有滴水石锥的方块上方，最终泥巴会转变为黏土。

红树

引入一种适应水环境的新型树木，它们会由根部支撑着生成。

  • 有几率生成蜂巢
  • 由红树胎生苗生长而成

红树林沼泽

泥泞！混浊！壮丽！欢迎来到最新的生物群系——红树林沼泽。

  • 生成于你通常会在 Minecraft 中找到沼泽生物群系的更温暖、更潮湿的地区。
  • 在这里你可以找到蜜蜂和暖蛙。
  • 这个生物群系的地表覆盖着厚厚的一层泥巴，所以一定要带上你最好的靴子。
  • 乘船在红树巨型根部的下方和周围愉快地航行吧。

追溯指南针

新的追溯指南针可以使用回响碎片合成，回响碎片只在远古城市的箱子中生成，且为该结构独有。

  • 与普通指南针不同，追溯指南针会指向你最后一次死亡的地点。
  • 如果你不在你最后死亡的维度中，或者在你的世界中还没有死亡过，它就会随机旋转。
  • 可以用 1 个指南针和 8 个回响碎片合成，回响碎片可以在远古城市中找到。

22w14a 中的更改

  • 监守者现在会对所有碰撞到它的活体生物发怒，而不仅仅是玩家。

22w14a 中的技术性更改

  • CatType 字段在类型为 minecraft:cat 的实体上已被替换为 variant，数字值被替换为字符串 ID（例如，5 变为 minecraft:calico）
  • 实体谓词中的一些互斥测试（player、fishing_hook、lightning_bolt 和 catType）已被合并为 type_specific 字段
  • 添加了 item_delivered_to_player 进度触发器
  • 添加了 allay_drop_item_on_block 进度触发器

谓词

实体谓词

  • 字段 player、fishing_hook、lightning_bolt 和 catType 已被替换为 type_specific
  • type_specific 有字段 type（其值为 player、fishing_hook、lightning_bolt 或 cat 之一）以及与被移除字段相同的字段
  • 示例：
    • 之前：
     "lightning_bolt": {
   "blocks_set_on_fire": 0
 }
    • 之后
      "type_specific": {
    "type": "lightning",
    "blocks_set_on_fire": 0
  }
  • catType 已被包装以匹配新格式，并且现在使用新的猫变体名称而不是纹理名称：
    • 之前
     "catType": "minecraft:textures/entity/cat/british_shorthair.png"
    • 之后
     "type_specific": {
    "type": "cat",
    "variant": "minecraft:british"
 }
  • 新的 type_specific 选项：
    • frog 有 variant 字段，匹配青蛙变体（minecraft:warm、minecraft:temperate 或 minecraft:cold）
    • slime 适用于史莱姆和岩浆怪，有 size 字段，匹配史莱姆体型（最小为 1）

进度

  • 从触发器 location、slept_in_bed、hero_of_the_village 和 voluntary_exile 中移除了字段 location - 它之前与 player.location 的处理方式完全相同

新触发器

item_delivered_to_player

  • 当悦灵将物品交付给玩家时触发
  • 条件：
    • player - 此触发器所作用于的玩家

allay_drop_item_on_block

  • 当悦灵将物品掉落在方块上时触发
  • 条件：
    • player - 此触发器所作用于的玩家
    • location - 对物品掉落所在方块的谓词
    • item - 对掉落物品的谓词
