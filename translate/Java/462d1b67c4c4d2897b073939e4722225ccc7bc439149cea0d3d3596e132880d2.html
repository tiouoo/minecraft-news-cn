今天是 26.2 Pre-Release 5 发布的时候了，其中包含对极限模式设置的更改以及其他修复！正如 Minecraft Live 上宣布的那样，本次更新将于 6 月 16 日发布！

祝大家（小心地）极限挖矿愉快！

更改

  • 图形 API 的游戏设置现在会在启动时检测到崩溃时更改
  • 现在，击打弹跳原型硫磺方块时播放正确的声音
  • 作为世界主机，使用 F3 + F4 或命令更改游戏模式现在会更改世界的默认游戏模式
  • “游戏模式”和“允许命令”按钮在极限模式世界中不再可用

图形 API 的启动和回退行为

  • 如果游戏在设置了“首选 Vulkan”的情况下启动时崩溃，该设置将自动更改为“默认”
  • 当设置为“默认”时，游戏仍会在启动时尝试收集有关 Vulkan 的系统信息
  • 如果游戏在设置为“默认”时启动崩溃，该设置将自动更改为“首选 OpenGL”
    • 设置“首选 OpenGL”后，如果 Vulkan 会导致崩溃，则不会与 Vulkan 进行任何交互

26.2 Pre-Release 5 中修复的漏洞

  • MC-308470 - “弹跳”硫磺方块原型的声音音量明显更高
  • MC-308575 - flower_default 和 flower_warm 特性生成单朵花，而不是一片花丛
  • MC-308587 - 在间歇泉上使用带有突刺的矛会将你向下发射
  • MC-308619 - 在极限模式世界中，玩家可以通过世界选项菜单更改游戏模式
  • MC-308620 - 在好友屏幕的用户名字段中，按下绑定到“好友屏幕”键位的按键会关闭它，而不是输入字符
  • MC-308622 - 自定义对话框按钮会破坏游戏菜单
  • MC-308630 - 更改是否启用命令不会正确更新世界选项屏幕中“游戏规则”按钮的状态
  • MC-308633 - 使用命令更改游戏模式不会更新世界选项屏幕
  • MC-308648 - 当存在“服务器链接...”按钮时，游戏菜单中的“统计信息”按钮会向右移动
  • MC-308657 - gui.friends.error.unauthorized 字符串包含逗号拼接错误
  • MC-308674 - 重新进入存档后，游戏模式被设置为生存模式
  • MC-308686 - 极限模式死亡可以通过重新加入世界来绕过
