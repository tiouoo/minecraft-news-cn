轰！！26.2 快照 5 就这么炸裂登场了！本快照引入了会喷发的间歇泉，以及硫磺怪的全新爆炸原型！

挖矿愉快！

新特性

  • 新的硫磺怪原型：爆炸型
  • 强效硫磺现在可以形成间歇泉

硫磺怪生物

  • 体内有方块时，现在对爆炸免疫

硫磺怪原型

  • 现在有了第三种特殊原型：
    • 爆炸型：与普通型特性相似，但空气阻力略高，
      • 在吸收 TNT 方块时使用
      • 被吸收的 TNT 可通过红石、火源（包括装有打火石的发射器）或附近的爆炸点燃
      • 被火或红石点燃时，被吸收的 TNT 引信时间为 6 秒
      • 被爆炸点燃时，被吸收的 TNT 使用 0.75 到 3 秒的随机引信时间
      • 体内有已点燃 TNT 的硫磺怪无法用桶装起
      • 体内有已点燃 TNT 的硫磺怪无法受到伤害
      • 被吸收的已点燃 TNT 方块无法用剪刀剪出
      • 爆炸时不会生成小型硫磺怪

强效硫磺

  • 放置在岩浆块上方，且位于 1-4 个水源方块下方时，会生成间歇泉
  • 间歇泉会以随机间隔喷发，向上喷出一股水粒子，并对上方的实体施加向上的冲量

密度函数

添加了 minecraft:interval_select

根据输入密度函数和一组阈值，在多个密度函数之间进行选择。格式：包含字段的对象：

  • input - 密度函数，将要与任意给定 thresholds 进行比较的值
  • thresholds - 非空浮点数列表，用于与 input 进行比较的阈值
    • 如果 input < thresholds[i]，将选择 functions[i] 的结果
    • 如果输入大于最后一个阈值，将选择最后一个函数
    • thresholds 必须比 functions 少一个
  • functions - 至少包含 2 个密度函数的列表，将从中选择结果函数
    • functions 中的元素必须比 thresholds 多一个

移除了 minecraft:weird_scaled_sampler

  • 此密度函数已被移除，其功能由 interval_select 取代
  • 当 rarity_value_mapper 为 type_1 时，等价于：
    • 阈值为 -0.75, -0.5, 0.5, 0.75 的 interval_select
    • 所选函数如下：abs(rarity * noise(x/rarity, y/rarity, z/rarity))
      • 对应的稀有度值：0.5, 0.75, 1.0, 2.0, 3.0
  • 当 rarity_value_mapper 为 type_2 时，等价于：
    • 阈值为 -0.5, 0.0, 0.5 的 interval_select
    • 所选函数如下：abs(rarity * noise(x/rarity, y/rarity, z/rarity))
      • 对应的稀有度值：0.75, 1.0, 1.5, 2.0

粒子

添加了 minecraft:geyser_base

  • 在喷发的强效硫磺方块底部作为一团云雾生成
  • 格式：包含字段的对象：
    • water_blocks - 正整数，缩放粒子大小及其爆裂冲量
    • burst_impulse_base - 浮点数，缩放初始爆裂冲量

添加了 minecraft:geyser_poof

  • 在喷发的强效硫磺方块底部作为一团云雾生成
  • 格式：包含字段的对象：
    • water_blocks - 正整数，缩放粒子大小及其爆裂冲量
    • burst_impulse_base - 浮点数，缩放初始爆裂冲量

添加了 minecraft:geyser_plume

  • 在喷发的强效硫磺方块上方作为一股上升流生成
  • 格式：包含字段的对象：
    • water_blocks - 正整数，缩放粒子大小及其爆裂冲量

添加了 minecraft:geyser

  • 一种发射器粒子，会在喷发的强效硫磺方块上方生成 geyser_base、geyser_poof 和 geyser_plume 粒子
  • 格式：包含字段的对象：
    • water_blocks - 正整数，缩放粒子大小及其爆裂冲量
