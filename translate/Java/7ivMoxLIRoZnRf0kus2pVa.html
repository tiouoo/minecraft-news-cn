我们现在已经发布了 Minecraft 1.16.2 的第二个预发布版，其中又修复了一轮漏洞！

1.16.2 预发布版 2 中的更改

  • 绯红菌索和诡异菌索现在无需剪刀即可采集

1.16.2 预发布版 2 中的技术性更改

execute 命令

  • execute in 现在会遵循维度缩放

1.16.2 预发布版 2 中修复的漏洞

  • MC-69876 位于 Y=1 的活塞无法向下推动 / 位于 Y=254 的活塞无法向上推动
  • MC-124320 末影人可以拾起并放置无雪的积雪草方块
  • MC-130558 当游戏规则 doEntityDrops 设为 false 时，物品展示框无法被清空
  • MC-134084 如果游戏规则 sendCommandFeedback 被禁用，/msg 或 /tell 不会向发送者显示消息
  • MC-136553 创造模式物品栏中的染料顺序是反的
  • MC-152037 动力铁轨、激活铁轨和探测铁轨在被推/拉到无法放置的方块上时会被删除
  • MC-187357 末地要塞不会在 floating_islands 或 caves 预设中生成
  • MC-189736 谓词中的 "distance" 不再起作用
  • MC-190552 演示模式在启动时会重置位置和物品栏
  • MC-190859 floating_islands 或 caves 自助式世界不再生成末地要塞，升级到 1.16 后末影之眼也无法定位之前生成的末地要塞
  • MC-192136 熔岩伤害与之前的版本表现不同
  • MC-192236 末影人可以将方块放置在位于地面上的物品展示框顶部
  • MC-192371 在同一个方块空间内的画在区块加载时会弹出
  • MC-192845 1.16 中的方块事件延迟过高
  • MC-194217 熔岩会点燃下界植被，尽管它们具有抗火性
  • MC-194867 矿车从下界传送门的错误一侧出来，并且在返回主世界时失去动量
  • MC-194953 自定义生物群系无法在谓词中使用
  • MC-195803 生物击杀统计的格式是反的：“N killed you times”
  • MC-195851 猪灵在以物易物时，“帽子”图层会从它们的头上脱离
  • MC-196245 附近有僵尸变种时，闪电苦力怕并不总是掉落头颅
  • MC-196441 合成超过一组的物品后，切石机/锻造台的配方不会授予
  • MC-196469 F1 会隐藏恶心效果的绿色色调
  • MC-196473 河豚给予恶心 II 而不是最高为恶心 I
  • MC-196653 创建多个引用相同 dimension_type 字符串的数据包维度会导致“未注册维度”崩溃
  • MC-196743 自定义/修改的生物群系在主世界中无法工作
