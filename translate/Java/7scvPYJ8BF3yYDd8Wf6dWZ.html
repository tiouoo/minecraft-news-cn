在本快照中，我们添加了对自定义世界设置和自定义维度的支持。这是一个早期版本，用于听取你对这项功能的反馈——请注意，此支持被视为实验性且不受支持。任何自定义世界设置都可能随着快照更新而发生变化，使用自定义设置的世界将在你的世界列表中被明确标记为实验性。 ​

20w21a 的新特性

​

  • 新增了在红石线的十字形和点状之间切换的功能
  • 新增了导入/导出世界设置的功能
  • 新增了 disableMultiplayer 命令行选项——使用后，多人游戏按钮将被禁用
  • 新增了 disableChat 命令行选项——使用后，接收和发送在线聊天将被禁用

​

红石切换

​

  • 右键单击单个红石时，会在十字形和点状之间切换
  • 点状红石不会为其周围的方块充能

​

20w21a 的更改

​

  • 猪灵在欣赏金锭时不再四处走动
  • 如果你在猪灵欣赏金锭时伤害它，金锭现在会消失
  • 提高了玄武岩三角洲中矿石的生成几率，以平衡该生物群系中下界岩数量减少的问题
  • 睡莲现在被视为垃圾钓鱼战利品而非宝藏
  • 更新了 Mojang Studios 和 Minecraft 的徽标
  • 暂时从超平坦世界预设字符串中移除了结构设置（变通方法：使用导入/导出设置功能）

​

20w21a 的技术性更改

​

  • 新增了控制 spreadplayers 命令高度的功能
  • 新增了自定义世界和自定义维度

​

命令

​

spreadplayers

​ 新增了一个可选参数，用于指定最大高度。 新语法：spreadplayers <center> <spreadDistance> <maxRange> [under <maxHeight>] <respectTeams> <targets> ​

  • maxHeight - 指定结果位置的最大高度

​

locate

​

  • 结构名称现在使用全小写字母指定

​

自定义世界

​

  • 加入了实验性的自定义世界支持
  • 编辑世界界面现在有一个选项，可以将世界设置导出为 JSON 文件
  • 在创建世界期间，你可以导入之前导出的世界设置
  • 大量新参数被开放，但被标记为实验性，这意味着你可以尝试使用它们，但不能保证其中任何一项还能继续正常工作（即使在下个快照中也不行！）
  • 超平坦世界预设字符串丢失了结构设置（它们现在以通用格式存储在所有世界中），我们将很快恢复某种形式的功能
  • 无法再从 server.properties 创建自助式世界，超平坦世界设置略有改动；即将为服务器端提供更好的自定义世界创建支持

​
