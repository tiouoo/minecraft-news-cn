快照 21w16a 介绍了对杜鹃花和滴水石的一些更改。除此之外，我们还调整了粗矿的材质。洞穴与山崖预览数据包也有一些新增内容。

21w16a 中的新特性

  • 现在可以对杜鹃花和盛开的杜鹃花使用骨粉来生成杜鹃花树
  • 添加了滴水石生长

滴水石生长

  • 如果钟乳石悬挂在滴水石块下方，且其上方有水源，则会缓慢生长，使上方钟乳石和下方石笋同时生长
  • 生长速度是随机的，但非常缓慢，单次生长可能需要数个 Minecraft 天
  • 钟乳石最多只会生长到 7 格长
  • 只有当下方的地面或石笋在 10 格以内时，钟乳石才会促使石笋生长
  • 如果钟乳石尖端位于水中，就不会滴水，因此也不会触发任何生长
  • 如果石笋尖端位于水中，就不会接收到滴落的水，因此不会因滴水钟乳石而生长。如果两个尖端之间存在任何流体，情况亦然
  • 石笋或钟乳石永远都不会生长到流体中

21w16a 中的更改

  • 调整了粗矿和粗矿石块的材质

洞穴与山崖预览的更改

在此下载更新的数据包 快照 21w16a 中的熔岩含水层。点击此处查看完整分辨率图像链接。

  • 高度低于 0 的含水层有时会是熔岩含水层，而非水含水层
  • 矿脉现在可以生成在地下

矿脉

  • 矿脉是大型、稀有、蛇形的地下矿石结构
  • 铜矿脉形成于高度 0 以上，并与花岗岩混合
  • 铁矿脉形成于高度 0 以下，并与凝灰岩混合

21w16a 中的技术更改

  • 之前永久拒绝服务器资源包的用户，如果资源包为强制要求，现在仍会看到资源包提示（而不是立即被断开连接）
  • 游玩时间的统计已被重命名为 play_time
  • 现在有一个“世界开启时间”（total_world_time）的统计，其中也包括游戏暂停的时间
