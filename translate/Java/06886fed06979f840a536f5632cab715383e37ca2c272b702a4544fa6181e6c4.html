今天我们发布了 26.2 预发布版 4，包含对“混沌方块”更新的一些修复和调整。正如 Minecraft Live 上宣布的那样，该更新将于 6 月 16 日正式发布！

祝大家游戏愉快！

更改

  • 当游戏粒子数量过载时，不再移除正在飞行中的现有粒子，而是随机选择渲染或不渲染某些粒子，以保持在粒子限制以下
    • 此更改在大量新的间歇泉喷发时尤为明显

硫磺方块生物

  • 随着击退附魔等级的提高，硫磺方块现在将被击退得更远

强力硫磺

  • 末影龙将不再受间歇泉的影响

用户界面

  • “多人游戏选项”屏幕已改回“对局域网开放”
  • 修复了 Realms 配置屏幕可能无法打开的问题

世界选项屏幕

  • 世界主机现在可以在“世界选项”屏幕中访问“游戏模式”和“允许作弊”按钮

对局域网开放屏幕

  • 与世界选项不同，世界主机可以为世界中的其他玩家配置“游戏模式”和“允许作弊”的值（与自身设置分开）
    • 这些按钮位于“其他玩家设置”标题下

技术性更改

  • 数据包版本现在为 107.1
  • particle_render_stats 现在包含不同粒子组的计数（SQ 代表 单四边形，NR 代表 不渲染，EG 代表 远古守卫者，IP 代表 物品拾取），以及总数

数据包版本 107.1

实体标签

  • 添加了 #not_affected_by_geysers - 不受间歇泉喷发向上冲击力影响的实体

26.2 预发布版 4 中修复的漏洞

  • MC-223248 孢子花粒子逐渐消失/减少，直到世界重新加载
  • MC-306460 全屏模式下游戏窗口高度多出一个像素
  • MC-307382 Windows 全屏模式下截取的屏幕截图高度多出一个像素
  • MC-308063 启用多人游戏并开启作弊后禁用多人游戏时，客户端仍认为作弊已启用
  • MC-308097 游戏菜单中的“服务器链接...”按钮看起来位置不当
  • MC-308174 物品实体的碰撞箱比物品实体本身渲染得更远
  • MC-308337 “好友界面”按键绑定在设置为鼠标按钮时无法生效
  • MC-308339 大量连续间歇泉同时喷发时，粒子效果出现视觉故障
  • MC-308579 为带有多重射击 32 级或更高等级的弩装填会导致游戏崩溃
  • MC-308583 破坏大多数生物头颅时，方块破坏动画不再渲染
  • MC-308584 使用 Vulkan 渲染后端时，方块破坏动画与方块发生深度冲突（OpenGL 后端下极少发生）
  • MC-308588 调试按键组合现在会执行绑定在该键上的其他按键绑定
  • MC-308592 使用 F3 + F4 切换游戏模式时会触发 F4 的按键绑定
