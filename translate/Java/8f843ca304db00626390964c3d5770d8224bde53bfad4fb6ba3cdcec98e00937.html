我们以另一个预发布版开启本周，包括一些音乐和快乐恶魂的漏洞修复。《追猎天空》更新即将到来，预发布计划可能每周包含不止一个预发布版。

更改

音乐与声音

  • 以下声音分类已重命名：
    • 友好生物 -> 友好生物
    • 敌对生物 -> 敌对生物

技术性更改

对话框

对话框描述格式

输入控件类型

minecraft:text

  • 输出值：

    • 作为模板替换时：内容中的特殊字符会被转义以符合 SNBT 字面量（注意：' 和 " 都会被转义）

  • 对于 multiline 字段：

    • 如果省略了 height 字段，但存在 max_lines，则为了适应最大行数而选择的高度不能超过 512

修复 1.21.6 预发布版 2 中的漏洞

  • MC-217887 在 1.9-pre1 或更早版本中编写的未签名书籍无法正确升级
  • MC-297575 拥有 NBT 标签 NoAI 设为 true 的快乐恶魂无法被玩家控制
  • MC-297591 末影珍珠可能会意外停下
  • MC-298104 多行文本输入控件的 max_lines 字段不受限制，会导致游戏卡顿
  • MC-298144 minecraft:text 输入类型的初始值仅限 32 个字符，无论 max_length 字段如何
  • MC-298155 使用多行文本输入的对话框 command_template 会导致玩家因聊天中出现非法字符（即 \n）而被踢出服务器
  • MC-298209 玩家接触快乐恶魂身体时无法移动
  • MC-298301 在对话框中，光标闪烁会将多行文本输入控件中光标右侧的所有字符向右移动
  • MC-298307 在创造模式下进出苍白花园会导致当前音乐曲目持续无声
  • MC-298358 骑着生物进入细雪时，玩家不再受到应有的影响
  • MC-298361 玩家骑乘快乐恶魂时，退出下界传送门后会来回传送
  • MC-298368 "music_notes.png.mcmeta" 包含一个不存在的额外索引，导致出现警告
  • MC-298394 在细雪中的冻结效果非常不一致且抖动
  • MC-298422 在某些情况下，恶魂和快乐恶魂不会受到有害方块造成的伤害
