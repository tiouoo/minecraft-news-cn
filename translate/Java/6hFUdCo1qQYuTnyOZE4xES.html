在我们迈向 1.16.2 的进程中，是时候开启新一轮的快照周期了！此快照引入了猪灵蛮兵，你也许已经在基岩版测试版中听说过它们。

猪灵蛮兵将是 1.16.2 中唯一的新增内容，其余快照将专注于修复漏洞。

20w27a 新增内容

  • 加入了猪灵蛮兵！

猪灵蛮兵

  • 猪灵蛮兵是猪灵的更强版本，它们生活在堡垒遗迹中，守护着那里的宝藏
  • 与它们懦弱贪婪的同类不同，猪灵蛮兵不会被黄金分散注意力，也什么都不怕
  • 猪灵蛮兵会一见到玩家就发动攻击，无论玩家穿着什么
  • 猪灵蛮兵手持斧头，并且不需要任何盔甲，因为它们就是那么强悍

20w27a 中的更改

  • 僵尸疣猪兽现在可以被拴绳牵引
  • 绯红菌和诡异菌现在可以放置在菌丝体上

20w27a 中的技术性更改

  • 对数据包和资源包选择界面进行了小幅改进

包选择界面

  • 界面打开时，当包目录内容发生变化，界面会自动更新
  • 两个包选择界面现在都会将 pack.png 的内容显示为包图标

20w27a 中修复的漏洞

  • MC-1058 如果佩戴龙头的实体不在视野中，龙头会不可见
  • MC-2404 潜行时走下台阶会导致从方块上掉落
  • MC-49476 NBT 的 "HideFlags" 无法隐藏皮革盔甲上的 "已染色" 标签
  • MC-68487 同一玩家的玩家头颅总是具有相同的皮肤纹理，即使保存的纹理数据不同
  • MC-97507 使用会修改手持物品的物品会显示 "装备" 字幕
  • MC-145691 将 "打开/关闭物品栏" 绑定到 Tab 键只会打开物品栏
  • MC-150417 灵魂沙上方有液体时，某些物品会卡在灵魂沙中
  • MC-167285 在船上时，如果末地折跃门的另一侧有平台，会被瞬间传送回去
  • MC-171739 垂泪藤、缠怨藤、竹子和海带可以同时被破坏和放置，从而被"树苗"替换
  • MC-173526 所有矿车都能在熔岩中存活
  • MC-178729 不一致之处：红色和棕色蘑菇不能在菌岩上生长为巨型蘑菇，而在所有其他 "草" 方块上却可以
  • MC-182652 废弃传送门并非总是会生成箱子
  • MC-183663 农民村民无法正确堆肥
  • MC-183743 铁傀儡数量过多
  • MC-185274 在 20w21a 或更新版本的快照中进食时，字幕仍会显示 ''装备''
  • MC-188473 资源包界面在添加或移除资源包时不再更新
  • MC-188969 物品栏中有迷之炖菜时，喂养棕色哞菇会阻止所有类型的迷之炖菜进入物品栏
  • MC-189909 当只有一个物品且该物品被消耗时，player_interacted_with_entity 不会触发
  • MC-190021 潜行时尝试骑乘猪或炽足兽会播放手部动画
  • MC-190266 玩家和其他实体在熔岩中骑着炽足兽登录后可能会着火
  • MC-190274 在创造模式中用瓶子收集液体与新的创造模式桶机制不一致
  • MC-190849 粘液块只能推动实体 5 格高，而在 1.15.2 中是 6 格高
  • MC-191915 在船上时，鞘翅不会显示为已附魔
  • MC-192894 调整大小时，透明图层会丢失其辅助深度缓冲 ID

获取快照

快照适用于 Minecraft Java 版。要安装快照，请打开 Minecraft 启动器，并在"安装"选项卡中启用快照。

测试版本可能会损坏你的世界，请备份世界和/或在不同于主世界的文件夹中运行它们。
