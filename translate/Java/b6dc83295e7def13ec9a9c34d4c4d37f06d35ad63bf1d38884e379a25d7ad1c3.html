新物品组件

minecraft:item_model

  • 控制物品模型
  • 存在于每个物品上
  • 格式：命名空间 ID
    • namespace:id 将引用模型 /assets/<namespace>/models/item/<id>

minecraft:equippable

  • 如果存在，该物品可以被玩家装备到选定的槽位
  • 当使用带有此组件的物品右键点击时，它会与对应槽位中的物品交换
  • 格式：包含字段的对象
    • slot：head、chest、legs、feet、body、mainhand 或 offhand 之一
    • equip_sound（可选）：装备物品时播放的声音事件
      • 如果未指定，将播放默认的盔甲装备声音
    • model（可选）：装备时使用的装备模型的命名空间 ID
      • 这些模型定义从资源包加载
      • 如果未指定，则在头部槽位时回退为渲染物品本身（如果不适用则不渲染）
    • allowed_entities（可选）：实体 ID、实体标签或实体 ID 列表，用于限制哪些实体可以装备此物品
      • 如果未指定，则允许任何（可以穿戴此类装备的）实体装备此物品
    • dispensable：布尔值（默认：true），该物品是否可以通过发射器装备
      • 如果该物品类型有特殊的发射器行为，则此选项无效
    • 例如：equippable={slot:'chest',equip_sound:'item.armor.equip_chain'}

minecraft:glider

  • 如果存在，该物品在装备时将允许玩家滑翔（如同鞘翅）
  • 格式：空对象
    • 例如：glider={}

minecraft:tooltip_style

  • 如果存在，该物品可以为提示文本背景和边框使用自定义精灵图
  • 格式：提示文本样式的命名空间 ID
    • 名称为 namespace:path 的提示文本样式将使用以下 ID 的精灵图：
      • <namespace>:tooltip/<path>_background 和 <namespace>:tooltip/<path>_frame
    • 例如：tooltip_style='minecraft:special_sword'

谓词

  • 在玩家子谓词中添加了一个新字段 input，可用于检测玩家正在按下哪些移动键
  • 如果指定，该谓词会匹配玩家正在按下的对应按键；它支持检测以下输入：
    • forward：布尔值（可选）
    • backward：布尔值（可选）
    • left：布尔值（可选）
    • right：布尔值（可选）
    • jump：布尔值（可选）
    • sneak：布尔值（可选）
    • sprint：布尔值（可选）

自定义装备模型

现在可以通过在资源包中定义“装备模型”来自定义玩家或某些生物装备时的外观。

  • 装备模型定义从 assets/<namespace>/models/equipment/<path>.json 加载
    • 然后可以通过 equippable 组件以 model id 为 namespace:path 来引用它们
  • 模型定义是一个包含字段的对象：wolf_body、horse_body、llama_body、humanoid、humanoid_leggings、wings
    • 所有字段都是可选的，可用于为给定的模型层类型指定层列表
    • 每个字段包含层对象列表：
      • texture：此层的命名空间纹理位置
        • namespace:path 将解析为 assets/<namespace>/textures/entity/equipment/<layer_type>/<path>.png
      • dyeable：包含字段的对象（可选），指定该层在染色时的行为（在 dyeable 物品标签中，并具有 dyed_color 组件）
        • color_when_undyed：RGB 颜色整数（可选）
        • 如果指定，该层将被 dyed_color 组件中包含的颜色着色
          • 如果物品不可染色或未染色，则将根据 color_when_undyed 指定的颜色着色
          • 如果未指定 color_when_undyed 且物品未染色，则该层将被隐藏
      • use_player_texture：布尔值（默认：false），如果此层纹理应由玩家提供的纹理覆盖，则为 true
        • 仅用于 wings 层，将用玩家的自定义鞘翅纹理覆盖

同时指定玩家和马铠层的模型定义可能如下所示：

{
  "layers": {
    "horse_body": [
      { "texture": "minecraft:iron" }
    ],
    "humanoid": [
      { "texture": "minecraft:iron" }
    ],
    "humanoid_leggings": [
      { "texture": "minecraft:iron" }
    ]
  }
}

纹饰

  • 所有定义了装备模型的可装备物品都支持基于 trim 组件渲染纹饰
  • 纹饰纹理将从 textures/trims/entity 目录中的相应文件夹加载
    • 例如，带有 wolf_body 层的盔甲将从 textures/trims/entity/wolf_body 获取纹饰
