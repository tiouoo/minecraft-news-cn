现在是 Minecraft 1.19 预发布版 3 的发布时刻，这也是本周的最后一个预发布版。在此预发布版中，我们调整了音爆攻击，并修复了更多漏洞。

尽情享受吧！

1.19 预发布版 3 的更改

  • 循声守卫的音爆攻击现在会绕过盔甲附魔（如保护）的伤害减免效果

1.19 预发布版 3 的技术性更改

  • item_interact_start 不再被检测为振动，以便更具体的动作（如 drink 或 eat）能被检测到，但 item_interact_finish 仍会被检测

1.19 预发布版 3 修复的漏洞

  • MC-209932 幽匿感测体在被踩踏时只检测到最后一个被破坏的海龟蛋
  • MC-210277 鸡下蛋时幽匿感测体未被激活
  • MC-210278 蜜蜂进出蜂巢或蜂箱时幽匿感测体未被激活
  • MC-214622 幽匿感测体无法检测阳光传感器模式切换
  • MC-249094 幽匿尖啸体内侧面的意外剔除
  • MC-249230 青蛙在受到伤害时优先捕食实体而非逃跑
  • MC-250162 在物品展示框中放置地图会破坏与其相交的画和带有地图的物品展示框
  • MC-250238 青蛙试图寻路至其攻击范围外的实体，导致它们不断旋转和抽搐
  • MC-250983 悦灵可能会卡在非完整方块中并无法移动
  • MC-251220 22w17a 中延伸部分的方块光照相比 1.18.2 暗淡了许多
  • MC-251420 演示模式：“立即购买！”链接的目标地址不正确
  • MC-251858 字幕位置比之前的版本更高
  • MC-251872 在命令中使用实体选择器时，游戏输出和服务器控制台会记录有关无效签名聊天数据包的警告
  • MC-251878 幽匿感测体听到物品掉落地面的声音时，即使是由玩家掉落的，也不会提醒尖啸体
  • MC-251968 运行聊天相关命令的 /execute 会记录“收到没有有效签名的聊天数据包”警告
  • MC-252071 如果信号在循声守卫死亡前传递，循声守卫在死后仍会检测
  • MC-252078 悦灵在受到伤害时不再逃跑或恐慌
