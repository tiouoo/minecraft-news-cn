悦灵，这个没人真正确定怎么发音的生物，现在进入了最新的 Minecraft: Java Edition 快照。伴随着我们闪亮的蓝色新朋友，我们还加入了远古 城市，自从几周前的实验性快照以来，它们经历了一些相当巨大的变化，所以务必去看看。

采矿愉快！

22w13a 中的新特性

  • 加入了悦灵生物
  • 加入了远古城市

悦灵

  • 悦灵会收集周围所有与它们手持物品相同的物品
  • 悦灵会喜欢将物品交给它们的玩家，并将收集到的物品带给它们喜欢的玩家
  • 如果悦灵听到音符盒奏响，该音符盒将成为悦灵最喜欢的音符盒，持续30秒。在此期间，悦灵会待在音符盒附近，并将收集到的物品带到音符盒处而不是带给玩家
  • 空手与悦灵互动会取下悦灵手持的物品
  • 悦灵可以在掠夺者前哨站和林地府邸中找到

远古城市

在深暗之域深处游荡于这些废弃已久的结构大厅中，以发掘一些被遗忘的遗物。

  • 远古城市结构会在深暗之域生物群系中生成
  • 在由幽匿感测体和幽匿尖啸体守卫的箱子中，你可以找到新的迅捷潜行附魔
  • 你还可以在这里找到一种名为强化深板岩的神秘新方块，它无法在生存模式中获得
  • 生物不能在远古城市中生成

与实验性深暗之域快照相比的差异

  • 远古城市进行了许多调整，包含新增和调整过的结构
  • 远古城市的战利品表已进行调整，包括为“冰盒”结构单独设置了一个战利品表

22w13a 中的更改

  • 带有箱子/熔炉/TNT/漏斗的矿车的配方现在变为无序合成
  • 每种矿车变体被破坏时现在会掉落自身作为物品，而不是拆分为两个物品（例如箱子和矿车）
  • 现在只有羊毛和羊毛地毯会阻挡来自音符盒的声音

22w13a 中的技术性更改

  • 加入了 kill_mob_near_sculk_catalyst 进度触发器
  • 幽匿尖啸体的方块状态更改
  • 重命名了一些游戏事件

进度

新触发器

kill_mob_near_sculk_catalyst

  • 当玩家在幽匿催化体旁边杀死一个实体时触发
  • 条件：
    • player - 此触发器所针对的玩家
    • entity - 对被杀死实体的谓词
    • killing_blow - 对实体死亡方式的谓词

幽匿尖啸体

  • 为幽匿尖啸体加入了 can_summon 方块状态，用于决定尖啸体是否能召唤循声守卫
  • 通过世界生成放置的尖啸体将把 can_summon 设为 true
  • 当尖啸体被放置或通过幽匿块扩散生成时，can_summon 会被设为 false

游戏事件

一些游戏事件已被重命名，其中部分更改是为了让它们在语法上更加一致：

  • drinking_finish -> drink
  • entity_killed -> entity_die
  • entity_damaged -> entity_damage
  • elytra_free_fall -> elytra_glide
  • mob_interact -> entity_interact
  • ravager_roar -> entity_roar
  • wolf_shaking -> entity_shake

以下事件已合并为 block_activate 和 block_deactivate：

  • block_press
  • block_unpress
  • block_switch
  • block_unswitch

游戏事件的其他杂项更改：

  • ring_bell 已被移除，替换为 block_change
  • shulker_open 和 shulker_close 均已被移除，改用 container_open 和 container_close
  • fishing_rod_cast 和 fishing_rod_reel_in 已重命名为 item_interact_start 和 item_interact_finish
  • 加入了 ignore_vibrations_on_occluding_block 游戏事件标签及其后续逻辑
  • 与各种生物互动时，entity_interact 应该会更频繁地触发
