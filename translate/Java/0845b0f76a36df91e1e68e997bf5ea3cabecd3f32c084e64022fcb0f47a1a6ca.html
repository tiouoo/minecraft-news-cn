噪声（Noises）

噪声格式（定义于 worldgen/noise 注册表，或是内联在基于噪声的方块状态提供器中）已更新。

噪声用于定义分形布朗运动（fBm）配置，具备以下特性：

  • 输出数值（近似）服从正态分布

  • 若无额外指定，输出振幅范围适配 [-1; 1]

    • 受正态分布影响，实际 99.7% 的采样结果会落在该区间内，但依旧有可能出现区间外的值

  • 默认参数：持续性 persistence=0.5，空隙度 lacunarity=2.0

    • 含义：每经过一个八度，振幅减半、频率翻倍

  • 拥有稳定种子机制；对单个八度进行增强、衰减或叠加修改，不会影响其余八度

  • firstOctave 重命名为 base_octave

  • 新增 base_amplitude — 非负浮点数，噪声输出的缩放系数

    • 如不填写，默认值为 1.0

  • 新增 octave_count — 1~32 之间的整数，代表采样使用的八度数量

  • 新增 normalize — 布尔值或字符串 "legacy"，控制输出振幅归一化方式

    • 设为 true：base_amplitude 为输出预期振幅（即 99.7% 的采样值落在 [-base_amplitude; base_amplitude]）
    • 设为 false：base_amplitude 仅代表第一个八度的振幅
    • 设为 "legacy"：沿用旧版格式的归一化逻辑
      • 该模式下最终值域通常会小于预期范围
    • 不指定时默认 true
    • 注意：归一化不受 amplitude_modifiers 字段影响；因此单独修改某个八度振幅不会改变其他八度振幅

  • amplitudes 重命名为 amplitude_modifiers — 浮点数组，对应每个八度的缩放系数

    • 数组元素数量必须和 octave_count 保持一致
    • 如上所述，该缩放系数不受归一化限制，会直接改变最终输出振幅
    • 此字段不再为必填项；省略时全部默认为 1.0

密度函数（Density Functions）

新增 pow

对底数进行指定次幂运算。

格式：包含如下字段的对象：

  • base — 密度函数，底数
  • exponent — 密度函数，指数

新增 sqrt

计算输入值的平方根。

格式：包含如下字段的对象：

  • input — 密度函数，待求平方根的数值

新增 log

计算输入值的自然对数。

格式：包含如下字段的对象：

  • input — 密度函数，待求自然对数的数值

新增 sign

求取输入值的符号：

  • 输入为正数，返回 1
  • 输入为 0，返回 0
  • 输入为负数，返回 -1

格式：包含如下字段的对象：

  • input — 密度函数，待求取符号的数值

新增 distance_to_point

使用指定距离公式计算到固定坐标点的距离。

格式：包含如下字段的对象：

  • point — 由 3 个整数组成的数组 [x, y, z]，目标坐标点
  • metric，可选值：
    • euclidean — 欧氏距离：sqrt(dx^2 + dy^2 + dz^2)
    • euclidean_squared — 欧氏距离平方：dx^2 + dy^2 + dz^2
    • manhattan — 曼哈顿距离：abs(dx) + abs(dy) + abs(dz)
    • chebyshev — 切比雪夫距离：max(abs(dx), abs(dy), abs(dz))

gradient 更新（由 y_clamped_gradient 重命名）

格式：包含如下字段的对象：

  • axis — x、y 或 z，梯度生效坐标轴
  • tiling，可选值：
    • clamp_to_edge — 超出梯度范围时，使用边界最近处的数值
    • repeat — 在范围外循环重复梯度
    • mirrored_repeat — 镜像循环，奇数次重复进行翻转，保证衔接处连续
  • from_coordinate — 整数，梯度起始坐标
  • to_coordinate — 整数，梯度终止坐标
    • 不可与 from_coordinate 相同
  • from_value — 浮点数，梯度起点数值
  • to_value — 浮点数，梯度终点数值

新增 slice

沿着指定坐标轴固定坐标进行切片，移除输入定义域中的一个维度。举例：当 axis=y、coordinate=0 时，将沿着 XZ 平面切片，所有采样均取 y=0 处的值。

格式：包含如下字段的对象：

  • axis — x、y 或 z，将要移除的坐标轴
  • coordinate — 整数，固定采样坐标
  • input — 密度函数，原始输入函数

end_outer_islands 改动

由 end_islands 重命名。不再计算主岛屿的密度。

装备资源

trim_palette_replacements 字段被替换为 trim_overrides。该字段可针对指定纹饰材料或纹饰样式，替换装备使用的纹理或调色板，不再局限于单纯替换调色板。

  • 格式：一组覆盖规则条目，每条包含：
    • when — 匹配条件对象，用于指定要匹配的材料与/或样式
      • material — 可选，纹饰材料ID，待匹配材料（填写时生效）
      • pattern — 可选，纹饰样式ID，待匹配样式（填写时生效）
        • 注意：该参数不是旧版的调色板 ID，与 trim_palette_replacements 不同！
      • material、pattern 至少填写一项
      • 两项同时填写时，需要全部匹配才会启用本条规则
    • texture — 可选，纹饰样式资源ID；匹配成功后替换使用的纹理
      • 资源标识符格式与常规资源ID保持一致
      • 不填写时，使用该纹饰样式默认纹理
    • palette — 可选，调色板ID；匹配成功后替换使用的调色板
      • 不填写时，不对纹理进行调色板映射
    • 始终选取第一条满足匹配条件的条目
    • texture 和 palette 至少定义一项
