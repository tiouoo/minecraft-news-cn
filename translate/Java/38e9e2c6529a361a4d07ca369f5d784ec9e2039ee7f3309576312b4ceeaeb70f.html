我们又有一个预发布版火热来袭！这次新增了一个进度触发器和声音类别，但最重要的是修复了一些急需解决的错误。

新特性

音乐和声音

  • 新增了一个名为“UI”的声音类别，用于播放UI元素产生的声音，例如按钮点击声

技术性更改

  • 数据包版本号现在为80

数据包版本80

  • 新增了player_sheared_equipment触发器

新触发器

新增了minecraft:player_sheared_equipment

  • 当玩家剪下实体身上可剪下的装备时可触发
  • 条件：
    • item - 被剪下的物品
    • entity - 被剪下装备的实体

命令

修改了playsound

  • 新增了ui类别
    • 游戏暂停时，此类别中的声音会继续播放，与music类似
