紫水晶

紫水晶块

  • 紫水晶在晶洞中会以两种方块形式生成：紫水晶块和紫水晶母岩
  • 所有类型的紫水晶方块（包括紫水晶簇）在你行走、挖掘、放置或使用弹射物击中它们时都会发出美妙的声音——去制作一些音乐吧！

紫水晶簇

  • 紫水晶簇从紫水晶母岩上长出，紫水晶母岩可以在晶洞中找到
  • 紫水晶簇有4个生长阶段：小型紫水晶芽、中型紫水晶芽、大型紫水晶芽和紫水晶簇
  • 紫水晶簇只有放置在紫水晶母岩块上时才能生长
  • 完全长成的紫水晶簇在玩家使用铁镐或更高等级镐挖掘时会掉落4个紫水晶碎片（使用时运魔咒会更多），否则被破坏时不会掉落任何物品
  • 紫水晶簇在任何阶段都可以使用精准采集采集

紫水晶晶洞

  • 这些巨大的晶洞可以在主世界地下的任何地方找到
  • 紫水晶晶洞的外层是一种叫凝灰岩的新石头
  • 紫水晶晶洞的第二层是另一种叫方解石的新方块
  • 紫水晶晶洞的内层是各种紫水晶方块

紫水晶碎片

  • 紫水晶簇会掉落4个紫水晶碎片（使用时运魔咒会更多）

紫水晶母岩

  • 在紫水晶母岩块的空气中或水源方块一侧，最终会长出小型紫水晶芽
  • 紫水晶芽只有附着在紫水晶母岩上时才能生长，并会长成紫水晶簇

收纳袋

  • 收纳袋是用来装其他物品的物品。
  • 一个收纳袋可以装下多种物品，但只能装一组量。例如，一个收纳袋可以装下：
    • 64个泥土
    • 32个泥土+32个石头
    • 32个泥土+8个末影珍珠
    • 每种颜色的羊毛、混凝土、地毯和陶瓦各1个（共64个方块）
    • 或1个钻石头盔
  • 使用鼠标右键将一个物品放入收纳袋。
  • 右键点击收纳袋以清空它。
  • 把礼物放进收纳袋送给你的朋友吧！

蜡烛

  • 蜡烛有全部16种颜色+1种无色变种
  • 一个方块内最多可以放置4根蜡烛
  • 蜡烛能让你好好地为某人送上生日祝福
  • 可以含水！（但在水下不能点燃它们，笨蛋）
  • 用插上蜡烛的蛋糕祝任何人生日快乐吧！

炼药锅

  • 炼药锅现在可以用熔岩桶装填！
  • 装满熔岩的炼药锅会发出强度为1的红石信号

铜

铜块

  • 用9个铜锭合成一个铜块
  • 合成切制铜块、切制铜楼梯和切制铜台阶
  • 使用蜜脾合成涂蜡铜块

铜矿石

  • 铜矿石可以像铁和煤一样在主世界的矿团中找到（这不是铜的最终生成方式……）
  • 烧炼铜矿石获得铜锭

避雷针

  • 避雷针由三个铜锭合成
  • 在雷暴中保护你的建筑（嗯，只要避雷针周围最近的区域是防火的）！
  • 避雷针会保护自身周围4*16格的区域免受有时是毁灭性的雷击！
  • 避雷针被闪电击中时会发出红石信号

氧化

  • 铜会随着时间推移氧化
  • 有四个阶段：铜、轻度风化的铜、半风化的铜和风化的铜
  • 铜块氧化一个阶段需要50-82个Minecraft天（在已加载的区块中）
  • 涂蜡的铜块不会氧化
  • 你可以给任意氧化阶段的铜涂蜡——这意味着你可以把那些漂亮的轻度风化铜块永远保持在轻度风化阶段，多么可爱啊！

望远镜

  • 你可以使用望远镜看远处的东西
  • 可以假装自己是船长，或者当场抓住把你的羊染成黄绿色的邻居
  • 望远镜由两个铜锭和一个紫水晶碎片合成

遮光玻璃

  • 遮光玻璃是一种不允许光线穿过的玻璃
  • 遮光玻璃可以通过将一个玻璃块放在4个紫水晶碎片中间来合成
  • 遮光玻璃无需精准采集即可获得；它不会像普通玻璃那样碎裂

20w45a中的更改

  • 经验球在数量较多时现在有时会合并以提升性能。这不会改变玩家吸收它们的速度，只是限制了世界中漂浮的独立经验球数量。合并后的经验球会继承最近生成的那个经验球的存活时间。
  • 现在可以使用配方书合成包含1个火药的简易烟花火箭
  • 现在可以用锹对着泥土、灰化土、菌丝或砂土（以及草方块）来制造土径（原草径）
  • 矿车和铁轨现在可以在水中工作
  • 活塞破坏方块时现在会出现粒子

矿车

矿车和铁轨现在可以在水中工作

  • 所有铁轨都可以含水（使用发射器和 水桶也可以）
  • 流动的水不会破坏铁轨
  • 矿车可以穿过水，但会比平时受到更大的减速

20w45a中的技术性更改

  • 实体现在与地形区块分开保存。
  • 加入了战利品表函数set_banner_pattern
  • version.json中的包格式已拆分为数据和资源版本
  • 服务器现在可以要求玩家接受自定义资源包

自定义服务器资源包

专用服务器可以通过在server.properties中设置require-resource-pack来强制使用自定义资源包。 使用该选项后，玩家会收到提示并要求做出回应，如果拒绝所需资源包，他们将被断开连接。

实体存储

实体已从主（地形）区块中移出，现在存储在单独的entities目录中（类似于POI存储）。 这些新文件仍然是带有NBT的区域文件。

战利品表

新函数

set_banner_pattern

设置旗帜图案所需的标签。 参数：

  • patterns - 图案对象列表：
    • pattern - 图案名称（square_bottom_left、bricks等）
    • color - 颜色名称（light_gray等）
  • append - 如果为true，新元素将附加到现有元素之后，而不是替换它们
