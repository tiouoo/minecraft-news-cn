祝你探索愉快！

命令

swing 命令改动

  • 对玩家使用该命令时，不再重置玩家的攻击强度
  • 新增可选参数，用于指定播放的挥动动画
    • 可选值：whack（挥击）、stab（刺击）
    • 省略该参数时，默认为 whack
  • 新增参数，用于设置挥动动画的持续时长（如提供该参数）
    • 格式：正数时间值（默认单位为刻）
    • 省略该参数时，默认为 6t

数据组件

新增 minecraft:attack_animation

  • 物品用于攻击实体时播放的动画
  • 格式：包含如下字段的对象：
    • type — 挥动动画类型，可选 whack 或 stab
    • duration — 正整数，动画持续刻数

新增 minecraft:interact_animation

  • 物品用于与方块/实体交互时播放的动画
  • 格式与 minecraft:attack_animation 一致

移除 minecraft:swing_animation

  • 该组件已被 minecraft:attack_animation 和 minecraft:interact_animation 替代
    • 已移除 none 挥动动画类型
    • 世界中已存在的物品会自动迁移为默认的 whack（挥击）
    • 将这两个新组件设置为相同值，功能上将等价于旧组件，但存在以下例外：
      • /swing 命令 — 动画类型现在由命令参数指定
      • 实体掉落的物品

移除 minecraft:map_color

  • 地图不再使用着色叠加层进行绘制，该组件已无作用对象
  • 加载旧地图时会移除该组件
  • 对应资源包部分也移除了 minecraft:map_color 着色源，详见资源包章节

战利品函数

minecraft:exploration_map 改动

  • 移除了 map_color 字段
  • 该函数不再修改作用物品的类型，仅向现有物品附加地图数据
    • 旧版本需要传入 minecraft:map，输出 minecraft:filled_map
    • 生成何种物品现在由战利品条目或村民交易自行决定；制作探险家地图的数据包需要将物品从 minecraft:map 修改为 minecraft:filled_map（或对应探险家地图物品）
    • 若未找到匹配的结构，物品不会附带 minecraft:map_id。原版战利品表与村民交易使用 minecraft:filtered 搭配 minecraft:discard_item 将这类无效物品丢弃，你的数据包也应照此处理

密度函数

  • 密度函数与噪声不再使用双精度浮点数运算，改为单精度浮点数
    • 该改动影响全部中间计算步骤，不只是最终结果

开发者注：我们了解部分数据包利用了浮点数舍入细节，本次改动可能会影响部分配置。针对我们已知的场景，我们已经提供替代实现。如果你遇到无法继续实现的场景，欢迎前往 feedback.minecraft.net 或者反馈 Discord 服务器 discord.com/invite/minecraftfeedback 向我们反馈。
