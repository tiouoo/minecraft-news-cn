Minecraft 1.21.4 的第一个预发布版现已推出。今天的更新以及 1.21.4 周期的其余部分，你将主要看到错误修复和调整。此外，预发布版不遵循常规快照仅在星期三发布的节奏，所以请留意下一个预发布版。

一如既往，非常感谢社区在快照系列中提供的反馈、报告的错误和绝妙的想法。预发布版开始啦！

技术更改

  • 资源包版本现在为 46
  • 与方块物品类似，可执行仅限管理员命令的实体的刷怪蛋现在会在提示文本中显示警告

资源包版本 46

  • 新增了一种方法，可在特定模型切换物品时抑制第一人称手臂动画
  • Unifont 已更新至 16.0.01

物品模型

  • 客户端物品信息格式（即 /assets/*/items/*.json 文件）中添加了一个新字段
    • hand_animation_on_swap - 布尔字段，描述当物品堆叠发生变化（无论是类型、数量还是组件）时，是否应在第一人称视角下播放落下并抬起的动画，默认值：true
      • 仅考虑新物品的值
      • 不控制 GUI 中拾取物品或数量变化时的“弹出”动画

minecraft:model 物品模型类型

新增 minecraft:team 色调来源类型

  • 返回上下文实体所属队伍的队伍颜色（如果存在）
  • 字段：
    • default - 当没有上下文实体、实体不在队伍中或队伍没有颜色时返回的 RGB 值

更改了 minecraft:head 特殊模型类型

  • 新增字段 animation - 控制头部动画（如猪灵耳朵或末影龙下颌）的浮点数，默认值：0.0

新增 minecraft:view_entity 布尔属性

  • 未处于旁观模式时，如果上下文实体是本地玩家实体（即由客户端控制的实体），则返回 true
  • 旁观模式下，如果上下文实体是被旁观的实体，则返回 true
  • 如果上下文实体不存在，则返回 false
  • 无字段

将属性 minecraft:holder_type 重命名为 minecraft:context_entity_type

开发者注：上下文实体最初仅用于指南针和时钟，这意味着该类型仅在那些物品能够显示正确读数的渲染上下文中可用（参见 MC-186797 及相关错误）。重命名是为了更好地反映这一点。

新增 minecraft:context_dimension 属性

  • 返回上下文中的维度 ID（如果存在）
  • 无字段
  • 值：带命名空间的维度 ID（如 minecraft:overworld）

更改了 minecraft:time 数值属性

  • 移除了字段 natural_only
  • 新增字段 source - 时间来源，可能的值：
    • daytime - 一天中的时间
    • moon_phase - 月相
    • random - 随机值

更改了 minecraft:compass 数值属性

  • 为字段 target 添加了值 none，该值始终返回无效目标

新增 minecraft:empty 物品模型类型

  • 不渲染任何内容
  • 无字段
