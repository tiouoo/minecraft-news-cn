大家好！这个技术性很强的快照包含了振动机制变更、数据包与资源包更改、一些网络优化、新的调试工具，以及一些错误修复。玩得开心！

更改

  • 振动机制变更

振动

  • 振动不再会因模拟距离限制而丢失
  • 卸下物品会发出频率为 4 的新的 unequip 振动
  • 雕纹书架从漏斗接收书时会发出频率为 11 的 block_change 振动
  • 海龟蛋开裂时会发出频率为 11 的 block_change 振动
  • 海龟蛋孵化时会发出频率为 12 的 block_destroy 振动
  • 使用骨粉会发出频率为 3 的 item_interact_finish 振动
  • 火被水瓶扑灭时会发出频率为 12 的 block_destroy 振动
  • 唤魔者召唤恼鬼或尖牙时会发出频率为 14 的 entity_place 振动
  • 兔子吃胡萝卜时会发出频率为 11 的 block_change 振动
  • 狐狸吃甜浆果时会发出频率为 11 的 block_change 振动
  • 骆驼吃仙人掌时会发出频率为 8 的 eat 振动

技术性更改

  • 资源包版本现在为 17
  • 上个快照随附的 slicer 工具中，一个涉及饥饿值图标的错误已被修复。这里是新版本
  • 数据包版本现在为 17
  • 优化了网络传输，以改善低带宽连接下的体验

资源包版本 17

  • 文本框背景现在是位于 widget/text_field 和 widget/text_field_highlighted 的九宫格切片精灵图
  • 列表和文本框中的滚动条现在是位于 widget/scroller 的九宫格切片精灵图

数据包版本 17

  • 更改了物品、实体和方块实体上状态效果的存储方式

状态效果存储更改

  • 游戏在将状态效果存储到世界中时不再使用数值（例如，4 会变成 minecraft:mining_fatigue）
  • 各种状态效果字段已重命名，以与新结构保持一致

状态效果实例

此结构在许多地方使用，因此单独描述其更改。

  • Id -> id，并且从数字 ID 改为字符串 ID
  • Ambient -> ambient
  • Amplifier -> amplifier
  • Duration -> duration
  • ShowParticles -> show_particles
  • ShowIcon -> show_icon
  • HiddenEffect -> hidden_effect，同时因为它本身是状态效果实例，所以更改会递归应用
  • FactorCalculationData -> factor_calculation_data

物品

potion, lingering_potion, splash_potion, tipped_arrow
  • CustomPotionEffects -> custom_potion_effects，内容转换为状态效果实例列表
suspicous_stew
  • Effects -> effects，对于每个条目：
    • EffectId -> id，并且从数字 ID 改为字符串 ID
    • EffectDuration -> duration

实体

mooshroom
  • 移除了 EffectId 和 EffectDuration
  • 添加了 stew_effects，其格式与 suspicious_stew.effects 标签相同（即效果 ID 和持续时间的列表）
area_effect_cloud
  • Effects -> effects，内容转换为状态效果实例列表
arrow
  • CustomPotionEffects -> custom_potion_effects，内容转换为状态效果实例列表
玩家、盔甲架和生物
  • ActiveEffects -> active_effects，内容转换为状态效果实例列表

方块实体

beacon
  • Primary -> primary_effect，并且从数字 ID 改为字符串 ID
  • Secondary -> secondary_effect，并且从数字 ID 改为字符串 ID

战利品表

  • 添加了 sequence 战利品函数
    • 包含 1 个字段：
      • functions：按顺序运行的子函数数组
    • 也可以声明为不带类型的内联数组
      • 这与现有的行为一致，即战利品函数 JSON 文件可以声明为复合函数数组
  • 战利品表中的 all_of 谓词现在可以隐式声明为一个不带类型的内联数组
    • 这也与现有的行为类似，即战利品谓词 JSON 文件可以声明为子谓词数组

网络优化

  • 游戏数据包现在被打包进更大的 TCP 数据包中，以减少 TCP 标头带来的开销，显著降低网络使用量
  • 按 CTRL + F3 打开调试屏幕时，现在会显示 ping 和接收网络流量的图表

安全聊天

  • 客户端在收到无效的聊天消息时不再自行断开连接
    • 而是会在聊天中显示一条占位消息
