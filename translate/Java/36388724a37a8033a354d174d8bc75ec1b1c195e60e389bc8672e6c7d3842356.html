我们为您带来了 1.21 的第一个预发布版，包含可拴绳的船、可穿过传送门的末影珍珠以及错误修复！

在此快照中，我们暂时移除了使用火焰附加魔咒点燃方块的功能，因为我们想进一步优化它。此功能将在后续版本中重新加入。

传送愉快！ ;)

新内容

不祥试炼刷怪笼

  • 当试炼刷怪笼转换为不祥状态时，被其移除的生物现在会掉落它们之前从地面捡起的任何物品

更改

  • 重锤的攻击速度已改为 0.6
  • 不同材料的门现在可以组成双开门
  • 通过传送门投掷的末影珍珠现在可以将玩家传送到与当前所在维度不同的维度
  • 现在可以骑乘实体（如马或矿车）穿过传送门
    • 骑乘实体穿过传送门时，传送前的延迟不会生效

技术性更改

  • 数据包版本现在为 46
  • 移除了上个快照中引入的 entitiesWithPassengersCanUsePortals 游戏规则。实体带乘客使用传送门现在是默认行为。
  • 报表数据生成器现在包含关于网络数据包的信息
  • 游戏现在会将加载和保存失败区块的报表存储在 debug 目录中

服务器链接

  • 有一些通用用途的链接名称，如“支持”或“网站”，没有任何特殊功能

数据包版本 42 到 46

  • 为拼图结构和 single_pool_element 类型添加了新的可配置字段

魔咒

基于等级的值

lookup

一种基于等级的值类型，将值列表映射到特定等级，并在等级大于提供的值的数量时应用后备值。字段：

  • values - 按 level - 1 索引的值列表，如果存在则应用
  • fallback - 一个后备的基于等级的值，当等级大于 values 的大小时应用

效果条件

与战利品表不同，所有效果条件必须是内联对象，不能是引用。

标签

方块标签

  • fire_aspect_lightable 已被移除
    • 在此快照中，我们暂时移除了使用火焰附加魔咒点燃方块的功能，因为我们想进一步优化它。此功能将在后续版本中重新加入。

战利品表

条件

random_chance_with_enchanted_bonus

  • chance: 字段已被移除
  • unenchanted_chance: 未附魔物品几率的新字段
  • enchanted_chance: 附魔物品几率的新字段 - 一个基于等级的值

结构

  • 为 minecraft:jigsaw 类型的结构添加了 liquid_settings 字段。可能的值：
    • apply_waterlogging: 如果任何可含水方块与现有水重叠，它将变为含水状态
    • ignore_waterlogging: 不会使与现有水重叠的任何可含水方块含水
    • 默认值为 apply_waterlogging
  • 为 single_pool_element 元素类型添加了可选字段 override_liquid_settings
    • 与拼图结构中 liquid_settings 的可能值相同
    • 在此池元素生成时，覆盖从父级拼图结构继承的液体设置
