今天我们发布了 26.2 快照 8！OpenGL 现在是默认选项，而 Vulkan 则进入实验性领域。你还会发现硫磺洞穴和硫磺立方体的更新，以及床现在比以前更有弹性了！

尽情弹跳吧！

新特性

硫磺洞穴生物群系

  • 如果暴露在地表，该生物群系将以上下硫磺洞穴生物群系的全部特征生成

硫磺立方体生物

  • 内部包含方块的硫磺立方体现在对岩浆块的伤害免疫，也免疫于其他包含岩浆块的硫磺立方体造成的伤害

更改

  • 游戏现在默认使用 OpenGL 图形 API
  • 床现在稍微更有弹性，与基岩版保持一致

更改了“图形 API”视频设置

  • “Vulkan”现在被标记为“实验性”
    • 如果你愿意，仍然可以使用它，它在大多数常见系统上运行良好，但在某些其他系统上可能会降低性能或导致不稳定
  • “默认”选项现在将在底层使用 OpenGL
  • 该设置将为所有玩家重置为“默认”

UI 精灵图

  • 添加了 friends/background_dark — friends/background 面板精灵图的更深色变体，用作好友 UI 中确认对话框的背景

技术性更改

  • 数据包版本现在为 106.0

伤害类型

  • 添加了新的 minecraft:sulfur_cube_hot 伤害类型

数据包版本 106.0

命令

发布

  • 现在 publish 命令的第一个参数需要一个额外的布尔值，以指定服务器是对在线多人游戏开放，还是仅对本地多人游戏开放
    • 默认值：true（在线多人游戏）

取消发布

  • 添加了 unpublish 命令，如果存在集成服务器，则取消发布该服务器
