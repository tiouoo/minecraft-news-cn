水域更新日志

常规

  • 所有亡灵生物现在都会下沉
  • 改变了水下视野
    • 你待在水下的时间越长，视野会逐渐提升
  • 全面重做了世界生成
  • 全面重做了命令解析器
  • 新增世界类型“自助式”
    • 允许你创建包含独特生物群系的世界
    • 自助式世界类型将在后续更新中获得更多功能
  • 新增了大量新音效
  • 新增了三首新音乐
  • 新增了水下环境音效
  • 新增了游泳动画
    • 在水下按下疾跑键即可开始游泳
  • 新增了数据包
    • 允许你编辑配方、标签、战利品表、函数和进度
  • 新增了新的进度
  • 部分方块现在可以含水
    • 对方块使用水桶可让水环绕其间
  • 新增“优化世界”按钮（单人游戏 → 编辑世界 → 优化世界），可将整个世界从旧版本一次性升级至最新版本

方块

  • 新增蓝冰
    • 可在冰山上找到
  • 新增珊瑚块
  • 新增珊瑚扇
  • 新增珊瑚
  • 新增潮涌核心
    • 将1个海洋之心与8个鹦鹉螺壳合成潮涌核心
    • 让你在水下的生活轻松许多
  • 新增干海带块
    • 用9个干海带合成一个干海带块
  • 新增海带和海草
  • 普通南瓜不再有脸
  • 新增雕刻南瓜
    • 用剪刀对着南瓜使用即可雕刻
  • 新增海泡菜
  • 新增气泡柱
    • 使用岩浆块或灵魂沙可生成气泡柱
  • 新增木头方块
    • 用任意4个原木合成一个木头方块
  • 新增去皮木头
    • 手持斧头并右键点击原木或木头可得到去皮木头
  • 新增海晶石楼梯和台阶
  • 为全部6种木材的压力板、活板门和按钮添加了变种
  • 新增海龟蛋
    • 务必保护它们免受敌对生物破坏

生物

  • 新增热带鱼
  • 新增海龟
    • 一种在沙滩上产蛋的友好生物
  • 新增海豚
    • 一种中立生物，喂它鱼会带你找到宝藏
    • 千万不要攻击它们，除非你想被一整群海豚追赶
  • 新增溺尸
    • 可在海洋和河流中自然生成的敌对生物
    • 生成时可能携带三叉戟
    • 僵尸在水下待太久会变成溺尸
  • 新增幻翼
    • 若不想被它们俯冲袭击，就好好睡一觉
    • 掉落幻翼膜
  • 新增鳕鱼、鲑鱼和河豚生物
  • 修改了马的模型，使其与其他生物更加一致
  • 移除Herobrine

物品

  • 新增三叉戟
    • Minecraft中最新的武器
    • 由溺尸掉落
    • 既可作为近战武器，也可作为远程武器
  • 新增三叉戟附魔
  • 新增用水桶捕获鱼的能力
  • 新增地图标记
    • 手持地图并右键点击旗帜，即可创建标记
  • 新增海洋之心
    • 可在埋藏的宝藏中找到
  • 新增鹦鹉螺壳
    • 由溺尸掉落，也可通过钓鱼获得
  • 新增幻翼膜
    • 由幻翼掉落，可用于修复鞘翅，也用于酿造缓降药水
  • 新增鳞甲
    • 小海龟长大时掉落
  • 新增神龟药水
    • 给予缓慢 IV 和抗性提升 III
  • 新增缓降药水
  • 新增干海带
  • 为所有新增生物添加了刷怪蛋

生物群系

  • 新增多种海洋生物群系
  • 新增珊瑚礁
  • 新增水下洞穴
  • 新增水下峡谷

结构

  • 新增沉船
  • 新增海底废墟
  • 新增冰山
