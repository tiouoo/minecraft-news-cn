数据包版本 103.0

属性

新增 minecraft:nameplate_distance

  • 控制实体的名称标签在多远的距离内可见（以方块为单位）
  • 如果实体不可见，则名称标签也不可见
  • 接受介于 0.0 和 512.0 之间的值
  • 默认值：64.0

新增 minecraft:below_name_distance

  • 控制 below_name 记分板显示在多远的距离内可见（以方块为单位）
  • 如果实体不可见，则名称标签也不可见
  • 接受介于 0.0 和 512.0 之间的值
  • 默认值：10.0

遥测

新增必需事件

  • graphics_capabilities
    • 这是一个在启动时发送的新事件，它告诉我们在玩游戏时所用图形设备的能力
    • 新增属性：backend_name
      • 它将为 Vulkan 或 OpenGL，有助于我们了解玩家使用的是哪种图形 API
    • 新增属性：backend_failure_reason
      • 这将是一组简短错误代码的列表，例如 vulkan_device_version_too_low，有助于我们识别与既定 Vulkan 要求相关的任何问题
    • 新增属性：backend_failure_message
      • 这将是一条简短且笼统的消息，例如 Failed to find the GLFW platform surface extensions，如果玩家在使用 Vulkan 运行时遇到问题，这将有助于我们缩小问题范围
    • 新增属性：backend_failure_missing_capabilities
      • 这将是从 Vulkan 缺失的能力列表，例如 VULKAN_CORE_1_2, VK_KHR_dynamic_rendering，有助于我们了解玩家使用 Vulkan 所需的能力
