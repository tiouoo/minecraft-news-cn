这是 2025 年的首个快照星期三，我们带来了一些有趣的新功能来开启新的一年。本快照为游戏添加了新的环境特性，包括野花、落叶层和飘落的树叶。猪获得了两种新变种：你可以前往较冷的生物群系寻找冷猪，或者前往阳光充足的地方遇到它的对应变种——暖猪！磁石也变得更容易制作，使它们在游戏早期更容易获得。现在你只需要一个铁锭和你的錾制石砖。

新特性

  • 为树叶方块添加了新的飘落树叶粒子
  • 为猪添加了冷和暖变种
  • 添加了野花方块
  • 添加了落叶层方块

树叶方块粒子

  • 所有树叶方块现在都有机会生成飘落的树叶粒子
  • 受此更改影响的方块有：
    • 橡树树叶
    • 丛林树叶
    • 金合欢树叶
    • 深色橡树树叶
    • 云杉树叶
    • 红树林树叶
    • 白桦树叶
    • 杜鹃树叶
    • 盛开的杜鹃树叶

猪变种

  • 添加了新的猪变种，变种由其生成的生物群系决定
  • 温带猪——我们都熟悉的猪
    • 默认在冷猪和暖猪变种不生成的生物群系中生成
  • 冷猪——在以下生物群系中生成的变种：
    • 原始松木针叶林
    • 原始云杉针叶林
    • 针叶林
    • 积雪的针叶林
    • 风袭丘陵
    • 风袭砾质丘陵
    • 风袭森林
  • 暖猪——在以下生物群系中生成的变种：
    • 热带草原
    • 热带高原
    • 风袭热带草原
    • 丛林
    • 稀疏丛林
    • 竹林
    • 被侵蚀的恶地
    • 繁茂的恶地
    • 恶地
  • 当由玩家繁殖时，小猪的变种不会由当前生物群系决定，而是从父母变种中随机选择一个

野花

  • 野花是一种新类型的花朵，生长在白桦森林、原始白桦森林和草甸中
  • 野花在一个方块空间内可以有不同数量的花朵
    • 同一个方块空间内最多可放置四朵野花
    • 将野花放入已放置的野花方块中会增加花朵数量
    • 对野花使用骨粉会产生更多野花
  • 野花可以朝四个方向放置
  • 野花可以合成黄色染料

落叶层

  • 落叶层是一种新类型的装饰性方块，可以在森林、黑森林和繁茂的恶地中找到
  • 落叶层在一个方块空间内可以有不同数量的落叶
    • 同一个方块空间内最多可放置四片落叶层
    • 将落叶层放入已放置的落叶层方块中会增加落叶数量
  • 落叶层可以朝四个方向放置
  • 落叶层可以通过熔炼任何类型的树叶方块获得
  • 落叶层可以用作熔炼燃料
  • 落叶层有独特的方块音效

更改

  • 磁石有了新的合成配方，现在可以在废弃传送门中找到
  • 为铁块、铁栏杆、铁活板门、铁门和重型测重压力板添加了新的破坏、放置、脚步、坠落和敲击音效
  • 僵尸猪灵现在需要由玩家杀死才能掉落玩家专属战利品
    • 这使它们与游戏中所有其他生物保持一致
  • 由传送门加载的区块现在会在世界重新打开时自动再次加载
  • 农场动物现在可以在恶地生成
  • 短草现在在草甸中生成得稍微稀疏一些
  • 讲述者的音量现在会受到‘语音’类别中游戏配置音量的影响
  • 将世界上传到 Realms 现在会默认启用命令方块
  • 现在可以将硬核单人世界上传到 Realms
  • 气泡柱在不受其影响的实体处于其中时产生的粒子和声音更少
  • 如果游戏检测到上次启动未正常完成，现在会重置全屏选项

花园觉醒更改

  • 苍白花园生物群系现在占据了更多原本属于黑森林的空间
  • 林地府邸现在可以在苍白花园生物群系中生成
  • 苍白橡树树叶和苍白橡树树苗的地图颜色已更新
  • 吱吱怪现在可以使用命名牌命名
    • 被命名的吱吱怪会持续存在到白天
      • 但是，如果它与玩家卡在一起，或者离它的心脏太远，它仍然会被拆毁
    • 被命名的吱吱怪仍然对所有伤害免疫，并且可以通过粒子与它们的心脏交流
  • 正确放置于原木之间的吱吱怪心脏在白天有新的休眠纹理
    • 休眠中的吱吱怪心脏无法生成新的吱吱怪和树脂
  • 吱吱怪心脏在苏醒和休眠状态之间的转换，以及眼之花的转换，现在基于固定的白天时间
    • 所有这些行为不再受天气或维度亮度影响

磁石更改

  • 磁石现在由 1 个铁锭周围环绕 8 个錾制石砖合成
  • 磁石现在可以作为战利品在主世界或下界的废弃传送门中找到

技术更改

  • 数据包版本现在为 62
  • 资源包版本现在为 47

数据包版本 62

  • 对命令的更改
  • 更新了文本组件的数据格式
  • load 模式下的 structure_block 现在有了一个新选项：Strict Placement
    • 如果设置为 false，放置结构中的方块将不会触发方块更新、方块实体副作用或形状更新
  • 驯服动物的 Owner 字段不再局限于引用玩家
  • 更新了实体数据中装备掉落几率的数据格式
  • 为猪变种添加了数据驱动的注册表
  • 添加了用于匹配猪变种的 pig 实体子谓词

命令

  • 诸如 /tellraw 或 /title 等命令中的文本组件现在使用 SNBT 而不是 JSON 指定
  • 在 /scoreboard 命令中指定 styled 数字格式时的文本样式现在也使用 SNBT 而不是 JSON 指定
  • setblock 和 fill 命令在处理方块实体数据时的行为发生了变化：
    • 如果未指定方块实体数据，并且现有方块有数据，则保留方块实体数据
    • 如果指定了方块实体数据，则将方块实体数据设置为指定值
    • 要显式清除方块实体数据，现在必须将方块实体数据指定为 {}
    • 现在，只要方块状态发生变化或方块实体数据发生变化，操作就会成功
  • fill、clone、setblock 和 place template 接受一个新选项：strict
    • 如果指定，命令将按原样放置方块，而不触发方块更新和形状更新
  • fill 命令中的 replace 选项不再是终结选项，后面可以跟其他选项
  • 命令使用新 strict 选项的新语法，以及更灵活地使用 replace：
    • fill <from> <to> <block> keep
    • fill <from> <to> <block> [replace <filter>]? [strict|destroy|hollow|outline]?
    • clone [from <sourceDimension>]? <begin> <end> [to <targetDimension>]? <destination> [strict]? [[replace|masked|filtered <filter>] [force|move|normal]?]?
    • setblock <pos> <block> [destroy|keep|replace|strict]?
    • place template <template> [<pos> [<rotation> [<mirror> [<integrity> [<seed> [strict]?]?]?]?]?]?

文本组件数据格式

  • 文本组件不再存储为字符串包装的 JSON
  • 格式本身与之前相同，但直接内联到外层结构中
  • 例如，物品组件 minecraft:custom_name="{\"text\":\"Renamed item\"}" 将变为 minecraft:custom_name={text:'Renamed item'}
  • 这包括作为参数传递给诸如 /tellraw 或 /title 等命令的文本组件
    • 例如，/tellraw @s "\"text\":\"Hello world\"" 可能变为 /tellraw @s {text:'Hello world'}
  • 注意：在文本组件嵌入 NBT 的情况下，布尔类型和整数类型之间没有区别
    • 要向翻译传递布尔参数，必须使用字符串形式
  • 对于具有 nbt 类型且 interpret 设置为 true 的文本组件，将直接从给定的 NBT 解析文本组件，而不是转换为字符串并作为 JSON 解析
  • 悬停事件和点击事件的格式已更新

悬停事件

  • hoverEvent 字段已重命名为 hover_event
  • 不再支持旧的 value 字段（该字段从渲染的文本组件中解析）
  • 对于 show_text 操作：
    • contents 字段已重命名为 text
    • 例如，{action:'show_text',contents:'Hello world'} 变为 {action:'show_text',text:'Hello world'}
  • 对于 show_item 操作：
    • contents 字段已内联
    • 例如，{action:'show_item',contents:{id:'minecraft:stick',count:2}} 变为 {action:'show_item',id:'minecraft:stick',count:2}
    • 如果 contents 仅指定为物品 ID，则替换为完整格式并内联
    • 例如，{action:'show_item',contents:'minecraft:stick'} 变为 {action:'show_item',id:'minecraft:stick'}
  • 对于 show_entity 操作：
    • contents 字段已内联
    • id 字段已重命名为 uuid
    • type 字段已重命名为 id
    • 例如，{action:'show_entity',contents:{id:[I;0,0,0,0],type:'minecraft:pig'}} 变为 {action:'show_entity',uuid:[I;0,0,0,0],id:'minecraft:pig'}

点击事件

  • clickEvent 字段已重命名为 click_event
  • 对于 open_url 操作：
    • value 字段已重命名为 url
    • 如果点击事件不是具有 https:// 或 http:// 方案的有效 URI，则不再解析，而不是仅仅不工作
    • 例如，{action:'open_url',value:'https://minecraft.net'} 变为 {action:'open_url',url:'https://minecraft.net'}
  • 对于 run_command 操作：
    • value 字段已重命名为 command
    • 如果命令包含不允许的字符，则点击事件不再解析，而不是仅仅不工作
    • 不再要求指定的 command 字段具有 / 前缀
    • 例如，{action:'run_command',value:'/say Hi'} 变为 {action:'run_command',command:'/say Hi'}
  • 对于 suggest_command 操作：
    • value 字段已重命名为 command
    • 如果命令包含不允许的字符，则点击事件不再解析，而不是仅仅不工作
    • 例如，{action:'suggest_command',value:'/help'} 变为 {action:'suggest_command',command:'/help'}
  • 对于 change_page 操作：
    • value 字段已重命名为 page
    • page 值现在要求是正整数而不是字符串
    • 例如，{action:'change_page',value:'1'} 变为 {action:'change_page',page:1}
  • copy_to_clipboard 格式不变

标签

方块标签

  • 添加了 #replaceable_by_mushrooms - 蘑菇放置或生长时可替换的所有方块的详尽列表

实体数据

  • ArmorDropChances、HandDropChances 和 body_armor_drop_chance 字段已合并到一个 drop_chances 字段中
    • 格式：装备槽类型和几率值之间的映射
      • 有效的装备槽：head、chest、legs、feet、mainhand、offhand、body
      • 如果未指定或移除，几率将采用默认值（0.085f）
      • 例如，drop_chances:{chest:0.1,feet:1.0}
    • 具有默认值的掉落几率将不再存储，如果全部为默认值，则完全移除 drop_chances 字段
  • 区域效果云有一个新字段：potion_duration_scale（浮点数）
    • 如果未指定，默认为 1.0
    • 应用的药水效果持续时间按此因子缩放
    • 由滞留药水创建的区域效果云的缩放系数为 0.25

猪变种

  • 猪变种可以通过向 data/<namespace>/pig_variant/<id>.json 添加条目来实现数据驱动
  • 此功能是实验性的
  • 文件中的字段：
    • model - 以下之一：normal、cold
    • texture - 此变种的纹理 ID，解析为 assets/<namespace>/textures/<path>.png
    • biome - 描述此变种自然生成的生物群系的单个条目、列表或标签
      • 如果未指定，则仅在没有任何其他变种匹配当前生物群系时才会选择此变种

配方

crafting_transmute 配方类型

  • result 字段现在支持指定数量和应用到结果的组件修补
  • 组件修补应用于最终转化的物品
  • 新格式是包含以下字段的对象：
    • id - 物品 ID
    • count - 正整数（默认：1）
    • components - 组件修补对象（默认：空）
    • 例如，"result": {"id": "minecraft:stick", "count": 3, "components": {"!minecraft:damage": {}, "minecraft:enchantment_glint_override": {}}}
  • 该字段仍可以像以前一样定义为内联物品 ID（例如 "result": "minecraft:stick"）

物品组件

新的 weapon 组件

  • 存在时，每次使用该物品攻击都会增加‘物品使用’统计
  • 每次攻击都可以对物品造成指定量的伤害
  • 格式：包含以下字段的对象：
    • damage_per_attack - 非负整数（默认：1）
      • 每次攻击对武器造成的伤害量
    • can_disable_blocking - 布尔值（默认：false）
      • 如果为 true，成功攻击将使格挡的盾牌失效
    • 例如，weapon={damage_per_attack:2}

新的 potion_duration_scale 组件

  • 存在时，对于具有 potion_contents 组件的物品，应用效果持续时间将按此因子缩放
  • 这也适用于 potion_contents 组件中的 custom_effects，不像以前硬编码的缩放因子
  • 如果未指定，默认为 1.0
  • 格式：非负浮点数
    • 例如，potion_duration_scale=0.25

tool 组件

  • 添加了新的可选字段：can_destroy_blocks_in_creative（布尔值）
    • 如果为 false，玩家在创造模式中手持此工具时无法破坏方块
    • 如果未指定，默认为 true
