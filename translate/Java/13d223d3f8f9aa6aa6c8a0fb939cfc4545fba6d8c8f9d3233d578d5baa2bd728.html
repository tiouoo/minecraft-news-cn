今天我们发布了 Java 版 26.1 的第一个预发布版，即 Tiny Takeover 游戏更新！从现在开始，你应该会看到大部分内容都是漏洞修复。此外，预发布版不会遵循常规的快照周二发布节奏，所以请密切关注下一个预发布版。

更改

  • 更新了主菜单背景全景图

技术性更改

  • 数据包版本现在为 101
  • 资源包版本现在为 84
  • 对 minecraft:nbt 文本组件格式进行了更改
  • 对 minecraft:selector、minecraft:nbt 和 minecraft:object 文本组件格式进行了更改

数据包版本 101

  • “默认组件”报告生成器不再为没有任何组件的条目输出文件

命令

对 time 的更改

语法：

  • time [of <clock>] rate <rate> - 设置时钟应前进的速率倍率
    • 注意：这只会改变世界时钟（World Clock）及任何依赖它的时间线推进其内部计时器的速率
      • 例如，对于 minecraft:overworld 时钟，值越大，昼夜循环就会越快，但实际游戏模拟不会加速（就像使用 /tick rate 那样）
    • rate 为 1 时对应正常速度
    • rate 是一个介于 0（不含）和 1000（含）之间的浮点数

数据组件

修改了 minecraft:provides_banner_patterns

  • 该组件现在除了标签（tag）之外，还接受 ID 或 ID 列表

修改了 minecraft:blocks_attacks

  • 字段 bypassed_by 现在除了标签之外，还接受 ID 或 ID 列表

修改了 minecraft:damage_resistant

  • 字段 types 现在除了标签之外，还接受 ID 或 ID 列表

战利品函数

更改了 minecraft:set_instrument

  • options 字段现在除了标签之外，还接受 ID 和 ID 列表

谓词

新增 minecraft:environment_attribute_check 战利品谓词

精确匹配给定位置的环境属性值。注意：只要环境属性会随位置变化，此谓词就需要一个设置了 origin 位置的上下文。

格式：包含以下字段的对象：

  • attribute - 要测试的环境属性 ID
  • value - 要匹配的环境属性的精确值
  • 例如：{condition: 'environment_attribute_check', attribute: 'gameplay/piglins_zombify', value: true}

数字提供器

新增 minecraft:environment_attribute

获取并提供环境属性的值（该值可以表示为数字）。注意：只要环境属性会随位置变化，此提供器就需要一个设置了 origin 位置的上下文。

格式：包含以下字段的对象：

  • attribute - 要获取的环境属性 ID
  • 例如：{type: 'environment_attribute', attribute: 'gameplay/sky_light_level'}

世界生成

花朵地物

  • 由骨粉生成的地物不再局限于 flower 地物类型，而是由 #can_spawn_from_bone_meal 已配置地物标签控制
  • 已移除 flower、flower_no_bonemeal 和 random_patch 地物类型
    • 取而代之，斑块可以通过 count 和 random_offset 放置修饰符的序列来表示

整数提供器

新增 trapezoid 整数提供器

选择一个具有梯形分布的随机值，类似于 trapezoid 浮点提供器。

格式：包含以下字段的对象：

  • min：整数，要生成的最小值
  • max：整数，要生成的最大值
  • plateau：整数，分布“平台”的宽度，在此范围内所有值出现的概率相等
    • 值为 0 时等同于三角形分布
    • 值为 max-min 时等同于均匀分布

标签

已配置地物标签

  • 新增 #can_spawn_from_bone_meal - 添加到生物群系后，在该生物群系中使用骨粉时可以生成的地物

文本组件

`minecraft:object

  • 新增了一个名为 fallback 的可选字段，其中包含一个文本组件，当对象组件本身无法显示时使用（例如在服务器日志中打印消息或进行旁白时）
  • 类型为 player 的对象（玩家头颅）不再能用于服务器状态消息（MotD）
    • 该类型的所有组件都将被回退文本替换

资源包版本 84

  • 更新了 Pup 的纹理以修复纹理重叠的问题

物品模型

minecraft:end_cube 特殊模型类型

  • 新的特殊模型类型，渲染一个立方体，其纹理效果与末地传送门和末地折跃门方块相同
  • 字段：
    • effect - 要应用的纹理效果，可选值：portal、gateway

方块状态渲染

  • 末地折跃门和末地传送门在方块显示实体上渲染时，现在应与放置在世界中时的外观一致

着色器 & 后期处理效果

  • 已移除 core/rendertype_translucent_moving_block 着色器，以 core/block 替代
