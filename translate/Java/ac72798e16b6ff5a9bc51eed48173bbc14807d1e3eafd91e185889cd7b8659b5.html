又是一个星期二，又是一个快照！本周的发布带来了一些实用的新粒子，用于更好地判断你的金蒲公英是在让生物保持幼年状态，还是即将将成长的概念重新引入它们的方块生活。我们还缩小了幼年僵尸类生物的头，并像往常一样修复了一系列漏洞。

挖矿愉快！

更改

  • 修复了嗅探幼兽纹理中的像素间隙
  • 修复了幼年炽足兽的鬃毛没有动画的问题
  • 炽足兽现在会正确继承其所站炽足兽的温度，与基岩版一致
  • 缩小了以下幼年生物模型的头部尺寸：
    • 僵尸
    • 尸壳
    • 溺尸
  • 金蒲公英现在根据用于开始或停止成长而显示不同的粒子效果
    • 当成长停止时，会显示向下移动的绿色粒子
    • 当重新开始成长时，会显示向上移动的绿色粒子
  • 小型盔甲架现在会使用成年盔甲并缩放来正确显示

界面

  • 如果没有打开任何界面，IME 输入将被取消
  • 当文本输入获得焦点时，IME 将打开；当文本输入失去焦点时，IME 将关闭
  • 已添加 sound_cache 调试项

技术性更改

  • 数据包版本现在为 99.3
  • 资源包版本现在为 82

数据包版本 99.3

粒子

  • 新增 pause_mob_growth - 显示在使用金蒲公英停止成长的幼年生物身上的粒子
  • 新增 reset_mob_growth - 显示在使用金蒲公英重置并开始成长的幼年生物身上的粒子

资源包版本 82

  • 更新了幼年僵尸、幼年尸壳和幼年溺尸的纹理，使其头部更小
