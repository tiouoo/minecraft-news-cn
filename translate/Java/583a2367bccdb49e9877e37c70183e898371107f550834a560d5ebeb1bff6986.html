一个炽热如熔岩的热修复。这是 Minecraft 1.21.7，为你的迪斯科带来更新，外加一幅壁画和一些崩溃与 Bug 修复。我们添加了一幅新的 3x3 画作，以致敬大家最好的朋友，并更新了一种标志性生物掉落的战利品。骑鸡的小僵尸（鸡骑士）被击败后会掉落“熔岩鸡”音乐唱片。

我们将在几周后携下一个快照回归。

挖矿愉快！

新特性

  • 添加了一幅名为“乖狗狗”的画作，由艺术家 Sarah Boeving 创作
  • 添加了由 Hyper Potions 创作的音乐唱片“熔岩鸡”
    • 击败骑鸡的小僵尸（鸡骑士）时掉落

技术性更改

  • 数据包版本现已更新至 81
  • 资源包版本现已更新至 64

  • MC-298710 TTF 字形在某些元素上的渲染不正确
  • MC-298818 Java 版中缺少“乖狗狗”画作
