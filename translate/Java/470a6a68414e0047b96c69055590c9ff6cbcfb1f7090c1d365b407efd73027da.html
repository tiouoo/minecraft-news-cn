我们带来了 26.3 的第二个快照！本周新增了一个渲染选项，旨在改善 Minecraft Java 版中的透明度处理。我们还优化了当玩家不在附近时某些生物的移动行为，并做出了一些游戏性调整，包括技术性更改和修复。

祝挖矿愉快！

已知问题

  • 在 Mac 上使用 Vulkan 时，世界将无法渲染，而是显示粉红色屏幕
  • 实体上的光照不正确，例如顶面渲染得过暗

更改

  • 当玩家不在附近时，持久性生物的随机行走/游泳行为将与非持久性生物一样停用
  • 用新的与顺序无关的透明度算法取代了当前的“改进的透明度”方案，预计该算法在解决半透明问题方面会表现得更佳
  • 当同时使用盾牌与锄头或锹时，举起盾牌将优先于耕地和铺设土径

对方块、物品和实体的小调整

  • 如果玩家距离手持三叉戟的溺尸 3 格以内，溺尸将使用近战攻击

与顺序无关的透明度（OIT）

  • 一般来说，半透明表面需要从后到前渲染，以避免视觉问题
    • 为了做到这一点，必须在渲染前对半透明几何体进行排序
    • 这代价非常高，即使对单个三角形进行完美排序，也无法正确渲染相交的三角形
  • 在此快照之前，“改进的透明度”视频设置试图缓解与半透明相关的视觉问题
    • 它通过将不同类型的半透明对象（实体、粒子、水等）渲染到不同的纹理中，再将这些纹理组合成最终图像来实现
    • 这让我们修复了一些问题，但会带来一些性能影响
    • 然而，它引入了其他一些不太明显的问题
  • 现在，“改进的透明度”视频设置将改为启用一个新的与顺序无关的透明度算法（我们将称之为 OIT）
    • 这可以在不排序的情况下按任意顺序渲染半透明对象
    • 它修复了所有现存的与半透明相关的主要视觉问题（例如某些对象透过半透明物体观看时会消失的问题）
    • 然而，该算法是一种近似方法，因此会引入一些新的轻微视觉瑕疵（例如透过多层半透明表面观看时，云的颜色会有些不正确）
  • 我们预计 OIT 的性能影响将高于之前“改进的透明度”的实现
  • 当“改进的透明度”关闭时，游戏行为没有实质性变化，游戏仍将优先考虑性能而非正确性，同时按需对几何体进行排序

新增 minecraft:block_transformer

  • 该组件允许物品在与方块交互时将其转换为另一个方块
  • 格式：对象列表，字段如下：
    • block_state_provider - 方块状态提供器，用于为转换后的方块提供状态
      • 如果方块状态提供器未返回结果（例如，由 rule_based_state_provider 返回），则会尝试列表中的下一条规则
      • 方块状态提供器的集合与世界生成中使用的方块状态提供器相同
    • sound - 可选字段，交互时播放的声音事件，例如 minecraft:item.axe.strip
      • 如果未提供，默认不播放任何声音事件
    • particle - 可选字段，交互时播放的粒子
      • 如果未提供，默认为 none
        • none
        • scrape
        • wax_on
        • wax_off
    • disallowed_faces - 可选字段，指定被点击方块上不能被交互的面（方向）列表
      • 如果交互了被禁止的面，则会尝试列表中的下一条规则
      • 如果未提供，默认为空列表
      • 值：
        • up
        • down
        • north
        • south
        • east
        • west
    • loot - 可选战利品表，用于在成功转换时掉落物品的战利品表，例如 minecraft:till/rooted_dirt
      • 如果未提供，默认不使用战利品表
    • drop_strategy - 可选字段，配置战利品应从方块的哪个位置掉落
      • 如果未提供，默认为 from_middle
      • 值：
        • from_middle - 从方块中心掉落
        • clicked_face - 从交互的面掉落
    • transform_type - 可选字段，配置转换应如何影响附近的方块
      • 如果未提供，默认为 single_block
      • 值：
        • single_block - 仅影响被交互的方块
        • copper_chest - 如果输入和输出方块都是任意风化状态、打蜡或未打蜡的铜箱子，此转换将影响双箱的两侧
    • consume_on_use - 可选布尔值，决定物品是否应被消耗
      • 仅适用于可堆叠物品
      • 如果未提供，默认为 true
    • item_damage_per_use - 可选整数，决定每次使用物品承受的耐久度损失
      • 仅适用于不可堆叠物品
      • 如果未提供，默认为 1

更改了 minecraft:stepped_column_cluster 地物类型

由 minecraft:basalt_columns 重命名而来。现在开放了对地物功能的更多控制。

格式更改：

  • 新增字段 block：方块状态提供器，指定要放置的方块
  • 新增字段 can_replace：方块谓词，指定哪些方块可以被柱体替换
  • 新增字段 continue_through：方块谓词，指定哪些已存在的方块可被接受为柱体的一部分
  • 新增字段 cannot_place_on：方块 ID、方块 ID 列表或以 # 开头的方块标签 ID，表示开始放置时需避开的方块
  • 将字段 reach 重命名为 column_reach
  • 新增字段 column_count：整数提供器（1 到 150 之间）——生成的柱体数量
  • 新增字段 cluster_reach：整数提供器（0 到 13 之间）——尝试生成柱体的正方形范围大小
    • 实际范围也受 height 限制

更改了 minecraft:single_block_pillar 地物类型

由 minecraft:basalt_pillar 重命名而来。现在开放了对地物功能的更多控制。

格式更改：

  • 新增字段 block：方块状态提供器，指定要放置的方块
  • 新增字段 can_replace：方块谓词，指定哪些方块可以被替换
  • 新增字段 direction：柱体的垂直方向——up 或 down 之一
  • 新增字段 chance_to_continue：可选概率，介于 0 和 1 之间（默认：1），表示柱体继续延伸一格的概率（前提是 can_replace 匹配）
  • 新增字段 cap_feature：可选已放置地物，放置在柱体末端

更改了 minecraft:random_neighbor_spread 地物类型

由 minecraft:glowstone_blob 重命名而来。现在开放了对地物的更多控制。以原点为中心在区域内随机放置方块，每次放置都会使该方块恰好拥有一个被接受的邻接方块。

格式更改：

  • 新增字段 block：方块状态提供器，指定要放置的方块
  • 新增字段 accepted_neighbors：方块 ID、方块 ID 列表或以 # 开头的方块标签，指定哪些方块可视为有效邻接方块
  • 新增字段 can_replace：方块谓词，指定哪些方块可以被替换
  • 新增字段 attempts：整数提供器，介于 1 到 3000 之间，指定尝试放置的次数
  • 新增字段 xz_offset：整数提供器，介于 -16 到 16 之间，指定沿 x 和 z 轴尝试的偏移量
  • 新增字段 y_offset：整数提供器，介于 -16 到 16 之间，指定沿 y 轴尝试的偏移量

新增 minecraft:overlay 地物类型

在同一位置放置一组地物。注意，与 minecraft:sequence 地物类型不同，无论单个地物是否成功放置，所有地物都会被放置。

格式：

  • features：已放置地物 ID、非空的已放置地物 ID 列表或以 # 开头的已放置地物标签，用于指定要放置的地物

新增 minecraft:projected_random_patchy_square 地物类型

生成一个正方形，其中每个方块根据其距正方形中心的距离决定是随机放置还是不放置，中心比边缘更有可能生成。当条件满足时，每个放置的方块都可以向下投影。

格式：

  • block：方块状态提供器，指定要放置的方块
  • project_through：方块谓词，指定哪些方块被视为“空”并应被投影穿过
  • size：整数提供器，介于 1 到 16 之间，决定从中心到边缘计算的正方形大小
  • max_projection_height：非负整数，表示正方形中方块从原始高度到放置高度的最大 y 轴变化量

噪声设置

生成目标

spawn_target 字段已更新，现在允许使用任意密度函数，而不仅仅是 noise_router 字段中定义的函数子集。

候选生成位置的适宜性通过在某些任意 n 维空间中求到一组目标超立方体的平方欧几里得距离来确定。

例如，一个轴可能是 temperature，第二个轴是 erosion，适宜性由到 temperature=0.1, erosion=0.2 与 temperature=0.3, erosion=0.5 之间正方形的距离决定。这会同等偏好这些范围内的所有候选生成位置，同时对距离该范围非常远的候选生成位置施加惩罚。

格式：目标超立方体列表

  • 目标格式：密度函数 ID 与该轴上范围之间的映射：
    • 范围指定为以下之一：
      • 浮点数，精确的目标值
      • 由 2 个浮点数组成的数组，表示形式为 [min, max] 的目标值范围
      • 包含字段的对象：
        • min - 浮点数，目标范围的最小值
        • max - 浮点数，目标范围的最大值

着色器与后期处理效果

开发者注：尽管在资源包中覆盖核心着色器是可行的，但这被视为不受支持的行为，并非资源包的预期功能。这些着色器作为游戏内部实现的一部分存在，因此随着游戏内部机制的演变，它们可能随时发生变化。我们理解覆盖核心着色器被用于实现一些非常酷的资源包功能，其中许多缺乏受支持的替代方案。我们希望在将来提供更好、受支持的替代方案。
