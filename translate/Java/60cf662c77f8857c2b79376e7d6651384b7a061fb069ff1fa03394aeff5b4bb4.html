快照星期三快乐！（你不会以为我们已经结束了吧？）今天的快照充满了新特性：向在主世界寒冷和温暖生物群系中漫游的寒冷与温暖牛变体打个招呼，用新的沙漠环境音效款待你的耳朵，并用灌木方块和闪闪发光的萤火虫灌木来美化你的建筑！当然，我们还为你带来了全新的错误修复和技术更新。挖矿愉快！

新特性

  • 为牛添加了寒冷和温暖变体
  • 添加了萤火虫灌木方块
  • 添加了灌木方块
  • 为沙漠和恶地生物群系的环境音效添加了新的环境方块音效

牛变体

  • 添加了新的牛变体，变体由它们生成的生物群系决定
  • 温带变体 - 我们都熟悉的牛
    • 默认生成在寒冷和温暖变体不生成的生物群系中
  • 寒冷变体 - 在以下生物群系中生成的变体：
    • 原始松木针叶林
    • 原始云杉针叶林
    • 针叶林
    • 积雪的针叶林
    • 风袭丘陵
    • 风袭沙砾丘陵
    • 风袭森林
  • 温暖变体 - 在以下生物群系中生成的变体：
    • 热带草原
    • 热带高原
    • 风袭热带草原
    • 丛林
    • 稀疏丛林
    • 竹林
    • 被侵蚀的恶地
    • 繁茂的恶地
    • 恶地
  • 当由玩家繁殖时，幼年牛的变体不会被当前生物群系决定，而是从父母变体中随机选择

萤火虫灌木

  • 萤火虫灌木可在沼泽和河流附近找到
  • 当环境变暗时，发光的萤火虫粒子会出现在萤火虫灌木周围
  • 在萤火虫灌木上使用骨粉会生成另一个萤火虫灌木物品
  • 萤火虫灌木发出光照等级 2

灌木

  • 灌木是一种新的装饰性方块，可在以下生物群系中以小块形式找到：
    • 平原
    • 风袭丘陵
    • 风袭沙砾丘陵
    • 风袭森林
    • 河流
    • 冻河
    • 森林
    • 桦木森林
    • 原始桦木森林
  • 灌木可用于堆肥桶
  • 在灌木上使用骨粉时，如果可能，会在此灌木旁边放置一个相邻的灌木

沙漠和恶地的新环境音效

  • 沙子、红沙和任意颜色的陶瓦，当被其中任一种方块从至少 3 个方向、8 格范围内包围时，有几率播放环境音效
    • block.sand.idle 可在任何生物群系中播放
    • block.sand.wind 仅在沙漠或恶地生物群系中播放
  • 枯萎的灌木方块在任一生物群系中，如果放置在任意颜色的陶瓦、沙子或红沙方块之上，则有几率播放环境音效

更改

  • 温带牛的外观略有更新，增加了突出的口鼻部
  • 信标及其光束现在可以渲染到超过 16 个区块的距离，直到客户端渲染距离
    • 为了在远距离时保持清晰可见，光束会根据距离越远而渲染得越粗
    • 光束现在可渲染至 2048 格高，此前为 1024 格

牛变体

  • 通过向 data/<namespace>/cow_variant/<id>.json 添加条目，牛变体可以实现数据驱动
  • 此功能为实验性功能
  • 文件中的字段：
    • model - 以下之一：normal、cold、warm
    • asset_id - 此变体资源的命名空间 ID，解析为 assets/<namespace>/textures/<path>.png
    • spawn_conditions - 上述统一变体选择中描述的字段

物品组件

blocks_attacks 组件的更改

  • 新增 bypassed_by 字段 - 带 # 的伤害类型标签（可选）
    • 如果指定，格挡将被这些伤害类型绕过
  • damage_reductions 列表中的对象现在有一个新字段：
    • horizontal_blocking_angle - 以正浮点数表示的角度（默认：90）
      • 格挡生效时，玩家面朝方向与来袭攻击之间的最大角度
