世界时钟

世界时钟包含一个每游戏刻都会增加的内部时间。它们可以在数据包中的 world_clock 注册表下定义（即位于 data/<namespace>/world_clock/<id>.json）。

  • 世界时钟可以暂停或恢复，并且可以通过 time 命令更改或查询时钟的时间
  • 格式：无字段的对象

时间轴

  • 新增了一个 clock 字段：一个世界时钟 ID，指定该时间轴绑定到哪个世界时钟
    • 此字段为必填项，但为了匹配之前的行为，可以使用 minecraft:overworld 时钟
  • 新增了一个可选的 time_markers 字段，这是一个可选的映射，将带命名空间的时间标记 ID 映射到整数或时间标记对象，
    • 格式：
      • 非负整数，即时间标记所标记的游戏刻
      • 或者具有以下字段的对象：
        • ticks：介于 0 和 period_ticks 之间的整数，即时间标记所标记的游戏刻
        • show_in_commands：可选的布尔值，指定时间标记是否会出现在命令建议中
          • 默认值：false

时间标记

时间标记为特定世界时钟的某个特定（可重复的）时间点分配一个名称。时间标记取代了之前可由 /time set 使用的预定义名称，例如 day 或 night。

时间标记将在特定世界时钟的上下文中存在。这意味着，即使不同的时间标记由不同的时间轴定义，对于特定的世界时钟，也只能存在一个具有特定 ID 的时间标记。这也意味着两个世界时钟可以拥有同名的时间标记。

时间标记的内置用途

某些时间标记用于驱动原版游戏行为。通常，它们被配置为不出现在 /time 命令中。

  • minecraft:wake_up_from_sleep - 当该维度中的玩家睡醒后，维度默认时钟应推进到的时间
  • minecraft:roll_village_siege - 维度默认时钟上，应评估僵尸村庄围攻事件发生随机几率的时间

命令

对 swing 的更改

  • 两个参数现在都可以省略，并将回退到以下默认值：
    • 如果省略，实体选择器将为 @s
    • 如果省略，挥动的手将为 mainhand

对 time 的更改

  • time 命令现在基于世界时钟
    • 可以选择使用 time of <clock> ... 为 time 命令指定一个时钟作为输入
    • 如果未指定时钟（像之前一样使用 /time ...），则使用该维度的默认时钟
  • set 和 add 子命令的返回值（例如来自 /execute store）现在为时钟的总经过游戏刻数，而不是当前时间

语法：

  • time [of <clock>] set <time> - 设置时钟的总经过游戏刻数
  • time [of <clock>] set <timemarker> - 将时钟推进到时间标记的下一次出现的位置
    • 对于 minecraft:overworld 时钟，可用的时间标记有：day、noon、night 和 midnight
  • time [of <clock>] add <time> - 向时钟添加游戏刻数，可以是负数或正数
  • time [of <clock>] pause - 暂停时钟
  • time [of <clock>] resume - 恢复时钟
  • time [of <clock>] query <timeline> - 显示并返回时间轴周期内的当前游戏刻数
  • time [of <clock>] query <timeline> repetitions - 显示并返回时间轴周期已重复的次数
  • time [of <clock>] query time - 显示并返回时钟的总经过游戏刻数
  • time query gametime - 和之前一样，返回世界内的总经过游戏刻数（不受使用 /time 对时钟所做的更改影响）
