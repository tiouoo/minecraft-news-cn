牵绳在最近的快照中已成为热门物品，本周它们获得了更新的配方，使得制作牵绳更加容易，满足你所有的拴绳需求。干燥恶魂也获得了一个新配方，基于灵魂沙和恶魂之泪。我们将 Unifont 更新至 16.0.03，这次还包含了 Unifont 私人使用区的字形。这意味着创作者现在可以使用 Under-ConScript Unicode Registry 中的文字，如 Tengwar 或 Sitelen Pona。

更改

  • 喷溅药水的效果强度现在基于碰撞箱之间的距离
  • 牵绳配方中的粘液球已被替换为线
  • 猪灵现在可以通过以物易物给予干燥恶魂块
  • 干燥恶魂块的配方已更新，现在需要灵魂沙块而不是骨块

喷溅药水

  • 喷溅药水与受影响实体的距离现在取决于实体碰撞箱与喷溅药水落地位置的碰撞箱之间的最近距离
    • 这意味着如果实体被喷溅药水直接击中，它将获得药水的全部效果
    • 如果实体聚集在一起，它们将获得相同的效果强度

技术性更改

  • 数据包版本现在为 75
  • 资源包版本现在为 59
  • 所有 JSON 文件（在世界、包、配置等中）现在都以严格模式解析

数据包版本 75

实体数据

  • 为所有生物添加了 home_pos 和 home_radius 字段
    • 设置了家园位置的生物将限制其寻路，以保持在指定区域内
    • 有些生物，如蝙蝠、史莱姆、岩浆怪、幻翼和末影龙，可能会忽略它
    • 与牵绳互动或骑乘可能会改变生物的家园位置

实体标签

  • 更新了 #followable_friendly_mobs，将快乐恶魂包含在内

资源包版本 59

  • 将 Unifont 更新至 16.0.03

UI 精灵图

  • 现在，hud/locator_bar_arrow_up 和 hud/locator_bar_arrow_down 精灵图使用相应的 .mcmeta 文件中的标准 animation 定义进行动画化

字体

Unifont

  • 将 Unifont 更新至 16.0.03
  • 添加了先前遗漏的用于私人使用区的 Unifont 字形
    • 这些字形作为单独的子字体 minecraft:include/unifont_pua 加载，不包含在任何常规使用的字体中
    • 这些区域中的字符由 Under-CSUR（Under-ConScript Unicode Registry）管理，该注册表添加了官方 Unicode 集中不存在的各种文字，如 Tengwar 或 Sitelen Pona

unihex 字体提供者

  • 字段 size_overrides 现在是可选的（默认为空列表）
