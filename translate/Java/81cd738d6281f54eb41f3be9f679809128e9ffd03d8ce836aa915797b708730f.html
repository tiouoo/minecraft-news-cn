附魔

附魔现在通过数据设置。附魔是一组核心属性（如等级范围和费用）以及一些效果的集合。大多数效果类型还支持一组条件，从而可以仅在满足特定条件时应用。

附魔可以添加到 enchantment 注册表中。所有原版附魔都可以在客户端和服务端 JAR 文件中的原版数据包中找到。

字段：

  • description：附魔以文本显示时的名称，表示为文本组件
  • exclusive_set：与此附魔互斥的附魔
    • 如果两个附魔中的任意一个在另一个的互斥集中，则二者永远无法同时存在于同一物品上
    • 指定为附魔 ID、附魔 ID 列表或带有 # 前缀的附魔标签
    • 可选 - 如果省略，则互斥集为空
  • supported_items：可以拥有此附魔的物品类型
    • 物品 ID、物品 ID 列表或带有 # 前缀的标签
  • primary_items：此附魔会出现在附魔台和交易装备上的物品类型
    • 物品 ID、物品 ID 列表或带有 # 前缀的标签
    • 必须是 supported_items 的子集
  • weight：与其他所有可用附魔的总 weight 相比，该附魔出现的频率
    • 正整数 - 值越大越常见
  • max_level：附魔的最高等级
    • 所有附魔的等级范围为 1 到其最高等级
    • 正整数
  • min_cost、max_cost：描述此附魔在附魔台中的费用范围（以及祛魔时返还多少）
    • 最小和最大费用都使用线性公式描述：
    • base：1 级时的基础费用
    • per_level_above_first：每超过 1 级增加的费用
  • anvil_cost：铁砧中为此附魔收取的费用
    • 非负整数
    • 当附魔添加到书上时，该值减半
    • 实际费用乘以附魔的等级
  • slots：此附魔起作用的槽位组列表
    • 每个条目为 any、hand、mainhand、offhand、armor、feet、legs、chest、head 和 body 之一
  • effects：效果组件的映射，如下方“效果组件”部分所述

基于等级的值

附魔的许多效果取决于附魔的等级。对于这些字段，使用了一种称为“基于等级的值”的类型。其最基本的形式可以写成浮点常量，这会被解释为实际上不基于等级的值，即对所有等级都使用该常量。

如果基于等级的值不是浮点常量，则它是一个带有 type 字段的对象，指定以下类型之一。

linear

最常见的基于等级的值类型是 linear（线性）值。一个 linear 基于等级的值有两个字段：

  • base：添加到所有等级的基础值
  • per_level_above_first：每高于第一级一个等级所增加的值

实际上，linear 基于等级的值的结果为 base + per_level_above_first * (level - 1)。

clamped

一种将值限制在最小值和最大值之间的基于等级的值类型。字段：

  • value：用作输入的基于等级的值
  • min：指定输出最小值的浮点值
  • max：指定输出最大值的浮点值

fraction

一种表示两个值之间比值的基于等级的值类型。字段：

  • numerator：用作分子的基于等级的值
  • denominator：用作分母的基于等级的值

levels_squared

一种基于等级的值类型，计算结果为等级的平方，再加上一个加数。字段：

  • added：添加到等级平方结果上的浮点值

实际上，levels_squared 基于等级的值的结果为 level ^ 2 + added。

数值效果类型

数值效果是用于操纵游戏中某个事物数量的效果。

add

一种向处理结果添加数值的数值效果。

字段：

  • value：确定添加多少的基于等级的值
    • 支持负值

all_of

一种按顺序运行多个其他数值效果的数值效果。当一组条件适用于多个数值效果时，这很有用。

字段：

  • effects：要运行的数值效果列表

multiply

一种将处理后的值乘以给定因子的数值效果。

字段：

  • factor：确定要乘入的因子的基于等级的值

remove_binomial

一种运行二项式系列检查的数值效果，每次成功检查都会使输入值减少 1。

字段：

  • chance：表示输入值被丢弃的概率的基于等级的值。
    • 范围为 0 到 1，0 表示没有机会丢弃输入值，1 表示丢弃所有输入值

set

一种用给定的基于等级的值覆盖输入值的数值效果。

字段：

  • value：用作结果的基于等级的值

属性效果

属性效果使用属性系统，在附魔物品被正确装备时应用属性修饰符。属性效果没有动态类型——它们都是相同的类型。

字段：

  • name：要添加的属性修饰符名称
  • attribute：要修改的属性的 ID
  • operation：属性修饰符的运算
    • 为 add_value、add_multiplied_base 和 add_multiplied_total 之一
  • amount：描述数量的基于等级的值
  • uuid：包含 UUID 的字符串，供属性修饰符使用
    • 必须唯一，以避免不同的附魔（或其他系统）相互干扰

实体效果类型

实体效果是附魔效果，通常对事件中涉及的实体产生影响。受影响的实体取决于正在配置的具体组件。

all_of

一种运行其他实体效果列表的实体效果。当一组条件应适用于多个实体效果时，这很有用。

字段：

  • effects：要运行的实体效果列表

apply_mob_effect

一种从一组选项中选择一个随机的生物效果应用于受影响实体的实体效果。持续时间和效果等级在给定范围内随机。将最大值指定为大于最小值的效果是未定义的。

字段：

  • to_apply：要应用的效果选项
    • 为效果 ID、效果 ID 列表或带有 # 前缀的效果标签之一
  • min_duration、max_duration：表示效果最小和最大持续时间（以秒为单位）的基于等级的值
  • min_amplifier、max_amplifier：表示最小和最大效果等级的基于等级的值

damage_entity

一种对受影响实体施加伤害的实体效果。伤害量在给定范围内随机。将最大值指定为大于最小值的效果是未定义的。

字段：

  • damage_type：要使用的伤害类型的 ID
  • min_damage、max_damage：表示最小和最大伤害量的基于等级的值

damage_item

一种对附魔物品施加伤害的实体效果。

字段：

  • amount：确定要施加的伤害量的基于等级的值

explode

一种引起爆炸的实体效果。

字段：

  • attribute_to_user：一个布尔值，决定爆炸是否应归因于附魔工具的使用者
  • damage_type：可选的爆炸伤害类型 - 如果省略，爆炸不会造成伤害
  • immune_blocks：可选的方块、方块列表或以 # 开头的方块标签，指定哪些方块能完全阻挡爆炸
  • knockback_multiplier：决定爆炸造成的击退倍率的基于等级的值 - 如果省略，则应用默认爆炸击退
  • offset：爆炸生成位置的位置偏移
    • 格式：3 个整数组成的列表，分别代表 X、Y 和 Z 偏移
    • 可选，如果省略则使用 [0, 0, 0]
  • radius：表示爆炸半径的基于等级的值
  • create_fire：一个布尔值，决定爆炸是否会引起火焰
  • block_interaction：爆炸与方块的交互方式。以下之一：
    • none：无效果
    • block：视为方块引起的爆炸 - 掉落物遵循 blockExplosionDropDecay 游戏规则
    • mob：视为生物引起的爆炸 - 掉落物遵循 mobExplosionDropDecay 游戏规则
    • tnt：视为 TNT 引起的爆炸 - 掉落物遵循 tntExplosionDropDecay 游戏规则
    • trigger：触发红石激活的方块
  • small_particle：爆炸释放的小粒子
  • large_particle：爆炸释放的大粒子
  • sound：爆炸引起的声音事件

ignite

一种使受影响实体着火指定秒数的实体效果。

字段：

  • duration：指定火焰持续秒数的基于等级的值

play_sound

一种播放声音的实体效果。

字段：

  • sound：要播放声音的声音事件 ID
  • volume：介于 0.00001 和 10.0 之间的浮点提供器，指定声音的音量
  • pitch：介于 0.00001 和 2.0 之间的浮点提供器，指定声音的音调

replace_block

一种替换世界中方块的实体效果。

字段：

  • block_state：提供要设置的方块状态的方块状态提供器
  • offset：从事件位置到放置方块位置的位置偏移
    • 格式：3 个整数组成的列表，分别代表 X、Y 和 Z 偏移
    • 可选，如果省略则使用 [0, 0, 0]
  • predicate：用于确定是否应替换方块的世界生成风格方块谓词
    • 可选，如果省略则替换所有方块类型

replace_disc

一种替换世界中圆盘/圆柱体范围内方块的实体效果。

字段：

  • block_state：提供要设置的方块状态的方块状态提供器
  • radius：描述圆柱体半径的基于等级的值
  • height：描述圆柱体高度的基于等级的值
  • offset：从事件位置到圆柱体中心的位置偏移
    • 格式：3 个整数组成的列表，分别代表 X、Y 和 Z 偏移
    • 可选，如果省略则使用 [0, 0, 0]
  • predicate：用于确定是否应替换方块的世界生成风格方块谓词
    • 可选，如果省略则替换所有方块类型

run_function

一种运行命令函数的实体效果。效果执行所针对的执行实体表示为 @s，~ ~ ~ 是事件的位置。

字段：

  • function：要运行的命令函数的命名空间 ID

set_block_properties

一种在方块上设置属性的实体效果

字段：

  • properties：属性键到属性值的映射（与 minecraft:block_state 物品组件格式相同）
  • offset：从事件位置到圆柱体中心的位置偏移
    • 格式：3 个整数组成的列表，分别代表 X、Y 和 Z 偏移
    • 可选，如果省略则使用 [0, 0, 0]

spawn_particles

一种在受影响实体周围生成粒子的实体效果。

字段：

  • particle：粒子类型定义
  • horizontal_position、vertical_position：决定粒子在水平和垂直方向上的生成位置。具有以下字段的对象：
    • type：指定位置选择类型。以下之一：
      • "entity_position"：根据实体位置生成粒子
      • "in_bounding_box"：根据实体边界框内的随机位置生成粒子
    • offset：指定位置源偏移的浮点值
      • 可选，如果省略则视为 0
    • scale：指定缩放因子的浮点值
      • 仅在类型为 "in_bounding_box" 时可用
      • 可选，如果省略则视为 1
  • horizontal_velocity、vertical_velocity：决定生成的粒子的初始速度。具有以下字段的对象：
    • base：提供沿给定轴的基础速度的浮点提供器
      • 可选，如果省略则视为 0
    • movement_scale：应用于实体沿给定轴速度的浮点缩放因子
      • 可选，如果省略则视为 0
      • 示例：movement_scale 为 1 时，会将实体的速度添加到生成的粒子上

summon_entity

一种在事件位置生成一个新实体的实体效果，该实体从一组实体类型中随机选择。

字段：

  • entity：要生成的实体类型的选项
    • 可以是实体类型 ID、实体类型 ID 列表或带有 # 前缀的实体类型标签
  • join_team：布尔值，指定生成的实体是否应加入附魔物品所有者的队伍

基于位置的效果类型

基于位置的效果是特殊效果，它们会根据附魔物品所有者移动的位置而激活和停用。基于位置的效果仅在以下情况下触发：此类物品最初被装备时，以及此后当所有者实体移动到方块网格中的新空间时（即其坐标变为新的整数值时）。

所有实体效果类型也可以用作基于位置的效果，此外，attribute 可用于将属性效果指定为基于位置的效果。

效果条件

大多数附魔效果使用条件进行过滤（与战利品表中的类型相同）。这使效果可以针对不同情况具体化。每个效果组件定义了条件可以评估哪些参数——某些参数可用于所有这些参数集，而某些参数则特定于某个集合。

每个效果组件在下面的效果组件列表中指定了哪些参数可用。

伤害参数

  • 实体：this、attacker、direct_attacker
  • 附魔等级
  • 原点
  • 伤害来源

物品参数

  • 工具
  • 附魔等级

位置参数

  • 实体：this
  • 附魔等级
  • 原点
  • 附魔激活状态

实体参数

  • 实体：this
  • 附魔等级
  • 原点

效果组件

附魔中的 effects 字段是效果组件类型到效果列表数据的映射。大多数效果组件是列表，因此可以添加任意数量的任何组件类型的效果。每个效果的数据通常涉及指定的条件上下文和效果类型，但有些效果也偏离此格式。

在文档指定条件上下文和效果的情况下，组件是一个列表。列表中的每个条目都有一个名为 effect 的字段，其值为该列表所使用的类型的效果。条目还可以选择性地包含一个名为 requirements 的字段，指定条件参数，这些参数随后会在文档所述的上下文中进行评估。

  • minecraft:armor_effectiveness：用于改变攻击目标的护甲有效性的效果
    • 条件上下文：伤害参数
    • 效果：对护甲有效性的数值效果：0 表示完全无效，1 表示完全有效
  • minecraft:attributes：未经过滤的属性效果列表。
  • minecraft:ammo_use：用于拉弓射箭时（射出弓或装填弩时）消耗弹药的效果
    • 条件上下文：物品参数 - 工具是弹药物品
    • 效果：对消耗弹药量的数值效果
  • minecraft:block_experience：用于使用附魔物品挖掘方块时掉落经验值的数量
    • 条件上下文：物品参数 - 工具是所使用的挖掘工具
    • 效果：对奖励经验值的数值效果
  • minecraft:crossbow_charge_sounds：用于改变弩装填声音的效果
    • 注意：这些效果中只能有一个处于活动状态 - 选择最高等级
    • 格式：弩声音库列表：
      • start：可选的开始装填声音事件 ID
      • mid：可选的装填中段声音事件 ID
      • end：可选的装填完成声音事件 ID
    • 列表中的每个条目代表附魔一个等级的声音，因此第一个条目代表 1 级附魔使用的声音
  • minecraft:crossbow_charge_time：用于弩装填时间的效果
    • 条件上下文：物品参数 - 工具是弩
    • 效果：对弩装填时间（以秒为单位）的数值效果
  • minecraft:damage：用于攻击造成伤害量的效果
    • 条件上下文：伤害参数
    • 效果：对伤害量的数值效果
  • minecraft:damage_immunity：用于完全伤害免疫的效果
    • 条件上下文：伤害参数
    • 效果：未指定 - 任何匹配的条目都会导致伤害免疫
  • minecraft:damage_protection：用于伤害保护的效果
    • 条件上下文：伤害参数
    • 效果：对伤害保护量的数值效果
    • 注意，这会增加伤害保护（“魔法护甲”），而不是直接处理伤害本身
  • minecraft:equipment_drops：用于在目标被附魔物品所有者击杀时装备掉落几率的效果
    • 条件上下文：伤害参数
    • 效果：对装备掉落几率（介于 0 和 1 之间）的数值效果
    • 还有一个字段：
      • enchanted：指定谁需要被附魔才能应用该效果
      • 可能值为 attacker 和 victim
  • minecraft:fishing_luck_bonus：用于给予钓鱼玩家幸运值的数量效果
    • 条件上下文：实体参数 - this 是钓鱼的玩家
    • 效果：对幸运值的数值效果
    • 注意：总幸运值（以整数形式）作为幸运效果应用于钓鱼战利品表
  • minecraft:fishing_time_reduction：用于减少钓鱼时等待鱼上钩时间的效果
    • 条件上下文：实体参数 - this 是钓鱼的玩家
    • 效果：对节省时间（以秒为单位）的数值效果
    • 注意：这里的值越高，等待鱼上钩的时间越短
  • minecraft:hit_block：武器或工具击中方块后应用的效果
    • 条件上下文：实体参数 - this 是击中方块的实体
    • 效果：对击中方块的实体的实体效果
    • 注意：对于弹射物攻击，this 是弹射物
  • minecraft:knockback：用于攻击造成击退量的效果
    • 条件上下文：伤害参数
    • 效果：对攻击造成击退量的数值效果
  • minecraft:item_damage：用于物品受损时损失耐久度的效果
    • 条件上下文：物品参数 - 工具是受损物品
    • 效果：对物品伤害量的数值效果
  • minecraft:location_changed：当实体进入新的方块位置时生效的效果
    • 条件上下文：位置参数
    • 效果：基于位置的效果
  • minecraft:mob_experience：用于使用附魔物品击杀生物时掉落经验值的数量
    • 条件上下文：实体参数 - this 是被击杀的生物
    • 效果：对奖励经验值的数值效果
  • minecraft:post_attack：攻击对目标造成伤害后应用的效果
    • 条件上下文：伤害参数
    • 效果：实体效果
    • 还有两个其他字段：
      • enchanted：指定谁需要被附魔才能应用该效果
      • affected：指定效果应用于谁
    • 两个字段的可能值均为 attacker、damaging_entity 和 victim
    • 例如，火焰附加附魔会指定当 attacker 被 enchanted 时，应用 ignite 效果，并且 affected 方为 victim
    • 另一个例子：荆棘会指定当 victim 被 enchanted 时，应用 damage_entity 效果，并且 affected 方为 attacker
  • minecraft:prevent_armor_change：用于防止附魔物品从盔甲槽位卸下的效果
    • 格式：空对象
  • minecraft:prevent_equipment_drop：用于防止所有者在死亡时掉落附魔物品的效果
    • 格式：空对象
  • minecraft:projectile_count：用于使用弹射物武器时抽出的弹射物数量的效果
    • 条件上下文：实体参数 - this 是拉弓的实体
    • 效果：对抽出弹射物数量的数值效果
  • minecraft:projectile_piercing：用于从弹射物武器发射的弹射物的穿透数量（即可以击中的目标数量）的效果
    • 条件上下文：物品参数 - 工具是弹药物品
    • 效果：对发射弹射物穿透数的数值效果
  • minecraft:projectile_spread：用于弹射物武器发射多个弹射物时箭矢散布的效果
    • 条件上下文：实体参数 - this 是使用武器的实体
    • 效果：对弹射物最大散布角度（以度为单位，相对于瞄准线）的数值效果
  • minecraft:projectile_spawned：发射弹射物武器生成弹射物实体后应用的效果
    • 条件上下文：实体参数 - this 是弹射物实体
    • 效果：对弹射物实体的实体效果
  • minecraft:repair_with_xp：玩家拾取物品时使用经验值修复物品的效果 - 存在任何效果都会触发该功能
    • 条件上下文：物品参数 - tool 是被修复的物品
    • 效果：将经验值数量转换为修复耐久度数量的数值效果
  • minecraft:smash_damage_per_block_fallen：用于重锤粉碎攻击每摔落一格造成的伤害量的效果
    • 条件上下文：伤害参数
    • 效果：对伤害量的数值效果
  • minecraft:tick：正确装备的附魔物品每游戏刻应用的效果
    • 条件上下文：实体参数 - this 是附魔物品的所有者
    • 效果：对附魔物品所有者的实体效果
  • minecraft:trident_return_acceleration：用于三叉戟返回所有者时的特殊加速度值的效果
    • 条件上下文：实体参数 - this 是三叉戟实体
    • 效果：对加速度值的数值效果
  • minecraft:trident_spin_attack_strength：用于三叉戟作为旋转攻击使用时的强度效果
    • 条件上下文：实体参数 - this 是持有三叉戟的玩家
    • 效果：对攻击强度的数值效果
    • 任何大于 0 的结果值都会将三叉戟变成旋转攻击武器，而不是投掷攻击
  • minecraft:trident_sound：用于改变三叉戟攻击充能声音的效果
    • 注意：这些效果中只能有一个处于活动状态 - 选择最高等级
    • 格式：声音事件列表
    • 列表中的每个条目代表附魔一个等级的声音，因此第一个条目代表 1 级附魔使用的声音

末影人战利品附魔提供器

  • enderman_loot_drop：用于对被击杀末影人手持方块应用“假工具”的附魔提供器

村民交易再平衡附魔提供器

村民交易再平衡实验中的所有与装备相关的村民交易附魔现在都来自附魔提供器。

这些附魔提供器仅在启用村民交易再平衡实验时使用，并且都具有以下模式：

trades/<biome>_<profession>_<equipment>_<level>

例如：trades/desert_armorer_helmet_4 和 trades/taiga_armorer_chestplate_5。

附魔提供器类型

single_enchantment

始终提供相同附魔的附魔提供器。附魔的等级可以是常量或随机值。

字段：

  • enchantment：附魔的命名空间 ID
  • level：表示附魔等级的整数提供器

enchantments_by_cost

根据给定费用（类似于附魔台中的费用值）从一组选项中选择一个或多个附魔的附魔提供器。

字段：

  • enchantments：附魔集合，可以是单个附魔、附魔列表或以 # 为前缀的附魔标签
  • cost：表示附魔过程所用费用的整数提供器

enchantments_by_cost_with_difficulty

一种与 enchantments_by_cost 类似的附魔提供器，但费用部分基于导致添加附魔的事件发生区域的局部难度计算。

所使用的费用是最小费用加上一个均匀随机因子，该因子最多为基础费用跨度乘以特殊因子。特殊因子在局部难度达到 2 时为 0，在局部难度为 4 时线性增加到 1，之后任何难度都保持恒定值 1。

字段：

  • enchantments：附魔集合，可以是单个附魔、附魔列表或以 # 为前缀的附魔标签
  • min_cost：表示最小可能费用的正整数
  • max_cost_span：表示特殊因子处于最大值时费用随机化跨度的非负整数

伤害类型

  • 新伤害类型：campfire，从 in_fire 中分离出来

目标

一些目标实体名称已被重命名，以适应更通用的上下文：

  • direct_killer 现在称为 direct_attacker
  • killer_player 现在称为 attacking_player

enchantment_active_check

新条件，要求上下文中存在“附魔激活”参数，目前这意味着它仅在附魔条件中有效。

字段：

  • active：布尔值，决定检查是否应匹配激活（true）或未激活（false）状态

random_chance

  • chance 字段现在是一个数字提供器

random_chance_with_enchanted_bonus

由 random_chance_with_looting 重命名而来。字段更改：

  • looting_multiplier：字段已被移除
  • chance：现在是一个基于等级的值
  • enchantment：新字段，包含给予额外几率的附魔的命名空间 ID

函数

enchanted_count_increase

由 looting_enchant 重命名而来。现在有一个新字段：

  • enchantment：增加产出量的附魔的命名空间 ID

enchant_randomly

  • 格式已更改 - enchantments 字段现在称为 options
  • options 现在指定为附魔、附魔列表或附魔标签（以 # 为前缀）之一
  • only_compatible：新的可选布尔字段 - 如果为 true，则只允许与该物品兼容的附魔
    • 如果省略，默认为 true
    • 注意：书被认为与所有附魔兼容

enchant_with_levels

  • treasure 字段已被移除
  • 格式已更改 - options 现在指定为附魔、附魔列表或附魔标签（以 # 为前缀）之一

copy_name

  • source 字段的一些可能值已更改：
    • killer 重命名为 attacking_entity
    • killer_player 重命名为 last_damage_player

数字提供器

enchantment_level

一个新的数字提供器，从附魔等级参数中获取值。

字段：

  • amount：一个基于等级的值，根据附魔等级给出一个值

谓词

附魔谓词

  • enchantment 字段已被移除
  • 新增了一个 enchantments 字段，可以是附魔、附魔列表或附魔标签（以 # 为前缀）之一
    • 如果通过列表或标签指定了多个附魔，则只要任意一个附魔匹配，该谓词即匹配
  • 如果未指定 enchantments 字段，则任何匹配 levels 的附魔都会使测试通过
    • 如果 levels 和 enchantments 字段均未定义，则谓词将匹配具有任何附魔的物品

实体标志谓词

新的可能字段：

  • is_on_ground：可选布尔值 - 如果提供，则匹配实体的“在地面上”状态
  • is_flying：可选布尔值 - 如果提供，则匹配实体是否在飞行，包括：
    • 使用鞘翅滑翔
    • 在创造模式中飞行

位置谓词

新的可能字段：

  • can_see_sky：可选布尔值 - 如果提供，则仅当该位置具有最高可能的天光亮度时匹配
  • weather：可选枚举值，匹配位置所在维度的天气。以下之一：
    • clear
    • raining
    • thunder

移动谓词

新的子谓词，可在实体谓词中作为 movement 使用。可能字段：

  • x、y、z：沿某轴的移动速度的 min/max 限制，以方块/秒为单位
  • speed：总移动速度的 min/max 限制，以方块/秒为单位
  • horizontal_speed：实体移动水平速度分量的 min/max 限制，以方块/秒为单位
  • vertical_speed：实体移动垂直速度分量的 min/max 限制，以方块/秒为单位
  • fall_distance：实体摔落距离的 min/max 限制，以方块为单位

周期刻

新的实体子谓词，可在实体谓词中作为 periodic_ticks 使用。格式：正整数。

此子谓词在实体存在时间中每 n 刻为真。

属性

generic.attack_knockback

现在对玩家也生效。

generic.burning_time

实体被点燃后持续燃烧时间的因子。因子为 0 时完全移除燃烧时间，因子为 1 时使实体按默认火焰时间燃烧 - 更大的值会增加实体持续燃烧的时间。

  • 默认值：1
  • 最小值：0
  • 最大值：1024

generic.explosion_knockback_resistance

实体从爆炸中受到的击退量的因子。因子为 1 时完全移除击退，因子为 0 时意味着不减少击退。

  • 默认值：0
  • 最小值：0
  • 最大值：1

player.mining_efficiency

使用能高效挖掘方块的工具时，添加到挖掘速度上的挖掘速度因子。

  • 默认值：0
  • 最小值：0
  • 最大值：1024

generic.movement_efficiency

实体在阻碍移动的地形中移动的效率。因子为 1 时移除所有移动惩罚，因子为 0 时施加全部移动惩罚。

  • 默认值：0
  • 最小值：0
  • 最大值：1

generic.oxygen_bonus

实体在水下时不消耗氧气几率的因子。0 无效果，大于 0 的值用于以下公式来确定消耗氧气的几率：

1 / (oxygen_bonus + 1)

  • 默认值：0
  • 最小值：0
  • 最大值：1024

player.sneaking_speed

潜行时的移动速度因子。因子为 1 意味着潜行速度与行走一样快，因子为 0 意味着潜行时无法移动。

  • 默认值：0.3
  • 最小值：0
  • 最大值：1

player.submerged_mining_speed

处于水下时的挖掘速度因子。因子为 1 意味着在水下挖掘和在陆地上一样快，因子为 0 意味着在水下无法挖掘。请注意，这仅表示浸没因子本身，其他因素（如未接触地面）也会生效。

  • 默认值：0.2
  • 最小值：0
  • 最大值：20

player.sweeping_damage_ratio

横扫攻击中，基础攻击伤害有多少会传递到次要目标上。这是对横扫伤害本身基础攻击 1 的加值。值为 0 意味着不传递任何基础攻击伤害（横扫伤害为 1）。值为 1 意味着传递全部基础攻击伤害（横扫伤害为 attack_damage + 1）。

  • 默认值：0
  • 最小值：0
  • 最大值：1

generic.water_movement_efficiency
