今天我们为 Minecraft Java 版发布了快照 20w29a。我们修复了一些 bug，但也悄悄加入了一两个技术性改动！

20w29a 中的更改

  • 工具现在会按材质在创造模式物品栏中进行排序

20w29a 中的技术性更改

命令

spawnpoint 与 setworldspawn

添加了角度参数，用于设置重生玩家的默认朝向角度。
语法：spawnpoint [targets] [pos] [angle]
语法：setworldspawn [pos] [angle] 新参数：

  • angle：以度表示的浮点角度。支持相对坐标修饰符 ~

自定义世界生成

  • worldgen/noise_settings 现在可以包含噪声配置

20w29a 中修复的漏洞

  • MC-194464 "large_oak_foliage_placer" 被错误序列化为 "blob_foliage_placer"
  • MC-194298 骨粉无法生成花朵
  • MC-194257 在 vanilla_worldgen 配置中，有若干处 "snowy" 被拼写为 "snovy"
  • MC-194220 不死图腾给予你抗火 II，而不是最高等级的抗火 I
  • MC-194200 白桦树在桦木森林和桦木森林丘陵生物群系中生成不正确
  • MC-194173 在流畅和优质的图像设置下，拾取物品或经验时，碰撞箱会偏移渲染
  • MC-193662 创造模式下飞行时，玩家略高于方块并潜行、跳跃，会被限制在该方块上
  • MC-193560 在特定情况下，鞘翅上的附魔闪光不会渲染
  • MC-192021 在极佳图像设置下，透明方块上的附魔闪光效果无法正确渲染
  • MC-191623 末影龙被打败后，末影龙战斗音乐不会停止
  • MC-191031 旁观模式下的玩家可以与船互动
  • MC-190559 幼年炽足兽在雨天处于熔岩中时不会死亡
  • MC-189788 船移动时，船上的某些生物有时会受到溺水伤害
  • MC-185019 structures 参数为空的世界生成设置会以极高的频率生成所有结构
  • MC-176836 空手的卫道士在攻击时会以挑衅的方式举起手臂
  • MC-176778 当方块因服务器延迟过高而重新出现时，相机视角会被重置
  • MC-166718 生物不再会在灵魂沙、耕地或草径中窒息
  • MC-158735 没有弩的掠夺者会举起手臂，这种姿势可能会冒犯某些人
  • MC-153230 旁观模式下的玩家可以停下矿车
