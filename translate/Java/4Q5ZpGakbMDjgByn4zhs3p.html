大家好！我们现在发布了1.19.3的首个快照！你可能原本以为这个快照会是为1.20准备的，但时代在变。今后，我们将改变 Minecraft：Java 版发布次要版本和主要版本的方式。简单来说，我们将更频繁地发布次要版本。关于这一点，你可以在此处的文章中了解更多详情。

在这个快照中，我们引入了功能开关，你可能已经在我们昨天发布的文章中看到过相关内容。这意味着我们可以为1.20更新添加一个开关，包含骆驼等功能，而不必承诺在1.19.3版本中发布它们。这样，我们就能在测试实验性功能的同时，仍然能够发布包含新功能、更改和改进的更新，而无需先移除这些功能。

在这个快照中，你会看到我们在 Minecraft Live 上谈论过的功能作为实验性功能出现，还有一些聊天改动、一些技术性更改以及许多漏洞修复。

22w42a 中的新特性

  • 某些实验性功能现在可通过内置的实验性数据包使用
  • 收纳袋现在作为实验性功能提供
  • 新增了一个“全景图滚动速度”辅助功能选项

实验性功能

  • 某些实验性功能现在需要启用后才会出现在世界中
  • 此类功能通过在世界创建时添加内置数据包来启用
  • 功能开关旨在隐藏未完成或实验性的功能，以确保你现有的世界不受影响
  • 使用实验性功能的世界将在世界选择列表中标记为“实验性”
  • 无法为现有世界切换实验性功能

新增骆驼

启用1.20实验性功能后，现在可以使用骆驼了。

  • 骆驼可以装备鞍，并可供两名玩家骑乘
  • 骆驼自然生成于沙漠村庄
  • 骆驼很高
    • 当你骑在骆驼上时，大多数敌对生物无法攻击到你
    • 它们可以不费吹灰之力越过栅栏
  • 骆驼是非常优雅但又脾气暴躁的生物
    • 它们会随机坐下
    • 坐下时，很难让它们移动
  • 骆驼可以缓慢行走，也可以快速冲刺
  • 它们还可以向前猛冲，但这样做后会暂时失去体力

竹质方块系列

启用1.20实验性功能后，现在可以使用一系列新的竹质方块。

  • 新的木质方块
    • 竹板
    • 竹门
    • 竹活板门
    • 竹告示牌
    • 竹楼梯
    • 竹台阶
    • 竹栅栏
    • 竹栅栏门
    • 竹按钮
    • 竹压力板
  • 竹板可以用2x2竹子合成
  • 新增了一种竹子独有的“马赛克”木板变种，称为竹马赛克
    • 可以用1x2竹台阶以垂直条状合成
    • 你可以合成竹马赛克楼梯和台阶变种
  • 新增了独特的竹筏和竹箱筏，可以像普通船一样合成，但使用竹板
    • 功能与普通船相同，但外观独特

雕纹书架

启用1.20实验性功能后，现在可以使用书架的新雕纹变种。

  • 用6个木板和3个木台阶合成
  • 可以存放书、书与羽毛笔、成书和附魔书
    • 最多存放6本书
    • 安全保存你世界中的故事与传说
  • 比较器可以检测最后放入/取出的书
    • 非常适合在你的阴森图书馆里隐藏秘密

悬挂告示牌

曾想过把你的告示牌挂起来吗？拿几条锁链，剥一些原木，现在就可以了！启用1.20实验性功能后，现在可以使用悬挂告示牌。

  • 悬挂告示牌是普通告示牌的更昂贵版本
    • 使用2个锁链和6个你所选木材类型的去皮原木合成
    • 一次合成可获得6个悬挂告示牌
  • 可以通过以下方式悬挂：
    • 挂在能够提供中心支撑的方块下方，例如完整方块或栅栏
    • 附着在方块的实心侧面
    • 附着在另一个悬挂告示牌的侧面或下方
  • 与普通告示牌不同，如果没有来自侧面或上方的支撑，它们不能直接放置在地面上
    • 但是，带有横杆的悬挂告示牌在支撑方块被移除时不会掉落

声音

  • 各种木材类型现在在放置、破坏或踩踏时都有独特的声音
    • 共有三套独特声音：主世界木材类型、下界木材类型和竹子

22w42a 中的更改

  • 重做了创造模式物品栏标签页
  • 聊天改动
  • Realms 新闻按钮在打开链接前现在会显示确认界面
  • 要塞生成位置代码已变得更高效，导致要塞位置发生变化

创造模式物品栏

创造模式物品栏中标签页的顺序和内容已进行调整，让寻找相关方块和物品的体验更轻松。

  • 方块和物品已被移至更合适的类别中
  • 方块现在尽可能按材质排序
    • 例如，所有橡木方块及变体现在都排列在一起
  • 某些物品现在可以在多个标签页中找到
  • 多个标签页已重命名或合并到其他标签页中
  • 搜索标签页现在按其他标签页的顺序分组列出物品
    • 例如，在建筑方块中出现的物品总是排在红石方块中的物品之前
  • 石化橡木台阶已从创造模式物品栏中移除
    • 仍可通过命令获取
  • 这是为创造模式物品栏带来更好体验的第一次迭代，我们将密切关注这些改动的反馈，并根据需要进行迭代

聊天

  • 移除了聊天预览
  • 服务器管理员删除的聊天消息将不再完全隐藏，而是替换为说明“此聊天消息已被服务器删除。”的文字
  • 被删除的聊天消息现在会在聊天窗口中至少显示3秒后才隐藏
  • 聊天信任状态指示器已调整：
    • 对于仅更改了样式的服务器修改消息，将不再显示“已修改”标签
    • “已修改”标签图标和指示器现在为深灰色
    • “不安全”标签现在为浅灰色，并且没有图标
  • 部分被过滤的聊天消息现在会将过滤后的文本显示为灰色井号，并带有悬停文本说明其已被过滤

22w42a 中的技术性更改

  • 新增功能开关 - 用于启用或禁用某些实验性或未完成功能（如方块、实体和物品）的世界选项
  • 网络协议更改
  • 具有配方书的配方类型实例现在有 category 字段来决定放置位置

功能开关

常规说明

  • 功能开关是启用或禁用某些游戏元素组（如方块、实体和物品）的选项，这些元素组后文称为“功能”
  • 由开关控制的游戏元素是硬编码的
  • 功能开关存储在世界中

配置和数据包更改

  • 功能开关由数据包启用
    • 新增了名为 features 的包元数据部分，其中包含 enabled 列表内的已启用功能开关
  • 游戏现在包含内置数据包（类似于“Programmer Art”资源包），用于启用功能并提供相关的配方、进度、战利品表等
  • 向 server.properties 添加了新字段，以允许初始选择数据包（仅在世界创建时生效）
    • initial-enabled-packs - 要启用的数据包逗号分隔列表（功能包需要显式启用）
    • initial-disabled-packs - 不自动启用的数据包逗号分隔列表
  • 在世界创建后发现的数据包，如果其所需功能未在所加载世界中启用，则将被禁用

功能开关的影响

方块

  • 被禁用的方块ID无法被可创建新方块的命令识别
  • 被禁用方块对应的方块物品会被禁用
  • 被禁用的方块不会在结构中生成
  • 被禁用的方块不会作为实体的一部分加载（例如作为下落的沙子或末影人携带的方块）
  • 玩家无法与被禁用的方块交互

实体

  • 被禁用的实体ID无法被可召唤新实体的命令识别
  • 被禁用的实体不会生成或加载
  • 被禁用实体对应的刷怪蛋物品会被禁用

物品

  • 被禁用的物品会从创造模式菜单中隐藏
  • 配方和战利品表将被阻止创建被禁用的物品
  • 被禁用的物品ID无法被可创建新物品的命令识别
  • 被禁用的物品不能用于交互或攻击

网络协议

  • 网络协议现在支持在不将玩家实体添加到“Tab”玩家列表的情况下将其添加到世界中
  • 服务器现在可以在玩家的首个聊天数据包中延迟分发玩家的档案公钥
  • 在发送私密消息时，安全聊天协议中的消息“标头”不再需要分发
  • 出于效率考虑，安全聊天网络协议中的上下文消息引用现在会进行去重

配方

合成书类别

  • 合成书的类别/标签页现在可以由配方定义控制
  • 可用于 shaped/shapeless 和各种特殊合成配方的类别：
    • building
    • redstone
    • equipment
    • misc（默认）
  • 可用于 smelting、blasting、smoking、campfire_cooking 的类别：
    • food
    • blocks
    • misc（默认）
  • 某些合成书会将多个类别合并到单个标签页中
  • 确切的映射关系将来可能会改变

资源包

  • 资源包版本现在是11
  • 移除了版本3和4（扁平化之前）资源包的“修复器”
    • 游戏将不再尝试将这些版本的资源包适配到当前版本
