在我们的快照发布计划近期出现了一些不规律之后（说的就是你们，公共假日！），我们又回到了周三发布！除其他内容外，24w20a 中还提升了女巫掉落红石粉的数量，并对活塞声音进行了期盼已久的更改，使其更加悦耳。我们还加入了 41 个新 Bug 修复，因为我们喜欢消灭 Bug。

挖矿愉快！

更改

  • 女巫死亡时现在总是会掉落 4-8 个红石粉
    • 这是为了提高利用女巫小屋获取红石粉的农场的可行性
  • 改进了玩家属性和效果处理
    • 自定义设置的基础属性现在会在重生时保留
    • 活跃效果和修饰符在更改维度或通关游戏时会保留
  • 更新了制作人员名单

声音

  • 更新了活塞声音，降低了音量和衰减
    • 这是为了解决长期以来的反馈，即旧声音过于刺耳和响亮，导致红石装置非常嘈杂

技术更改

  • 数据包版本现为 44

数据包版本 44

  • dimension_padding 拼图结构 NBT 标签已更改
    • 现在它是一个包含以下字段的对象：
      • bottom 维度底部的垂直填充，非负整数
      • top 维度顶部的垂直填充，非负整数
    • 也可以写成一个非负整数，同时应用于顶部和底部字段
      • 例如 dimension_padding: 10 或 dimension_padding: { bottom: 10, top: 5 } 均有效
  • 数据驱动附魔字段 weight 现在有上限 1024
  • 数据驱动附魔字段 max_level 现在有上限 255

谓词

实体谓词

  • 新选项：movement_affected_by - 可选的位置谓词
    • 当存在时，会对实体下方最多 0.5 格处、可能影响其运动的方块添加要求
