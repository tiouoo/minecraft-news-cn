在本周的快照中，我们暂停添加新功能，转而改进已添加的功能，包括修复命令，以及让饰纹陶罐能够使用战利品表。

更改

  • 铜门和铜活板门的纹理已更新

技术性更改

  • 数据包版本现在为 23

数据包版本 23

  • 饰纹陶罐现在可以使用战利品表，并会读取 LootTable 标签键
  • 对命令函数进行了额外更改

命令

tick

  • tick step 命令中的 <time> 参数现在是可选的。默认值为 1

return

  • return run 现在将始终返回
    • 如果所返回的命令没有有效结果，包含 return run 的函数将会失败（即 success=0 和 result=0）
  • return run 现在将与结果值一同传播成功值（之前始终将成功值设为 1）
  • return run 现在也允许存储数值——这意味着 execute store ... run return run some_command 会同时存储数值并将数值返回至函数外部
  • 新增了子命令 return fail，使整个函数失败（即返回 success=0 和 result=0）

function

  • 如果 function <function tag> 与 return run 结合运行多个函数，执行将在任何函数中的第一个 return 后停止
  • 当与 return run 一起运行时，单次调用 function 命令总是会返回
    • 例如，return run execute [split context] run function <some function with conditional return> 在处理第一个上下文后总是会返回

execute if|unless function

  • 如果所有函数都没有返回，execute if|unless function 将不再总是失败
    • 如果所调用的函数中没有 return，则 if 会失败，unless 会通过
    • 所调用函数中的第一个 return 将返回（针对单个上下文）
