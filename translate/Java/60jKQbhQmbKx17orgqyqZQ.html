  • MC-251840 - 获取方块状态时游戏崩溃：cwj: Missing Palette entry for index 8
  • MC-251859 - 装备盔甲/鞘翅时，每次耐久度变化都会播放装备音效
  • MC-251989 - 自 1.19 Pre-release 1 起，在多人游戏中无法发送聊天消息或使用命令
