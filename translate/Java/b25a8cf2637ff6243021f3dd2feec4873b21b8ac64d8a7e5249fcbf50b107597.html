坐垫

  • 坐垫是一种物品，玩家可以将其放置在世界中并与它互动坐下
  • 有 16 种颜色变体可供制作
  • 坐垫由 3 个同色羊毛台阶合成

坐垫放置规则

  • 坐垫可以放置在任意平坦表面上
  • 坐垫在水平方向上始终对齐网格，但在垂直方向上位于支撑表面之上
  • 坐垫无法移动
  • 如果支撑方块被移除，坐垫会破坏
  • 坐垫没有碰撞箱，可以与其他物体重叠（除其他坐垫外）

草床

  • 草床是一种新型床，可以让你睡过整夜而不设置重生点
  • 它只能使用一次，使用后会被破坏
  • 它不能在下界或末地使用，如果你试图在那里睡觉，它会被破坏
  • 使用 3 个干草块合成，会得到 4 个草床
  • 统计信息窗口中新增了一个统计项目，记录在草床上睡觉的次数

命令

新增 posteffect

  • 允许向玩家添加或移除“后期效果”
  • 这些是在游戏完成正常渲染后应用于玩家屏幕的后处理着色器
  • 后期效果存在于客户端（资源包中），而非服务器——服务器无法知道某个效果是否会实际生效
  • 后期效果本身已是资源包格式的一部分，但此前只有少数硬编码的效果可供使用

开发者注释: 这现在使自定义着色器可以完全从资源包中使用，但请注意，着色器仍可能被随意更改，所涉及的功能（命令、后期效果或着色器）可能会在未来重新设计。

语法：

  • /posteffect add <player> <posteffect> - 为玩家添加该后期效果（如果尚未存在）
  • /posteffect clear <player> - 移除玩家身上的所有后期效果（如果存在）
  • /posteffect list <target> - 列出玩家身上的所有后期效果（如果存在）
  • /posteffect remove <player> <posteffect> - 从玩家身上移除该后期效果（如果存在）

药水谓词

minecraft:potion_contents 数据组件谓词已更改，允许匹配特定的药水效果。

以前的谓词格式使用药水类型列表，新格式允许更精细的匹配。

以下字段可以任意组合使用，所有字段都是可选的：

  • potions - 要匹配的药水类型列表或药水标签
  • effects - 用于匹配的 mob_effects 谓词的集合谓词
    • 集合谓词格式如下：
    • contains - 要匹配的 mob_effects 谓词列表
    • count - 用于匹配特定数量生物效果谓词的选项列表，格式与 minecraft:effects 实体子谓词`
      • test - 要匹配的 mob_effects 谓词
      • count - 所需匹配的数量，或与 min 和 max 一起匹配一个数量范围
    • size - 要求生物效果列表具有特定大小，或与 min 和 max 一起匹配一个大小范围

mob_effects 谓词格式是将效果类型映射到该效果的属性。所有字段都是可选的，仅使用提供的字段进行匹配：

    {
        "minecraft: <effect type>": {
          "duration": <integer bounds representing a duration in ticks>,
          "amplifier": <integer bounds>,
          "ambient: true/false,
          "visible": true/false
        }
    )

以下是匹配多种不同效果和条件的示例：

      "effects": {
        "minecraft:jump_boost": {
          "duration": 3600,
          "amplifier": 5,
          "ambient: true,
          "visible": true
        },
        "minecraft:speed": {
          "duration": {
            "min": 360,
            "max": "3600
          },
          "amplifier: {
            "min": 2
          }
        },
        "minecraft:resistance": {}
      }

所有条件都是可选的。

  • minecraft:compostable/low_medium

新增 minecraft:number_dispatcher 类型

  • 返回第一个满足其条件的分支；如果没有，则返回 default
  • 字段：
    • cases - 按调度器尝试执行顺序排列的分支列表

        • condition - 一个 minecraft:predicate

    • default - 一个可选的 minecraft:number_provider
      • 如果省略，默认为常量 0

新增 minecraft:conditional_value 类型

  • 如果条件满足，则返回 on_true 中的值，否则返回 on_false 中的值
  • 字段：
    • conditions - 一个 minecraft:predicate
    • on_true - 一个 minecraft:number_provider，在条件满足时执行
    • on_false - 一个可选的 minecraft:number_provider
      • 如果省略，默认为常量 0

配方

药水酿造配方

药水酿造配方现在是数据驱动的。可以通过数据包添加新配方，也可以修改原版配方。酿造配方使用 minecraft:brewing 类型。

主要内容包括：

  • input - 一个药水材料，具有必填的 item 字段和可选的 potion_contents 字段，使用 minecraft:potion_contents 数据组件谓词
  • reagent - 一个药水材料，具有必填的 item 字段和可选的 potion_contents 字段，使用 minecraft:potion_contents 数据组件谓词
  • output - 物品堆栈，即结果物品

以下是一个原版配方的示例：

{
  "type": "minecraft:brewing",
  "input": {
    "item": "minecraft:potion",
    "potion_contents": {
      "potion": "minecraft:water"
    }
  },
  "output": {
    "components": {
      "minecraft:potion_contents": {
        "potion": "minecraft:awkward"
      }
    },
    "id": "minecraft:potion"
  },
  "reagent": {
    "item": "minecraft:nether_wart"
  }
}

任何物品都可以用于这三个槽位中的任意一个，例如：

{
  "type": "minecraft:brewing",
  "input": { "item": "minecraft:bucket" },
  "output": { "id": "minecraft:sulfur_cube_bucket" },
  "reagent": { "item": "minecraft:potent_sulfur" }
}

新增 minecraft:cuboid

以长方体形状重复放置一个特性。

新增字段：

  • xz_size：1 到 16 之间的整数提供器，表示长方体沿 x 轴和 z 轴的大小
  • y_size：1 到 16 之间的整数提供器，表示长方体沿 y 轴的大小

常驻后期效果支持

  • 资源包现在可以定义 minecraft:end_of_frame 后期效果
