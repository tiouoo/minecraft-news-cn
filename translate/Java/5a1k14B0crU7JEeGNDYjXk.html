我们正在发布 Minecraft 1.18 的预发布版 5。此预发布版包含更多错误修复，并对现有区块下方的洞穴生成进行了调整。

1.18 预发布版 5 的更改

  • 如果某个区块在高度 0 处有基岩，则新世界生成将在该区块高度 0 处的任何非空气方块下方进行
