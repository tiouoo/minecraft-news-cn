更改

  • 命名牌现在可以合成了，可用1张纸和任意1个金属粒合成。
  • 僵尸马受伤时不再恐慌。
  • 调整了默认JVM选项。
  • 为狼、猫和猪添加了新的幼年音效。
  • 重新设计了多种幼年生物的视觉效果。
  • 在兔子重新建模后，移除了程序员美术风格的兔子纹理。

默认JVM选项

  • 游戏现在默认分配4 GB内存（原为2 GB）。
  • 兼容设备上的垃圾回收已从G1GC改为ZGC。

开发者注记：默认内存分配已从2GB提升到4GB，以使游戏运行更流畅并减少卡顿。此外，借助分代ZGC，你应该会看到更稳定的帧率，尤其是在执行高内存占用任务时。如果你在内存小于4GB的机器上运行Minecraft，请参阅这篇帮助文章。如果你想更改垃圾回收器，请参阅这篇帮助文章。第三方启动器可能不支持这些更改。

  • 数据包版本现在为96。
  • 资源包版本现在为77。

  • 玩家身上的current_explosion_impact_pos和current_impulse_context_reset_grace_time字段已添加到所有生物和盔甲架。

物品标签
