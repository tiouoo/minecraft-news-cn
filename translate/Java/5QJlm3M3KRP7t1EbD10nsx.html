21w14a 的新特性

  • 加入了粗铜、粗铁和粗金物品
  • 凝灰岩团簇现在可在高度 0 到 16 之间找到

可烧炼的矿石掉落物

  • 可烧炼的矿石现在会掉落矿石的粗制物品形式，而不是矿石块本身，并且这些粗制物品可以像以前一样被烧炼
  • 这是为了防止物品栏混乱，并让所有矿石的时运附魔效果保持一致
  • 旧世界中的矿石块和精准采集获得的矿石块仍然可以烧炼

21w14a 中的更改

  • 完全氧化的铜现在可以被涂蜡
