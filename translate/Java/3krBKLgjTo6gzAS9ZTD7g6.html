  • 加入了阴沉石！

阴沉石

阴沉石可以在地底最深处找到，并且比普通石头更难开采。

  • 与黑石一样，阴沉石可用于制作基础工具、熔炉和酿造台。
  • 你可以使用这种新石头类型合成以下方块：
    • 阴沉石台阶
    • 阴沉石楼梯
    • 阴沉石墙
    • 磨制阴沉石
    • 磨制阴沉石台阶
    • 磨制阴沉石楼梯
    • 磨制阴沉石墙
    • 阴沉石砖
    • 阴沉石砖台阶
    • 阴沉石砖楼梯
    • 阴沉石砖墙
    • 阴沉石瓦
    • 阴沉石瓦台阶
    • 阴沉石瓦楼梯
    • 阴沉石瓦墙
    • 錾制阴沉石

21w07a 的更改

  • 对世界生成和矿石的调整与更新
  • 更改了一些矿石和石头类型的视觉效果
  • 重新排列了创造模式物品栏中的红石选项卡

世界生成

  • 调整了巨大洞穴，使其更稀有，并降低了洞穴充满水的概率
  • 更改了矿石生成以匹配新的世界高度，并增加了采矿的策略性
  • 调整了闪长岩、安山岩和花岗岩生成的尺寸与位置
  • 例外：闪长岩、花岗岩和泥土不再在 y=0 以下生成
  • 要塞现在大部分被石头包裹
  • 矿井通道现在在需要时由下方的原木柱支撑或上方的锁链悬挂

视觉效果

  • 出于无障碍考虑，没有独特形状的矿石获得了新纹理，以便仅凭形状就能区分每种矿石
  • 作为最具标志性的矿石，钻石矿石的纹理保持不变，以维持那种经典的感觉
  • 黑石、磨制黑石砖和裂纹磨制黑石砖进行了一些细微的润色

创造模式物品栏

  • 红石选项卡已重新排序，以优先显示常用方块
  • 红石物品/方块已按以下方式分组和排序：
    • 基础
    • 特殊激活器
    • 杂项
    • 常用激活器
    • 可开启物
