杨树

  • 一种新的树木，有三种颜色变体：
    • 红色杨树叶
    • 橙色杨树叶
    • 黄色杨树叶
  • 每种树木变体都有与树叶颜色匹配的落叶粒子变体
  • 杨树叶会掉落杨树树苗，树苗会随机成长为三种不同变体之一
  • 可以通过与流浪商人交易获得杨树树苗
  • 层架菇和落叶会自然生成在杨树上或其周围
  • 树干由杨树原木构成
  • 杨树原木可以合成一套新的杨树木材方块

层架菇

  • 一种新的蘑菇，生成在杨树和倒下的杨树上
  • 有小型和大型两种尺寸
  • 使用骨粉可以将小型层架菇培育成大型层架菇
  • 大型层架菇被破坏时会掉落两个层架菇物品
  • 可以像其他蘑菇一样用来制作炖菜
  • 可以通过与流浪商人交易获得
  • 踩上层架菇时会有一点弹性，和床类似
  • 当生物在层架菇上弹跳时，层架菇会发出弹跳声

红色灌木

命令

对 item 的更改

  • 现在接受槽位源作为参数，取代之前使用槽位的任何位置
    • 将使用 minecraft:command_slot_source 战利品类型进行评估
    • 可以是内联或引用形式的槽位源
    • 可以是针对多个槽位的槽位源
    • replace 子命令有了新的语义：
      • 按照槽位源提供的顺序，用对应的源物品逐一替换每个目标槽位的内容
      • 当目标槽位多于源物品时，剩余槽位将被忽略
        • 示例：replace [12345] with (ABC) -> [ABC45]
      • 当目标槽位少于源物品时，剩余物品将被忽略
        • 示例：replace [123] with (ABCDE) -> [ABC]
    • 仍然允许使用 <slot_type> 或 <slot_type>.<slot_number> 形式的字符串表示槽位范围
      • 可以是单个槽位，例如 armor.chest
      • 可以是多个槽位，例如 container.*
      • 作为使用该槽位范围的 minecraft:slot_range 槽位源的简写
        • 示例：hotbar.4 等同于 {type:"minecraft:slot_range",slots:"hotbar.4"}
  • from entity 物品源中的实体参数现在可以是一个指定多个实体的选择器
    • 当指定多个实体时，从每个实体获取的槽位会拼接在一起
  • 添加了新的 fill 和 override 子命令，两者语法与 /item replace 相同
    • /item fill
      • 用源物品填充每个目标槽位
      • 当目标槽位多于源物品时，物品会重复，直到每个槽位都被填满
        • 示例：fill [12345] with (ABC) -> [ABCAB]
    • /item override
      • 用对应的源物品覆盖每个目标槽位的内容
      • 当目标槽位多于源物品时，剩余槽位将被清空
        • 示例：override [12345] with (ABC) -> [ABC__]（其中 _ 表示空槽位）

对 execute 的更改

  • 添加了新的 slots 条件子命令
    • 统计目标方块或实体上来自槽位源的槽位数量
    • 槽位源将使用 minecraft:command_slot_source 战利品类型进行评估
    • 语法：
      • /execute if|unless slots block <pos> <slot source>
      • /execute if|unless slots entity <targets> <slot source>
  • items 条件子命令现在接受槽位源作为参数，而不是槽位
    • 槽位源将使用 minecraft:command_slot_source 战利品类型进行评估
    • 语法：
      • /execute if|unless items block <pos> <slot source> <item predicate>
      • /execute if|unless items entity <targets> <slot source> <item predicate>

纹饰材料

trim_material 注册表中元素的格式已更新：

  • asset_name 已被 palette 取代 - 用于此材料的调色板纹理 ID
  • override_armor_assets 已被移除，覆盖项现在在资源包装备资产中定义

乐器

instrument 注册表中元素的格式已更新：

  • 添加了 durability_damage 字段 - 可选的非负整数，每次使用消耗的耐久度
  • 更新了 use_duration 字段 - 现在可以为 0，表示无冷却

方块实体数据

minecraft:decorated_pot

sherds 字段不再存储包含 4 个物品 ID 的列表。新格式是一个包含 4 个可选物品堆叠字段的对象，字段名为：

  • back
  • left
  • right
  • front

槽位源

  • 槽位源现在可以定义为数据包内 slot_source 文件夹中的文件
    • 可以用在以槽位源为参数的命令中
    • 可以通过 minecraft:reference 类型用于内联槽位源
  • minecraft:contents 不再仅限于选择非空槽位

添加了 minecraft:reference

  • 使用所引用的槽位源
  • 字段：
    • name - 槽位源的命名空间 ID

更改了 minecraft:slot_range

  • source 字段新增有效类型 container，它会从通过战利品上下文提供的容器或物品栏中获取槽位
  • source 字段现在可选
    • 缺省时默认使用 container 源类型

战利品函数

  • 添加了 minecraft:command_slot_source 战利品表类型
    • 目前用于通过 /item 和 /execute 命令评估槽位源
    • 它接受以下参数：
      • container，正在评估的容器或物品栏
      • origin，命令执行时的位置
      • this_entity，正在执行命令的 @s 实体（可选）

minecraft:tree 地物类型

  • 以指定概率在原木上放置层架菇
  • 格式：包含字段的对象：

添加了 poplar_foliage_placer 树叶放置器类型

  • 以菱形形状，在两种可能方向之一中放置杨树的树叶方块
  • 格式：包含字段的对象：
    • height - 整数提供器（介于 5 和 16 之间），树叶的高度

添加了 poplar_trunk_placer 树干放置器类型

  • 以笔直形状放置杨树的原木方块，并在树叶开始处生成树枝
  • 格式：
    • trunk_height_above_branches - 整数提供器（介于 0 和 8 之间），树枝上方树干的高度
    • branch_amount - 整数提供器（介于 1 和 4 之间），在树叶旁生成的树枝数量

噪声设置

  • surface_rule 字段已更名为 material_rule
    • 格式：内联材料规则或材料规则 ID 引用

材料规则注册表

引入了一个新的数据驱动注册表，从 data/<namespace>/worldgen/material_rule/<id>.json 加载。

此注册表中的元素定义了选择在给定位置放置哪个基础方块到世界中的流水线。

格式与之前写在噪声设置文件的 surface_rule 字段中的格式相同，并有以下扩展：

  • 材料规则现在可以内联指定（与之前一样），也可以作为对 worldgen/material_rule 注册表中元素的 ID 引用
  • 材料条件现在也可以作为对 worldgen/material_condition 注册表中元素的 ID 引用

材料条件注册表

引入了一个新的数据驱动注册表，从 data/<namespace>/worldgen/material_condition/<id>.json 加载。

此注册表中的元素定义了一种可以在材料规则流水线内引用的条件（例如测试生物群系或表面深度）。

格式与之前写在 condition 材料规则类型中的格式相同，并有以下扩展：

  • 材料条件现在也可以作为对 worldgen/material_condition 注册表中元素的 ID 引用

结构放置

添加了 minecraft:dimension_origin

  • 新的结构放置方式，在维度原点放置单个结构实例
    • 维度原点定义为基于噪声设置的维度的 spawn_target，否则为区块 (0, 0)
  • 没有其他字段

规则测试

这些是 ore 地物（targets[].target）和 rule 结构处理器（rules[].input_predicate 和 rules[].location_predicate）使用的谓词。

添加了规则测试类型 minecraft:height_match

  • 这会检查方块的 y 高度，仅当它大于等于 min_inclusive 且小于等于 max_inclusive 时返回 true
  • 格式：包含字段的对象：
    • min_inclusive - 整数，允许方块的最小 y 值（含）
    • max_inclusive - 整数，允许方块的最大 y 值（含）

添加了规则测试类型 minecraft:all_of

  • 检查一组规则测试是否对同一个方块都返回 true
  • 格式：包含字段的对象：
    • rules - 规则测试列表，用于测试方块的规则
