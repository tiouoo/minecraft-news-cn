紫水晶方块

  • 紫水晶在晶洞中以两种形态的方块呈现：紫水晶块和紫水晶母岩
  • 所有类型的紫水晶方块（包括紫水晶簇）在行走、破坏、放置或被弹射物击中时都会发出美妙的声音——去创作音乐吧！

紫水晶簇

  • 紫水晶簇由紫水晶母岩生长而来，紫水晶母岩可在紫水晶晶洞中找到
  • 紫水晶簇有四个生长阶段：小型紫水晶芽、中型紫水晶芽、大型紫水晶芽和紫水晶簇
  • 紫水晶簇只有附着在紫水晶母岩方块上时才能生长
  • 完全长成的紫水晶簇在用时挖掘时会掉落四个紫水晶碎片（使用时运会增加），用手、活塞或其他方式破坏时掉落两个紫水晶碎片
  • 紫水晶簇在任何阶段都可以使用精准采集获取

紫水晶晶洞

  • 这些巨大的晶洞可以在主世界地下的任何地方找到
  • 紫水晶晶洞外层是一种叫做平滑玄武岩的新石头
  • 紫水晶晶洞第二层是另一种新方块，叫做方解石
  • 紫水晶晶洞内层是各种紫水晶方块

紫水晶碎片

  • 紫水晶簇被手、活塞或其他方式破坏时掉落两个紫水晶碎片
  • 紫水晶簇用镐挖掘时掉落四个紫水晶碎片（使用时运会增加）

美西螈

  • 两栖生物！
  • 美西螈生成于完全黑暗的地下水中，下方是石头、花岗岩、闪长岩、安山岩、凝灰岩或深板岩
  • 美西螈喜欢热带鱼！热带鱼桶可用于繁殖美西螈
  • 如果你任一只手拿着热带鱼桶，美西螈会和你一起游泳
  • 当玩家杀死美西螈正在攻击或被攻击的生物时，美西螈会给予玩家暂时的生命恢复，并移除任何挖掘疲劳效果，以示感谢
  • 如果玩家已经有超过两分钟的生命恢复效果，美西螈不会给予额外的生命恢复
  • 你可以用水桶装起美西螈，像鲑鱼或鳕鱼一样随身携带
  • 美西螈总是会追逐并攻击鱿鱼、发光鱿鱼、热带鱼、鳕鱼、鲑鱼、河豚、溺尸、守卫者和远古守卫者
  • 美西螈不喜欢离开水，如果离开水超过五分钟，它们会变干并开始受到伤害
  • 只要美西螈在水中或雨中，它就不会变干
  • 有时美西螈在水中受到伤害时会装死，以停止被攻击
  • 美西螈有四种常见变种和一种稀有变种（蓝色）
  • 美西螈生成于完全黑暗、上方是天然石头方块的地下水源中
  • 美西螈在捕食非敌对目标后现在有两分钟冷却时间：鱿鱼、发光鱿鱼、热带鱼、鳕鱼、鲑鱼和河豚
  • 它们会优先攻击敌对生物，而不是捕食

  • 蜡烛只能放置在下方的实心表面上，但即使下方的表面被移除，蜡烛也会保留

炼药锅

  • 炼药锅现在可以用熔岩和细雪桶填充！
  • 装满熔岩的炼药锅在使用比较器时会发出强度为3的红石信号

铜块

  • 用九个铜锭合成一个铜块
  • 合成切制铜块、切制铜楼梯和切制铜台阶
  • 切石机可用于制作不同的铜方块变种
  • 使用蜜脾合成涂蜡铜块
  • 对铜块使用蜜脾右键以给它们涂蜡
  • 在发射器中使用蜜脾给铜块涂蜡

铜矿石

  • 铜矿石会像铁和煤一样在主世界以矿团形式生成（这不是铜的最终生成方式...）
  • 烧炼铜矿石获得铜锭
  • 铜矿石掉落2-3个粗铜

深板岩

  • 深板岩可以在最深的地下找到，比普通石头更难挖掘
  • 深板岩会掉落深板岩圆石，类似于石头掉落圆石
    • 你可以使用精准采集获得深板岩
  • 像圆石一样，深板岩圆石可以用于合成基础工具、熔炉和酿造台
  • 你还可以使用深板岩合成以下方块：
    • 深板岩圆石台阶
    • 深板岩圆石楼梯
    • 深板岩圆石墙
    • 磨制深板岩
    • 磨制深板岩台阶
    • 磨制深板岩楼梯
    • 磨制深板岩墙
    • 深板岩砖
    • 深板岩砖台阶
    • 深板岩砖楼梯
    • 深板岩砖墙
    • 深板岩瓦
    • 深板岩瓦台阶
    • 深板岩瓦楼梯
    • 深板岩瓦墙
    • 雕纹深板岩
    • 裂纹深板岩砖
    • 裂纹深板岩瓦
  • 地下还有一种被感染的深板岩变种
  • 深板岩圆石可以烧炼成深板岩

深板岩矿石

  • 添加了铁、金、青金石、红石和钻石矿石的深板岩变种，这些变种会在矿石替换深板岩时生成
  • 挖掘难度是普通矿石的两倍
  • 虽然它们不会在地下生成，但已为地图制作者和数据包添加了铜、绿宝石和煤矿石的深板岩变种

滴水石块

  • 装饰性方块
  • 可以用四个滴水石锥合成

滴水石锥

  • 放置在天花板上会形成钟乳石，放置在地板上会形成石笋
  • 可以组合成更长的钟乳石和石笋
  • 如果尖端彼此相邻，钟乳石和石笋会合并，除非你在放置时按住Shift
  • 石笋如果没有附着在下方的东西上就会断裂
  • 落在或跳上石笋会受伤，而且它们很锋利！
  • 钟乳石如果没有附着在上方的东西上就会掉落
  • 被掉落的钟乳石击中会受伤，而且它们很锋利！
  • 钟乳石会滴水（如果天花板上有熔岩则滴熔岩）
  • 天花板上有水源的钟乳石会逐渐将下方的炼药锅装满水
  • 天花板上有熔岩源的钟乳石会在一段时间后将下方的炼药锅装满熔岩
  • 投掷的三叉戟会破坏滴水石锥

滴水石生长

  • 如果钟乳石悬挂在滴水石块下方，且上方有水源，它会慢慢生长，同时上方会长出钟乳石，下方会长出石笋
  • 生长速度随机但非常缓慢，一步生长可能需要好几个Minecraft日
  • 钟乳石最多只能长到七格长
  • 只有当下方的地板或石笋在十格以内时，钟乳石才会促成石笋生长
  • 如果钟乳石尖端在水中，它不会滴落，因此不会触发任何生长
  • 如果石笋尖端在水中，它不会接收滴落物，因此不会因滴水的钟乳石而生长。如果两个尖端之间有任何液体，情况也是如此
  • 石笋或钟乳石永远不会长入液体中

发光地衣

  • 一种在洞穴中生成的昏暗光源
  • 使用剪刀采集
  • 使用骨粉使其沿方块表面蔓延

发光鱿鱼

  • 发光鱿鱼自带光芒，从远处就能看到！
  • 发光鱿鱼被杀死时会掉落荧光墨囊
  • 荧光墨囊可用于告示牌，使文字格外显眼，即使在夜晚也是如此。支持颜色！
  • 在工作台中将荧光墨囊与物品展示框合成，即可制作荧光物品展示框。荧光物品展示框中的任何物品都会被完美照亮，即使在夜晚也是如此。
  • 在告示牌上使用墨囊可以移除发光效果
  • 美西螈会攻击它们看到的任何发光鱿鱼，所以...小心
  • 发光鱿鱼生成于完全黑暗的地下水中，下方是石头、花岗岩、闪长岩、安山岩、凝灰岩或深板岩

山羊

  • 山羊生成于山地
  • 山羊凭借惊人的跳跃力可以攀登山坡
  • 山羊可以用小麦引诱和繁殖
  • 山羊是牛奶的另一个来源！
  • 山羊会冲撞任何移动的东西...也包括盔甲架
  • 每100只山羊中就有2只有非常重要的话要告诉你！
  • 山羊会避免在细雪上行走
  • 尖叫山羊比其他山羊更频繁地使用冲撞攻击
  • 被山羊冲撞的生物不会反击

被感染的方块

  • 被感染的方块不再被瞬间破坏，而是具有其非感染对应物一半的破坏时间

避雷针

  • 避雷针由三个铜锭合成
  • 在雷暴期间保护你的建筑（好吧，只要避雷针周围最近区域防火就行）！
  • 避雷针会保护周围8 * 16格的区域免受有时具有破坏性的雷击！
  • 避雷针被闪电击中时会发出红石信号

繁茂洞穴方块

  • 添加了苔藓
  • 添加了垂滴叶
  • 添加了缠根泥土和垂根
  • 添加了孢子花（目前仅在创造模式物品栏中提供）
  • 添加了洞穴藤蔓和发光浆果
  • 添加了杜鹃花丛

杜鹃花丛

  • 添加了杜鹃花丛和盛开的杜鹃花丛
  • 蜜蜂会将盛开的杜鹃花（以及盛开的杜鹃花树叶）视为花朵
  • 对杜鹃花或盛开的杜鹃花使用骨粉可获得杜鹃花树

洞穴藤蔓和发光浆果

  • 洞穴藤蔓像垂泪藤一样从天花板向下生长
  • 它们生长时有几率结出发光浆果
  • 发光浆果既是自然光源，也是食物来源
  • 狐狸吃发光浆果
  • 使用发光浆果种植新的洞穴藤蔓
  • 对洞穴藤蔓使用骨粉会结出发光浆果

垂滴叶

  • 小型垂滴叶需要水分，所以它生长在黏土上或水下
  • 小型垂滴叶方块的朝向由玩家放置时面对的方向决定
  • 流浪商人有时会出售小型垂滴叶植物
  • 小型垂滴叶在使用骨粉后会长成大型垂滴叶
  • 大型垂滴叶在使用骨粉后会长得更高
  • 如果你站在大型垂滴叶上，它过一会儿会倾斜，你会掉下去
  • 倾斜的大型垂滴叶过一会儿会重新立起
  • 大型垂滴叶被弹射物击中时会倾斜
  • 被红石信号激活的大型垂滴叶不会倾斜（除非被弹射物击中）

苔藓

  • 两种新的装饰性方块：苔藓块和苔藓地毯
  • 苔藓地毯可以用苔藓块合成
  • 苔藓块可以与圆石或石砖合成，以制作这些方块的苔藓变种

根

  • 添加了缠根泥土和垂根——这些装饰性方块将出现在即将到来的繁茂洞穴生物群系中
  • 对缠根泥土使用骨粉会在其下方长出垂根
  • 用锄耕缠根泥土会将其变成泥土，并掉落一个垂根物品

孢子花

  • 一种美丽的大花，放置在天花板上
  • 粒子从它上面滴落，并出现在它周围的空气中

矿车和铁轨在水下工作

  • 所有铁轨都可以含水（也适用于发射器和装水桶）
  • 流动的水不会破坏铁轨
  • 矿车可以穿过水，但会比平时减速更多

氧化

  • 铜会随着时间的推移而氧化
  • 有四个阶段：铜、斑驳的铜、风化的铜和氧化的铜
  • 铜块氧化一个阶段需要50-82个Minecraft日（在已加载区块中）
  • 涂蜡铜块不会氧化
  • 你可以给任何氧化阶段涂蜡——让那块漂亮的风化铜块永远保持风化阶段！
  • 闪电击中铜会清除其氧化
  • 涂蜡铜块可以合成九个铜锭
  • 斧头可以刮掉铜块上的蜡和氧化层

细雪

更雪白的雪！

  • 细雪是一种陷阱方块，任何走进它的实体都会陷入其中
  • 你可以使用桶采集和放置细雪
  • 穿着皮革靴子可以防止自己陷入细雪方块
  • 把炼药锅放在飘雪中，它会装满细雪
  • 着火的实体现在会在碰撞到细雪时被熄灭。细雪方块也会被破坏
  • 骷髅被冻住时会转化为流浪者
  • 细雪可以被活塞和黏性活塞推动
  • 兔子、末影螨、蠹虫和狐狸可以在细雪表面行走而不会陷进去

更改的触发器

effects_changed

  • 添加了与触发更改的实体匹配的source触发器
  • 在以下情况下可能为空：
    • 没有实体（例如，从信标获得的效果）
    • 效果是自身施加的
    • 效果被移除

闪电

  • blocks_set_on_fire - 范围的检查，用于此实体点燃的方块
  • entity_struck - 被此闪电击中的实体的谓词（如果存在，必须匹配一个或多个）

新触发器

lightning_strike

  • 当闪电打击完成时（即实体消失）触发
  • 为闪电打击一定半径内的任何玩家触发
  • 条件
    • player - 此触发器运行的玩家
    • lightning - 闪电实体的谓词
    • bystander - 打击周围一定区域内未被伤害的实体之一的谓词

started_riding

  • 当玩家开始骑乘坐骑，或实体开始骑乘当前由玩家骑乘的载具时触发
  • 条件：
    • player - 要么是已经开始骑乘的玩家，要么是船上的乘客之一

using_item

  • 在使用物品的每一刻触发（如弩和望远镜）
  • 条件
    • player - 使用物品的玩家
    • item - 正在使用的物品

聊天组件分隔符

  • 添加了occludes_vibration_signals方块标签。此标签中的任何内容都会遮挡振动，并默认继承wool标签条目
  • 打印名称列表的组件，如selector或nbt，现在可以使用separator元素覆盖分隔符（默认为, ）
  • 示例：
    • {"selector": "@e[type=chicken]", "separator": "|"}
    • {"nbt": "CustomName", "entity": "@e[type=chicken]", "interpret": true, "separator": {"text": "*", "color": "red"}}

命令

item

修改物品或方块物品栏。 此命令有三种形式： 可能的来源和目标： 例如，/item replace block ~ ~ ~ container.0 from entity @s enderchest.0会将玩家末影箱中的第一个物品复制到玩家当前所站容器的第一个槽位。

  • /item replace <target> with <item stack> [<count>] - 与旧的replaceitem相同
  • /item replace <target> from <source> [<modifier>] - 将物品从源复制到目标，可选择应用修饰器
  • /item modify <target> <modifier> - 修改物品（不复制）
  • entity <selector> <slot>
  • block <x> <y> <z> <slot>

自定义服务器资源包

  • 专用服务器可以通过在server.properties中设置require-resource-pack来强制使用自定义资源包
    • 使用此选项时，玩家将被提示响应，如果他们拒绝所需的包，将被断开连接
    • 如果用户设置为自动拒绝包，仍会显示提示（因为否则将自动断开连接）
  • 专用服务器还可以配置在资源包提示上显示附加消息（server.properties中的resource-pack-prompt，期望聊天组件语法，可以包含多行）
    • 如果用户已经拒绝了包且不是必需包，则不会显示此消息

此函数现在有add参数。如果为true，更改将相对于当前伤害。如果为false，伤害将被替换为当前值（默认行为）

value_check

检查值的范围。 参数：

  • value - 参见“新的值提供器”部分（当前是随机数生成器和分数的组合）
  • range - 最小/最大范围

新函数

set_banner_pattern

设置旗帜图案所需的标签。 参数：

  • patterns - 图案对象列表：
    • pattern - 图案名称（square_bottom_left、bricks等）
    • color - 颜色名称（light_gray等）
  • append - 如果为true，新元素将附加到现有元素之后，而不是替换它们

set_enchantments

修改物品上的附魔。

参数
  • enchantments - 附魔ID到等级值的映射（可以是分数或随机数）
  • add - 如果为true，更改将相对于当前等级。如果为false，等级将被替换为当前值（默认行为）

新的值提供器

注意：值提供器可以在与随机数生成器相同的地方使用。

score

返回缩放后的计分板数值。

参数
  • score - 计分板名称
  • target - 见下文
  • scale - 缩放因子（浮点数）

  • <target>或{"type": "context", "target": <target>}，其中<target>可以是this、killer、direct_killer、killer_player之一（并非所有上下文都可使用）

客户端 F3+L 快捷键

在游戏中按F3+L将开始录制10秒，捕获诸如tick持续时间、使用的堆大小等指标以及其他更详细的统计信息。 在10秒限制之前按F3+L将提前结束录制。 此快捷键始终对客户端可用，即使在多人服务器上也会记录客户端性能。

专用服务器 perf start/stop 命令

  • perf start将开始录制10秒，捕获诸如tick持续时间、使用的堆大小等指标以及其他更详细的统计信息。
  • 在10秒限制之前perf stop将提前结束录制。
