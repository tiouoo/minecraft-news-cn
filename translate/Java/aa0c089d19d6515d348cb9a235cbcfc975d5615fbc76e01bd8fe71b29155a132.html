大家好！在本周的快照中，我们修复了一些与村庄袭击生成、收纳袋和红石相关的重要漏洞。

祝挖矿愉快！

实验性功能

收纳袋

  • 现在只能通过滚动来在收纳袋中选择物品

开发者备注：在之前的快照中，你可以使用数字键在收纳袋中选择物品。我们移除了这一功能，因为它与高级玩家使用的快捷键冲突，而且现在收纳袋可以显示超过10个物品，这个功能也不再那么有用了。

更改

  • 袭击者必须在村庄中心垂直上方或下方96格以内找到可生成的位置，否则袭击不会开始
  • 现在袭击者袭击时找不到有效生成位置的可能性要小得多

技术性更改

  • 数据包版本现在为51

数据包版本51

  • 字段 normal_config 和 ominous_config 中的试炼刷怪笼配置现在定义在注册表 trial_spawner 中
    • 这使得在数据包中更轻松地自定义试炼刷怪笼配置
    • 仍支持内联配置数据
  • 实体在x轴上的旋转现在被限制在-90到90之间
  • loot 命令现在在尝试从没有战利品表的方块（如空气）掉落物品时会返回错误

战利品表

  • 特殊的战利品表 empty 已被移除，不再定义在原版数据包中

绵羊战利品表

  • 绵羊现在始终使用单一的战利品表 entities/sheep
  • 羊毛掉落仍定义在 entities/sheep/<color> 的子表中，但现在它们只是从主表中分发
    • 注意：羊肉掉落现在由主表控制，而子表只负责羊毛掉落
  • 绵羊剪毛现在由 shearing/sheep 战利品表控制

哞菇剪毛战利品表

  • 哞菇剪毛现在由 shearing/mooshroom 战利品表控制

新条件

sheep 实体子谓词

用于测试绵羊羊毛的新实体子谓词字段：

  • sheared - 可选布尔值
  • color - 可选的羊毛染料颜色
