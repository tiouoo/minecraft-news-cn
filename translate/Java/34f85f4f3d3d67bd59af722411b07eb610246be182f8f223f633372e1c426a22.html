命令

对 /fetchprofile 的更改

  • 新增了一个 entity 子命令，用于打印世界中实体的档案信息
    • 语法：/fetchprofile entity <single entity selector>
    • 如果目标实体没有档案（目前只有玩家和假人有），此命令将失败
    • 请注意，档案会按原样显示——不会进行额外的解析

文本组件

minecraft:selector

  • 字段 selector 不再接受选择器后的尾随数据

minecraft:nbt

  • 当 interpret 字段设置为 false 时，使用 minecraft:nbt 文本组件解析的标签现在会以美化格式打印，而不是被扁平化为单个 text 组件
  • 当解析失败时，nbt 和 block 字段的内容不再被静默拒绝
  • 字段 entity 不再接受选择器后的尾随数据
  • 新增了一个名为 plain 的选项，用于移除美化打印文本的样式
    • plain 和 interpret 选项不能同时启用
