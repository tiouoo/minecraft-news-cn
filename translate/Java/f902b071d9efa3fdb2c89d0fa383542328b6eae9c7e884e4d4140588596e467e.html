周二发快照？是的！从现在开始，我们会将快照的发布日调整到与正式版相同的星期，也就是周二。

本周，我们发布了 2025 年第二个游戏内容更新的首个快照，包括快乐恶魂、幼年恶魂、干恶魂方块和恶魂鞍具。借助快乐恶魂体验全新的飞行玩法，并了解如何养育一只属于你的快乐恶魂——从下界取回干恶魂方块，再到主世界将其浸入水中以生成幼年恶魂。本周，我们也将在 Java 版中加入定位栏，你终于可以在冒险时轻松找到你的朋友了。

和快乐恶魂一起进行首次试飞，制作你自己的干恶魂——并将你的反馈发送给我们！

干恶魂方块

  • 可在下界中找到于下界化石结构中
  • 由 1 个骨块和 8 个恶魂之泪合成
  • 当含水时，它会在约 20 分钟内经历 3 次状态变化，直到生成一个幼年恶魂生物
  • 会根据状态发出声音并显示粒子效果
  • 如果在含水期间被挖掘，无论它在含水过程中达到了什么状态，都会恢复到“干燥”状态
  • 当它不再处于含水状态时，会以相同的时间尺度恢复到初始的“干燥”状态

快乐恶魂生物

幼年恶魂

  • 幼年恶魂是快乐恶魂生物的年轻版本
  • 从持续含水约 20 分钟的干恶魂方块中生成
  • 生成后，幼年恶魂会尝试跟随：
    • 16 格半径内的玩家，或
    • 16 格半径内的成年非水生被动生物（以及一些中立生物）
  • 如果周围没有玩家或合适的生物，幼年恶魂会在其家园位置（生成或最后与之互动的位置）周围 32 格内闲逛
    • 如果它被移动到距离其家园区域边界超过 16 格的位置，它会重置其家园位置
  • 可以使用雪球来引诱和喂食
  • 大约 20 分钟后会长成快乐恶魂（如果喂食雪球则更快）

快乐恶魂

  • 成年快乐恶魂是一种新的飞行坐骑，最多可承载四名玩家
  • 由幼年恶魂在大约 20 分钟后成长而来（如果给幼年恶魂喂食雪球则更快）
  • 可以装备鞍具，然后被最多 4 名玩家骑乘
  • 会被雪球和鞍具引诱
    • 只有在快乐恶魂未装备鞍具时，鞍具引诱才有效
  • 受到伤害时不会进入恐慌状态
  • 无法繁殖
  • 缓慢恢复生命值，在雨天、雪天或在与云层相同高度飞行时，恢复速度会加快
  • 第一个骑上快乐恶魂的玩家将控制它，坐在快乐恶魂的前方，正好在它面部上方
    • 按下前进键将使快乐恶魂朝着玩家注视的方向飞行
    • 按下后退键将使快乐恶魂朝着玩家注视的相反方向飞行
    • 按下左、右键将使快乐恶魂向相应方向侧移
    • 按下跳跃键将使快乐恶魂直接向上飞
    • 按下潜行键将使玩家从快乐恶魂上下来
  • 当玩家骑上时，快乐恶魂的护目镜会降下遮住眼睛，表示现在可以控制它
  • 在第一个玩家驾驶快乐恶魂后骑上的玩家会坐在它两侧的位置，从第一个玩家开始按顺时针方向排列
  • 按下下蹲按钮会使快乐恶魂上方的玩家下来
  • 如果快乐恶魂检测到身上有玩家，它会停止所有移动，并对齐到最近的基本水平方向
  • 无论是否装备鞍具，都会发生这种情况
  • 当玩家骑乘快乐恶魂时，第三人称摄像机会向后移动
  • 当没有玩家骑乘或站在快乐恶魂身上时，护目镜会升起，快乐恶魂开始在家园位置周围游荡
  • 如果玩家在半空中下来，快乐恶魂会在恢复游荡前向地面下降
  • 无法进入船
  • 以与幼年恶魂类似的方式，在其家园位置周围 64 格内闲逛
    • 如果装备了鞍具，快乐恶魂会在离家园位置更近的地方闲逛（32 格内）
  • 快乐恶魂独自游荡时会尽量靠近方块

鞍具物品

  • 鞍具是一种新物品，可以装备在快乐恶魂上，让玩家可以骑乘它

  • 只能装备在快乐恶魂上
  • 允许最多 4 名玩家骑乘快乐恶魂
  • 可以使用剪刀从快乐恶魂上取下，但只能在没有玩家骑乘时进行

定位栏

定位栏是一个实验性的新 UI 元素，用于向玩家显示航点的方向。

  • 此实验允许服务器管理航点及其与玩家的连接
  • 默认情况下，所有玩家都会从自身发送一个航点，并且所有玩家都会接收所有航点；这样玩家就可以在多人游戏中定位其他玩家
  • 当摄像机朝向某个航点的 120 度范围内时，定位栏会显示彩色指示器。如果航点位于摄像机视口（屏幕）的上方/下方，将显示上/下箭头
  • 任何被认定为属于某个队伍的玩家或生物的航点，其颜色指示器将与队伍颜色匹配

属性

添加了 waypoint_transmit_range 和 waypoint_receive_range

  • 默认值：0.0，最小值：0.0，最大值：60000000.0
  • 玩家的默认发送和接收范围为 60,000,000
  • 发送范围大于零的生物会向附近的接收者发送航点数据包
  • 同样，接收者只在范围大于零时接收，且无法接收此范围之外的航点

waypoint 命令

这是一个用于查询和修改航点的新命令。

waypoint list

waypoint modify <entity-selector> color <color>
waypoint modify <entity-selector> color hex <hex-color>
waypoint modify <entity-selector> color reset
waypoint modify <entity-selector> fade <fade_start> <alpha_start> <fade_end> <alpha_end>
waypoint modify <entity-selector> fade reset

参数：

  • entity-selector：用于选择作为航点发送的实体（参见 waypoint_transmit_range 属性）
  • color：覆盖此航点的定位栏图标颜色
  • hex <hex-color> 参数采用网页格式（RRGGBB）
    • 红色可以是 hex F00 或 hex FF0000
    • 矢车菊蓝是 hex 6495ED
  • fade：设置航点的淡出效果
    • 参数 <fade_start> <alpha_start> <fade_end> <alpha_end> 处理开始/结束淡出距离和 alpha 不透明度
      • *_start 是近处的值（离玩家最近）
      • *_end 是远处的值（离玩家最远）
    • reset 将恢复远处定位栏图标淡出至 0.2 alpha 的默认行为

命令

添加了 version

  • 无参数
  • 在服务端打印当前版本信息
  • 在单人游戏或服务器管理员中可用

添加了 datapack create

  • 为当前世界创建一个新的空目录数据包
  • 支持的包版本始终与游戏支持的版本一致
  • 仅对服务器所有者可用
  • 语法：datapack create <id> <name>
    • id - 新包名称，必须是有效的目录名
    • name - 将放入 pack.mcmeta 中 description 的文本组件

属性

添加了 camera_distance

  • 默认值：4.0
  • 修改第三人称视角下摄像机与玩家或被旁观实体之间的距离
  • 如果被骑乘的实体具有更大的 camera_distance 属性，则使用该距离
  • 该距离会与 scale 属性相乘，以得到最终的摄像机目标距离

数据组件

attribute_modifiers 物品组件

  • 为 attributes_modifiers 条目添加了可选的 display 字段
    • 有 3 种 display 类型：
      • default - 当前行为，在物品提示中显示计算出的属性修饰符值
      • hidden - 不显示属性修饰符条目
      • override - 替换显示的属性修饰符文本
        • 包含一个单独的 value 字段，用于设置此属性修饰符条目要显示的文本内容
