本周的快照引入了数据包中自定义生物群系的实验性支持。这项工作涉及重新处理一些幕后的内部管线，所以可能有点“漏水”。我们希望没有重要的部件滴漏出来，但如果真的漏了，请帮我们捡起来。

一如既往，如果你在快照中尝试世界，请务必进行备份。

20w28a 中的更改

​

  • 村民在加入村庄、认领床或获得工作站/职业时现在会发出绿色粒子。
  • 酿造台现在可以用黑石合成。
  • 调整了以物易物的战利品。
  • 不死图腾在激活时现在会提供 40 秒的抗火状态效果。

​

20w28a 中的技术更改

​

  • 自定义世界现在支持自定义生物群系。
  • 专用服务器现在可以对客户端进行速率限制。

​

自定义世界生成

​

  • 现在对数据包中的 worldgen 文件夹提供了实验性支持。
  • worldgen/biome 可以包含生物群系定义。
  • worldgen/configured_carver 可以包含世界雕刻器设置的的定义。
  • worldgen/configured_feature 可以包含地物放置的定义。
  • worldgen/configured_structure_feature 可以包含结构放置的定义。
  • worldgen/configured_surface_builder 可以包含地表定义。
  • worldgen/processor_list 可以包含方块处理器的集合。
  • worldgen/template_pool 可以包含用于拼图结构的池定义。
  • 自定义生物群系现在可以用于单一生物群系/洞穴/浮空岛世界类型（请先添加包含该生物群系的数据包）。
  • 自定义生物群系现在可以用于自定义维度生成器中。

​

专用服务器数据包限制

​

  • 专用服务器现在可以踢出在一秒内持续发送过多数据包的客户端。
  • 通过 server.properties 中的 rate-limit 设置进行控制。
  • 默认速率限制为 0，表示“无限制”。

​
