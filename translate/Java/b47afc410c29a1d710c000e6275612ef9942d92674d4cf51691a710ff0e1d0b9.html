数据包版本 99

世界存储

  • 所有默认维度现在都存储在dimensions子文件夹中
    • 主世界的数据已从根文件夹移至dimensions/minecraft/overworld
      • 这包括region、entities和poi文件夹，以及来自data的相关文件
    • 下界的数据已从DIM-1移至dimensions/minecraft/the_nether
    • 末地的数据已从DIM1移至dimensions/minecraft/the_end
    • 顶层data文件夹现在仅用于跨维度共享的数据，而不再同时用于主世界
  • 玩家数据存储已移至players子目录
    • advancements -> players/advancements
    • playerdata -> players/data
    • stats -> players/stats
  • 世界资源包（resources.zip）已移至resourcepacks子目录
  • 保存在data文件夹中的数据现在具有命名空间
    • 这意味着所有数据现在都将存储在相应data文件夹中的命名空间子文件夹内
      • 所有现有的原版数据文件都已相应移动
      • 例如：data/scoreboard.dat -> data/minecraft/scoreboard.dat
    • 命令存储现在存储在命名空间子文件夹中，而不是带有命名空间后缀
      • 例如：data/command_storage_foo.dat -> data/foo/command_storage.dat
    • chunks.dat已更名为chunk_tickets.dat
    • 地图数据现在存储在data/minecraft/maps子文件夹中
      • 地图索引文件已重命名为仅包含数字
        • 例如：map_1.dat -> 1.dat
      • idcounts.dat已更名为last_id.dat
    • 不再有raids_end.dat特例
    • 末地现在也使用raids.dat
  • 由结构方块保存的结构已从generated/namespace/structures移至generated/namespace/structure

世界生成

  • 基于规则的方块状态提供器已更改，其fallback现在是可选的，并且可以为空
  • 在调用空fallback的情况下，使用它们的地物将不会放置任何内容
  • 当前使用基于规则的方块状态提供器的配置是disk地物中的state_provider
  • forest_rock地物被重命名为block_blob
  • block_blob地物配置已更改以支持以下参数：
    • state构成岩石的方块
    • can_place_on一个方块谓词，定义岩石可以放置在哪些方块上
  • ice_spike地物被重命名为spike
  • spike地物配置现在支持以下参数：
    • state构成尖刺的方块
    • can_place_on一个方块谓词，定义尖刺可以放置在哪些方块上
    • can_replace一个方块谓词，定义尖刺可以替换哪些方块
  • huge_red_mushroom和huge_brown_mushroom地物配置有一个新参数：
    • can_place_on一个方块谓词，定义巨型蘑菇可以放置在哪些方块上
  • alter_ground树木装饰器配置已更改，provider现在是一个基于规则的方块状态提供器
  • tree地物配置已将force_dirt和dirt_provider参数替换为一个below_trunk_provider基于规则的方块状态提供器：
    • 格式：
      • fallback - 一个可选的方块状态提供器
      • rules - 规则列表
        • if_true - 一个方块谓词，在提供方块之前检查方块位置
        • then - 一个方块状态提供器
    • 默认值：
      "below_trunk_provider": {
    "rules": [
        {
            "if_true": {
                "type": "minecraft:not",
                "predicate": {
                    "type": "minecraft:matching_block_tag",
                    "tag": "minecraft:cannot_replace_below_tree_trunk"
                }
            },
            "then": {
                "type": "minecraft:simple_state_provider",
                "state": {
                    "Name": "minecraft:dirt"
                }
            }
        }
    ]
}
    • 之前使用force_dirt的任何树木现在都有一个始终提供dirt方块的below_trunk_provider
