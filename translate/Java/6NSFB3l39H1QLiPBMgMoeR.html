Minecraft Java Edition 1.16.2 的预发布版来了！

从现在起，你们应该会看到大部分漏洞修复，直到 1.16.2 正式发布，预计会在几周后到来。

1.16.2 预发布版 1 的新内容

  • 新增了辅助功能设置，以帮助提升视觉舒适度

辅助功能

  • 现在可以减少诸如反胃和下界传送门覆盖层等扭曲效果
  • 在较低数值下，反胃效果会替换为绿色覆盖层，作为替代视觉呈现
  • 现在可以减少应用速度效果后显示的视野（FOV）效果

1.16.2 预发布版 1 的更改

  • 锁链现在可以在所有方向上放置
  • 末影人不再会将其手持的方块放置在基岩方块上
  • 猪灵现在会对打开或破坏箱式矿车的玩家发怒
  • 村民现在在切换维度时会失去其工作站点
  • 聊天设置界面中新增了聊天延迟选项

1.16.2 预发布版 1 的技术性更改

  • 自定义世界生成和维度设置现在在数据包中使用与其他资源相同的文件夹模式（namespace/<type>/resource.json）
