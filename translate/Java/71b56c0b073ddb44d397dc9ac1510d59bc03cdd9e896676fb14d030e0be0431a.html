物品堆叠组件

在这个快照中，我们对物品堆叠特定属性的存储和表示方式进行了较大更改，用结构化组件取代了当前的 NBT 'tag'。

进行此更改是为了：

  • 提高游戏需要频繁查找物品属性的场景中的性能（例如盔甲纹饰每帧渲染）
  • 在加载时验证物品属性，以便更容易识别命令和数据包中的无效数据
    • 这应避免在命令中指定自定义物品数据时出现任何“静默”损坏，以应对未来任何可能的格式变更
  • 继续发展游戏，以支持创建动态内容

我们理解，这对于许多数据包和自定义地图来说是一次重大的破坏性变更，需要付出大量努力来升级。

但我们确实相信，这为未来的可扩展性奠定了关键基础。我们精心安排了一次性发布这些更改，希望避免未来因渐进式变更而需要对包进行许多小更新。

当前的 NBT 'tag' 已经存在相当长的时间，我们意识到，人们已经利用它在命令和数据包中开发出了许多巧妙的技术。

尽管我们已尽最大努力识别这些情况，但其中一些技术依赖于某些标签配置的未记录或未定义行为。

我们希望确保任何功能都不会在没有合适替代方案的情况下丢失，但由于这些技术未被记录，我们很可能未能覆盖所有情况！

我们希望在这个快照周期的剩余时间内解决所有回归问题。

对于如此大的更改，我们非常重视您的反馈！您可以在反馈网站上分享您对这些更改的想法：让我们来谈谈物品堆叠组件！。

  • 附加在物品堆叠上的非结构化 NBT 数据（tag 字段）已被结构化的“components”取代
    • 该数据会在物品加载时被解析和验证
    • 这应能提高某些场景（如盔甲纹饰渲染）中的性能，因为在这些场景中，物品数据曾频繁被比较、请求和解析
    • 自定义数据仍可存储在 minecraft:custom_data 组件中
  • 物品类型（例如 minecraft:stick）在物品上持有一组默认组件，单个物品堆叠可以覆盖这些组件
  • 序列化物品和数据包中物品的格式已更新，以保持一致并支持组件
  • 命令中的物品语法已更新以支持组件
  • 启用高级提示框（F3+H）时，将显示组件数量而不是标签数量
  • 物品的默认组件值现在列在 reports 目录下生成的 items.json 中
  • 村民交易中的 ignoreTags 字段已被移除，取而代之的是基于伤害的组件谓词
  • 方块定义现已添加到 blocks.json 报告中（注意：这些定义尚未使用，仅用于提供信息）
  • 如果宝库方块的 key_item 字段不存在，则无法解锁宝库

minecraft:custom_data

  • 可用于在物品上存储自定义数据
  • 可在命令中使用现有的标签语法（{...}）访问
    • 在谓词（例如 /clear）中，将像当前一样进行部分匹配
  • 升级世界时，物品 tag 中的任何非游戏数据都将移入此处
  • 格式：包含任意字段的对象
    • 例如 custom_data={some:'data'}

minecraft:damage

  • 从物品中扣除的耐久度
  • 如果移除该组件，物品将不再具有耐久损耗
  • 取代 Damage 标签
  • 格式：非负整数
    • 例如 damage=12
  • 对于可损耗物品，隐式默认值为：0

minecraft:repair_cost

  • 在铁砧上修改物品所需的额外经验值成本
  • 取代 RepairCost 标签
  • 格式：非负整数
    • 例如 repair_cost=12
  • 如果未设置，隐式默认值为：0

minecraft:unbreakable

  • 如果设置，物品在使用时不会损失任何耐久度
  • 取代 Unbreakable 布尔标签
  • 格式：包含字段的对象
    • show_in_tooltip：布尔值（默认：true）
      • 如果为 true，提示框中将显示“不可破坏”一行
      • 取代 HideFlags 标签的第 3 位
    • 例如 unbreakable={}、unbreakable={show_in_tooltip:false}

minecraft:enchantments

  • 在物品上存储附魔列表及其等级
  • 取代 Enchantments 标签
  • 格式：包含字段的对象
    • levels：附魔（ID 字符串）到等级（整数 [0; 255]）的对象
    • show_in_tooltip：布尔值（默认：true）
      • 如果为 false，物品提示框中将不显示任何附魔
      • 取代 HideFlags 标签的第 1 位
    • 例如 enchantments={levels:{'minecraft:protection':2},show_in_tooltip:false}
  • 如果未设置，隐式默认值为：{levels:{}}

minecraft:stored_enchantments

  • 存储附魔书的附魔列表及其等级
  • 附魔提供的效果不会由此组件生效
  • 取代附魔书上的 StoredEnchantments 标签
  • 格式：与 minecraft:enchantments 相同
    • show_in_tooltip 值取代 HideFlags 标签的第 6 位
  • 对于附魔书，隐式默认值为：{levels:{}}

minecraft:custom_name

  • 物品的自定义名称覆盖
  • 取代 display.Name 标签
  • 格式：JSON 聊天组件字符串
    • 例如 custom_name='{"text": "This item is renamed!", "color": "red"}'

minecraft:lore

  • 要包含在物品提示框中的额外行
  • 取代 display.Lore 标签
  • 格式：JSON 聊天组件字符串列表（最多：64 条）
    • 例如 lore=['{"text": "The cake is a lie!"}']
  • 如果未设置，隐式默认值为：[]

minecraft:can_break

  • 控制冒险模式玩家可以使用此物品破坏哪些方块
  • 取代 CanDestroy 标签
    • 这些此前以平面字符串存储，但现在使用战利品表和进度中已使用的更灵活的方块谓词格式
  • 格式：包含字段的对象
    • predicates：方块谓词列表
      • blocks：方块、方块列表或带哈希前缀的方块标签
      • nbt：要匹配的方块实体 NBT
      • state：状态属性键到要匹配值的映射
    • show_in_tooltip：布尔值（默认：true）
      • 取代 HideFlags 标签的第 4 位
    • 例如 can_break={predicates:{blocks:'minecraft:furnace',state:{facing:'north'}}
    • 或者，可以用单个方块谓词表示
      • 例如 can_break={blocks:'minecraft:stone'}

minecraft:can_place_on

  • 控制冒险模式玩家可以使用此物品在哪些方块上放置
  • 取代 CanPlaceOn 标签
  • 格式：包含字段的对象
    • predicates：方块谓词列表
      • 与 can_break.predicates 相同
    • show_in_tooltip：布尔值（默认：true）
      • 取代 HideFlags 标签的第 5 位
    • 例如 can_place_on={predicates:{blocks:'minecraft:furnace',state:{facing:'north'}}
    • 或者，可以用单个方块谓词表示
      • 例如 can_place_on={blocks:'minecraft:stone'}

minecraft:dyed_color

  • 表示应用于可染色物品（#minecraft:dyeable 标签）的颜色
  • 取代 display.color 标签
  • 格式：包含字段的对象
    • rgb：整数，RGB 值
    • show_in_tooltip：布尔值（默认：true）
      • 取代 HideFlags 标签的第 7 位
    • 例如 dyed_color={rgb:16711680}

minecraft:attribute_modifiers

  • 保存应用于任何物品的属性修饰符
  • 取代 AttributeModifiers 标签
  • 格式：包含字段的对象（默认：{modifiers:[]}）
    • modifiers：属性修饰符列表
      • type：属性 ID
        • 取代 AttributeName
      • slot：以下之一：
        • any（默认）
        • hand：主手或副手（新）
        • armor：任意盔甲栏（新）
        • mainhand
        • offhand
        • head
        • chest
        • legs
        • feet
        • 修饰符仅在物品装备到指定栏位时生效
        • 取代 Slot
      • uuid：UUID，唯一表示此修饰符
        • 具有相同 ID 的修饰符只能存在一个
        • 取代 UUID
      • name：字符串，人类可读的名称
        • 取代 Name
      • amount：双精度浮点数，修改此属性的单位数（由 operation 控制）
        • 取代 Amount
      • operation：以下之一：
        • add_value（原 0）：将 amount 加到属性上
        • add_multiplied_base（原 1）：将 amount * 基础值加到属性上
        • add_multiplied_total（原 2）：将 amount * 总值（来自之前所有修饰符）加到属性上
        • 用整数 ID 取代 Operation
    • show_in_tooltip：布尔值（默认：true）
      • 取代 HideFlags 标签的第 2 位
    • 例如 attribute_modifiers={modifiers:[type:'minecraft:generic.scale',uuid:[1,2,3,4],name:'Big!',amount:1.0,operation:'add_multiplied_base']}
  • 如果未设置，隐式默认值基于物品类型的默认属性（例如武器的攻击伤害）

minecraft:charged_projectiles

  • 保存已装入弩的所有弹射物
  • 如果不存在，则弩未装填
  • 取代 Charged 和 ChargedProjectiles 标签
  • 格式：物品堆叠列表
    • 例如 charged_projectiles=[{id:'minecraft:arrow'}]
    • 不再限制为 3 个条目

minecraft:intangible_projectile

  • 标记弹射物物品在发射时为无形状态（即只能被创造模式玩家捡起）
  • 仅当物品位于弩的 charged_projectiles 组件中时设置
  • 格式：空对象
    • 例如 intangible_projectile={}

minecraft:bundle_contents

  • 保存收纳袋中存放的所有物品
  • 如果移除，物品将无法加入收纳袋
  • 取代 Items 标签
  • 格式：物品堆叠列表
    • 例如 bundle_contents=[{id:'minecraft:poisonous_potato'}]
  • 对于收纳袋，隐式默认值为：[]

minecraft:map_color

  • 表示已填充地图物品上装饰的色调
  • 取代 display.MapColor 标签
  • 格式：整数，RGB 值
    • 例如 map_color=16711680
  • 对于已填充地图，隐式默认值为：4603950

minecraft:map_decorations

  • 保存要放置在已填充地图上的标记列表（用于探险家地图）
  • 取代 Decorations 标签
  • 格式：唯一装饰 ID 到装饰的映射
    • type：以下之一：
      • player（原 0）
      • frame（原 1）
      • red_marker（原 2）
      • blue_marker（原 3）
      • target_x（原 4）
      • target_point（原 5）
      • player_off_map（原 6）
      • player_off_limits（原 7）
      • mansion（原 8）
      • monument（原 9）
      • banner_white（原 10）
      • banner_orange（原 11）
      • banner_magenta（原 12）
      • banner_light_blue（原 13）
      • banner_yellow（原 14）
      • banner_lime（原 15）
      • banner_pink（原 16）
      • banner_gray（原 17）
      • banner_light_gray（原 18）
      • banner_cyan（原 19）
      • banner_purple（原 20）
      • banner_blue（原 21）
      • banner_brown（原 22）
      • banner_green（原 23）
      • banner_red（原 24）
      • banner_black（原 25）

minecraft:map_id

  • 引用保存已填充地图内容和标记的共享地图状态
  • 取代 map 标签
  • 格式：整数 ID
    • 例如 map_id=1

minecraft:custom_model_data

  • 可用于通过物品模型中的 minecraft:custom_model_data 属性来替换物品模型
  • 取代 CustomModelData 标签
  • 格式：整数值
    • 例如 custom_model_data=43

minecraft:potion_contents

  • 保存药水（药水、喷溅药水、滞留药水）的内容，或应用于物品的药水（药箭）
  • 取代 Potion、CustomPotionColor 和 custom_potion_effects 标签
  • 格式：包含字段的对象
    • potion：药水 ID（可选）
      • 此物品中的药水类型：物品将继承其所有效果
    • custom_color：整数，RGB 值（可选）
      • 覆盖药水的视觉颜色
    • custom_effects：效果实例列表（默认：[]）
      • 此物品应应用的额外自定义效果列表，这些效果可能无法由现有药水表示
    • 例如 potion_contents={potion:'minecraft:invisibility',custom_color:16711680}
  • 对于药水或药箭物品，隐式默认值为：{}

minecraft:writable_book_contents

  • 保存书与羽毛笔中的内容
  • 取代 pages 和 filtered_pages 标签
    • 页面列表直接映射，使用 {text:'...'} 包装
    • filtered_pages 通过索引键拉取到 filtered 字段下的相应页面条目中
  • 格式：包含字段的对象
    • pages：以下之一组成的列表：
      • 包含字段的对象
        • text：字符串，页面的纯文本内容
        • filtered：字符串，过滤后的页面内容（可选）
          • 如果指定，启用聊天过滤的玩家将看到此页面而不是 text
      • 或：字符串，页面的纯文本内容
    • 例如 writable_book_contents={pages:[{text:'Hello world!'}]}
  • 对于书与羽毛笔，隐式默认值为：{pages:[]}

minecraft:written_book_contents

  • 保存成书的内容和元数据
  • 取代 pages、filtered_pages、title、filtered_title、author、generation 和 resolved 标签
  • 格式：包含字段的对象
    • pages：列表
      • 与 writable_book_contents 页面格式相同，但使用可格式化的 JSON 聊天组件字符串
    • title：过滤字符串（与页面格式相同）
    • author：字符串，玩家名称
    • generation：整数 [0; 2]
      • 这本书被复制的次数（0 = 原稿）
    • resolved：布尔值
      • 如果这本书中的聊天组件已被解析（实体选择器、计分板分数已替换），则为 true
      • 如果为 false，将在玩家打开时解析
    • 例如 written_book_contents={pages:[{text:'Hello world!'}],title:{text:'A delightful read'},author:'Herobrine',generation:1,resolved:true}

minecraft:trim

  • 保存应用于物品的纹饰
    • 该组件的存在不再受 #minecraft:trimmable_armor 标签限制（尽管该标签仍用于配方）
  • 取代相同格式的 Trim 标签
  • 格式：包含字段的对象
    • pattern：图案 ID（或内联图案）
    • material：材料 ID（或内联材料）
    • show_in_tooltip：布尔值（默认：true）
      • 取代 HideFlags 标签的第 8 位
    • 例如 trim={pattern:'minecraft:silence',material:'minecraft:redstone'}

minecraft:suspicious_stew

    • 例如 suspicious_stew=[{id:'minecraft:poison'}]
  • 对于可疑炖菜，隐式默认值为：[]

minecraft:hide_additional_tooltip

  • 取代 HideFlags 标签的第 6 位
  • 格式：空对象

minecraft:debug_stick_state

命令

  • 诸如 /give、/item、/loot 和 /clear 等命令已更新物品语法
  • 现在可以在方括号中的物品名称后指定组件
    • 组件使用 = 赋值（例如 wooden_pickaxe[damage=23]）
    • 组件以逗号分隔（例如 netherite_hoe[damage=5,repair_cost=2]）
  • 组件类型会自动补全，但值本身不会
  • 但值会被验证，如果组件指定不正确，命令将解析失败
    • 例如 /give @s wooden_pickaxe[damage=-34] 无效
  • 现有的 NBT 语法（{...}）被重新接线为设置或匹配 minecraft:custom_data 组件
    • 例如 /give @s stick{foo:'bar'} 等同于 /give @s stick[custom_data={foo:'bar'}]
    • 如果同时指定了 [...] 和 {...}，则 [...] 必须排在 {...} 之前
  • /clear 中的物品谓词参数在匹配组件和自定义数据方面具有新的语义
    • 每个指定的组件都必须存在于目标物品上，并且解析后的值必须完全相等
    • 具有默认值的组件（例如默认 damage=0）如果未指定，将被假定存在于目标物品上
      • 因此，/clear @s diamond_pickaxe[damage=0] 将只匹配未损坏的钻石镐
      • 另一方面，/clear @s diamond_pickaxe 将匹配任何钻石镐，无论其损坏程度如何
    • 即使对于 minecraft:custom_data 组件，也适用组件值的精确匹配
    • 但是，使用 {...} 自定义数据语法将使用现有的 NBT 部分匹配行为
      • 这要求谓词中指定的所有标签都存在于目标物品上，但额外的标签可能被忽略
      • 目标中的列表必须包含谓词中指定的所有项目，但可以包含额外项目，且忽略顺序
  • /attribute 命令中的修饰符操作已重命名：
    • add -> add_value
    • multiply_base -> add_multiplied_base
    • multiply -> add_multiplied_total

物品堆叠格式

  • 除了组件导致的格式更改外，磁盘和数据包中物品堆叠的结构也已更新以保持一致
  • 之前的 id（字符串）和 Count（字节）字段已被 id（命名空间字符串）和 count（整数）字段取代
    • 此格式还应用于进度中的 icon 字段、聊天组件悬停事件中的物品，以及烧炼配方中的 result 字段（result 和 count 不再内联）
  • count 字段是可选的（默认为 1），如果为默认值则不再存储
    • 堆叠数量现在限制为物品的最大堆叠数量
  • tag 字段已被移除，升级时任何剩余内容最终都会放入 minecraft:custom_data 组件中
  • 新的 components 字段存储附加到物品上的所有组件
    • 格式：组件 ID 到组件值的映射（因组件 ID 而异）
      • 例如 {..., components: {'minecraft:damage': 12}}
      • 带有 ! 前缀的组件（例如 "!minecraft:damage": {}）将导致该组件被移除
    • 等于默认值的组件将不会被存储
  • 物品堆叠格式不再表示空堆叠（air 物品或 count 为 0）
    • 相反，在支持的地方，应省略该字段
    • 在某些情况下，例如堆叠列表（如生物实体中的 HandItems），使用空映射（{}）表示空堆叠

其他格式更改

  • 药箭不再存储其应用的药水效果
    • 这改为从其持有的 item 获取
  • 区域效果云现在以 potion_contents 字段存储药水，格式与 minecraft:potion_contents 组件相同：
    • Potion -> potion_contents.potion
    • Color -> potion_contents.custom_color
    • effects -> potion_contents.custom_effects
  • 旗帜现在以 patterns 字段存储应用的图案，格式与 minecraft:banner_patterns 组件相同：
    • Patterns[].Pattern（字符串短 ID） -> patterns[].pattern（字符串图案注册表 ID）
    • Patterns[].Color（整数染料 ID） -> patterns[].color（字符串染料名称）
  • 蜂箱格式也已更新：
    • Bees[].EntityData -> bees[].entity_data
    • Bees[].TicksInHive -> bees[].ticks_in_hive
    • Bees[].MinOccupationTicks -> bees[].min_ticks_in_hive
    • FlowerPos -> flower_pos
  • 村民交易可以配置为通过选择 'minecraft:damage': 0 仅接受未损坏的物品
    • 默认情况下，如果未指定组件，则接受任何物品（类似于物品谓词中的 components 字段）
