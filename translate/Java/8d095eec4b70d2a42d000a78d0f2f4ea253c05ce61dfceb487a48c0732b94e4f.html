又是一个星期二，又一个快照版本发布！除了技术更新和漏洞修复外，本周我们还带来了今年第三次游戏更新中的一组铜制好物：用铜火把、铜灯笼、铜锁链和铜栏杆进行建造，并看着它们逐渐形成那令人惊叹的标志性铜绿。在本周的版本中，你还会发现陈列架上展示的物品学会了坐下的高尚艺术。

祝挖矿愉快！

新特性

  • 添加了铜制装饰方块

铜制装饰

  • 添加了铜火把
    • 由铜粒、煤炭和木棍合成的火把的绿色变种
    • 功能与火把相同
  • 添加了铜栏杆
    • 功能与现有铁栏杆方块相同
    • 由铜制成，并会随时间氧化
  • 添加了铜锁链
    • 功能与现有锁链方块（现已更名为铁锁链）相同
    • 由铜制成，并会随时间氧化
  • 添加了铜灯笼
    • 合成方式与普通灯笼类似，但使用铜和铜火把
    • 灯笼本身会氧化，随时间改变外观
    • 功能与灯笼相同

更改

  • 锁链方块已更名为“铁锁链”

方块、物品和实体的小调整

  • 陈列架上的物品已重新定位，使其“坐”在陈列架上
  • 所有铜傀儡雕像现在被挖掘时总是以物品形式掉落
  • 所有铜傀儡雕像现在被活塞推动时都会以物品形式弹出

配方

  • 改变了铜活板门的配方，现在使用 4 个铜锭而不是 6 个

技术性更改

文本渲染

object 文本组件

  • 添加了类型为 object 的新文本组件
  • 该组件会将精灵图集中的单个精灵图显示为一个字符
  • 精灵图始终渲染为 8x8 像素的矩形
  • 格式：
    • atlas - 精灵图集的命名空间 ID，默认值：minecraft:blocks
    • sprite - 精灵图集中精灵图的命名空间 ID，例如 item/porkchop

关于精灵图集内容的通用说明：

  • 精灵图集包含物品、方块、生物效果、GUI 元素等的纹理
  • 内容由资源包中 assets/minecraft/atlases/ 目录下的文件控制
  • 当前内容可通过 F3+S 键组合查看
