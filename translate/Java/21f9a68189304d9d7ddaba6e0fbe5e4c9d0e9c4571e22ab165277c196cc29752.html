UI

  • 移除了原始输入鼠标设置

  • 键位绑定现在使用物理按键，而非特定于键盘布局的键码

  • 调试叠加层现在支持与游戏其他部分独立的 GUI 缩放比例
  • 可通过调试选项界面（F3 + F6）自定义

  • 另一个选项是“不变”，与你的常规 GUI 缩放比例一致
  • 其余选项与常规“GUI 缩放比例”中的相同，直接控制缩放比例
  • 添加了“player_speed”调试条目，以每 tick 的方块数显示玩家的速度
  • 调试叠加层现在会显示显示器刷新率

环境属性

新增 minecraft:gameplay/natural_mob_spawns

  • 在环境属性源中定义生物生成
  • 在世界生成阶段，只有维度（Dimension）和生物群系（Biome）会应用此环境属性
  • 格式：具有以下字段的对象：
    • spawns_by_category - 生成类别到加权生成数据列表的映射
      • 生成数据格式：具有以下字段的对象：
        • type - 实体类型，要生成的实体
        • count - int provider，生成数量
    • spawn_costs - 实体类型到具有以下字段的对象的映射：
      • energy_budget - float，每次生成允许的能量变化
      • charge - float，现有生物对其他带电生物的吸引或排斥程度
  • 可用的属性修饰器：
    • overlay
      • 对于每个生物类别，将较低层的生成设置替换为较高层的设置，除非该类别未包含在内
      • 将每一层的生成成本合并在一起，如果两层都定义了相同的实体类型，则以较高层的生成成本覆盖较低层的
  • 默认值：空

新增 minecraft:gameplay/creature_world_gen_spawn_probability

  • 设置在世界生成期间运行一次迭代的概率，在该迭代中，定义为在 creature 生物类别中生成的生物将会生成
  • 只有维度（Dimension）和生物群系（Biome）会应用此环境属性
  • 格式：[0,1) 范围内的 float
  • 默认值：0.1

更改了 minecraft:visual/ambient_particles

  • 现在支持在时间线关键帧之间进行插值（概率将交叉淡化）
  • 引入了对新修饰器的支持：append
    • 与完全替换粒子列表的 override 不同，此修饰器会将所有元素与下方各层连接起来

数据组件

新增 minecraft:cooking_fuel

  • 描述可用作熔炉、烟熏炉或高炉燃料的物品
  • 格式：具有以下字段的对象：
    • burn_time - 指向 minecraft:number_provider 注册表元素的命名空间 ID，表示该燃料燃烧的时间（以 tick 为单位）
    • speed_multiplier - 指向 minecraft:number_provider 注册表元素的命名空间 ID，表示烹饪/熔炼的速度

新增 minecraft:brewing_fuel

  • 描述可用作酿造台燃料的物品
  • 格式：具有以下字段的对象：
    • uses - 指向 minecraft:number_provider 注册表元素的命名空间 ID，表示该燃料在被消耗前可酿造的次数
    • speed_multiplier - 指向 minecraft:number_provider 注册表元素的命名空间 ID，表示酿造速度
  • 注意：#brewing_fuel 物品标签已被移除，将不再用于注册新的酿造燃料

新增 minecraft:sign_text_front 和 minecraft:sign_text_back

  • 两个相同的组件，分别表示告示牌正面和背面的文字
  • 内容将显示在物品提示框中
  • 格式与 minecraft:sign 和 minecraft:hanging_sign 方块实体上的 front_text 和 back_text 字段相同，即：
    • messages - 文本组件列表
    • filtered_messages - 可选的文本组件列表，如果省略，将设置为与 messages 相同的值
      • messages 和 filtered_messages 必须具有相同的条目数
    • color - 可选染料颜色，默认值：black
    • has_glowing_text - 可选布尔值，默认值：false

新增 minecraft:waxed

  • 用于标记内容已涂蜡的方块
  • 无字段

新增 minecraft:cushion/color

  • 当使用物品放置坐垫实体时，应用于坐垫实体
  • 格式：16 种染料颜色之一

新增 minecraft:villager_food

表示村民可以食用的物品。村民除了会拾取 #villager_picks_up 标签中的物品外，还会拾取带有此组件的物品。

  • 格式：具有以下字段的对象：
    • nutrition - 正整数，表示村民食用后该物品能恢复多少饥饿度

新增 minecraft:mob_visibility

表示带有相应 minecraft:equippable 组件的物品所提供的可见性百分比，用于修改生物能够探测到实体的范围

  • 格式：具有以下字段的对象：
    • targeting_entity - 要匹配的实体 ID、命名空间实体 ID 列表或带 # 前缀的实体标签
    • visibility - float（介于 0.0 和 10.0 之间），0.0 会将生物探测实体的范围缩小到 2 个方块，而 10.0 会将探测范围扩大十倍
      • 虽然带有此组件的多个物品会叠加，但最大视野仍不会超过 10.0

  • multiple - 密度函数，输出将舍入为此值的整数倍
    • 如果未指定，默认为常量 1（即舍入到整数）
