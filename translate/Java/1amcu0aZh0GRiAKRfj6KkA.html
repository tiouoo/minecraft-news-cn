《我的世界》1.20：踪迹与故事更新的首个预发布版本现已到来！

从现在开始，更新内容将以漏洞修复为主。另外，预发布版本不再遵循每周三快照的常规发布节奏，请持续留意后续预发布版本。

一如既往，非常感谢社区提供的反馈、提交的漏洞报告以及一系列快照开发周期中各种精彩创意。预发布阶段正式开启！

改动内容

  • 各色羊毛、地毯与床现在可以直接染成其他任意颜色

技术性改动

  • 新增伤害类型：outside_border 和 generic_kill
  • 战利品表的随机序列现在具备确定性
  • 调整 server.properties 文件编码相关逻辑
  • data 命令的字符串数据源现支持负数边界值，代表从字符串末尾向前计数索引

伤害类型

  • 处于世界边界外的玩家受到的伤害类型由 in_wall 改为 outside_border
  • 使用 /kill 等方式强制移除实体时，伤害类型由 out_of_world 改为 generic_kill

战利品表随机序列

游戏现在使用命名随机序列，让战利品表的生成结果具备确定性。每条随机序列依据世界种子与序列ID生成独有的随机数列，意味着在同一个世界、相同参数下运行同一份战利品表，产出结果保持一致。

战利品表需要使用的随机序列ID，在新增字段 random_sequence 中指定。

server.properties

  • 文件优先以 UTF-8 编码读取，读取失败时回退使用旧编码（ISO 8859-1/Latin 1）
  • 文件写入时统一采用 UTF-8 编码
