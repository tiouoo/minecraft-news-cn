数据包版本 118

命令

添加 `compute`

  • 在各种上下文中评估 `minecraft:number_provider`
  • 在所有上下文中，`origin` 设置为当前命令上下文位置，而 `this` 实体设置为 `@s`

语法：

  • /compute <target> <provider> [<scale>|integer]，其中：
    • <target> - 以下之一：
      • default - 在 `minecraft:command_compute_default` 上下文中运行提供器，该上下文只提供公共参数（位置和 `this` 实体）
      • block <pos> - 在 `minecraft:command_compute_position` 上下文中运行提供器，其中方块状态和方块位置基于位置 `<pos>` 处的方块设置
      • entity <entity selector> - 在 `minecraft:command_compute_entity` 上下文中运行提供器，其中 `target_entity` 设置为选择器结果
    • <provider> - 可以是 `minecraft:number_provider` 注册表中的一个元素，或内联值
    • <scale> - 可选比例值，默认值为 `1.0`
      • 最终结果将乘以 `<scale>` 并向负无穷取整
    • integer - 用于整数模式的可选标记
      • 由于中间步骤之间的截断，即使比例为 `1.0`，此模式也不等同于浮点模式

对 `data` 的更改

  • 向 `/data modify ... append|insert|merge|prepend|set` 添加了名为 `compute` 的新来源
  • 新来源将评估一个 `minecraft:number_provider`，然后以整数或浮点标签形式提供结果
  • 语法：compute <target> <provider> [integer]，其中 `target`、`provider` 和 `integer` 的语法与 `/compute` 函数中的相同
  • 示例：/data modify storage foo bar set compute entity @n[type=minecraft:armor_stand] {type:score,target:{type:context,target:target_entity},score:baz}

方块转换器

  • 添加了包含将方块转换为另一个方块规则的 `minecraft:block_transformer` 注册表
  • 格式：对象列表，包含以下字段：
    • `block_state_provider` - 方块状态提供器，用于提供转换后方块的状态
      • 如果方块状态提供器返回无结果（例如 `rule_based_state_provider`），将尝试列表中的下一个规则
      • 方块状态提供器集合与世界生成中使用的方块状态提供器相同
    • `sound` - 可选字段，交互时播放的声音事件，例如 `minecraft:item.axe.strip`
      • 如果不存在，默认为不播放声音事件
    • `particle` - 可选字段，交互时播放的粒子
      • 如果不存在，默认为 `none`
        • `none`
        • `scrape`
        • `wax_on`
        • `wax_off`
    • `disallowed_faces` - 可选字段，Direction 列表，指定被点击方块上不能交互的面
      • 如果交互了禁止的面，将尝试列表中的下一个规则
      • 如果不存在，默认为空列表
      • 值：
        • `up`
        • `down`
        • `north`
        • `south`
        • `east`
        • `west`
    • `loot` - 可选战利品表，用于在成功转换时掉落物品，例如 `minecraft:till/rooted_dirt`
      • 如果不存在，默认为不使用战利品表
    • `drop_strategy` - 可选字段，配置任何战利品应从方块中的哪个位置掉落
      • 如果不存在，默认为 `from_middle`
      • 值：
        • `from_middle` - 从方块中部
        • `clicked_face` - 从交互的面
    • `update_from_neighbors` - 可选布尔值，转换后的方块是否应根据相邻方块更新。例如，这允许栅栏连接
      • 如果不存在，默认为 true
    • `transform_type` - 可选字段，配置附近方块应如何受转换影响
      • 如果不存在，默认为 `single_block`
      • 值：
        • `single_block` - 仅影响被交互的方块
        • `copper_chest` - 如果输入和输出方块都是任何风化状态、涂蜡或未涂蜡的铜箱子，则此转换将影响双箱子的两侧
    • `consume_on_use` - 可选布尔值，决定物品是否应被消耗
      • 仅适用于可堆叠物品
      • 如果不存在，默认为 `true`
    • `item_damage_per_use` - 可选整数，决定每次使用物品受到的伤害
      • 仅适用于不可堆叠物品
      • 如果不存在，默认为 `0`
  • 原版中的默认值：
    • `minecraft:shovel` - 锹的默认值
    • `minecraft:axe` - 斧的默认值
    • `minecraft:hoe` - 锄的默认值

世界生成

噪声设置

  • 将 `preliminary_surface_level` 重命名为 `chunk_surface_level`
    • 此密度函数不再隐式地在整个区块中插值
  • `ore_veins_enabled` 字段已移除，并替换为 `minecraft:ore_vein` 材质规则
  • 移除了 `noise.size_horizontal` 和 `noise.size_vertical` 字段，这些现在在 `interpolated` 密度函数中指定
  • 添加了可选的 `debug_functions` 字段 - 对象列表，包含字段，要在 `chunk_generation_stats` 调试条目中显示的密度函数值
    • 字段：
      • `label` - 字符串，用于识别此密度函数的标签
      • `function` - 密度函数，要计算并显示在玩家位置处的密度函数
    • 如果未指定，则不显示密度函数值

材质规则

添加 `minecraft:ore_vein`

  • 格式：对象，包含字段：
    • `ore_block` - 方块状态，要放置的矿石方块
    • `raw_ore_block` - 方块状态，要放置的粗矿石方块
    • `filler_block` - 方块状态，要放置的填充方块
    • `raw_ore_chance` - 0 到 1 之间的浮点数，放置 `raw_ore_block` 而非 `ore_block` 的概率
    • `density` - 密度函数，0 到 1 之间的概率，矿脉替换方块
      • 如果为 `0` 或更低，则不会替换任何方块
    • `richness` - 密度函数，0 到 1 之间的概率，放置 `ore_block` 或 `raw_ore_block`（相对于 `filler_block`）
      • 如果为 `0` 或更低，则所有方块都是 `filler_block`
      • 如果为 `1` 或更高，则没有方块是 `filler_block`
    • `filler_gap` - 密度函数，作为 `richness` 的覆盖：如果为正，则始终放置 `filler_block`

更改 `minecraft:noise`

引入了以下字段：

  • `shift_x` - 可选密度函数，应用于 x 的域扭曲
    • 如果未指定，则不应用扭曲（相当于 `0`）
  • `shift_y` - 可选密度函数，应用于 y 的域扭曲
    • 如果未指定，则不应用扭曲（相当于 `0`）
  • `shift_z` - 可选密度函数，应用于 z 的域扭曲
    • 如果未指定，则不应用扭曲（相当于 `0`）

移除 `minecraft:shifted_noise`

  • 由 `minecraft:noise` 替代

更新 `minecraft:interpolated`

添加了字段：

  • `cell_size_xz` - 正整数，XZ 轴上插值网格单元的大小（以方块为单位）
  • `cell_size_y` - 正整数，Y 轴上插值网格单元的大小（以方块为单位）

更新 `minecraft:cache`（从 `minecraft:cache_once` 重命名）

  • 格式没有更改

移除 `minecraft:cache_2d`、`minecraft:cache_all_in_cell` 和 `minecraft:flat_cache`

  • 可以用 `minecraft:cache` 替代
  • `minecraft:slice` 可以用来始终选择 Y=0，正如以前由 `minecraft:flat_cache` 处理的那样
