更改

  • 所有“Pottery Shards”已更名为“Pottery Sherds”
  • 如果振动被安排由幽匿感测体或幽匿尖啸体接收，那么它们将保持排队状态，直到所有相邻区块都已加载并开始 tick
    • 防止振动共振装置在从远处卸载其区块时失效
  • 游戏的应用程序图标已更新
    • 在正式版中它将是一个草方块，在快照版中则是一个泥土块
  • 添加了对 Windows 上 ARM64 机器架构的原生支持
    • 要试用此功能，你需要手动在启动器中指定一个原生 Java 可执行文件

嗅探兽

  • 嗅探兽现在可以被火把花种子吸引

古迹废墟

  • 根据社区反馈重制了结构
  • 添加了更多结构变体
  • 沙子不再生成于结构内部
  • 调整了沙砾和泥土的数量
  • 调整了可疑的沙砾的数量
  • 拆分了结构中可疑的沙砾的战利品表。现在有专门的战利品表用于稀有战利品物品（如陶罐碎片、锻造模板），以及专门的战利品表用于更常见的战利品掉落物（如染色玻璃板、工具、蜡烛等）
  • 由于这些更改，你可能会在旧的快照世界中看到类似 Failed to get element ResourceKey[minecraft:worldgen/processor_list / minecraft:trail_ruins_suspicious_sand] 的错误。这些错误是无害的，但之前未被完全加载的现有古迹废墟结构可能会缺少部分结构

技术性更改

  • 数据包版本现在为 14，以处理物品显示方向的变化
  • 添加了 return 命令
  • 添加了 recipe_crafted 进度触发器

命令

return

return 命令可用于控制函数内的执行流程并更改其返回值。效果：

  • 当前执行函数中剩余的其他顶层命令（如果有）将被跳过
  • 触发该函数的 function 命令的结果值将从已执行命令的数量更改为 value
  • return 命令的结果值也是 value

语法：

return <value>

参数：

  • value：一个整数返回值

进度

新触发器

recipe_crafted

  • 在合成配方时触发
  • 条件：
    • recipe_id - 所制作配方的资源位置
    • ingredients - 一个用于配方中物品堆叠的谓词数组
      • 单个物品堆叠只能用于满足一个谓词
      • 每个谓词都需要被满足才能触发进度。这允许区分具有相同标识符但使用不同配料的配方
      • 此字段是可选的。当未提供或留空时，只有 recipe_id 会决定触发的成功与否

标签

  • 添加了 villager_plantable_seeds 来表示村民能够种植哪些种类的种子
  • 添加了 maintains_farmland 来表示哪些方块放置在其上时不会导致耕地变成泥土
