各位 Minecraft 玩家大家好！今天我们为大家带来了一个包含技术性更改和错误修复的快照。

技术性更改

  • 数据包版本现已更新至 38
  • 游戏现在需要 Java 21 才能运行
  • 游戏现在需要 64 位操作系统
  • 附带的 Java 发行版现已改为 Microsoft 构建的 OpenJDK 21.0.2

数据包版本 38

  • 为 set_attributes 战利品函数新增了 replace 字段（默认值：true）
    • 当设为 false 时，属性将被追加
  • 书本组件中可筛选条目内的 text 字段已重命名为 raw，以避免歧义
  • profile 组件以及玩家头颅物品和方块上的相关字段现在支持通过 UUID 解析
    • 通过仅指定 id 字段而不提供 name，系统将查找对应的 name 和纹理
