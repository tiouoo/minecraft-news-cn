用这个全新的 Minecraft Java 版 1.16 第五个预发布版来度过你的周末吧——它新增了一项检查，当你的系统显卡设置过高时会发出警告，同时还修复了大量漏洞。

1.16 预发布版 5 中的更改

  • 为已知在使用“极佳”图形时会出现渲染问题的显卡驱动添加了 GPU 警告列表
  • 如果检测到你的 GPU 驱动存在问题，将会显示一条警告消息，其中包含检测到的问题详情
  • 可以忽略此警告消息，但对于使用警告列表中的显卡驱动运行“极佳”图形的情况，我们无法提供支持

1.16 预发布版 5 中修复的漏洞

  • MC-141934 使用 Ctrl + 选取方块键获取讲台时，虽然书已保存到 NBT，但不会显示其书
  • MC-148955 铁傀儡可以在非完整方块内部生成
  • MC-149308 抛出的物品会在一帧内出现在眼前正前方

  • MC-166413 物品展示框在放置时会瞬间变黑
  • MC-166718 生物不再会在灵魂沙、耕地或草径内窒息
  • MC-167359 物品被破坏后会在短时间内变亮
  • MC-167362 物品展示框在放置后会在短时间内变亮
  • MC-177361 村民/流浪商人不会逃离僵尸疣猪兽
  • MC-180867 使用带有 NBT+ 的选取方块功能获取的唱片机，右键点击时不会弹出唱片
  • MC-181605 副手持有物品时右键点击重生锚会使用该物品
  • MC-182119 游戏模式描述文字不再居中，且在部分语言中会超出屏幕范围
  • MC-183469 生物不会绕过洞穴或熔岩寻路
  • MC-185777 在锻造台中按住 Shift 点击下界合金锭会将锭移动到装备栏
  • MC-186206 水在玻璃顶部和侧面后方渲染的色调不同
  • MC-188468 从 1.16 预发布版 2 升级到 3 时，“与副手交换物品”的用户控制设置会被重置
  • MC-188489 “与副手交换物品”的键盘快捷键在创造模式物品栏的搜索物品选项卡中仍然有效，并会覆盖文本输入
  • MC-188505 潜行时攻击实体，会短暂取消潜行，然后导致客户端和服务器关于玩家高度的不同步
  • MC-188509 僵尸猪灵在敌对状态下死亡时掉落经验值，但不掉落金锭
  • MC-188542 自定义世界生成设置导致 Minecraft 在导入时崩溃

  • MC-188655 在创造模式搜索物品时，数字键会覆盖搜索栏中的输入，导致意外切换快捷栏物品
  • MC-188675 床的头部、高花和门的底部会掉落两个物品
  • MC-188678 给牛/哞菇挤奶或获取蘑菇煲时，会消耗物品却不返还任何东西
  • MC-188691 不再能使用火焰弹在黑曜石侧面点燃下界传送门
