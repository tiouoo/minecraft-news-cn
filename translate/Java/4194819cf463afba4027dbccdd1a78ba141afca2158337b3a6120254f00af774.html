我们带着 26.2 的第三个快照回来了，今天为大家带来了可供测试的硫磺尖刺！这些尖锐的方块会在硫磺洞穴中自然生成，为你的建筑增添一抹色彩缤纷的尖刺点缀！但要小心——坠落的硫磺尖刺可是会造成刺伤的！

挖矿愉快！

新特性

硫磺尖刺

  • 是一种新方块，会自然生成于硫磺洞穴生物群系中的硫磺块上
  • 放在顶部会形成钟乳石，放在地面会形成石笋
  • 可以组合成更长的钟乳石和石笋
  • 钟乳石和石笋的尖端相互紧邻时会合并，除非你在放置时按住 Shift
  • 石笋下方如果没有依附物就会碎裂
  • 钟乳石上方如果没有依附物就会坠落
  • 被坠落的钟乳石击中会很疼，而且它们可是很锋利的！
  • 投掷的三叉戟会破坏硫磺尖刺

谓词

实体谓词

实体谓词格式已从包含多个可选字段的结构，改为与数据组件映射类似的结构。

例如，此前 effects 是一个可选字段：

{
    "effects": {...}
}

在此版本中，它变成了一个类似组件的子谓词条目：

{
    "minecraft:effects": {...}
}

主要的功能性改动如下：

  • 实体谓词中的所有键现在均为标识符
    • 由于标识符可以省略命名空间（默认为 minecraft 命名空间），现有字段名称仍然有效
    • 例外：字段 type 已重命名为 minecraft:entity_type
  • 无法识别的子谓词组件现在会被拒绝（此前未识别的字段会被忽略）

现有的特定类型子谓词已重命名并移至顶层。

  • minecraft:lightning 改为 minecraft:type_specific/lightning
  • minecraft:fishing_hook 改为 minecraft:type_specific/fishing_hook
  • minecraft:player 改为 minecraft:type_specific/player
  • minecraft:raider 改为 minecraft:type_specific/raider
  • minecraft:sheep 改为 minecraft:type_specific/sheep
  • minecraft:slime 改为 minecraft:cube_mob，因为它现在除了史莱姆和岩浆怪之外还会包含硫磺怪

例如：

{
  "type_specific": {
    "type": "minecraft:player",
    "looking_at": {
      "type": "minecraft:ender_dragon"
    }
  }
}

变为

{
  "minecraft:type_specific/player": {
    "looking_at": {
      "minecraft:type": "minecraft:ender_dragon"
    }
  }
}

新增了 minecraft:entity_tags 实体子谓词

此谓词用于匹配实体标签（即通过 /tag 命令设置的标签）。

字段：

  • any_of - 可选的字符串列表，若存在，则匹配的实体必须至少拥有所列标签中的一项
  • all_of - 可选的字符串列表，若存在，则匹配的实体必须拥有所有列出的标签
  • none_of - 可选的字符串列表，若存在，则匹配的实体必须不拥有任何列出的标签
