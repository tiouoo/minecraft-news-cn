本周三，全新快照将进入领域！没错，在 26.3 快照 8 中，领域所有者现在可以创建并管理邀请码，加入其中将比以往更加轻松。

在这些新增内容之外，我们还对世界选项界面进行了进一步改进，并包含了一些游戏性修复和技术更新。

挖矿愉快！

新内容

探险者地图

  • 以下地图已重命名：
    • 埋藏的远古城市地图
    • 埋藏的废弃矿井地图
    • 废弃营地地图

领域

  • 领域所有者现在可以创建并管理邀请码
    • 每个领域最多可拥有五个邀请码
    • 邀请码可以配置为启用 / 停用，并可删除
    • 邀请码的过期时间也可以配置
  • 玩家现在可以通过在新“加入领域”界面中输入邀请码来轻松加入领域

更改

  • 坐垫现在只会在完全被会造成窒息的方块覆盖时被破坏
  • 村民提升职业等级所解锁的新交易，现在即使玩家正在与其交易也会更新

用户界面

世界选项

  • 世界选项界面已进行了一些进一步改进，现在可从暂停菜单进入
    • “游戏模式”按钮已重命名为“默认游戏模式”
    • “常规”板块新增了一项：
      • 个人游戏模式：你在当前世界中的活动游戏模式（相当于 /gamemode 命令，或 F3+F4）
    • “多人游戏”板块新增了一项：
      • 强制游戏模式：控制其他玩家的游戏模式是否会被强制与世界的默认游戏模式一致

技术性更改

  • 数据包版本现已为 116.0
  • 资源包版本现已为 96.0

数据包版本 116.0

世界生成

地物

  • 已移除的地物类型：
    • minecraft:desert_well

更改了 minecraft:template

  • 新增字段 processors：命名空间 ID 或结构处理器列表的内联定义，用于应用到模板上

放置修饰器

新增 minecraft:randomly_selected

从列表中随机选择一个放置修饰器，并将放置操作委托给它。

格式：

  • placements：非空的放置修饰器列表，用于从中选择

方块谓词

新增 minecraft:volume_match

检查体积中的每个方块是否都匹配给定的方块谓词。

格式：

  • min：范围在 -16 到 16 之间的 3 个整数列表，指定体积的下角，作为相对于测试位置的偏移
  • max：范围在 -16 到 16 之间的 3 个整数列表，指定体积的上角，作为相对于测试位置的偏移
  • match：用于在每个位置进行测试的方块谓词

资源包版本 96

着色器 & 后处理效果

移除的核心着色器

  • 已移除 core/text_background.fsh 和 core/text_background.vsh，文本显示实体中的文本背景现在使用文本着色器进行渲染

与顺序无关透明度 (OIT) 相关的着色器更改

  • 已移除 OIT_FORCE_ZERO_DEPTH 着色器定义，因为它用于的透视文本现在会在 OIT 之外的独立渲染通道中渲染
