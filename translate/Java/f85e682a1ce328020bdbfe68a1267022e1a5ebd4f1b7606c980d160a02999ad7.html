随着万圣节季的结束，我们带着快照 24w45a 的发布进入了十一月。这次更新包含大量错误修复、对生物与地面可装备物品互动方式的更改、通过添加更多功能对物品模型进行改进等等。对于资源包来说，这是一次重磅更新！尽情享受吧！

更改

  • 幼年猫和幼年狼现在会获得一个项圈，其颜色会尽可能混合自父母项圈的颜色
  • 将迷之炖菜的效果持续时间与基岩版对齐：
    • 饱和：0.35秒（未更改）
    • 夜视：5秒（未更改）
    • 抗火：3秒
    • 失明：11秒
    • 虚弱：7秒
    • 再生：7秒
    • 跳跃提升：5秒
    • 凋零：7秒
    • 中毒：11秒

开发者注：耶！现在它们全都是质数了！（其实不是）

生物拾取物品

我们对生物决定如何用地面上的物品替换已装备物品的方式做了一些更改。

  • 如果该物品属于盔甲槽位，满足以下任一条件时替换原物品：
    • 新物品具有更高的基础护甲值
    • 新物品具有更高的基础护甲韧性值
    • 新物品拥有更多附魔
    • 新物品耐久损耗更少
    • 新物品拥有自定义名称，而旧物品没有
  • 如果该物品属于主手槽位，满足以下任一条件时替换原物品：
    • 新物品是首选武器，而旧物品不是
      • 如果旧物品是首选武器而新物品不是，则不替换物品
    • 新物品具有更高的基础伤害值
    • 新物品拥有更多附魔
    • 新物品耐久损耗更少
    • 新物品拥有自定义名称，而旧物品没有

数据包版本 59

  • minecraft:equippable 组件中的 model 字段已重命名为 asset_id
  • trim_material 注册表中的 item_model_index 字段已被移除（模型渲染不再需要）
  • minecraft:custom_model_data 组件以及 minecraft:set_custom_model_data 修改器已得到扩展

  • 移除了 #tall_flowers

组件

minecraft:custom_model_data

  • 该组件现在有更多字段，以适应各种模型属性获取器的新用途
  • 字段：
    • floats - 浮点数列表
    • flags - 布尔值列表
    • strings - 字符串列表
    • colors - RGB 颜色值列表

物品修改器

minecraft:set_custom_model_data

  • 该组件现在有更多字段，以适应更复杂的组件结构
  • 字段：
    • floats - 数字提供者的可选列表操作
    • flags - 布尔值的可选列表操作
    • strings - 字符串值的可选列表操作
    • colors - RGB 值或数字提供者的可选列表操作
  • 列表操作使用与 set_fireworks 修改器中 explosions 字段相同的格式
  • 例如，{function:"set_custom_model_data",floats:{values:[2],mode:replace_all}} 会用值 2 替换 floats

资源包版本 44

  • 物品展示框中的无效 minecaft:filled_map 物品（没有 map_id 组件的物品）不再改变展示框的大小
  • 用于数据驱动物品模型的新格式

重命名

  • equipment 目录已上移一级，即 models/equipment/ 变为 equipment/
  • broken_elytra 模型和纹理已重命名为 elytra_broken

物品模型

  • 引入了用于描述物品模型的新格式
  • 物品模型根据 minecraft:item_model 组件进行选择
    • 具有 item_model=foo:bar 的物品模型存储在 /assets/foo/items/bar.json 中
  • 文件格式为 { "model": {"type": <item model type>, <item model type specific fields> } }（具体类型见下文）
  • overrides 部分已从现有的方块模型中移除
  • models 目录中不再有硬编码路径——模型现在仅在 items 或 blockstates 目录中的定义引用时才会被使用
  • 仅重定向到方块模型的 models/item 中的模型已被移除
    • 在这种情况下，物品模型将直接引用 models/block 模型

minecraft:model 物品模型类型

  • 渲染来自 models 目录的普通模型
  • 字段：
    • model：models 中模型的命名空间 ID（如 minecraft:block/yellow_glazed_terracotta）
    • tints：应用于渲染模型元素的着色源列表（第一个条目应用于 tintindex 0，第二个应用于 1，依此类推）
      • 格式：
        • type：着色源类型（见下文）
        • <type-specific> - 取决于着色源类型的附加字段

minecraft:constant 着色源类型

  • 返回一个固定的 RGB 颜色
  • 字段：
    • value - 一个打包的整数 RGB 值（例如 -1）或 RGB 值数组（例如 [ 1, 1, 1 ]）

minecraft:dye 着色源类型

  • 返回 minecraft:dyed_color 组件中的值，如果不存在则返回默认值
  • 字段：
    • default - RGB 值

minecraft:grass 着色源类型

  • 基于 textures/colormap/grass.png，在特定气候参数下返回草的颜色
  • 与生物群系配置中由 downfall 和 temperature 选择的颜色相同
  • 字段：
    • temperature - 0..1（含）范围内的浮点数
    • downfall - 0..1（含）范围内的浮点数

minecraft:firework 着色源类型

  • 返回 minecraft:firework_explosion 组件中颜色的平均值，如果没有颜色则返回默认颜色
  • 字段：
    • default：RGB 值

minecraft:potion 着色源类型

  • 返回 minecraft:potion_contents 组件中的颜色：
    • 如果组件存在：
      • 如果组件中存在自定义颜色，则使用自定义颜色
      • 如果效果列表为空，则使用默认颜色
      • 否则使用效果颜色的平均值
    • 否则使用默认颜色
  • 字段：
    • default：RGB 值

minecraft:map_color 着色源类型

  • 返回 minecraft:map_color 组件中的值，如果组件不存在则返回默认颜色
  • 字段：

minecraft:custom_model_data 着色源类型

  • 字段：
    • index - colors 中字段的索引，默认值：0

minecraft:special 物品模型类型

  • 渲染特殊（非数据驱动）模型

    • model：特殊模型实例
      • 格式：
        • type - 特殊模型的类型（见下文）
        • <type-specific> - 取决于特殊模型类型的附加字段
    • base：models 中模型的命名空间 ID，提供变换、粒子纹理和 GUI 光照

minecraft:bed 特殊模型类型

minecraft:conduit 特殊模型类型

minecraft:chest 特殊模型类型

minecraft:head 特殊模型类型

minecraft:shulker_box 特殊模型类型

minecraft:shield 特殊模型类型

minecraft:condition 物品模型类型

minecraft:using_item 布尔属性

minecraft:xmas 布尔属性

minecraft:shift_down 布尔属性

minecraft:custom_model_data 布尔属性

  • 字段：
    • index - flags 中字段的索引，默认值：0

minecraft:select 物品模型类型

  • 根据离散属性渲染物品模型
  • 字段：
    • property：属性类型（见下文）
    • <property-specific> - 取决于属性类型的附加字段，以内联方式添加
    • cases - 要匹配的用例列表，格式如下：
      • when - 用于匹配属性的值，类型取决于属性
        • 可以是单个值或值列表
      • model - 选中该用例时要渲染的物品模型
    • fallback - 如果没有用例匹配该值时要渲染的物品模型
      • 如果未提供，则会渲染占位符“missing”模型

minecraft:main_hand 属性

minecraft:charge_type 属性

minecraft:trim_material 属性

minecraft:custom_model_data 属性

minecraft:range_dispatch 物品模型类型

  • 根据数值属性渲染物品模型
  • 取代方块模型中旧版的 overrides 部分
  • 将选择最后一个阈值小于或等于属性值的条目
  • 字段：
    • property：属性类型（见下文）
    • <property-specific> - 取决于属性类型的附加字段
    • scale - 用于乘以属性值的因子，默认值：1.0
    • entries - 条目列表，格式如下：
      • threshold - 浮点数值
      • model - 选中该条目时要渲染的物品模型
      • 注意：字段顺序无关紧要，列表在使用前将按阈值升序排序
    • fallback - 如果没有条目小于或等于属性值时要渲染的物品模型
      • 如果未提供，则会渲染占位符“missing”模型

minecraft:custom_model_data 数值属性

  • 返回 minecraft:custom_model_data 组件中 floats 列表的值
  • 字段：
    • index - floats 中字段的索引，默认值：0

minecraft:bundle/fullness 数值属性

  • 返回 bundle_contents 组件的重量，如果不存在则返回 0
  • 无字段

minecraft:damage 数值属性

  • 返回 damage 组件的值
  • 字段：
    • normalize：布尔值，默认值：true
      • 如果为 true，返回伤害值除以 max_damage 组件的值，并限制在 0..1 范围内
      • 如果为 false，返回伤害值，并限制在 0..max_damage 范围内

minecraft:count 数值属性

  • 返回堆叠数量
  • 字段：
    • normalize：布尔值，默认值：true
      • 如果为 true，返回数量除以 max_stack_size 组件的值，并限制在 0..1 范围内
      • 如果为 false，返回数量并限制在 0..max_stack_size 范围内

minecraft:cooldown 数值属性

  • 返回物品的剩余冷却时间，按比例缩放至 0..1
  • 无字段

minecraft:time 数值属性

  • 返回一天中的时间值（用于时钟），按比例缩放至 0..1
  • 字段：
    • wobble - 如果为 true，值会在稳定前围绕目标振荡一段时间，默认值：true
    • natural_only - 如果为 true，则在 natural=false 的维度中值为随机，默认值：true

minecraft:compass 数值属性

  • 返回持有者位置与目标之间在 x-z 平面上的角度，按比例缩放至 0..1
  • 如果目标无效（不存在、在其他维度或离持有者位置太近），则将返回随机值
  • 字段：
    • target - 以下之一：
      • spawn - 指向世界出生点
      • lodestone - 指向 lodestone_tracker 组件中存储的位置
      • recovery - 指向玩家上次死亡的位置
    • wobble - 如果为 true，值会在稳定前围绕目标振荡一段时间，默认值：true

crossbow/pull 数值属性

  • 返回弩特有的使用时间
  • 无字段

use_duration 数值属性

  • 返回物品使用刻数
  • 字段：
    • remaining - 如果为 true，返回值为剩余使用刻数；如果为 false，则为已使用刻数，默认值：false

use_cycle 数值属性

  • 返回剩余使用刻数对 period 取模的值
  • 字段：
    • period - 正浮点数，默认值 1.0

minecraft:bundle/selected_item 物品模型类型
