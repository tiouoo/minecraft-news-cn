实验性功能

收纳袋

收纳袋是一种物品，可让你将不同的方块或物品堆叠在同一个物品栏格子中。不同的物品通常无法堆叠在一起，因此每个格子里只放几个物品会浪费空间。收纳袋可以让你将这些物品打包在一起，从而不浪费空间。

  • 收纳袋是一项实验性功能——要使用它们，你必须在创建新世界时开启“收纳袋”实验选项

    • 请注意：收纳袋仍在预览版和测试版中进行打磨，包含 Bug 修复和调整，因此你可能会在此实验性版本中看到一些细微差异！

  • 收纳袋是一种可以将不同物品打包到同一堆叠中的物品

  • 收纳袋只能容纳一组堆叠（通常为 64 个物品），但可以是多种不同物品类型的混合

  • 你可以直接在物品栏中将物品放入收纳袋

  • 收纳袋有一个提示框，显示其中的物品

    • 提示框可容纳 3 行，并且始终至少显示 8 种物品类型

  • 你可以选择任意可见物品将其从收纳袋中取出

    • 使用鼠标滚轮、游戏控制器右摇杆，或在触控设备上点按

  • 选择要取出的物品时，收纳袋图标会显示该物品从收纳袋中伸出的样子

  • 手持收纳袋时，你可以将其内容物倒在地上

    • 在最新的 Beta 和预览版中，当在快捷栏中使用收纳袋时，会一次倒空一组物品，而不是一次性全部倒空

  • 收纳袋的合成配方为上方一根线、下方一块皮革

  • 现在获得皮革或线即可解锁收纳袋配方

  • 已知问题：

    • 在触控设备上移动物品时，错误的物品图标可能会短暂显示
    • 放入饰纹陶罐、交给悦灵，或通过漏斗和投掷器移动的收纳袋可能会丢失其内容物

稀有度

  • 多种物品和方块被指定的稀有度已更改（MCPE-182414）
    • 一旦这些稀有度变更在未来快照中应用于 Java 版，所有物品和方块的稀有度将在两个平台上保持一致
  • 稀有度是一组类别，用于确定物品或方块名称显示时使用的颜色
    • 它对游戏玩法没有影响，但用于表明获取某物的难度
    • 默认情况下，除非另有说明，所有物品和方块均为常见稀有度，其名称显示为白色
  • 我们重新评估了游戏中所有物品和方块的稀有度，以更准确地反映获取它们的当前难度，依据以下准则：
    • 物品和方块会根据以下因素变得更加稀有：
      • 在战利品表中找到它的概率，包括生物掉落物
      • 获取它所需的旅行距离
      • 获取它时必须克服的障碍的难度
      • 该物品或方块在世界中可能存在数量
    • 任何可以合成的物品或方块必须继承其合成原料中最高的稀有度
      • 例如，重锤具有史诗稀有度，因为它的原料之一（重核）具有史诗稀有度
      • 同理，任何仅使用常见原料合成的物品也必须是常见稀有度

    • 它只有一个字段“value”，接受以下值：
      • “common”
      • “uncommon”
      • “rare”
      • “epic”
    • 也可以写成内联值，例如：“minecraft:rarity”: “uncommon”
    • 物品的稀有度将决定其名称使用的颜色
      • 如果物品指定了“minecraft:hover_text_color”组件，则该悬停文本颜色将优先于稀有度颜色使用

  • 新增了“minecraft:storage_item”物品组件，允许物品存储与其关联的动态容器数据
    • 此组件需要启用“收纳袋”开关
    • 动态容器是与物品而非方块或实体关联的用于存储物品的容器
    • 要使用此组件，物品必须将“minecraft:max_stack_size”设置为 1
    • “max_slots”字段（1 到 64）定义动态容器的槽位数
    • “max_weight_limit”字段定义动态容器所有槽位中物品重量的最大允许总和
      • 可堆叠至 64 的物品每个重量为 1，可堆叠至 16 的物品每个重量为 4，不可堆叠的物品重量为 64
    • “allow_nested_storage_items”字段允许将其他带有“minecraft:storage_item”组件的物品放入其中
    • “weight_in_storage_item”（0 到 64）定义物品在另一个存储物品内部时增加的额外重量
      • 值为 0 表示此物品不允许放入另一个存储物品内部
    • “banned_items”字段定义不允许放入物品动态容器中的物品
    • “allowed_items”字段定义仅允许放入物品动态容器中的物品
      • 如果为空，则所有物品都允许放入物品的动态容器中
  • 新增了“minecraft:bundle_interaction”物品组件，以启用收纳袋专属的交互方案和提示框
    • 此组件需要启用“收纳袋”开关
    • 要使用此组件，物品必须定义“minecraft:storage_item”组件
    • “minecraft:bundle_interaction”组件与“minecraft:storage_item”组件创建的容器交互
    • “num_viewable_slots”字段（1 到 64）定义可从收纳袋顶部访问的最大物品堆叠数，其他槽位将被隐藏
