干恶魂

  • 可在下界的下界化石结构中找到。
  • 可以使用1个骨块和8个恶魂之泪合成。
  • 当它处于含水状态时，会在大约20分钟内经历3个阶段，直到生成一个恶魂宝宝生物。
  • 根据状态发出声音并显示粒子效果。
  • 如果在含水状态下被挖掘，无论其已达到哪个阶段，都会恢复到“干燥”状态。
  • 当它脱离含水状态时，会以相同的时间比例恢复到最初的“干燥”状态。

生物

恶魂宝宝

恶魂宝宝是快乐恶魂生物的幼年版本。

  • 从连续含水约20分钟的干恶魂方块中生成。
  • 生成后，恶魂宝宝会尝试跟随：
  1. 16格半径内的玩家 或
  2. 16格半径内的成年非水生被动型生物（以及部分中立生物）
    如果周围没有玩家或合适的生物，恶魂宝宝会在其家园位置（即生成位置或最后一次互动的位置）32格范围内闲逛。
  • 可以使用雪球引诱和喂食。
  • 大约20分钟后会成长为快乐恶魂（如果喂食雪球则更快）。
  • 可以使用命令召唤：/summon happy_ghast ~ ~ ~ ~ ~ minecraft:spawn_baby

快乐恶魂

快乐恶魂是一种新的飞行坐骑，最多可以搭载四名玩家。

  • 大约20分钟后由恶魂宝宝成长而来（如果给恶魂宝宝喂食雪球则更快）。
  • 可以装备鞍具，然后最多可被4名玩家骑乘。
  • 会被雪球和鞍具吸引。只有未装备鞍具的快乐恶魂才会被鞍具吸引。
  • 受到伤害时没有恐慌行为。
  • 不能繁殖。
  • 缓慢恢复生命值，在雨天、雪天或在与云层渲染高度相同的飞行时，恢复速度会加快。
  • 第一个骑乘快乐恶魂的玩家将控制它，坐在快乐恶魂前方，恰好在其面部上方。
  • 当玩家骑乘时，快乐恶魂上的护目镜会降下遮住眼睛，表示现在可以控制它。
  • 在驾驶员骑乘后，其他骑乘的玩家会被分配到快乐恶魂两侧的座位，从“驾驶员”玩家开始按顺时针方向排列。
  • 按下潜行按钮会使快乐恶魂顶部的玩家下坐骑。
  • 如果快乐恶魂检测到顶部有玩家，它会停止所有移动并对齐到最近的基本水平方向。
  • 无论是否装备鞍具，都会发生这种情况。
  • 当玩家骑乘快乐恶魂时，第三人称摄像机向后移动。
  • 当没有玩家骑乘或在快乐恶魂上行走时，护目镜会升起，快乐恶魂开始在家园位置周围游荡。
  • 如果玩家在半空中下坐骑，快乐恶魂会先向地面下降，然后继续游荡。
  • 不能进入船。
  • 会在离家园位置（生成位置或最后一次互动的位置）64格范围内闲逛。
  • 如果装备了鞍具，快乐恶魂会靠近家园位置（32格范围内）闲逛。
  • 快乐恶魂在自己游荡时会尝试靠近方块。
  • 已知问题：快乐恶魂的生命值当前为40，但应为20。我们将尽快解决这个问题！

鲜艳视效

这些特性、光照、效果和资源仍在开发中，因此随着我们不断迭代，内容可能会发生变化和改进。

支持的设备包括 Xbox Series X|S、Xbox One、PlayStation 4、PlayStation 5、Android、iOS 和 PC。

  • Android：Adreno 640、Mali-G68、Mali-G77 或 Xclipse 530 及更高版本
  • iOS：A12 或 M1 及更高版本
  • PC：在 DX12 上运行 Minecraft

我们的团队正努力在更多 Minecraft：基岩版设备上测试鲜艳视效，并希望未来能够更新此支持设备列表。

要在世界中使用鲜艳视效，你必须在“创建新世界”或“编辑世界”界面的“实验性”选项卡中启用“鲜艳视效”开关。这将使鲜艳视效作为游戏内视频设置的图形模式下拉菜单中的一个选项显示，可以与其他现有渲染模式一同选择。

视频设置中提供了“优先视觉效果”和“优先性能”之间的预设。还可以通过展开“鲜艳视效选项”来调整特定功能和视觉设置。

鲜艳视效不支持分屏游戏。如果本地有多名玩家加入，游戏将切换到高级或简单渲染。

市场附加包、皮肤和角色物品将与鲜艳视效兼容，但世界和纹理包目前尚不兼容新模式。

定位器栏

  • 定位器栏是玩家 HUD 上的一个新 UI 元素，用于显示世界中其他玩家的方向。

  • 当定位器栏实验性功能启用且世界中有多名玩家时，定位器栏将显示在每名玩家的屏幕上，取代经验条。玩家等级数字仍将像以前一样显示在定位器栏上方。

  • 当摄像机朝向另一名玩家的120度范围内时，定位器栏将显示彩色指示器。如果另一名玩家位于摄像机视口（屏幕）上方或下方30度处，将显示向上或向下的箭头。

  • 潜行会隐藏玩家，防止其指示器出现在其他玩家的定位器栏上。

  • 旁观模式下的玩家在定位器栏上不可见。

  • 在头部槽位佩戴生物头颅或雕刻南瓜时，同样会将玩家从定位器栏上隐藏。

  • 使用隐身药水也会将玩家从定位器栏上隐藏。

开发者注：当定位器栏退出实验性阶段后，我们计划将其变为玩家可以开关的功能。

  • 定位器栏上的玩家圆点现在无论模拟距离如何都能正确显示。

  • 现在，定位器栏上会向同样处于旁观模式的玩家显示代表旁观模式玩家的圆点。

已知问题

  • 定位器栏存在以下已知问题，因此我们建议使用4个区块的模拟距离进行测试。
    • 如果模拟距离设置为大于4个区块，则定位器栏可能不会显示4个区块与模拟距离之间的玩家。

编辑器 v0.9.5 功能亮点

选区更新

编辑器中的选区体验已彻底改变！全新的基于控件（Widget）的系统支持点击拖拽的选框选择、撤销/重做以及更新的键盘快捷键，让编辑更快、更精确。我们还新增了两个修剪操作——修剪和移除空气——帮助你将选区精简到你需要的方块。此外，新的魔法选择模式可让你快速抓取选定点上方的非空气方块，使处理结构变得比以往更容易。试试这些工具，提升你的建造流程吧！

新教程系统

我们新增了一个可从“帮助”菜单访问的新教程流程。它旨在帮助新用户快速上手如何使用编辑器及其核心功能。

  • minecraft:behavior.float_wander 已更新，新增了以下字段：

    • navigate_around_surface：启用新算法来寻找随机移动位置。新算法旨在固体（即非空气和非液体）方块附近寻找随机位置，如果失败，则会回退到在当前维度地表高度附近寻找随机位置。
    • additional_collision_buffer：确保目标位置周围的膨胀区域内不存在方块。
    • allow_navigating_through_liquids：允许生物在液体内部拥有目标位置。
    • surface_xz_dist：水平方向上寻找附近表面的距离。仅在 navigate_around_surface 为 true 时有效。

    • preferred_actor_type：优先跟随的 actor 类型。如果未指定，将在范围内的 actor 中随机选择。
    • filters：如果非空，则提供过滤标准，决定哪些附近的生物可以被跟随。如果为空，则使用默认标准，即排除玩家、鱿鱼变种、鱼类变种、蝌蚪、海豚以及与目标所有者同类型的生物。

    • “on_end”字段指定在目标结束时触发的事件。

  • 在剔除规则模式中添加了新字段“condition”。它可以更精细地控制哪些相邻方块会触发一个面或部分被剔除。

    • 支持的值有“default”、“same_culling_layer”、“same_block”和“same_block_permutation”。
      • “default”：如果相邻方块是完整且不透明的，则通过条件。
      • 所有条件都是“default”的扩展，意味着在检查扩展的“same_*”条件之前，完整且不透明的相邻方块始终是通过条件。
      • “same_culling_layer”：如果相邻方块与被遮挡方块共享相同的“culling_layer”（在几何组件中定义），则通过条件。
      • 如果比较的两个剔除层中任一个是“minecraft:culling_layer.undefined”，则条件永远不会通过。
      • “same_block”：如果相邻方块具有相同的标识符，则通过条件。
      • “same_block_permutation”：如果相邻方块具有相同的标识符且是完全相同的排列，则通过条件。
    • 此外，该功能目前只能在“即将推出的创作者功能”开关后面使用。

  • 在方块的几何组件中添加了新字段“culling_layer”。当在剔除规则文件中使用“same_culling_layer”条件时，它允许将不同的方块分组在一起。

    • 使用 minecraft 命名空间时，唯一允许的剔除层标识符是：“minecraft:culling_layer.undefined”或“minecraft:culling_layer.leaves”。
    • 此外，该功能目前只能在“即将推出的创作者功能”开关后面使用。
