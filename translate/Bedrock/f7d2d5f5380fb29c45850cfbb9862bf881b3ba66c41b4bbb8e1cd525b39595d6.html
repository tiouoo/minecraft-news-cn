混沌立方已登陆 Minecraft！在主世界寻找色彩鲜艳的硫磺泉，以发现隐藏在地下的惊艳洞穴生物群系。敢的话，就在冒泡的硫磺池中游泳，用色彩缤纷的朱砂和硫磺建造，但最棒的是——揭开硫磺立方对方块永无止境的食欲！从弹跳、滑行到爆炸惊喜，这个难以预测的生物会根据你喂给它的东西，解锁建造、竞争和生存的全新方式。在我们最新的更新中，混沌近在咫尺。今天就来玩 Minecraft 吧！

混沌立方特性

硫磺立方桶

  • 需要一种简单方式将你的新硫磺立方朋友从硫磺洞穴带到基地吗？当然，你可以尝试用方块让硫磺立方弹跳、滑行或长距离移动——或者直接用桶把它舀起来，安全地放进物品栏。

硫磺立方

  • 硫磺立方是 Minecraft 中的新生物，有着对……方块的好奇胃口！这种好奇的生物生成于硫磺洞穴，会根据玩家喂给它的方块而变形。尝试并发现如何让硫磺立方弹跳、滑行等等！

硫磺泉

  • 在主世界各处都可以找到硫磺泉。多亏了它的硫磺和朱砂方块——以及它散发出的有毒气体——你就能认出硫磺池！但在这些方块下挖掘，你会发现一个硫磺洞穴，里面充满了可开采的新方块和可遇见的新生物！

强效硫磺

  • 新的强效硫磺方块是硫磺泉如此多泡——且有点令人恶心的原因。你也可以将强效硫磺放在水下，制造出冒着热气的气泡池！你很快会看到气泡柱，以及一团团有毒气体。建造时请小心，因为有毒气体会让玩家和附近的生物恶心！

硫磺洞穴

  • 探索这种新洞穴类型，里面有浅水池和发光地衣。硫磺洞穴中充满了黄色的硫磺方块、红色的朱砂方块、硫磺尖刺，以及一种叫作硫磺立方的好奇生物！

全新方块系列

  • 你会在硫磺洞穴中找到两种新方块系列——朱砂和硫磺！这些新方块让你能为建筑增添浓郁的红与黄，每种都有完整的方块系列。将它们制成圆石、用它们合成、变成台阶或砖块——由你选择！

硫磺尖刺

  • 硫磺尖刺生长在朱砂和硫磺方块上，赋予硫磺洞穴独特的外观。与滴水石锥不同，踩上硫磺尖刺不会造成伤害，但它们仍会掉落并伤害你——只是相当罕见。

间歇泉

  • 注意脚下，否则你会飞起来！当岩浆块生成或被放置在浸没于 1 至 4 格水下的强效硫磺方块下方时，就会形成间歇泉。利用它们获得垂直弹射，或作为戏剧性的景观元素！

特殊方块：TNT

  • 为什么会有人把 TNT 方块喂给硫磺立方？当然是为了看看会发生什么！自己试试看，点燃它，然后享受（或深深后悔）爆炸结果。

  • 引入了 NoiseDescriptor 模式定义。此模式的目的是用作表面或地下构建器模式的一部分。它具有以下字段：

    • first_octave：控制生成噪声的一般频率特性。较低的值会导致噪声中的低频分量较高（必填）
    • amplitudes：控制生成噪声中前 n 个八度音的衰减（必填）

    • threshold：与所提供方块关联的最小采样噪声值（非必填）
    • range：与所提供方块关联的采样噪声值范围（非必填）
    • block：当噪声采样满足阈值或范围条件时要放置的方块（必填）

    • noise_block_specifiers：一组 NoiseBlockSpecifier，定义哪些噪声采样范围与哪些方块关联。提供的范围在区间 [0, 1] 内有效，并且可以在端点处重叠（必填）

      • 新添加的 "note.none" 可用于指定某个面没有声音

	"minecraft:block": {
		"description": {

		},
		"components": {
			"minecraft:instrument_sound": {
				"up": "note.bit",
                		"down": "note.bell"
			}
		}
	}
}
