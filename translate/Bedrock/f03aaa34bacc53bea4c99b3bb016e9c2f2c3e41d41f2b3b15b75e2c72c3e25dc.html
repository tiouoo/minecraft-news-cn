原版同步：

生物

  • 狼现在能够承受与 Java 版相同的伤害量
    • 目前 Java 版的做法是，除玩家或箭矢外，其他实体对已驯服狼造成的伤害减半；现在改为将已驯服狼的最大生命值从 20 提高到 40
    • 已存在的驯服狼需要喂食才能达到新的最大生命值
    • 为确保治疗速率保持一致，喂食狼恢复的生命值翻倍
    • Java 版将进行调整，以匹配新的基岩版实现

实验性功能：

风弹

  • 化身旋风人！使用风弹将发射一枚类似旋风人发射的风弹投射物
  • 玩家发射的风弹比旋风人发射的风弹提供 10% 更多的击退
  • 与旋风人发射的投射物一样，玩家发射的风弹直接命中实体也会造成伤害
  • 旋风人被击杀时会掉落 4-6 个风弹
  • 风弹的最大堆叠数量为 64 个
  • 每次使用后有半秒冷却时间
  • 风弹可以从发射器发射
  • 玩家使用风弹将自己发射出去时，只有在与风爆碰撞位置下方的 Y 高度才会累积摔落伤害

沼骸

  • 一种新的骷髅变种，会射出剧毒之箭
    • 它们更容易被击败，生命值为 16 而不是 20
    • 它们的攻击间隔更慢，为 3.5 秒而不是 2 秒
  • 被玩家击杀时有机会掉落剧毒之箭
  • 这些覆盖着苔藓和蘑菇的骷髅会自然生成在沼泽和红树林沼泽中
    • 也可能在部分试炼密室中的试炼刷怪笼生成

宝库

  • 一个存放上锁宝藏和战利品的方块——找到正确的钥匙即可弹出其奖励
    • 遍布试炼密室，包含该结构最有价值的战利品
    • 试炼密室中的宝库需要试炼钥匙才能解锁
  • 可以被无限数量的玩家解锁
    • 玩家解锁过某个宝库后，就无法再次解锁该宝库
    • 如果附近有玩家尚未解锁过该宝库，就会有一道橙色粒子流从玩家流向宝库
  • 有一个钥匙孔，其开合状态取决于附近的玩家
    • 如果附近有玩家尚未解锁该宝库，钥匙孔就会打开
    • 如果附近所有玩家都已解锁该宝库，钥匙孔就会关闭
  • 在笼子内，它会循环展示可能从其战利品表中弹出的物品
  • 每次解锁时，弹出的奖励都会从其战利品表中随机决定
  • 宝库目前沿用试炼密室中奖励箱此前使用的战利品表
    • 该战利品表是临时的，随着开发推进将进行全面修订
  • 无法在生存模式中合成或获得，开采时也不会掉落任何物品
  • 抗爆炸且无法被移动

狼

  • 已驯服狼的项圈尺寸已增大，不仅从正面可见，从其他角度也能看到

  • 修复了一个可能导致加载画面在 40% 左右卡住一段时间的漏洞（MCPE-175550）
